# تمرین‌های جلسه ۶ — متدها

## کلاسی (۳۰ دقیقه)

### ۱. IsEven
متد `bool IsEven(int n)` بنویسید.

### ۲. Max دو عدد
متد `int Max(int a, int b)` **بدون** `Math.Max`.

### ۳. جدول ضرب
متد `void PrintMultiplicationTable(int n)` — جدول ۱×N تا ۱۰×N.

### ۴. Sum با params
متد `int Sum(params int[] numbers)` — جمع هر تعداد عدد.

---

## خانه (۴۵ دقیقه)

### ۵. ماشین‌حساب با متد
متدهای `Add`, `Subtract`, `Multiply`, `TryDivide` و یک متد `Calculate(x, y, op)` بنویسید.

### ۶. Swap با ref
متد `Swap(ref int a, ref int b)` — دو عدد را جابجا کنید.

### ۷. MinMax با out
متد `void MinMax(int[] arr, out int min, out int max)`.

### ۸. Overload Format
دو overload: `FormatDate(int year, int month, int day)` → `"1403/06/15"` و `FormatDate(DateTime dt)`.
