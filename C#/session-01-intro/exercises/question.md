# تمرین‌های جلسه ۱

## تمرین ۱ (ساده)

برنامه‌ای بنویسید که این خروجی را بدهد:

```text
=== کارت معرفی ===
نام: [نام شما]
شهر: [شهر شما]
==================
```

## تمرین ۲ (متوسط)

برنامه‌ای بنویسید که:

1. از کاربر نام بپرسد
2. از کاربر رشته مورد علاقه را بپرسد
3. پیام شخصی‌سازی‌شده چاپ کند

مثال:

```text
سلام علی! رشته مورد علاقه‌ات: برنامه‌نویسی
```

## تمرین ۳ (چالش)

برنامه‌ای بنویسید که سه خط ASCII Art ساده چاپ کند (مثلاً یک ستاره یا صورتک).
