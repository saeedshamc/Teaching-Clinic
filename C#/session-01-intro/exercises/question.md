# تمرین‌های جلسه ۱ (۱.۵ ساعت)

## بخش A — تمرین کلاسی (۲۰ دقیقه)

### تمرین ۱: کارت معرفی
برنامه‌ای بنویسید که خروجی زیر را بدهد (با اطلاعات خودتان):

```text
╔════════════════════╗
║   کارت معرفی       ║
╠════════════════════╣
║ نام: ...
║ شهر: ...
║ هدف: یادگیری C#
╚════════════════════╝
```

### تمرین ۲: تعامل با کاربر
- نام کاربر را بپرسید
- سن را بپرسید (فعلاً string)
- یک پیام شخصی‌سازی‌شده چاپ کنید

### تمرین ۳: ASCII Art
یک شکل ساده ۴–۵ خطی با `Console.WriteLine` بسازید.

---

## بخش B — تکلیف خانه (۳۰ دقیقه)

### تمرین ۴: مستند شخصی
فایل `NOTES.md` بسازید و پاسخ دهید:

1. C# چیست؟
2. .NET چیست؟
3. `dotnet run` چه کار می‌کند؟
4. تفاوت `Write` و `WriteLine` چیست؟

### تمرین ۵: منوی ساده
برنامه‌ای که ۳ گزینه چاپ کند:

```text
1. درباره دوره
2. تماس
0. خروج
```

(فعلاً فقط چاپ منو — در جلسه ۴ شرط اضافه می‌کنیم)
