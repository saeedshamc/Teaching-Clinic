# تمرین‌های جلسه ۳

## کلاسی (۳۰ دقیقه)
1. **زوج/فرد:** عدد از کاربر، با `%` تشخیص دهید
2. **مقایسه سه عدد:** بزرگترین را بدون `Math.Max` پیدا کنید
3. **ماشین‌حساب mini:** دو عدد + عملگر char

## خانه (۴۵ دقیقه)
4. محاسبه نمره نهایی: `final = 0.4*mid + 0.6*finalExam` + قبول/مردود
5. برنامه تخفیف پلکانی:
   - بالای 500k → 15%
   - بالای 200k → 10%
   - غیره → 0%
