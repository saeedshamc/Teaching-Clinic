# تمرین‌های جلسه ۵ — حلقه‌ها

## کلاسی (۳۰ دقیقه)

### ۱. اعداد ۱ تا ۲۰
با `for` اعداد ۱ تا ۲۰ را چاپ کنید.

### ۲. جدول ضرب
عدد N از کاربر بگیرید. جدول ضرب آن (۱×N تا ۱۰×N) را چاپ کنید.

### ۳. جمع زوج‌ها
جمع همه اعداد **زوج** بین ۱ تا ۱۰۰ را با `for` محاسبه کنید. از `continue` برای skip فردها استفاده کنید.

### ۴. مین/ماکس آرایه
آرایه `{ 45, 12, 78, 34, 91, 23 }` — بزرگترین و کوچکترین را **بدون** `Math.Max/Min` و فقط با `foreach` یا `for` پیدا کنید.

---

## خانه (۴۵ دقیقه)

### ۵. سری Fibonacci
اولین ۱۵ عدد فیبوناچی را چاپ کنید: `0, 1, 1, 2, 3, 5, 8, ...`

### ۶. تشخیص عدد اول
عدد N بگیرید. با حلقه `for` بررسی کنید اول است یا نه.

### ۷. بازی حدس عدد
برنامه عدد تصادفی ۱–۱۰۰ تولید کند. کاربر حدس بزند تا درست شود. تعداد تلاش‌ها را بشمارید. از `while` استفاده کنید.

### ۸. مثلث ستاره
با nested `for` مثلث زیر را چاپ کنید:
```
*
**
***
****
*****
```
