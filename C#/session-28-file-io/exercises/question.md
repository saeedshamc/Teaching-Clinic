# تمرین‌های جلسه ۲۸ — File I/O

## کلاسی (۳۰ دقیقه)

1. **شمارش کلمات:** فایل `input.txt` بسازید، تعداد کلمات را بشمارید.
2. **کپی:** متد `CopyFile(source, dest)` با بررسی وجود source.
3. **لیست:** همه `.txt` فایل‌های یک پوشه را لیست کنید.

## خانه (۴۵ دقیقه)

4. **Todo File:** todoها را در `todos.txt` ذخیره/بارگذاری کنید (هر خط یک todo).
5. **Backup:** پوشه `source/` را به `backup/yyyy-MM-dd/` کپی کنید.
6. **Search:** در همه فایل‌های `.cs` یک پوشه، کلمه `class` را جستجو کنید.

## نکات

- `Path.Combine` برای مسیر
- `using` برای StreamReader
- UTF-8 برای متن فارسی
- try/catch برای FileNotFoundException
