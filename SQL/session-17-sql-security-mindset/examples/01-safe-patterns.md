# الگوهای امن (آموزشی)

## غلط (مفهومی — اجرا نکنید با ورودی کاربر)
چسباندن ورودی به متن SQL باعث می‌شود داده از دستور قابل‌تفکیک نباشد.

## درست
- در اپ: prepared statement / bind پارامتر
- در PHP این ریپو: `PHP/session-16-pdo-basics`
- در SQL خام آموزشی: فقط مقادیر ثابت خودتان در اسکریپت

## چک‌لیست کوتاه
1. هیچ ورودی کاربر داخل رشتهٔ SQL خام نرود
2. خطاهای DB را به کاربر نهایی خام نشان ندهید
3. کاربر DB اپ فقط دسترسی لازم را داشته باشد
