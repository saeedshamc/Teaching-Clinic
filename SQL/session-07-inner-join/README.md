# جلسه ۰۷: INNER JOIN و کلید خارجی مفهومی (۹۰ دقیقه)

**محیط فرض:** SQLite 3

## پیش‌نیازها
جلسات ۰۳–۰۵.

## اهداف قابل‌اندازه‌گیری
1. دو جدول مرتبط با ستون کلید بسازید
2. INNER JOIN بنویسید و نتیجه را توضیح دهید
3. مفهوم کلید خارجی را بدون اجبار PRAGMA بگویید
4. alias جدول (`u`, `o`) به کار ببرید

## چرا مهم است؟
بدون join مجبور می‌شوید داده را تکراری در یک جدول نگه دارید.

## مفهوم عمیق
```sql
SELECT u.name, o.total
FROM users AS u
INNER JOIN orders AS o ON o.user_id = u.id;
```

INNER فقط سطرهایی را می‌آورد که **دو طرف** جور باشند.

## اشتباه‌های رایج
1. شرط join را در WHERE فراموش کردن و ضرب دکارتی.
2. نام ستون مبهم بدون پیشوند جدول.
3. ذخیرهٔ نام کاربر داخل orders به‌جای user_id.

## مثال گام‌به‌گام
```bash
sqlite3 clinic.db < session-07-inner-join/examples/01-inner-join.sql
```

## الگوی بهتر
کلید عددی پایدار؛ متن‌های نمایشی از جدول مرجع.

## تمرین‌ها
### آسان
نام کاربر و عنوان سفارش را join کنید.
### چالشی
فقط سفارش‌های بالای مبلغ مشخص.

## راهنمای حل
`INNER JOIN ... ON ... WHERE o.total > 100000`

## خودآزمایی
1. INNER JOIN چه سطرهایی را نگه می‌دارد؟
2. کلید خارجی مفهومی چیست؟
3. ضرب دکارتی کی رخ می‌دهد؟
4. alias برای چیست؟
5. چرا نام را در orders تکرار نکنیم؟

## جمع‌بندی و پل جلسهٔ بعد
JOIN داخلی. جلسه بعد: LEFT JOIN.
