# دوره SQL — Teaching Clinic

مسیر جلسه‌محور فارسی برای یادگیری SQL کاربردی با **SQLite 3**.

## مخاطب
مبتدیان جدی و برنامه‌نویسانی که می‌خواهند کوئری، join، تجمیع و ذهنیت امن را قبل از لایهٔ اپ (مثلاً PHP/PDO) یاد بگیرند.

## پیش‌نیاز ابزار
[SETUP.md](./SETUP.md) — نصب `sqlite3`.

فهرست جلسات: [SYLLABUS.md](./SYLLABUS.md)

## نحوه مطالعه
1. جلسات را به‌ترتیب بخوانید.
2. هر `examples/*.sql` را اجرا کنید:
   - PowerShell: `sqlite3 clinic.db ".read مسیر/فایل.sql"`
   - bash: `sqlite3 clinic.db < مسیر/فایل.sql`
3. تمرین آسان را حتماً؛ چالش را جدی بگیرید.
