# جلسه ۱۲: توابع رشته و تاریخ (۹۰ دقیقه)

**محیط فرض:** SQLite 3

## پیش‌نیازها
جلسه ۰۵.

## اهداف قابل‌اندازه‌گیری
1. `length`، `upper`/`lower`، `substr`، `replace`، `trim` را به کار ببرید
2. الحاق رشته با `||` بنویسید
3. تاریخ را با توابع SQLite مثل `date`/`datetime` بخوانید
4. بگویید نام توابع در MySQL ممکن است فرق کند ولی ایده یکی است

## چرا مهم است؟
پاکسازی و نمایش داده بدون خروج از SQL گاهی لازم است.

## مفهوم عمیق
```sql
SELECT upper(name), length(name), 'سلام ' || name AS greet
FROM users;

SELECT date('now'), datetime('now', '+1 day');
```

## اشتباه‌های رایج
1. فرض کردن توابع MySQL عیناً در SQLite.
2. مقایسه تاریخ به‌صورت متن با فرمت ناسازگار.
3. منطق پیچیدهٔ کسب‌وکار را فقط در SQL رشته‌ای پیچیده کردن.

## مثال گام‌به‌گام
```bash
sqlite3 clinic.db < session-12-string-date-functions/examples/01-functions.sql
```

## الگوی بهتر
پاکسازی سنگین در اپ؛ SQL برای فیلتر و تبدیل سبک.

## تمرین‌ها
### آسان
نام‌ها را upper کنید.
### چالشی
سطرهایی که طول name بیش از ۳ است.

## راهنمای حل
`WHERE length(name) > 3`

## خودآزمایی
1. الحاق در SQLite با چیست؟
2. `date('now')` چه می‌دهد؟
3. چرا فرمت تاریخ مهم است؟
4. `trim` چه می‌کند؟
5. آیا باید همهٔ منطق در SQL باشد؟
