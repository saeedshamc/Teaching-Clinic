# جلسه ۰۲: انواع داده و NULL (۹۰ دقیقه)

**محیط فرض:** SQLite 3

## پیش‌نیازها
جلسه ۰۱.

## اهداف قابل‌اندازه‌گیری
1. چهار نوع کاربردی SQLite را نام ببرید: TEXT، INTEGER، REAL، BLOB
2. معنای `NULL` را از رشتهٔ خالی جدا کنید
3. بگویید affinity در SQLite یعنی چه (در حد کاربردی)
4. مقایسه با `IS NULL` / `IS NOT NULL` بنویسید

## چرا مهم است؟
اشتباه نوع و `NULL` منبع باگ‌های گزارش و join است.

## مفهوم عمیق
```sql
CREATE TABLE demo (
  id INTEGER,
  title TEXT,
  price REAL,
  payload BLOB
);
```

`NULL` یعنی «مقدار نداریم» — نه صفر و نه `''`.

```sql
WHERE email IS NULL;   -- درست
-- WHERE email = NULL; -- تقریباً همیشه غلط
```

## اشتباه‌های رایج
1. `= NULL` به‌جای `IS NULL`.
2. فرض اینکه ستون بدون مقدار `''` است.
3. ذخیرهٔ عدد به‌صورت متن بدون دلیل و انتظار جمع عددی.

## مثال گام‌به‌گام
```bash
sqlite3 clinic.db < session-02-data-types-null/examples/01-types-null.sql
```

## الگوی بهتر
برای پول در یادگیری `REAL` کافی است؛ در production گاهی INTEGER (ریال/سنت) بهتر است.

## تمرین‌ها
### آسان
یک سطر با `NULL` در ستون اختیاری درج و با `IS NULL` پیدا کنید.
### چالشی
تفاوت `COUNT(*)` و `COUNT(col)` را با یک مثال نشان دهید (پیش‌نمایش جلسه ۹).

## راهنمای حل
`COUNT(col)` مقادیر NULL آن ستون را نمی‌شمارد.

## خودآزمایی
1. چهار نوع اصلی؟
2. `NULL` یعنی چه؟
3. چرا `= NULL` کار نمی‌کند؟
4. TEXT برای عدد چه مشکلی می‌سازد؟
5. BLOB چه کاربردی دارد؟

## جمع‌بندی و پل جلسهٔ بعد
انواع. جلسه بعد: `CREATE TABLE`.
