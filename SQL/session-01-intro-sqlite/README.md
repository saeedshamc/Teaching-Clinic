# جلسه ۰۱: دیتابیس رابطه‌ای و اولین sqlite3 (۹۰ دقیقه)

**محیط فرض:** SQLite 3 · `sqlite3` در PATH · جزئیات در [SETUP.md](../SETUP.md)

## پیش‌نیازها
آشنایی با ترمینال/PowerShell. دانش زبان برنامه‌نویسی لازم نیست.

## اهداف قابل‌اندازه‌گیری
1. بگویید جدول، سطر و ستون چیست
2. تفاوت فایل `.db` با «سرور دیتابیس» را توضیح دهید
3. با `sqlite3` یک فایل بسازید و یک دستور ساده اجرا کنید
4. خروجی `.tables` و `.schema` را تفسیر کنید

## چرا مهم است؟
تقریباً هر اپ دادهٔ ساخت‌یافته دارد. بدون مدل ذهنی رابطه‌ای، ORM و PDO فقط جادو به نظر می‌رسند.

## مفهوم عمیق
دیتابیس رابطه‌ای داده را در **جداول** نگه می‌دارد. هر جدول از **ستون‌ها** (قرارداد) و **سطرها** (نمونه‌ها) ساخته می‌شود.

SQLite کل دیتابیس را معمولاً در **یک فایل** می‌گذارد — برای یادگیری عالی است.

```sql
SELECT 'سلام SQL' AS message;
```

## اشتباه‌های رایج
1. فکر کردن که بدون ساخت جدول می‌توان دادهٔ پایدار ذخیره کرد.
2. قاطی کردن Excel با مدل رابطه‌ای (کلید، یکپارچگی).
3. فراموش کردن مسیر فایل `.db` و ساخت چندین کپی ناخواسته.

## مثال گام‌به‌گام
```bash
cd SQL
sqlite3 clinic.db < session-01-intro-sqlite/examples/01-hello.sql
sqlite3 clinic.db ".tables"
```

## الگوی بهتر
برای هر تمرین یک فایل DB مشخص (`clinic.db`) و اسکریپت‌های قابل‌تکرار با `DROP IF EXISTS` در جلسات بعد.

## تمرین‌ها
### آسان
دستور `SELECT 1 + 1 AS two;` را در حالت تعاملی اجرا کنید.
### چالشی
با `.help` سه دستور نقطه‌ای مفید پیدا و یادداشت کنید.

## راهنمای حل
`.headers on`، `.mode column`، `.schema` از پرکاربردترین‌ها هستند.

## خودآزمایی
1. جدول چیست؟
2. SQLite سرور جدا لازم دارد؟
3. `sqlite3 file.db` چه می‌کند؟
4. تفاوت سطر و ستون؟
5. چرا این دوره با SQLite شروع می‌شود؟

## جمع‌بندی و پل جلسهٔ بعد
ابزار را راه انداختید. جلسه بعد: انواع داده و `NULL`.
