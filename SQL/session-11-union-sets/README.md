# جلسه ۱۱: UNION و عملگرهای مجموعه (۹۰ دقیقه)

**محیط فرض:** SQLite 3

## پیش‌نیازها
جلسه ۰۵.

## اهداف قابل‌اندازه‌گیری
1. `UNION` و `UNION ALL` را درست به کار ببرید
2. بگویید ستون‌ها باید هم‌تعداد و سازگار باشند
3. `INTERSECT` و `EXCEPT` را در SQLite در حد آشنایی اجرا کنید
4. کی UNION بهتر از OR پیچیده است را بگویید

## چرا مهم است؟
ادغام نتایج هم‌شکل از منابع/فیلترهای مختلف رایج است.

## مفهوم عمیق
```sql
SELECT email FROM users
UNION
SELECT email FROM archived_users;
```

`UNION` تکراری را حذف می‌کند؛ `UNION ALL` نگه می‌دارد.

## اشتباه‌های رایج
1. تعداد ستون نابرابر.
2. نوع‌های ناسازگار بدون تبدیل.
3. ORDER BY وسط دو SELECT بدون در نظر گرفتن کل نتیجه.

## مثال گام‌به‌گام
```bash
sqlite3 clinic.db < session-11-union-sets/examples/01-union.sql
```

## الگوی بهتر
alias یکسان برای ستون‌های خروجی؛ ORDER BY روی نتیجهٔ نهایی.

## تمرین‌ها
### آسان
دو فهرست نام را UNION کنید.
### چالشی
تفاوت تعداد سطر UNION و UNION ALL را نشان دهید.

## راهنمای حل
با دادهٔ تکراری بین دو مجموعه، UNION کمتر از UNION ALL می‌دهد.

## خودآزمایی
1. فرق UNION و UNION ALL؟
2. INTERSECT چیست؟
3. EXCEPT چیست؟
4. چرا تعداد ستون مهم است؟
5. OR همیشه جایگزین UNION نیست — چرا؟
