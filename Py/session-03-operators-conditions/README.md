# جلسه ۳: عملگرها، شرط‌ها و منطق برنامه

## اهداف یادگیری (Learning Objectives)

پس از این جلسه می‌توانید:
- با عملگرهای ریاضی و مقایسه‌ای آشنا شوید
- از شرط‌ها برای تصمیم‌گیری در برنامه استفاده کنید
- با `if`، `elif` و `else` کار کنید
- منطق برنامه‌نویسی را بهتر درک کنید

---

## عملگرها چیست؟

عملگرها نمادهایی هستند که برای انجام عملیات روی داده‌ها به کار می‌روند. مثال:

```python
x = 10
y = 3

print(x + y)
print(x - y)
print(x * y)
print(x / y)
```

### انواع رایج عملگرها
- ریاضی: `+`, `-`, `*`, `/`, `%`
- مقایسه‌ای: `==`, `!=`, `>`, `<`
- منطقی: `and`, `or`, `not`

---

## شرط‌ها

شرط‌ها به برنامه کمک می‌کنند تصمیم بگیرد. برای مثال اگر سن فرد بیشتر از ۱۸ بود، بگو «بزرگسال».

```python
age = 20

if age >= 18:
    print("بزرگسال")
else:
    print("کمتر از ۱۸")
```

### توضیح بخش به بخش
- `if age >= 18:` → اگر شرط درست باشد
- `print("بزرگسال")` → این خط اجرا می‌شود
- `else:` → اگر شرط درست نباشد

---

## چند شرط با `elif`

```python
score = 85

if score >= 90:
    print("عالی")
elif score >= 70:
    print("خوب")
else:
    print("نیاز به تلاش بیشتر")
```

---

## نکات رایج اشتباهات (Common Pitfalls)

### ❌ اشتباه ۱: فراموش کردن دو نقطه
```python
if age >= 18
    print("بزرگسال")
```

### ❌ اشتباه ۲: اشتباه در مقایسه
```python
if age = 18:
```

در Python برای مقایسه از `==` استفاده می‌کنیم، نه `=`.
