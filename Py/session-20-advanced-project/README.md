## پروژه: مدیر کارهای روزانه (Task Manager)

در این جلسه یک برنامه ساده مدیریت کار می‌سازیم که کارها را در حافظه نگه می‌دارد و می‌تواند آن‌ها را نمایش دهد، اضافه کند و وضعیت‌شان را تغییر دهد.

### ویژگی‌ها
- افزودن کار جدید
- نمایش همه کارها
- علامت‌گذاری کار به‌عنوان انجام‌شده
- خروج از برنامه

### نمونه کد
```python
tasks = []

def add_task(title: str) -> None:
    tasks.append({"title": title, "done": False})

def list_tasks() -> None:
    for index, task in enumerate(tasks, start=1):
        status = "✓" if task["done"] else " "
        print(f"{index}. [{status}] {task['title']}")

add_task("یادگیری Python")
list_tasks()
```

### توضیح
- هر کار یک دیکشنری با دو کلید `title` و `done` است
- `enumerate` شماره ردیف را می‌سازد
- توابع جداگانه، کد را مرتب و قابل تست نگه می‌دارند
