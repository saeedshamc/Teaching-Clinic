# جلسه ۱۰: ماژول‌ها و کتابخانه‌های استاندارد

## اهداف یادگیری (Learning Objectives)

پس از این جلسه می‌توانید:
- مفهوم ماژول (Module) را بفهمید
- از ماژول‌های استاندارد Python استفاده کنید
- کد خود را به بخش‌های منظم تقسیم کنید

---

## ماژول چیست؟

ماژول یک فایل Python است که شامل توابع و متغیرهای مفید می‌شود.

```python
import math

print(math.sqrt(16))
```

---

## ماژول‌های استاندارد پرکاربرد

- `math` → عملیات ریاضی
- `datetime` → کار با تاریخ و زمان
- `random` → عدد تصادفی
