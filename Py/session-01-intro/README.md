## ۱. Python چیست؟

Python یک **زبان برنامه‌نویسی سطح بالا** است — یعنی نزدیک به زبان انسان و دور از جزئیات سخت‌افزار. کد Python خوانا و مختصر است؛ برای همین در آموزش، علم داده، وب و اتوماسیون محبوب است.

```python
print("سلام دنیا!")
```

**خط به خط:**
- `print` — نام تابع built-in
- `("سلام دنیا!")` — آرگومان: یک رشته (string)
- Python دستورات را **از بالا به پایین** اجرا می‌کند

| کاربرد | کتابخانه / فریم‌ورک | توضیح |
|--------|---------------------|-------|
| تحلیل داده | pandas, numpy, matplotlib | پردازش جدول و نمودار |

## ۳. محیط مجازی (Virtual Environment)

هر پروژه ممکن است نسخه‌های مختلف کتابخانه بخواهد. **venv** یک پوشه جدا برای وابستگی‌های همان پروژه می‌سازد.

```bash
# ساخت (یک بار)
python -m venv venv

# فعال‌سازی — Windows PowerShell
venv\Scripts\Activate.ps1

# فعال‌سازی — Mac/Linux
source venv/bin/activate

# وقتی (venv) در ابتدای خط دیدید، فعال است

# غیرفعال
deactivate
```

**خط به خط:**
- `python -m venv venv` — ماژول `venv` را اجرا می‌کند و پوشه `venv` می‌سازد
- فعال‌سازی مسیر `python` و `pip` را به داخل `venv` هدایت می‌کند
- هر پروژه **venv خودش** را دارد — venv را داخل git commit نکنید (به `.gitignore` اضافه کنید)

## ۵. تابع `print()`

### ۵.۱. فرم پایه

```python
print("سلام، دنیا!")
print("Hello, World!")
print("به دوره Python خوش آمدید!")
```

**خط به خط:**
- هر `print` یک **statement** مستقل است
- رشته بین `"..."` یا `'...'` — هر دو یکسان
- خروجی پیش‌فرض هر `print` در **خط جدید** است

### ۵.۲. چند مقدار و `sep`

```python
print("سلام", "دنیا")           # سلام دنیا
print("سلام", "دنیا", sep="-")  # سلام-دنیا
print("2026", "09", "02", sep="/")  # 2026/09/02
```

- `sep` — جداکننده بین آرگومان‌ها (پیش‌فرض: فاصله)

### ۵.۳. پارامتر `end`

```python
print("خط اول", end=" ")
print("خط دوم")   # خط اول خط دوم (یک خط)
print()           # خط خالی
```

- `end` — کاراکتر پایان (پیش‌فرض: `\n` یعنی newline)

### ۵.۴. چاپ عدد و متن

```python
age = 25
print("سن:", age)
print(f"سن شما {age} است.")  # f-string — جلسه ۲
```

## ۶. کامنت‌ها (Comments)

```python
# این کامنت تک‌خطی است — Python اجرا نمی‌کند

"""
کامنت چندخطی
برای توضیحات بلند
"""

print("فقط این خط در خروجی دیده می‌شود")
```

**چرا کامنت؟**
- توضیح **چرا** نه **چه** — کد باید خودش گویا باشد
- مستندسازی برای خودتان و هم‌تیمی
- غیرفعال کردن موقت یک خط برای دیباگ

| اشتباه | مشکل | راه‌حل |

## ۹. بهترین شیوه‌ها (Best Practices)

1. **Python 3** — هرگز Python 2
2. **venv برای هر پروژه** — وابستگی‌ها جدا بمانند
3. **نام فایل معنادار** — `hello.py` نه `a.py`
4. **encoding UTF-8** — برای فارسی در فایل‌ها مشکلی نیست
5. **یک دستور در هر خط** — خوانایی بهتر
6. **کامنت برای «چرا»** — نه تکرار واضحات کد
