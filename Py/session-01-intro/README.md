## Python چیست؟

Python یک زبان برنامه‌نویسی است — یعنی ابزاری که باهاش به کامپیوتر دستور می‌دهید. تفاوتش با زبان‌های دیگر اینجاست که خواندنش بسیار شبیه به انگلیسی ساده است.

مثلاً برای نمایش یک پیام روی صفحه، فقط می‌نویسید:
```python
print("سلام دنیا!")
```

همین! یک خط، قابل فهم، بدون پیچیدگی.

## نصب Python

### ویندوز
1. به [python.org/downloads](https://www.python.org/downloads/) بروید
2. دکمه «Download Python 3.x.x» را بزنید
3. فایل نصب را اجرا کنید
4. **مهم:** تیک «Add Python to PATH» را حتماً بزنید
5. «Install Now» را کلیک کنید

### macOS
```bash
# روش ۱: از سایت python.org دانلود کنید
# روش ۲: با Homebrew
brew install python3
```

### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

### تأیید نصب
```bash
python3 --version
# خروجی باید چیزی شبیه این باشد: Python 3.11.x
```

## محیط مجازی (Virtual Environment) چیست؟

تصور کنید چند پروژه مختلف دارید. پروژه A به نسخه ۱.۰ یک کتابخانه نیاز دارد، پروژه B به نسخه ۲.۰ همان کتابخانه. اگر همه را در یک جا نصب کنید، گیر می‌کنید.

**محیط مجازی** مثل یک اتاق جداگانه برای هر پروژه است — هر پروژه کتابخانه‌های مختص خودش را دارد.

### ساخت و فعال‌سازی venv

```bash
# ۱. ساخت محیط مجازی (یک بار)
python3 -m venv venv

# ۲. فعال‌سازی (هر بار که کار می‌کنید)

# در Mac/Linux:
source venv/bin/activate

# در ویندوز (PowerShell):
venv\Scripts\Activate.ps1

# در ویندوز (CMD):
venv\Scripts\activate.bat

# ۳. وقتی دیدید (venv) در ابتدای خط، یعنی فعال است

# ۴. غیرفعال‌سازی
deactivate
```

## توضیح کدها

### 📄 `01_hello_world.py`

```python
print("سلام، دنیا!")
print("Hello, World!")
print("به دوره Python خوش آمدید!")
```

**خط به خط:**
- `print(...)` — این یک **تابع** (Function) داخلی Python است. کارش نمایش هر چیزی است که داخل پرانتز بگذارید
- `"سلام، دنیا!"` — این یک **رشته** (String) است؛ هر متنی که داخل گیومه باشد
- هر خط یک دستور مستقل است — Python آن‌ها را از بالا به پایین اجرا می‌کند

---

### 📄 `02_comments.py`

```python
# این یک کامنت تک‌خطی است — Python این خط را اجرا نمی‌کند

"""
این یک کامنت
چند خطی است.
برای توضیحات بلندتر استفاده می‌شود.
"""

print("کامنت‌ها در خروجی نمایش داده نمی‌شوند")
```

**چرا کامنت مهم است؟**
- توضیح می‌دهد کد چه کاری انجام می‌دهد
- وقتی ۶ ماه بعد به کدتان برگردید، می‌فهمید چه نوشته‌اید
- برای دیگران هم قابل فهم می‌شود

---

### 📄 `03_print_advanced.py`

```python
print("سلام", "دنیا")           # چاپ چند آیتم با فاصله
print("سلام", "دنیا", sep="-")  # جداکننده سفارشی
print("خط اول", end=" ")        # بدون رفتن به خط بعد
print("خط دوم")
print()                          # خط خالی
```

**توضیح پارامترها:**
- `sep` — جداکننده بین آیتم‌ها را تعیین می‌کند (پیش‌فرض: فاصله)
- `end` — کاراکتر پایانی را تعیین می‌کند (پیش‌فرض: رفتن به خط بعد `\n`)

## نکات رایج اشتباهات (Common Pitfalls)

### ❌ اشتباه رایج ۱: فراموش کردن گیومه
```python
print(سلام)      # خطا! Python فکر می‌کند "سلام" یک متغیر است
print("سلام")    # ✅ درست
```

### ❌ اشتباه رایج ۲: حساسیت به بزرگی/کوچکی حروف
```python
Print("سلام")    # خطا! Python به بزرگ/کوچک بودن حروف حساس است
PRINT("سلام")    # خطا!
print("سلام")    # ✅ درست — همیشه lowercase
```

### ❌ اشتباه رایج ۳: پرانتز را فراموش نکنید
```python
print "سلام"     # این Python 2 است، در Python 3 خطا می‌دهد
print("سلام")    # ✅ در Python 3 همیشه پرانتز لازم است
```

## بهترین شیوه‌ها (Best Practices)

- کدتان را همیشه کامنت‌گذاری کنید — حتی اگر ساده به نظر برسد
- از نام‌های معنادار استفاده کنید
- یک دستور در هر خط بنویسید (ساده‌تر و خواناتر)
- فایل‌های Python با `.py` ذخیره می‌شوند
