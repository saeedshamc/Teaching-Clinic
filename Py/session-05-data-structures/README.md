# جلسه ۵: ساختارهای داده

## اهداف یادگیری (Learning Objectives)

پس از این جلسه می‌توانید:
- با لیست، تاپل، دیکشنری و مجموعه آشنا شوید
- داده‌ها را در ساختارهای مناسب ذخیره کنید
- با این ساختارها عملیات ساده انجام دهید

---

## لیست (List)

لیست یک سری از داده‌ها را در یک جایگاه ذخیره می‌کند.

```python
fruits = ["سیب", "موز", "پرتقال"]
print(fruits[0])
```

---

## تاپل (Tuple)

تاپل شبیه لیست است، اما تغییرناپذیر است.

```python
point = (10, 20)
print(point[0])
```

---

## دیکشنری (Dictionary)

دیکشنری داده‌ها را به‌صورت کلید-مقدار نگه می‌دارد.

```python
person = {"name": "سعید", "age": 25}
print(person["name"])
```

---

## مجموعه (Set)

مجموعه برای نگهداری مقادیر یکتا استفاده می‌شود.

```python
numbers = {1, 2, 2, 3}
print(numbers)
```

---

- لیست، تاپل، دیکشنری و مجموعه چه هستند
- هر کدام چه زمانی استفاده می‌شوند
