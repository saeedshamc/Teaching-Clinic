---

## تابع چیست؟

تابع یک بلوک از کد است که یک کار مشخص انجام می‌دهد. به جای تکرار، می‌توان آن را یک بار تعریف کرد و چند بار استفاده کرد.

```python
def greet(name):
    print("سلام", name)


greet("سعید")
```

---

## پارامترها و مقدار بازگشتی

```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)
```

---

## Scope متغیرها

متغیرهای داخل تابع معمولاً فقط در همان تابع قابل دسترس‌اند.

```python
def show():
    message = "داخل تابع"
    print(message)

show()
```
