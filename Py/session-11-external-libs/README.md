---

## کتابخانه‌های بیرونی چیست؟

کتابخانه‌های بیرونی افزونه‌هایی هستند که توسط دیگران نوشته شده‌اند و می‌توانیم در پروژه‌های خود استفاده کنیم.

### نصب با pip
```bash
pip install requests
```

### استفاده
```python
import requests

response = requests.get("https://example.com")
print(response.status_code)
```

> اگر دسترسی اینترنت ندارید، این مثال ممکن است با خطا روبرو شود. در محیط آزمایشی، می‌توان از یک URL ساده استفاده کرد.
