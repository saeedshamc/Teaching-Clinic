- یک ابزار ساده خط فرمان بسازید
- کد خود را ساختارمند و قابل استفاده نگه دارید

---

## پروژه پیشنهادی: دفترچه یادداشت ساده

در این جلسه یک برنامه ساده می‌سازیم که متن‌های یادداشت را در یک فایل ذخیره می‌کند.

### ویژگی‌ها
- اضافه کردن یادداشت
- نمایش همه یادداشت‌ها
- خروج از برنامه

### نمونه کد
```python
notes = []

while True:
    choice = input("۱) افزودن ۲) نمایش ۳) خروج: ")
    if choice == "1":
        note = input("یادداشت را وارد کنید: ")
        notes.append(note)
    elif choice == "2":
        for note in notes:
            print("-", note)
    else:
        break
```
