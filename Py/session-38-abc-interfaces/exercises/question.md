# تمرین‌های جلسه ۳۸ — ABC

## کلاسی (۳۰ دقیقه)

1. **Shape:** Square و Circle — area و perimeter.
2. **Animal:** Dog و Cat — speak و move.
3. **TypeError:** instantiate Shape() — catch و explain.
4. **list[Shape]:** polymorphism روی shapes.

## خانه (۴۵ دقیقه)

5. **PaymentStrategy:** CreditCard و Wallet.
6. **UserRepository:** InMemory + UserService.
7. **Template Method:** DataExporter با format/write abstract.
8. **Protocol:** Drawable با typing.Protocol — مقایسه با ABC.

## نکات

- `@abstractmethod` روی متد خالی یا `...`
- subclass باید همه abstract را implement کند
- ABC برای contract runtime
- Repository — abstraction روی storage
