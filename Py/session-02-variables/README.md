# جلسه ۲: متغیرها و انواع داده پایه

## اهداف یادگیری (Learning Objectives)

پس از این جلسه می‌توانید:
- مفهوم متغیر (Variable) را درک کنید
- انواع داده پایه Python را بشناسید: int، float، str، bool
- با ورودی و خروجی کار کنید
- داده‌ها را در متغیرها ذخیره کرده و با آنها کار کنید

---

## متغیر چیست؟

متغیر مثل یک جعبه است. در آن جعبه می‌توانیم اطلاعاتی را نگه داریم و بعد دوباره از آن استفاده کنیم. در Python می‌توانیم این‌طور بنویسیم:

```python
name = "سعید"
age = 25
```

در اینجا `name` یک جعبه برای متن و `age` یک جعبه برای عدد است.

### چرا متغیر مهم است؟
- برنامه‌ها از داده‌ها استفاده می‌کنند
- متغیرها باعث می‌شوند کد خواناتر شود
- می‌توانیم مقدار را بعداً تغییر دهیم

---

## انواع داده پایه

### ۱) عدد صحیح (int)
```python
age = 25
```

### ۲) عدد اعشاری (float)
```python
price = 19.99
```

### ۳) متن (str)
```python
name = "پایتون"
```

### ۴) درست/نادرست (bool)
```python
is_student = True
```

---

## مثال ۱: تعریف متغیرها

```python
name = "سعید"
age = 25
height = 1.78
is_student = True

print("نام:", name)
print("سن:", age)
print("قد:", height)
print("دانشجو:", is_student)
```

### توضیح بخش به بخش
- `name = "سعید"` → یک متن در متغیر `name` ذخیره می‌شود
- `age = 25` → یک عدد صحیح در `age` ذخیره می‌شود
- `height = 1.78` → یک عدد اعشاری در `height` ذخیره می‌شود
- `is_student = True` → مقدار بولی درست ذخیره می‌شود
- `print(...)` → خروجی را روی صفحه نمایش می‌دهد

---

## مثال ۲: گرفتن ورودی از کاربر

```python
name = input("نام شما چیست؟ ")
age = int(input("سن شما چند است؟ "))

print(f"سلام {name}! سال بعد سن شما {age + 1} می‌شود.")
```

### توضیح بخش به بخش
- `input(...)` → مقدار واردشده توسط کاربر را می‌گیرد
- `int(...)` → متن را به عدد تبدیل می‌کند
- `f"..."` → قالب‌بندی متن با مقدار متغیر

---

## نکات رایج اشتباهات (Common Pitfalls)

### ❌ اشتباه ۱: استفاده از عدد به‌صورت متن
```python
age = input("سن شما چند است؟ ")
print(age + 1)  # خطا می‌دهد
```

در اینجا `age` متن است، پس باید تبدیل شود:
```python
age = int(input("سن شما چند است؟ "))
print(age + 1)
```

### ❌ اشتباه ۲: نام‌گذاری نامناسب متغیر
```python
x = "سعید"
```

بهتر است:
```python
name = "سعید"
```

### ✅ بهترین روش
- از نام‌های معنادار استفاده کنید
- برای متن از `"..."` استفاده کنید
- برای عدد از `int` یا `float` استفاده کنید
