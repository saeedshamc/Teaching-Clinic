## متغیر چیست؟

تصور کنید می‌خواهید نام دوستتان را در برنامه استفاده کنید. هر بار که بخواهید آن را چاپ کنید، نمی‌خواهید دوباره تایپش کنید. **متغیر** مثل یک برچسب روی یک جعبه است — روی جعبه می‌نویسید `name` و داخلش `"سعید"` را می‌گذارید. هر وقت به `name` اشاره کنید، Python محتوای جعبه را برمی‌گرداند.

```python
name = "سعید"
age = 25
```

در Python نیازی به اعلام نوع داده نیست — Python خودش تشخیص می‌دهد. این ویژگی **Dynamic Typing** نام دارد.

### چرا متغیر مهم است؟

| دلیل | توضیح |
|------|-------|
| خوانایی | `print(age)` بهتر از `print(25)` است |
| تغییرپذیری | می‌توانید مقدار را بعداً عوض کنید |
| استفاده مجدد | یک بار ذخیره، چند بار استفاده |

---

## انواع داده پایه (Basic Data Types)

### ۱) عدد صحیح — `int`
اعداد بدون اعشار: سن، تعداد، سال.

```python
age = 25
year = 2026
negative = -10
```

### ۲) عدد اعشاری — `float`
اعداد با اعشار: قیمت، قد، دما.

```python
price = 19.99
height = 1.78
pi = 3.14159
```

### ۳) متن — `str` (String)
هر متنی بین گیومه `"..."` یا `'...'`.

```python
name = "پایتون"
message = 'سلام دنیا'
```

### ۴) بولی — `bool` (Boolean)
فقط دو مقدار: `True` (درست) یا `False` (نادرست).

```python
is_student = True
has_license = False
```

---

## بررسی نوع داده با `type()`

```python
name = "سعید"
age = 25
print(type(name))  # <class 'str'>
print(type(age))   # <class 'int'>
```

### توضیح
- `type(متغیر)` نوع داده را برمی‌گرداند
- در دیباگ و یادگیری بسیار مفید است

---

## تبدیل نوع (Type Casting)

گاهی باید یک نوع را به نوع دیگر تبدیل کنید:

```python
age_text = "25"       # str
age = int(age_text)   # int → 25
price = float("19.99") # float → 19.99
count = str(100)      # str → "100"
```

**خط به خط:**
- `int("25")` — رشته عددی را به عدد صحیح تبدیل می‌کند
- `float("19.99")` — رشته را به عدد اعشاری تبدیل می‌کند
- `str(100)` — عدد را به رشته تبدیل می‌کند (برای چسباندن به متن)

---

## قالب‌بندی با f-string

```python
name = "سعید"
age = 25
print(f"سلام {name}! سن شما {age} است.")
# خروجی: سلام سعید! سن شما 25 است.
```

### توضیح
- حرف `f` قبل از گیومه یعنی «متغیرهای داخل `{}` را جایگزین کن»
- روش مدرن و خواناتر Python 3.6+

---

## گرفتن ورودی از کاربر — `input()`

```python
name = input("نام شما چیست؟ ")
age = int(input("سن شما چند است؟ "))
print(f"سلام {name}! سال بعد {age + 1} ساله می‌شوید.")
```

### خط به خط
- `input("...")` — پیام را نمایش می‌دهد و منتظر تایپ کاربر می‌ماند
- **مهم:** `input()` همیشه `str` برمی‌گرداند — برای محاسبه باید `int()` یا `float()` بزنید
- `age + 1` فقط وقتی کار می‌کند که `age` عدد باشد

---

## قوانین نام‌گذاری متغیر

| قانون | مثال درست | مثال نادرست |
|-------|-----------|-------------|
| با حرف یا `_` شروع شود | `name`, `_temp` | `2name` |
| فقط حروف، عدد و `_` | `user_age` | `user-age` |
| حساس به بزرگی/کوچکی | `age` ≠ `Age` | — |
| از کلمات کلیدی Python استفاده نکنید | `user_name` | `class`, `for` |

**سبک پیشنهادی:** `snake_case` — کلمات با `_` جدا شوند: `first_name`, `total_price`

name = "سعید"

**خط به خط:**

- `age = 25` — عدد صحیح (int)
- `height = 1.78` — عدد اعشاری (float)

### 📄 `02_user_input.py`

```python
name = input("نام شما چیست؟ ")
age = int(input("سن شما چند است؟ "))
print(f"سلام {name}! سال بعد سن شما {age + 1} می‌شود.")
```

**خط به خط:**
- `input(...)` — ورودی را به‌صورت رشته می‌گیرد
- `int(...)` — رشته عددی را به int تبدیل می‌کند تا بتوانیم `+ 1` بزنیم
- `f"..."` — متغیرها داخل `{}` جایگزین می‌شوند

> **نکته:** فایل شامل مسیر دمو بدون `input()` هم هست تا بدون تعامل اجرا شود.

## نکات رایج اشتباهات (Common Pitfalls)

### ❌ اشتباه ۱: جمع کردن عدد با رشته
```python
age = input("سن: ")   # age یک str است!
print(age + 1)         # TypeError
```
```python
age = int(input("سن: "))  # ✅ ابتدا تبدیل کنید
print(age + 1)
```

### ❌ اشتباه ۲: نام‌گذاری نامفهوم
```python
x = "سعید"
a = 25
```
```python
name = "سعید"   # ✅ نام معنادار
age = 25
```

### ❌ اشتباه ۳: استفاده از `=` به‌جای `==` برای مقایسه
```python
if age = 18:    # SyntaxError — = برای انتساب است
```
```python
if age == 18:   # ✅ == برای مقایسه
```

## بهترین شیوه‌ها (Best Practices)

- از نام‌های معنادار و انگلیسی/لاتین برای شناسه‌ها استفاده کنید (`user_name` نه `x`)
- همیشه بعد از `input()` نوع را بررسی یا تبدیل کنید
- برای چاپ متن با متغیر از f-string استفاده کنید
- با `type()` در ابتدای یادگیری مطمئن شوید نوع داده درست است
- مقادیر ثابت را در متغیر بگذارید تا کد خواناتر شود
