# جلسه 78: پروژه لندینگ کامل Bootstrap (2 ساعت)

## هدف پروژه
یک لندینگ چندبخشی بسازید که برای معرفی یک محصول/دوره مناسب باشد:

1. **Hero** — عنوان، جمله کوتاه، CTA
2. **ویژگی‌ها** — سه ستون در Grid
3. **CTA میانی** — دعوت به اقدام
4. **فوتر** ساده

این جلسه پایان بلوک Bootstrap است.

---

## چک‌لیست تحویل
- [ ] Hero با پس‌زمینه/رنگ متمایز و دکمه
- [ ] سه ویژگی در `row` / `col-md-4`
- [ ] بخش CTA با `id` برای اسکرول از دکمه hero
- [ ] فوتر با لینک یا کپی‌رایت
- [ ] فقط کلاس‌های Bootstrap (+ استایل کم در `style.css` اگر لازم)
- [ ] RTL درست

---

## نکتهٔ معماری
کلاس‌های Tailwind را اینجا نگذارید. از جلسه ۷۹ ذهنیت را عوض می‌کنید: utility-first جدا و کامل.

---

## ایدهٔ گسترش
- Navbar چسبان از جلسه ۶۷
- Accordion FAQ
- فرم ایمیل با validation جلسه ۷۰

## پایان بلوک Bootstrap
آفرین — Grid، کامپوننت، JS data-api و سفارشی‌سازی را لمس کردید.
