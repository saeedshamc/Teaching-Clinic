# جلسه 44: Design Tokens (2 ساعت)

## اهداف یادگیری
- تعریف توکن برای رنگ، فاصله، شعاع و elevation
- مصرف توکن با CSS variables
- جدا کردن «تصمیم طراحی» از «پیاده‌سازی کامپوننت»

---

## 1. توکن چیست؟

توکن یک نام معنادار برای مقدار طراحی است؛ مثلاً به‌جای تکرار `#7c3aed` همه جا می‌نویسید `--color-brand`.

وقتی برند عوض شود، یک جا را تغییر می‌دهید.

---

## 2. دسته‌های رایج

```css
:root {
  /* رنگ */
  --color-brand: #7c3aed;
  --color-danger: #dc2626;
  --color-surface: #ffffff;
  --color-text: #1e1b4b;

  /* فاصله */
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 0.75rem;
  --space-4: 1rem;
  --space-6: 1.5rem;

  /* شعاع و سایه */
  --radius-1: 8px;
  --radius-2: 12px;
  --shadow-1: 0 4px 14px rgba(15, 23, 42, 0.08);
  --shadow-2: 0 12px 30px rgba(15, 23, 42, 0.12);
}
```

---

## 3. مصرف در کامپوننت

```css
.btn {
  background: var(--color-brand);
  padding: var(--space-2) var(--space-4);
  border-radius: var(--radius-2);
  box-shadow: var(--shadow-1);
}
```

کامپوننت نباید عدد جادویی پخش کند؛ از توکن بردارد.

---

## اشتباهات رایج
- ساختن صدها توکن بی‌معنا (`--blue-3` بدون نقش)
- مخلوط کردن توکن معنایی (`--color-brand`) با خام (`--purple-500`) بدون لایه
- تغییر رنگ فقط در یک کامپوننت و فراموش کردن توکن

---

## تمرین‌ها
### آسان
سه توکن فاصله و یک دکمه بر اساس آن‌ها بسازید.
### متوسط
`--shadow-1` و `--shadow-2` را روی دو کارت اعمال کنید.
### چالش
توکن `--color-brand` را عوض کنید و ببینید چند جای UI یکجا عوض می‌شود.

## خلاصه
توکن‌ها زبان مشترک طراحی و کد هستند.
