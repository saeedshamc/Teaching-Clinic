# جلسه 30: Transform (2 ساعت)

## اهداف
- `translate`، `rotate`، `scale`، `skew`
- ترکیب transformها
- چرا transform برای حرکت UI معمولاً بهتر از جابه‌جایی layout است

```css
.cube:hover {
  transform: translateY(-10px) rotate(8deg) scale(1.05);
}
```
