# جلسه 64: سیستم Grid در Bootstrap (2 ساعت)

## اهداف
- ردیف `row` و ستون‌های `col-*`
- breakpointها: `col-sm`، `col-md`، `col-lg`، ...
- فاصله با `g-*` (gutter)

```html
<div class="row g-3">
  <div class="col-12 col-md-6">...</div>
  <div class="col-12 col-md-6">...</div>
</div>
```

۱۲ ستون در هر ردیف. مجموع `col`ها در یک breakpoint معمولاً ۱۲ است.

## تمرین
چیدمان ۴ کارت روی دسکتاپ (`col-lg-3`) و ۲ ستون روی تبلت.
