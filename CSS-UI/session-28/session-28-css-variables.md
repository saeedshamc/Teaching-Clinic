# جلسه 28: CSS Variables (2 ساعت)

## اهداف
- تعریف custom properties در `:root`
- مصرف با `var()`
- تغییر تم با عوض کردن متغیرها

```css
:root {
  --brand: #1d4ed8;
  --bg: #eff6ff;
}
.btn { background: var(--brand); }
```

توکن‌ها پایهٔ دیزاین‌سیستم‌اند (جلسات بعدی معماری).
