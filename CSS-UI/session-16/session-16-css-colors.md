# جلسه 16: رنگ‌ها (2 ساعت)

## اهداف
- `hex`، `rgb()`/`rgba()`، `hsl()`/`hsla()`
- `opacity` در برابر آلفا در رنگ
- `currentColor`

```css
.hex { background: #0ea5e9; }
.rgb { background: rgb(14 165 233 / 0.7); }
.hsl { background: hsl(198 93% 48%); }
```

برای تم‌سازی، `hsl` اغلب انعطاف بیشتری دارد.
