# جلسه 11: Combinator و Attribute (2 ساعت)

## اهداف
- نسل (` `)، فرزند مستقیم (`>`)، خواهر مجاور (`+`)، خواهر عمومی (`~`)
- attribute selector مثل `a[target="_blank"]`

```css
.menu > a { color: #1d4ed8; }
.menu a[target="_blank"] { color: #c026d3; }
.menu a + span { color: #64748b; }
```

## تمرین
لینک‌های داخلی و خارجی را با attribute جدا کنید.
