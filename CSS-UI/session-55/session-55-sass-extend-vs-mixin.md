# جلسه 55: Extend در برابر Mixin (2 ساعت)

## اهداف یادگیری
- دانستن `@extend` و placeholder `%`
- تصمیم‌گیری: چه موقع mixin، چه موقع extend
- دیدن خطر سلکتورهای گروهی پیچیده

---

## قاعده سرانگشتی

| نیاز | انتخاب |
|------|--------|
| پارامتر می‌خواهید | **mixin** |
| چند سلکتور صفات خشک یکسان دارند | گاهی **extend** / `%placeholder` |
| خروجی CSS تمیز و قابل‌پیش‌بینی برای تیم | اغلب **mixin** |

```scss
%card-base {
  border-radius: 12px;
  background: #fff;
}

.card { @extend %card-base; }
.panel { @extend %card-base; }
```

در خروجی، Sass ممکن است سلکتورها را گروه کند. گاهی خوانایی سخت می‌شود؛ برای همین خیلی از تیم‌ها mixin را ترجیح می‌دهند.

---

## تمرین
یک الگوی مشترک را یک‌بار با mixin و یک‌بار با `%placeholder` بنویسید و CSS خروجی را مقایسه کنید.
