# جلسه 94: پروژه UI Kit کوچک با Tailwind (2 ساعت)

## هدف
یک صفحه «کیت UI» برای پنل تنظیمات بسازید که شامل:

- دکمه‌ها (primary / secondary / danger)
- فیلد ورودی و select
- Alert موفقیت و خطا
- کارت تنظیمات با سوییچ (peer یا checkbox)

این جلسه پایان بلوک Tailwind است.
