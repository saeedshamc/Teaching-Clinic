# جلسه 39: سلکتورهای مدرن (2 ساعت)

## اهداف
- `:is()` و `:where()`
- `:has()` برای استایل والد بر اساس فرزند

```css
form:has(input:invalid) { border-color: #dc2626; }
:where(.card) a { color: inherit; } /* specificity صفر */
```

پشتیبانی مرورگر را در پروژه واقعی چک کنید.
