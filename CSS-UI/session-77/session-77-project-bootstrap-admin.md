# جلسه 77: پروژه داشبورد ادمین با Bootstrap (2 ساعت)

## هدف پروژه
یک پنل ادمین ساده بسازید که مهارت‌های جلسات ۶۳–۷۶ را جمع کند:

- سایدبار لینک‌ها (`list-group`)
- سه کارت آمار
- جدول کاربران با badge
- حس RTL درست

زمان پیشنهادی: حدود ۲ ساعت (طراحی + پیاده‌سازی + پولیش).

---

## چک‌لیست تحویل
- [ ] Grid: سایدبار `col-md-3` + محتوای `col-md-9`
- [ ] حداقل سه کارت آمار با رنگ متفاوت
- [ ] جدول داخل `table-responsive`
- [ ] یک badge وضعیت در جدول
- [ ] ناوبری سایدبار با آیتم `active`
- [ ] صفحه روی موبایل نشکند (سایدبار بالای محتوا برود)

---

## ساختار پیشنهادی

```
row
├── aside (لینک‌ها)
└── section
    ├── row کارت‌های آمار
    └── table کاربران
```

می‌توانید از Icons جلسه ۷۵ هم استفاده کنید.

---

## ایدهٔ گسترش (اختیاری)
- Modal «افزودن کاربر»
- Toast بعد از ذخیره
- Pagination زیر جدول
