# جلسه 100: Capstone مقایسه‌ای — یک UI با سه فریم‌ورک (2 ساعت)

## هدف نهایی دوره
یک **کارت پروفایل کاربر** (آواتار متنی، نام، نقش، دو دکمه) را سه بار بسازید:

1. با **Bootstrap**
2. با **Tailwind**
3. با **Bulma**

همان محتوا، سه پیاده‌سازی جدا — تا فرق ذهنیت را حس کنید.

---

## چک‌لیست
- [ ] سه بخش مجزا در صفحهٔ اصلی + سه فایل جدا در `bootstrap/`، `tailwind/`، `bulma/`
- [ ] بدون قاطی کردن کلاس‌های فریم‌ورک‌ها داخل یک کارت
- [ ] RTL حفظ شود
- [ ] یک پاراگراف کوتاه بنویسید: کدام را برای پروژه بعد انتخاب می‌کنید و چرا

---

## راهنمای انتخاب (خلاصه)

| نیاز | پیشنهاد |
|------|---------|
| سرعت با کامپوننت + Modal آماده | Bootstrap |
| طراحی سفارشی دقیق، دیزاین‌سیستم | Tailwind |
| کامپوننت خوانا بدون JS زیاد | Bulma |
