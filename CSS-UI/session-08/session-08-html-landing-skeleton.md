# جلسه 8: پروژه مینی — اسکلت لندینگ (2 ساعت)

## هدف جلسه
یک لندینگ کامل از نظر **ساختار HTML** بسازید؛ استایل را عمداً سبک نگه دارید تا روی محتوا و landmarkها تمرکز بماند.

## بخش‌های الزامی
1. `header` + `nav`
2. Hero (`section`) با عنوان و CTA
3. ویژگی‌ها (`ul` یا چند `article`)
4. قیمت‌گذاری ساده
5. CTA با فرم ایمیل
6. `footer`

## چک‌لیست تحویل
- [ ] یک `h1` در hero
- [ ] لینک‌های nav به `#` بخش‌ها می‌رسند
- [ ] فرم حداقل یک `label` + `input type="email"` دارد
- [ ] صفحه بدون خطای واضح در Elements باز می‌شود

## بعد از این جلسه
از جلسه ۹ وارد **CSS** می‌شویم و روی همین ذهنیت UI استایل حرفه‌ای می‌گذاریم.
