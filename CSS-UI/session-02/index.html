اسکلت HTML5

DOCTYPE، head، body، متاها، lang و dir — پایه‌ای که همهٔ جلسات بعدی روی آن سوار می‌شوند.

راهنما: توضیحات کامل در session-02-html-skeleton.md. ساختار همین فایل را در DevTools → Elements بررسی کنید.

نقشهٔ سند فعلی

  1. <!DOCTYPE html> — حالت استاندارد HTML5
  2. <html lang="fa" dir="rtl"> — زبان و جهت
  3. <head> — charset، viewport، title، CSS
  4. <body> — محتوای دیداری
برای دیدن lang/dir/title دکمه را بزنید.
