# جلسه 2: اسکلت HTML5 (2 ساعت)

## اهداف یادگیری
- نوشتن یک سند HTML5 معتبر از صفر
- شناخت نقش `DOCTYPE`، `html`، `head` و `body`
- افزودن متاهای ضروری (`charset`، `viewport`، `description`)
- استفادهٔ درست از `lang` و `dir` برای فارسی (RTL)

---

## 1. اسکلت مینیمال

هر صفحهٔ مدرن تقریباً این شکل را دارد:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>عنوان تب مرورگر</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- محتوای قابل‌مشاهده -->
</body>
</html>
```

### `DOCTYPE`
به مرورگر می‌گوید «این سند HTML5 است». بدون آن ممکن است حالت قدیمی (quirks) فعال شود و استایل‌ها عجیب شوند.

### `<html lang="fa" dir="rtl">`
- `lang="fa"`: زبان صفحه (دسترسی‌پذیری، SEO، خط‌کشی صحیح)
- `dir="rtl"`: جهت راست‌به‌چپ برای فارسی

### `<head>` در برابر `<body>`
| بخش | چه چیزی می‌رود؟ |
|-----|------------------|
| `head` | عنوان، متا، لینک CSS، گاهی اسکریپت غیرنمایشی |
| `body` | هرچه کاربر می‌بیند: متن، تصویر، فرم |

---

## 2. متاهای ضروری

### charset
```html
<meta charset="UTF-8">
```
بدون این، ممکن است فارسی به‌هم بریزد.

### viewport
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
برای موبایل حیاتی است؛ عرض منطقی را با عرض دستگاه هماهنگ می‌کند.

### description (اختیاری اما مفید)
```html
<meta name="description" content="توضیح کوتاه صفحه">
```

### title
متن تب مرورگر و نتیجهٔ جستجو — کوتاه و واضح بنویسید.

---

## 3. اتصال CSS و JS

```html
<!-- داخل head -->
<link rel="stylesheet" href="style.css">

<!-- معمولاً انتهای body -->
<script src="script.js"></script>
```

چرا اسکریپت آخر `body`؟ تا اول HTML خوانده شود، بعد JS عناصر را پیدا کند.

---

## 4. معنا (Semantics) خیلی کوتاه

از جلسهٔ بعد عمیق‌تر می‌شویم؛ فقط بدانید به‌جای همه‌چیز `<div>`، از تگ‌های معنادار استفاده می‌کنیم:

- `header` / `main` / `footer`
- `h1` برای عنوان اصلی صفحه (معمولاً یکی)

در دموی این جلسه یک اسکلت landmark ساده می‌بینید.

---

## اشتباهات رایج
- فراموش کردن `charset` → متن فارسی خراب
- نداشتن `viewport` → صفحهٔ موبایل زوم‌شده و درهم
- چند تا `h1` بی‌دلیل در یک صفحه
- گذاشتن محتوای دیداری فقط داخل `head`
- `dir="ltr"` ماندن روی پروژهٔ فارسی

---

## تمرین‌ها

### آسان
`title` و `meta description` را برای «صفحهٔ معرفی خودتان» عوض کنید.

### متوسط
یک `header`، یک `main` با یک `h1` و یک پاراگراف، و یک `footer` بسازید.

### چالش
صفحه را یک‌بار با `dir="rtl"` و یک‌بار با `dir="ltr"` ذخیره/مقایسه کنید و تفاوت چیدمان متن را در DevTools ببینید.

---

## خلاصه
- اسکلت HTML5 ثابت و ساده است؛ هر جلسه روی همین پایه می‌سازد
- `lang` و `dir` برای فارسی جدی گرفته شوند
- `head` = اطلاعات سند، `body` = محتوای دیداری
