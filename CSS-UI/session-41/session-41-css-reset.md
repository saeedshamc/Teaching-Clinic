# جلسه 41: Reset، Normalize و لایه Base (2 ساعت)

## اهداف یادگیری
- تفاوت Reset کامل و Normalize
- ساخت لایهٔ `base` پروژه
- یکسان‌سازی رفتار پیش‌فرض مرورگرها

---

## 1. چرا Reset؟

مرورگرها به `h1`، `ul`، `button` و `body` استایل پیش‌فرض متفاوت می‌دهند. بدون لایهٔ پایه، UI در Chrome و Safari «یکی» به نظر نمی‌رسد.

### رویکردها
| روش | ایده |
|-----|------|
| Reset سخت | تقریباً همه‌چیز صفر |
| Normalize | رفتارها را هم‌تراز می‌کند، ظاهر را کامل خالی نمی‌کند |
| لایه Base سفارشی | ترکیبی عملی برای پروژه‌های واقعی |

---

## 2. Base پیشنهادی این دوره

```css
*, *::before, *::after { box-sizing: border-box; }
html { line-height: 1.5; -webkit-text-size-adjust: 100%; }
body { margin: 0; }
img, svg, video { max-width: 100%; display: block; }
button, input, textarea, select { font: inherit; }
```

---

## اشتباهات رایج
- Reset کردن بدون بازسازی تایپوگرافی پایه
- فراموش کردن `box-sizing`
- وابسته شدن به margin پیش‌فرض مرورگر

## تمرین‌ها
### آسان
`base` را روی یک صفحه خالی اعمال و تفاوت لیست‌ها را ببینید.
### متوسط
برای `a` و `button` استایل پایه دسترسی‌پذیر بنویسید.
### چالش
یک فایل `base.css` جدا بسازید و به چند صفحه لینک کنید.
