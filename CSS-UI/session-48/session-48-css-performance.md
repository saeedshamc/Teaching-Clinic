# جلسه 48: پرفورمنس CSS (2 ساعت)

## اهداف یادگیری
- مفهوم critical CSS
- شناخت کارهایی که layout را سنگین می‌کنند
- ترجیح انیمیشن روی `transform` و `opacity`
- سلکتور ساده و قابل‌نگهداری

---

## 1. Critical CSS (مفهومی)

استایلی که برای **اولین نمای صفحه** لازم است بهتر است سریع در دسترس باشد. بقیه می‌تواند بعداً بیاید. در این دوره مفهوم را می‌فهمید؛ پیاده‌سازی بیلد پیشرفته بعداً با ابزارهاست.

---

## 2. چه چیزهایی گران‌اند؟

- انیمیت کردن `width` / `height` / `top` به‌صورت مداوم
- خواندن هندسه (`offsetWidth`) و بلافاصله نوشتن استایل در حلقه (layout thrash)
- سایه‌ها و فیلترهای سنگین روی عناصر زیاد هنگام اسکرول
- سلکتورهای بسیار عمیق و شکننده (بیشتر مشکل نگهداری‌اند تا همیشه سرعت)

---

## 3. جایگزین بهتر

```css
/* سنگین‌تر برای حرکت مداوم */
.box-bad { transition: height 0.3s; }

/* معمولاً بهتر */
.box-good { transition: transform 0.3s; }
.box-good:hover { transform: scale(1.03); }
```

---

## چک‌لیست ذهني
- [ ] حرکت اصلی با transform/opacity
- [ ] توکن و فایل‌ها منظم (کمتر CSS مرده)
- [ ] تصاویر و گرادیان‌های غول‌پیکر بی‌دلیل نه
- [ ] `:has` و افکت‌های سنگین را آگاهانه استفاده کنید
