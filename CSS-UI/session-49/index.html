مقدمه Sass / SCSS

پیش‌پردازنده بنویسید، CSS استاندارد تحویل مرورگر دهید.

توضیحات: session-49-sass-intro.md — منبع: main.scss · خروجی: style.css

گردش کار

  1. main.scss را ویرایش کنید
  2. npx sass main.scss style.css
  3. صفحه را رفرش کنید
npm install -D sass
npx sass main.scss style.css
npx sass --watch main.scss:style.css
این دکمه از style.css استایل می‌گیرد (خروجی Sass).
