# جلسه 47: DevTools برای CSS (2 ساعت)

## اهداف یادگیری
- Inspect کردن عنصر و دیدن باکس مدل
- تشخیص قانون برنده در پنل Styles
- استفاده از Computed برای مقادیر نهایی
- تغییر زنده برای آزمایش سریع

---

## 1. مسیر کار

1. روی عنصر راست‌کلیک → Inspect (یا F12)
2. در **Elements** گره HTML را ببینید
3. در **Styles** قوانین اعمال‌شده و خط‌خورده‌ها را بخوانید
4. در **Computed** مقدار نهایی `width`/`margin` را چک کنید

---

## 2. باکس مدل بصری

در بسیاری از DevToolsها با کلیک روی عنصر، نمودار content / padding / border / margin دیده می‌شود. این همان جلسه ۱۴ است، ولی حالا ابزار واقعی.

---

## 3. تکنیک‌های مفید

- تگگل چک‌باکس کنار هر declaration برای خاموش/روشن کردن
- تغییر موقت رنگ برای پیدا کردن عنصر
- فیلتر کردن قوانین در Styles
- نگاه به specificity وقتی دو قانون می‌جنگند (یادآوری جلسه ۱۳)

---

## تمرین‌های اجباری این جلسه
1. روی جعبهٔ دمو Inspect کنید.
2. `padding` را از DevTools زیاد کنید و تفاوت را ببینید.
3. یک قانون را disable کنید و ببینید کدام قانون بعدی فعال می‌شود.
4. با دکمهٔ صفحه، مقادیر Computed را در خروجی چاپ کنید و با DevTools مقایسه کنید.
