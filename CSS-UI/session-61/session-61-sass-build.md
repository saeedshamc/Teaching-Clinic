# جلسه 61: بیلد Sass با npm (2 ساعت)

## اهداف
- اسکریپت `sass` و `watch`
- source map برای دیباگ
- استفاده از `package.sample.json`

```json
{
  "scripts": {
    "sass": "sass main.scss style.css --source-map",
    "watch": "sass --watch main.scss:style.css"
  }
}
```

## تمرین
روی ماشین خود `npm install -D sass` و `npm run watch` را اجرا کنید.
