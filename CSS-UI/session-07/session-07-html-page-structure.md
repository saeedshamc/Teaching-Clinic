# جلسه 7: ساختار صفحه (2 ساعت)

## اهداف یادگیری
- چیدن landmarkهای HTML5: `header`، `nav`، `main`، `section`، `aside`، `footer`
- فهم اینکه چرا ساختار معنایی برای SEO و a11y مهم است
- اسکلت ذهنی هر لندینگ قبل از استایل سنگین

---

## Landmarkها

```html
<header>
  <nav>...</nav>
</header>
<main>
  <section id="services">...</section>
  <aside>...</aside>
</main>
<footer>...</footer>
```

| تگ | نقش |
|----|-----|
| header | بالای بخش یا صفحه |
| nav | مجموعه لینک‌های ناوبری |
| main | محتوای اصلی (معمولاً یکی) |
| section | بخش موضوعی |
| article | محتوای مستقل قابل‌بازنشر |
| aside | مکمل / کناری |
| footer | پایینی |

---

## تمرین‌ها
### آسان
صفحه با header/main/footer.
### متوسط
nav با ۳ لینک داخلی به sectionها.
### چالش
یک aside برای «نکته روز» اضافه کنید.
