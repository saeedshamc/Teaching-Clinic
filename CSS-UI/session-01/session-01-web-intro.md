# جلسه 1: وب، مرورگر و محیط توسعه (2 ساعت)

## اهداف یادگیری
- فهم اینکه یک صفحه وب چطور از فایل به تصویر روی صفحه می‌رسد
- شناخت نقش HTML، CSS و (در حد نیاز) JavaScript در UI
- راه‌اندازی VS Code، مرورگر و Live Server
- آشنایی با ساختار پوشه‌های این دوره (مثل دوره JavaScript)

---

## 1. وب چیست؟

وقتی آدرسی را در مرورگر باز می‌کنید، معمولاً این مسیر طی می‌شود:

1. مرورگر درخواست می‌فرستد
2. سرور (یا فایل محلی) پاسخ می‌دهد — اغلب یک فایل **HTML**
3. مرورگر HTML را می‌خواند و اگر به CSS/JS لینک شده باشد آن‌ها را هم می‌گیرد
4. صفحه **رسم (render)** می‌شود

در این دوره تمرکز ما روی **ظاهر و سیستم طراحی** است: HTML برای ساختار، CSS/Sass/فریم‌ورک‌ها برای UI.

### سه لایهٔ کلاسیک صفحه

| لایه | نقش | مثال |
|------|-----|------|
| HTML | ساختار و معنا | عنوان، فرم، لینک |
| CSS | ظاهر و چیدمان | رنگ، فاصله، Grid |
| JavaScript | رفتار | باز/بسته کردن منو |

> در جلسات اول عمداً JS را کم نگه می‌داریم؛ فقط برای تمرین محیط و دکمهٔ ساده.

---

## 2. مرورگر و DevTools

مرورگرهای پیشنهادی: Chrome، Edge، Firefox یا Safari به‌روز.

### DevTools را باز کنید
- کلید `F12`
- یا راست‌کلیک روی صفحه → Inspect

زبانهٔ مهم برای این دوره:

- **Elements / Inspector**: درخت HTML و استایل اعمال‌شده
- **Styles / Computed**: قوانین CSS و مقادیر نهایی
- **Console**: پیام‌ها و خطاهای ساده

### تمرین کلاسی (۵ دقیقه)
1. این صفحه را باز کنید
2. DevTools را باز کنید
3. روی یک عنوان کلیک کنید و در Elements ببینیدش
4. در Styles یک ویژگی (مثلاً `color`) را موقتاً عوض کنید

---

## 3. ویرایشگر و Live Server

### VS Code
از [code.visualstudio.com](https://code.visualstudio.com) نصب کنید.

افزونهٔ پیشنهادی: **Live Server** — با راست‌کلیک روی `index.html` → *Open with Live Server*.

بدون افزونه هم می‌توانید از ریشهٔ دوره:

```bash
npx --yes serve .
```

سپس آدرس چاپ‌شده را در مرورگر باز کنید.

> فایل‌هایی که بعداً ماژول/بیلد دارند (Sass، Tailwind با Vite) را با `file://` باز نکنید؛ همان Live Server یا `serve` کافی است.

جزئیات بیشتر: [SETUP.md](../SETUP.md)

## 5. اولین تغییر شما

هدف این بخش این است که «چرخهٔ ویرایش → ذخیره → دیدن نتیجه» را حس کنید.

1. در `index.html` یک جمله به بخش «یادداشت من» اضافه کنید
2. در `style.css` رنگ `--accent` را عوض کنید
3. دکمهٔ «ثبت وضعیت محیط» را بزنید و خروجی را ببینید
4. Console را باز کنید و پیام `session-01 ready` را پیدا کنید

## تمرین‌ها

### آسان
عنوان صفحه (`<title>`) را به نام خودتان تغییر دهید و تب مرورگر را چک کنید.

### متوسط
در `style.css` اندازهٔ فونت بدنه را کمی بزرگ‌تر کنید و با DevTools مقدار Computed را ببینید.

### چالش
یک باکس جدید در HTML بسازید و فقط با CSS یک حاشیهٔ رنگی به آن بدهید.
