# جلسه 4: جدول و رسانه (2 ساعت)

## اهداف یادگیری
- ساخت جدول معنایی با `caption`، `thead`، `tbody`، `th`، `td`
- درک `scope` برای دسترس‌پذیری جدول
- آشنایی با `<video>` و `<audio>` و ویژگی `controls`

---

## 1. جدول درست

```html
<table>
  <caption>مقایسه پلن‌ها</caption>
  <thead>
    <tr>
      <th scope="col">پلن</th>
      <th scope="col">قیمت</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">پایه</th>
      <td>۰</td>
    </tr>
  </tbody>
</table>
```

- `caption` موضوع جدول را می‌گوید
- `th` برای سرستون/سرردیف؛ `td` برای داده
- `scope="col"` یا `scope="row"` به خواندن صفحه‌خوان کمک می‌کند

---

## 2. چه موقع جدول؟

جدول برای **دادهٔ جدولی** است (قیمت، گزارش، مقایسه)، نه برای چیدمان کل صفحه. چیدمان را با CSS (Flex/Grid) انجام دهید.

---

## 3. ویدیو و صدا

```html
<video controls width="640" poster="cover.jpg">
  <source src="movie.mp4" type="video/mp4">
  مرورگر شما از ویدیو پشتیبانی نمی‌کند.
</video>

<audio controls>
  <source src="note.mp3" type="audio/mpeg">
</audio>
```

در این جلسه به‌خاطر وابستگی به فایل رسانه، برچسب‌ها و ساختار را یاد می‌گیرید؛ منبع واقعی را در پروژه خودتان بگذارید.

---

## اشتباهات رایج
- جدول برای لی‌اوت صفحه
- فقط `td` بدون `th`
- ویدیو autoplay با صدا (آزاردهنده و اغلب بلاک می‌شود)

---
