# جلسه 22: Flexbox ظرف (2 ساعت)

## اهداف
- `display: flex`
- محور اصلی/متقاطع: `justify-content`، `align-items`
- `gap`، `flex-direction`، `flex-wrap`

```css
.row {
  display: flex;
  gap: 1rem;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
}
```

Flex برای چیدمان یک‌بعدی (ردیف یا ستون) عالی است.

## تمرین
هدر با لوگو و منو؛ در عرض کم wrap شود.
