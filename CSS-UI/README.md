# دوره تخصصی CSS / Sass / UI Frameworks

مخاطب: از صفر مطلق تا کار حرفه‌ای با CSS، Sass و سه فریم‌ورک UI جداگانه (Bootstrap 5، Tailwind CSS، Bulma).

پیش‌نیاز ابزار: [SETUP.md](./SETUP.md)

جدول کامل: [SYLLABUS.md](./SYLLABUS.md) — برگهٔ سریع: [QUICK_REFERENCE.md](./QUICK_REFERENCE.md)

## نحوهٔ مطالعه

هر جلسه حدود ۲ ساعت است. ترتیب را حفظ کنید؛ فریم‌ورک‌ها تعمداً **جدا و کامل** تدریس می‌شوند.

ساختار هر جلسه مثل دورهٔ JS:

```
session-XX/
  ├── index.html
  ├── style.css
  ├── script.js
  ├── session-XX-*.md
  └── (در جلسات Sass/ابزار: main.scss یا فایل نمونهٔ بیلد)
```
