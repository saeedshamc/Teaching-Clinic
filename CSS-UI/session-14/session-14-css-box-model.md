# جلسه 14: Box Model (2 ساعت)

## اهداف
- اجزا: content، padding، border، margin
- `box-sizing: border-box`

```css
* { box-sizing: border-box; }
.box {
  width: 200px;
  padding: 20px;
  border: 4px solid #1d4ed8;
  margin: 20px;
}
```

با `content-box` (پیش‌فرض قدیمی)، width فقط محتواست؛ با `border-box` padding و border داخل width حساب می‌شوند.
