# جلسه 29: Transition (2 ساعت)

## اهداف
- `transition-property`، `duration`، `timing-function`
- انیمیت ویژگی‌های امن (رنگ، transform، opacity)

```css
.btn {
  transition: transform .25s ease, background .25s ease;
}
.btn:hover {
  transform: translateY(-3px);
}
```

از `transition: all` بی‌رویه پرهیز کنید.
