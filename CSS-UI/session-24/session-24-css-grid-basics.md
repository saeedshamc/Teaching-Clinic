# جلسه 24: Grid پایه (2 ساعت)

## اهداف
- `display: grid`
- `grid-template-columns` / `rows`
- `gap` و قرارگیری ساده

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 1rem;
}
```

Grid برای چیدمان دوبعدی است؛ Flex برای یک محور.
