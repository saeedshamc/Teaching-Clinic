# جلسه 65: Utilities در Bootstrap (2 ساعت)

## اهداف
- فاصله: `m-*`، `p-*`، `g-*`
- نمایش: `d-none`، `d-flex`، `d-md-block`
- رنگ متن/پس‌زمینه و `fw-bold`

```html
<div class="d-flex justify-content-between p-3 bg-dark text-white">...</div>
```

Utilityها برای تنظیم سریع‌اند؛ منطق تکراری UI را بهتر است به کامپوننت بسپارید.
