# جلسه 20: Positioning (2 ساعت)

## اهداف
- `static`، `relative`، `absolute`، `fixed`، `sticky`
- مرجع positioning برای `absolute`

```css
.parent { position: relative; }
.child { position: absolute; inset: auto 1rem 1rem auto; }
.sticky { position: sticky; top: 0; }
```
