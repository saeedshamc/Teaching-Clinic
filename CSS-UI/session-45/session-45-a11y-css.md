# جلسه 45: دسترسی‌پذیری در CSS (2 ساعت)

## اهداف یادگیری
- تأمین کنتراست کافی متن و پس‌زمینه
- فوکوس کیبورد با `:focus-visible`
- احترام به `prefers-reduced-motion`
- پرهیز از حذف بی‌جای `outline`

---

## 1. کنتراست

متن کم‌رنگ روی پس‌زمینه روشن خوانده نمی‌شود. برای متن عادی معمولاً نسبت کنتراست حدود 4.5:1 هدف‌گذاری می‌شود (WCAG AA).

در عمل: رنگ را در DevTools یا ابزار کنتراست چک کنید؛ فقط «قشنگ» کافی نیست.

---

## 2. فوکوس قابل‌دیدن

```css
.btn:focus-visible {
  outline: 3px solid #c4b5fd;
  outline-offset: 3px;
}
```

`:focus-visible` معمولاً وقتی با کیبورد می‌آیید نشان داده می‌شود؛ تجربهٔ ماوس به‌هم نمی‌ریزد.

**هرگز** بدون جایگزین، `outline: none` نگذارید.

---

## 3. حرکت کمتر

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation: none !important;
    transition: none !important;
    scroll-behavior: auto !important;
  }
}
```

کاربرانی که حرکت زیاد برایشان آزاردهنده است، سیستم‌عامل را روی reduce می‌گذارند؛ UI باید احترام بگذارد.

---

## اشتباهات رایج
- کنتراست خاکستری روشن روی سفید
- حذف outline برای «زیبایی»
- انیمیشن بی‌پایان بدون راه توقف / reduce

---

## تمرین‌ها
### آسان
با Tab روی لینک و دکمه بروید و outline را ببینید.
### متوسط
یک دکمه با focus-visible سفارشی بسازید.
### چالش
یک انیمیشن بسازید که با reduced-motion خاموش شود.

## خلاصه
a11y فقط ARIA نیست؛ CSS هم مسئول خوانایی، فوکوس و حرکت است.
