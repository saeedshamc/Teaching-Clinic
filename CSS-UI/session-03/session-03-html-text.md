# جلسه 3: متن، لیست، لینک و تصویر (2 ساعت)

## اهداف یادگیری
- استفاده از headingها و پاراگراف برای سلسله‌مراتب محتوا
- ساخت لیست مرتب و نامرتب
- لینک داخلی، خارجی و ویژگی‌های امن `target` / `rel`
- درج تصویر با `alt` معنادار و اندازهٔ واکنش‌گرا

---

## 1. متن و عنوان‌ها

```html
<h1>عنوان اصلی صفحه</h1>
<h2>بخش</h2>
<p>بدنهٔ متن. برای تاکید معنایی از <strong>مهم</strong> و <em>تاکید</em> استفاده کنید.</p>
```

قوانین کاربردی:
- معمولاً **یک `h1`** در هر صفحه
- سطوح را نپرید (h1 → h3 بدون h2)
- `b`/`i` فقط ظاهری‌اند؛ برای معنا `strong`/`em` بهتر است

---

## 2. لیست‌ها

```html
<ul>
  <li>آیتم بدون ترتیب</li>
</ul>

<ol>
  <li>گام اول</li>
  <li>گام دوم</li>
</ol>
```

`dl` / `dt` / `dd` برای اصطلاح و تعریف هم مفید است (در تمرین چالش).

---

## 3. لینک‌ها

```html
<a href="https://developer.mozilla.org/">MDN</a>
<a href="#gallery">برو به گالری</a>
<a href="https://example.com" target="_blank" rel="noopener noreferrer">خارجی در تب جدید</a>
```

- `#id` برای پرش داخل صفحه
- با `target="_blank"` همیشه `rel="noopener noreferrer"` بگذارید

---

## 4. تصویر

```html
<img
  src="https://placehold.co/640x240/0f766e/ffffff?text=UI"
  alt="نمونه بنر رابط کاربری با پس‌زمینه سبز"
  width="640"
  height="240"
>
```

- `alt` را خالی نگذارید مگر تصویر صرفاً تزئینی باشد (`alt=""`)
- `width`/`height` از پرش لایه‌اوت هنگام لود کم می‌کند
- در CSS معمولاً `max-width: 100%; height: auto;`

---

## اشتباهات رایج
- لینک بدون متن معنادار («اینجا کلیک کنید»)
- `alt` تکراری یا بی‌فایده («تصویر»)
- چند h1 در یک لندینگ بدون دلیل
- باز کردن تب جدید بدون `rel`

---

## تمرین‌ها

### آسان
یک بخش «خدمات» با `h2` و لیست `ul` سه آیتمی بسازید.

### متوسط
تصویر + `figcaption` داخل `figure` اضافه کنید.

### چالش
فهرست تعریف (`dl`) برای سه اصطلاح HTML بسازید.

---

## خلاصه
متن، لیست، لینک و تصویر اسکلت محتوای تقریباً هر UI هستند.
