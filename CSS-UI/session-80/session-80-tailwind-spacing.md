# جلسه 80: Spacing و Sizing در Tailwind (2 ساعت)

## اهداف یادگیری
- مقیاس فاصله: `p-*`، `m-*`، `gap-*`
- عرض و ارتفاع: `w-*`، `h-*`، `max-w-*`، `min-h-*`
- فاصله منطقی RTL: `ms-*`، `me-*`، `ps-*`، `pe-*`
- ساخت باکس‌های تو در تو بدون CSS جدا

---

## 1. مقیاس عددی

اعداد رایج به `0.25rem` ضرب می‌شوند:

| کلاس | تقریباً |
|------|---------|
| `p-1` | 0.25rem |
| `p-2` | 0.5rem |
| `p-4` | 1rem |
| `p-6` | 1.5rem |
| `p-8` | 2rem |

همین الگو برای `m-*`، `gap-*`، `space-x-*` / `space-y-*`.

جهت‌دار:
- `pt` `pr` `pb` `pl` — فیزیکی
- `ps` `pe` — منطقی (با RTL بهتر)

---

## 2. عرض

```html
<div class="w-full max-w-md mx-auto">محتوای محدود</div>
```

| کلاس | معنا |
|------|------|
| `w-full` | 100% |
| `w-1/2` | 50% |
| `max-w-sm` / `md` / `lg` / `xl` | سقف عرض |
| `min-h-screen` | حداقل ارتفاع ویوپورت |

---

## 3. الگوی کارت

```html
<article class="mx-auto max-w-sm rounded-xl bg-white p-6 shadow">
  <h2 class="text-lg font-bold">عنوان</h2>
  <p class="mt-2 text-slate-600">متن</p>
</article>
```

`mt-2` فاصله از عنوان؛ `p-6` پدینگ داخلی؛ `max-w-sm` عرض کارت.

---

## اشتباهات رایج
- ترکیب بی‌هدف ده‌ها margin روی یک عنصر
- استفاده از `ml`/`mr` به‌جای `ms`/`me` در RTL
- `w-screen` روی عنصری که باعث اسکرول افقی می‌شود

---

## تمرین‌ها
### آسان
پدینگ کارت را از `p-6` به `p-8` ببرید.
### متوسط
سه باکس با `gap-4` در یک `flex` بچینید.
### چالش
یک نوار با `px-4 py-3` و لوگوی `me-3` بسازید.
