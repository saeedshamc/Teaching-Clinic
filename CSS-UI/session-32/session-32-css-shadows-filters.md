# جلسه 32: Shadow و Filter (2 ساعت)

## اهداف
- `box-shadow` برای elevation
- `filter` و اشاره به `backdrop-filter`

```css
.card { box-shadow: 0 20px 40px rgba(15,23,42,.25); }
.shot img { filter: contrast(1.05) saturate(1.1); }
```

سه سطح سایه تعریف کنید نه سایه تصادفی روی همه چیز.
