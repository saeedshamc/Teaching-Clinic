# جلسه 15: واحدها (2 ساعت)

## اهداف
- `px`، `%`، `em`، `rem`
- واحدهای viewport: `vh` / `vw`
- `calc()` و `clamp()` برای اندازهٔ سیال

```css
.fluid { font-size: clamp(1rem, 2vw + .8rem, 1.6rem); }
.bar { width: calc(100% - 2rem); }
```

پیشنهاد: برای تایپ و فاصلهٔ پایدار بیشتر از `rem` استفاده کنید.
