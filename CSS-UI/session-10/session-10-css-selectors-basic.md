# جلسه 10: سلکتورهای پایه (2 ساعت)

## اهداف
- سلکتور element، class و id
- چه موقع class و چه موقع id

```css
p { color: #334155; }      /* element */
.hl { color: #16a34a; }    /* class — قابل تکرار */
#unique { color: #dc2626; } /* id — یکتا */
```

قانون طلایی: برای استایل روزمره **class**؛ id را بیشتر برای لنگر/JS نگه دارید.

## تمرین
یک کارت با کلاس و یک عنوان با id بسازید.
