# جلسه 12: Pseudo-class و Pseudo-element (2 ساعت)

## اهداف
- stateها: `:hover`، `:focus-visible`، `:active`
- شبه‌عنصر: `::before`، `::after`

```css
.link:hover { color: #b45309; }
.link:focus-visible { outline: 3px solid #93c5fd; }
.note::before { content: "※ "; color: #b45309; }
```

هرگز `outline` را بدون جایگزین دسترسی‌پذیر حذف نکنید.
