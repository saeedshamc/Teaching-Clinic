# جلسه 92: استخراج کامپوننت بدون فریم‌ورک JS (2 ساعت)

## اهداف یادگیری
- تشخیص تکرار کلاس‌ها
- استخراج به کلاس معنایی (با @apply یا CSS معمولی)
- یا استخراج به «قالب» HTML تکراری / web component ساده
- تعادل بین utility خالص و نام‌گذاری

---

## 1. بوی تکرار

اگر این رشته را بیش از ۲–۳ بار می‌بینید، کاندید استخراج است:

```
rounded-xl border bg-white p-5 shadow-sm
```

گزینه‌ها:
1. `@apply` → `.card`
2. تابع/کامپوننت در React/Vue (خارج از این دوره)
3. snippet در ادیتور

---

## 2. الگوی این جلسه

در `style.css` کلاس‌های `.ui-card` و `.ui-btn` تعریف شده‌اند تا HTML خواناتر شود — بدون ترک کامل utility برای جزئیات یک‌بارمصرف.

```html
<article class="ui-card">
  <h2 class="text-lg font-bold">...</h2>
  <button class="ui-btn">...</button>
</article>
```

---

## 3. قانون سرانگشتی

- یک‌بار مصرف → utility در HTML
- تکرار و معنای دامنه (دکمه اصلی، کارت محصول) → نام معنایی
- هرگز همه چیز را abstract نکنید

---

## تمرین‌ها
### آسان
یک `.ui-badge` بسازید.
### متوسط
دو کارت محصول با همان الگوی استخراج‌شده.
### چالش
دکمه primary و secondary را جدا کنید.
