# جلسه 26: Media Query (2 ساعت)

## اهداف
- رویکرد mobile-first با `min-width`
- تعریف breakpoint عملی

```css
.resp { background: #fee2e2; }
@media (min-width: 768px) {
  .resp { background: #dcfce7; }
}
```

از کوچک شروع کنید و قابلیت اضافه کنید؛ از پراکندگی فقط `max-width` بپرهیزید.
