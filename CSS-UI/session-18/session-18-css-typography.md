# جلسه 18: تایپوگرافی وب (2 ساعت)

## اهداف
- `font-family`، `font-size`، `font-weight`، `line-height`
- سلسله‌مراتب عنوان و بدنه
- نکتهٔ فونت وب (سیستم / لینک فونت)

```css
.type h1 { font-family: Georgia, serif; letter-spacing: -0.02em; }
.type p { line-height: 1.9; max-width: 40rem; }
```

خوانایی مهم‌تر از تزئین است؛ عرض خط را خیلی طولانی نکنید.
