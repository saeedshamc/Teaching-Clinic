# جلسه 33: استایل فرم (2 ساعت)

## اهداف
- استایل `input` / `textarea` / `button`
- stateهای `:focus`، `:hover`، `:disabled`
- حفظ outline دسترسی‌پذیر

```css
input:focus {
  outline: 3px solid #93c5fd;
  border-color: #2563eb;
}
button:disabled { opacity: .5; }
```
