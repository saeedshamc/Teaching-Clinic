# جلسه ۰۸: جنریک‌های پایه (۹۰ دقیقه)

**محیط فرض:** TypeScript 5.x · strict

## پیش‌نیازها
جلسات ۰۵–۰۶.

## اهداف قابل‌اندازه‌گیری
1. تابع جنریک با `<T>` بنویسید
2. `type Box<T> = { value: T }` تعریف کنید
3. محدودیت ساده با `extends` بگذارید
4. بگویید جنریک چه فرقی با `any` دارد

## چرا مهم است؟
`identity`، `map`، مخزن داده — بدون جنریک یا نوع را از دست می‌دهید یا تکرار می‌کنید.

## مفهوم عمیق
```ts
function first<T>(items: T[]): T | undefined {
  return items[0];
}

type ApiResponse<T> = {
  data: T;
  status: number;
};
```

`T` یک پارامتر نوع است؛ در هر فراخوانی پر می‌شود.

## اشتباه‌های رایج
1. `<T>` بی‌قید روی همه چیز بدون نیاز.
2. برگشت `any` داخل تابع جنریک.
3. قاطی کردن نام `T` با مقدار runtime.

## مثال گام‌به‌گام
```bash
npx tsx session-08-generics/examples/01-generics.ts
```

## الگوی بهتر
جنریک را سر مرزهای کتابخانه/کمک‌تابع بگذارید؛ دامنهٔ بیزنس را با type نام‌دار مدل کنید.

## تمرین‌ها
### آسان
`function wrap<T>(value: T): { value: T }`
### چالشی
`function pluck<T, K extends keyof T>(obj: T, key: K): T[K]`

## راهنمای حل
`return obj[key];` — `K extends keyof T` کلید معتبر را محدود می‌کند.

## خودآزمایی
1. جنریک چه مشکلی از `any` را حل می‌کند؟
2. `keyof` یعنی چه؟
3. محدودیت `extends` روی پارامتر نوع چه می‌کند؟
4. آیا می‌توان دو پارامتر نوع داشت؟
5. inference برای `T` از آرگومان چگونه است؟

## جمع‌بندی و پل جلسهٔ بعد
جنریک پایه. جلسه بعد: Utility types آمادهٔ TypeScript.
