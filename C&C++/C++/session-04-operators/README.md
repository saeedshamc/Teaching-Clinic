# جلسهٔ ۴ — عملگرها و عبارات

> تا اینجا داده را ذخیره و چاپ کردیم. حالا با داده **کار** می‌کنیم: جمع، مقایسه، شرط منطقی و ترتیب اجرا.

---

## اهداف این جلسه

1. عملگرهای حسابی، مقایسه‌ای، منطقی و انتسابی را بشناسید.
2. بدانید `++i` و `i++` چه تفاوتی دارند و کجا مهم می‌شوند.
3. اولویت عملگرها را بفهمید و با پرانتز کد خوانا بنویسید.
4. دام تقسیم صحیح، باقی‌مانده و سرریز را بشناسید.
5. بدانید چرا مقایسهٔ دقیق اعداد اعشاری خطرناک است.

---

## ۱. عملگرهای حسابی

| عملگر | معنا | نمونه | نتیجه |
|---|---|---|---|
| `+` | جمع | `7 + 3` | `10` |
| `-` | تفریق | `7 - 3` | `4` |
| `*` | ضرب | `7 * 3` | `21` |
| `/` | تقسیم | `7 / 2` | `3` (صحیح!) |
| `%` | باقی‌مانده | `7 % 2` | `1` |

`%` فقط روی اعداد صحیح کار می‌کند. برای اعشاری از `std::fmod` استفاده می‌شود (به‌ندرت لازم است).

فرم‌های کوتاه (compound assignment):

```cpp
int total = 10;
total += 5;    // total = total + 5  → 15
total -= 3;    // 12
total *= 2;    // 24
total /= 5;    // 4
total %= 3;    // 1
```

---

## ۲. افزایش و کاهش: `++` و `--`

```cpp
int i = 5;
++i;    // پیش‌افزایش: اول += 1 بعد استفاده → i = 6
i++;    // پس‌افزایش: اول استفاده بعد += 1
```

تفاوت وقتی دیده می‌شود که مقدار را همان‌جا استفاده کنید:

```cpp
int a = 5;
int b = a++;   // b = 5، سپس a = 6
int c = ++a;   // a = 7، سپس c = 7
```

در حلقه‌ها (جلسهٔ ۶) تفاوت عملی ندارد و `++i` کمی طبیعی‌تر است. در عبارات پیچیده، `i++` خواندن کد را سخت می‌کند؛ جدا بنویسید.

---

## ۳. عملگرهای مقایسه‌ای

| عملگر | معنا |
|---|---|
| `==` | مساوی |
| `!=` | نامساوی |
| `<`، `<=` | کوچک‌تر، کوچک‌تر یا مساوی |
| `>`، `>=` | بزرگ‌تر، بزرگ‌تر یا مساوی |

نتیجهٔ مقایسه همیشه `bool` است: `true` یا `false`.

```cpp
int age = 20;
bool adult = age >= 18;   // true
```

> **خطر شمارهٔ یک C++:** `=` انتساب است و `==` مقایسه. نوشتن `if (x = 5)` مقدار ۵ را در `x` می‌گذارد و همیشه درست است. کامپایلر با `-Wall` برای بعضی حالت‌ها هشدار می‌دهد؛ در حالت‌های مبهم از `if (5 == x)` استفاده کنید یا بیشتر `const` بنویسید.

---

## ۴. عملگرهای منطقی

| عملگر | معنا | نمونه |
|---|---|---|
| `&&` | و (هر دو درست) | `age >= 18 && age < 65` |
| `\|\|` | یا (حداقل یکی) | `day == 6 \|\| day == 7` |
| `!` | نقیض | `!isReady` |

**ارزیابی کوتاه‌مدار (short-circuit):**

```cpp
if (count != 0 && total / count > 10) { ... }
```

اگر `count == 0` باشد، سمت راست **اجرا نمی‌شود**؛ پس تقسیم بر صفر رخ نمی‌دهد. این ویژگی را برای محافظت از کد استفاده کنید.

---

## ۵. اولویت عملگرها

ترتیب کلی از بالا به پایین (قوی‌تر به ضعیف‌تر):

1. `()` — پرانتز
2. `++`، `--`، `!` (یکانی)
3. `*`، `/`، `%`
4. `+`، `-`
5. `<`، `<=`، `>`، `>=`
6. `==`، `!=`
7. `&&`
8. `||`
9. `=`, `+=`, ...

نمونه‌های کلاسیک که همه اشتباه می‌کنند:

```cpp
int a = 2 + 3 * 4;        // 14 نه 20
bool b = 1 < 2 == true;   // (1 < 2) == true → true
int c = 10 - 4 - 3;       // 3 نه 9 (چپ‌به‌راست)
```

قاعده: **اگر برای فهم عبارت باید فکر کنید، پرانتز بگذارید.** پرانتز هزینه ندارد و کد را برای نفر بعدی (احتمالاً خودتان) خوانا می‌کند.

## ۶. تقسیم صحیح و باقی‌مانده

```cpp
int a = 7, b = 2;
std::cout << a / b;   // 3   (بخش اعشاری حذف می‌شود، نه گِرد)
std::cout << a % b;   // 1
```

نکته‌های مهم:

- `-7 / 2` در C++17 برابر `-3` است (به سمت صفر می‌رود) و `-7 % 2` برابر `-1`.
- برای اعشاری، یکی از دو طرف را `double` کنید: `static_cast<double>(a) / b`.
- کاربردهای `%`: تشخیص زوج/فرد (`n % 2 == 0`)، تقسیم به رقم‌ها (`n % 10`)، چرخش در بازه (`i % size`).

---

## ۷. سرریز (overflow)

هر نوع بازهٔ محدودی دارد. اگر نتیجه از بازه بیرون بزند، برای انواع **علامت‌دار** رفتار تعریف‌نشده (UB) است — ممکن است عدد عجیب بدهید، ممکن است برنامه کرش کند، ممکن است درست کار کند و در سیستم دیگر خراب شود.

```cpp
int a = 100000;
int b = 100000;
// int bad = a * b;   // 10^10 از بازهٔ int بیرون است → UB
long long safe = static_cast<long long>(a) * b;   // درست: 10000000000
```

برای `unsigned` سرریز **تعریف‌شده** است و دور می‌زند (modulo 2^n)، ولی معمولاً همان‌قدر خطرناک است:

```cpp
unsigned int u = 0;
u = u - 1;      // 4294967295 (!)
```

پیشگیری: نوع بزرگ‌تر (`long long`)، بررسی قبل از عمل، یا `std::numeric_limits` برای مقایسه.

## ۸. مقایسهٔ اعداد اعشاری

اعداد اعشاری در حافظه دقیق ذخیره نمی‌شوند:

```cpp
0.1 + 0.2 == 0.3   // معمولاً false!
```

راه درست: مقایسهٔ اختلاف با یک آستانهٔ کوچک:

```cpp
#include <cmath>
constexpr double eps = 1e-9;
bool equal = std::fabs((0.1 + 0.2) - 0.3) < eps;
```

## ۱۰. اشتباهات رایج

1. `if (x = 5)` به‌جای `if (x == 5)`.
2. انتظار `7 / 2 == 3.5` بدون cast.
3. `%` روی `double` (خطای کامپایل).
4. `2 + 3 * 4` را ۲۰ انتظار داشتن.
5. فرض اینکه `-7 % 2` برابر `1` است (در C++ `-1` است).
6. `int` برای جمع‌های بزرگ؛ سرریز UB است.
7. مقایسهٔ `float`/`double` با `==`.

---

## ۱۱. بهترین شیوه‌ها

- برای وضوح، پرانتز بگذارید.
- تقسیم اعشاری را با `static_cast<double>` صریح کنید.
- قبل از ضرب اعداد بزرگ، نوع را بالا ببرید.
- `++count` را در حلقه ترجیح دهید و افزایش‌ها را از وسط عبارت بیرون بکشید.
- برای اعداد پولی، به‌جای `double` از «سِنت» به‌صورت `long long` استفاده کنید (جلسهٔ ۴۹ هم ابزارهای بیشتر می‌دهد).

---

## ۱۲. خلاصه

- `/` بین دو `int` صحیح است و `%` باقی‌مانده می‌دهد.
- `++i` اول افزایش، `i++` اول استفاده.
- `&&` و `||` کوتاه‌مدار هستند و می‌توانند از خطا جلوگیری کنند.
- اولویت عملگرها را بشناسید، ولی با پرانتز صریح بنویسید.
- سرریز علامت‌دار UB است؛ نوع بزرگ‌تر یا بررسی قبلی لازم است.
- اعشاری را با اختلاف کوچک مقایسه کنید.
