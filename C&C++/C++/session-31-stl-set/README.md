# جلسهٔ ۳۱ — `set` و `unordered_set`

> مجموعه یعنی «هر عضو یک بار». اگر یکتایی می‌خواهید، خودتان بررسی نکنید؛ `set` این کار را برایتان می‌کند.

---

## اهداف این جلسه

1. `set` را بسازید و بدانید چرا تکراری‌ها خودکار حذف می‌شوند.
2. از نتیجهٔ `insert` (`pair<iterator, bool>`) استفاده کنید.
3. با `count`/`find` عضویت را بررسی کنید.
4. عملگرهای مجموعه‌ای (`set_intersection`، `set_union`، `set_difference`) را به کار ببرید.
5. تفاوت `set` و `unordered_set` را بشناسید.

---

## ۱. `set` چیست

`std::set<T>` مجموعه‌ای از عناصر **یکتا** و **مرتب** است که با درخت متوازن پیاده شده:

- درج، حذف و جستجو `O(log n)`.
- ترتیب پیمایش همیشه صعودی است (بر اساس `operator<`).
- هیچ عنصری دو بار وجود ندارد؛ `insert` تکراری نادیده گرفته می‌شود.

```cpp
std::set<int> values{5, 1, 4, 1, 5};   // {1, 4, 5}
```

خروجی واقعی:

```
--- ساخت از فهرست با تکرار ---
  {1, 4, 5}  size = 3
```

پنج مقدار دادیم، سه عضو ماند — و مرتب شد.

---

## ۲. `insert` نتیجه‌دار

`insert` فقط درج نمی‌کند؛ **گزارش** می‌دهد که آیا درج شد:

```cpp
const auto [it, inserted] = values.insert(7);
```

- `it` به عنصر (جدید یا موجود) اشاره می‌کند.
- `inserted` می‌گوید آیا این فراخوانی چیزی اضافه کرد.

خروجی واقعی:

```
  insert(4) → inserted = خیر، مقدار در تکرارگر: 4
  insert(7) → inserted = بله، مقدار: 7
  {1, 4, 5, 7}  size = 4
```

این «درج یا بررسی» در یک عملیات، مزیت اصلی `set` بر `vector` است: با `vector` باید اول `find` بزنید و بعد `push_back`، یعنی دو جستجو.

---

## ۳. عضویت: `count` و `find`

```cpp
if (values.count(5) > 0) { /* هست */ }        // ۰ یا ۱
if (values.find(5) != values.end()) { /* هست */ }
```

در `set` مقدار `count` همیشه ۰ یا ۱ است، پس می‌توانید مستقیم به `bool` تبدیلش کنید:

```cpp
if (values.count(5)) { ... }
```

خروجی واقعی:

```
  count(5) = 1، count(9) = 0
  7 پیدا شد
```

`find` وقتی مفید است که به خود عنصر نیاز داشته باشید؛ `count` فقط وجود را می‌گوید و کوتاه‌تر است.

---

## ۴. حذف

```cpp
values.erase(5);   // با مقدار؛ تعداد حذف‌شده را برمی‌گرداند
```

```
--- erase با مقدار ---
  {1, 4, 7}  size = 3
```

`erase` در `set` دو شکل دارد: با مقدار (که تعداد حذف را برمی‌گرداند) و با تکرارگر.

---

## ۵. `unordered_set`

همان مجموعه، با جدول هش:

| ویژگی | `set` | `unordered_set` |
|---|---|---|
| جستجو | `O(log n)` | میانگین `O(1)` |
| ترتیب پیمایش | صعودی | **نامشخص** |
| نیاز نوع | `operator<` | `operator==` + هش |

```cpp
const std::unordered_set<int> fast{3, 1, 2, 1};
```

```
--- unordered_set ---
  size = 3 (ترتیب چاپ تضمین‌شده نیست)
  count(2) = 1
```

سه مقدار یکتا از چهار ورودی. برای بررسی عضویت سریع (مثلاً «این کلمه در دیکشنری هست؟») `unordered_set` انتخاب اول است؛ وقتی ترتیب هم مهم شد، `set`.

---

## ۶. عملگرهای مجموعه‌ای

کتابخانهٔ `<algorithm>` توابع آماده برای عملیات مجموعه‌ها دارد. همه ورودی **مرتب** می‌خواهند — و `set` همیشه مرتب است، پس ترکیب طبیعی‌اند.

```cpp
std::set<int> result;
std::set_intersection(a.begin(), a.end(), b.begin(), b.end(),
                      std::inserter(result, result.end()));
```

| تابع | معنی |
|---|---|
| `set_intersection` | اشتراک `A ∩ B` |
| `set_union` | اجتماع `A ∪ B` |
| `set_difference` | `A − B` (فقط در A) |
| `set_symmetric_difference` | در یکی هست و در دیگری نه |
| `includes` | آیا A همهٔ اعضای B را دارد؟ |

خروجی واقعی `02_set_operations.cpp`:

```
--- ورودی‌ها ---
  A = {1, 2, 3, 4, 5}
  B = {4, 5, 6, 7}
--- نتیجه ---
  A ∩ B = {4, 5}
  A ∪ B = {1, 2, 3, 4, 5, 6, 7}
  A − B = {1, 2, 3}
  A △ B = {1, 2, 3, 6, 7}
--- عضویت ---
  5 در A؟ بله
  6 در A؟ خیر
```

`std::inserter(result, result.end())` یک تکرارگر خروجی می‌سازد که هر عنصر را با `insert` در مجموعه می‌گذارد. بدون آن، الگوریتم جایی برای نوشتن ندارد؛ `begin()` مستقیم کار نمی‌کند چون `set` اندازه‌اش از قبل معلوم نیست.

## ۸. اشتباهات رایج

1. **`values[0]` روی `set`** → `set` عملگر `[]` ندارد؛ با تکرارگر کار کنید.
2. **انتظار ترتیب درج** → `set` بر اساس مقدار مرتب می‌کند، نه ورود.
3. **تغییر عنصر داخل مجموعه** → عناصر `set` ثابت (`const`) هستند؛ برای تغییر باید حذف و دوباره درج کنید.
4. **استفاده از `std::sort` روی `set`** → از قبل مرتب است و تکرارگر آن قابل نوشتن نیست؛ خطای کامپایل.
5. **`set_intersection` روی دادهٔ نامرتب** → خروجی ناقص و بی‌معنی. ورودی باید مرتب باشد.
6. **`push_back` روی `set`** → وجود ندارد؛ `insert`.
7. **مقایسهٔ `set<float>`** → خطای گردکردن اعشار می‌تواند دو مقدار «برابر» بسازد که به‌نظر متفاوت‌اند؛ برای مختصات اعشاری احتیاط کنید.
8. **کلید سفارشی بدون `operator<`** → خطای کامپایل طولانی.

---

## ۹. بهترین شیوه‌ها

- برای یکتاسازی مجموعه‌ای از داده، `std::set<T>(input.begin(), input.end())` یک خط است.
- برای حذف تکراری‌ها و حفظ ترتیب اصلی، به `set` تکیه نکنید؛ مرتب می‌شود (راه دیگر: `unordered_set` + فیلتر حفظ ترتیب).
- برای عضویت سریع و بی‌ترتیب، `unordered_set`.
- از `insert` نتیجه‌دار برای «درج اگر نبود» استفاده کنید.
- برای عملگرهای مجموعه‌ای همیشه هر دو ورودی را مرتب کنید.

---

## ۱۰. خلاصه

- `set` یکتا و مرتب است، `O(log n)`.
- `insert` یک `pair<iterator, bool>` برمی‌گرداند که می‌گوید درج شد یا نه.
- `count`/`find` عضویت را در `O(log n)` بررسی می‌کنند.
- `unordered_set` سریع‌تر ولی بی‌ترتیب است.
- `set_intersection`/`set_union`/`set_difference` عملیات مجموعه‌ای را با ورودی مرتب انجام می‌دهند.
