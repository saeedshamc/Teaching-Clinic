# پرامپت — تولید دوره آموزشی C++ (۵۰ جلسه)

می‌خوام یک دوره آموزشی کامل و جامع زبان C++ برای من بسازی، شامل ۵۰ جلسه، از سطح مطلقاً صفر تا سطح حرفه‌ای (شامل OOP کامل، STL، مدیریت حافظه مدرن و ویژگی‌های C++ جدید). تمام توضیحات باید به **زبان فارسی** باشد. خروجی باید شامل فایل‌های کد اجرایی + یک README آموزشی و روان برای هر جلسه باشد.

## ساختار کلی پوشه‌بندی

```
cpp/
├── README.md                     (فهرست کلی دوره، معرفی، پیش‌نیازها، نحوه استفاده)
├── session-01-intro/
│   ├── README.md
│   ├── examples/
│   │   ├── 01_example.cpp
│   │   ├── 02_example.cpp
│   │   └── ...
│   └── exercises/
│       └── exercise_01.cpp
├── session-02-.../
│   └── ... (همین ساختار)
...
├── session-50-.../
│   └── ...
```

هر جلسه باید پوشه مستقل خودش را داشته باشد با نام‌گذاری واضح (مثلاً `session-20-inheritance-basics`).

## الزام Git و کامیت‌ها

- ابتدا یک ریپازیتوری Git با `git init` در ریشه پروژه بساز و یک `.gitignore` مناسب برای پروژه‌های C++ (فایل‌های باینری، پوشه‌های build، `*.o`، و غیره) اضافه کن.
- **بعد از تکمیل کامل هر جلسه** (README + `examples/` + `exercises/` نوشته و تست‌شده)، یک کامیت جداگانه برای همان جلسه ثبت کن.
- پیام کامیت مثلاً: `git commit -m "session 01: مقدمه‌ای بر C++ و راه‌اندازی محیط"`
- دقیقاً ۵۰ کامیت جداگانه (به‌علاوه یک کامیت اولیه برای اسکلت پروژه) باید در تاریخچه وجود داشته باشد؛ هیچ‌وقت چند جلسه با هم ادغام نشود.
- در پایان کار خروجی `git log --oneline` را نشان بده.

## محتوای هر جلسه

1. **README.md اختصاصی جلسه** شامل:
   - عنوان جلسه و اهداف یادگیری به فارسی
   - توضیح مفهومی از صفر — مثل اینکه مخاطب هیچ پیش‌زمینه‌ای ندارد
   - توضیح **خط‌به‌خط یا بخش‌به‌بخش** هر کد نمونه، دقیقاً کنار همان بخش از کد
   - نکات رایج اشتباهات و به‌خصوص برای C++: مدیریت حافظه، خطاهای رایج OOP، تفاوت‌های ظریف با C هرجا مرتبط است
   - بهترین شیوه‌ها (Modern C++ Best Practices)
   - خلاصه پایان جلسه و لینک به فایل‌های `examples/`
   - حداقل ۱ تا ۲ تمرین عملی با سطح‌بندی (ساده / متوسط)

2. **فایل‌های کد واقعی و قابل کامپایل** (`.cpp`) در `examples/`:
   - با `g++` و استاندارد حداقل C++17 قابل کامپایل و اجرای بدون خطا یا هشدار (`-Wall -Wextra`)
   - کامنت‌های فارسی داخل کد
   - کد تمیز و مطابق سبک مدرن C++؛ همه‌ی کدها واقعاً کامپایل و اجرا و تست شوند

3. **تمرین‌ها** در `exercises/` با راه‌حل جدا یا در بخش قابل‌تاشدن README.

## سرفصل پیشنهادی ۵۰ جلسه (قابل تنظیم توسط خودت اگر منطقی‌تر است)

1. مقدمه‌ای بر C++، تفاوت با C، نصب g++ و کامپایل اولین برنامه
2. متغیرها، انواع داده، namespace و مبانی
3. جریان‌های ورودی/خروجی (cin/cout)
4. عملگرها و عبارات
5. شرط‌ها (if/else/switch)
6. حلقه‌ها (for/while/do-while)
7. توابع، پارامتر پیش‌فرض و overloading تابع
8. مرجع (Reference) در برابر اشاره‌گر (Pointer)
9. آرایه‌ها و مقدمه‌ای بر std::vector
10. رشته‌ها با std::string
11. اشاره‌گرها و حافظه پویا (new/delete)
12. تفاوت struct و class
13. مقدمه‌ای بر OOP: کلاس، شیء، کپسوله‌سازی (Encapsulation)
14. سازنده‌ها (Constructor) و مخرب‌ها (Destructor)
15. سطوح دسترسی (public/private/protected) و getter/setter
16. اعضای static در کلاس
17. اشاره‌گر this
18. سربارگذاری عملگر (Operator Overloading)
19. توابع و کلاس‌های friend
20. مبانی وراثت (Inheritance)
21. وراثت چندگانه (Multiple Inheritance)
22. چندریختی (Polymorphism) و توابع virtual
23. کلاس‌های abstract و pure virtual function
24. قالب‌های تابع (Function Templates)
25. قالب‌های کلاس (Class Templates)
26. مدیریت استثنا (try/catch/throw)
27. مقدمه‌ای بر STL (نمای کلی کانتینرها)
28. STL: بررسی عمیق vector
29. STL: list و deque
30. STL: map و unordered_map
31. STL: set و unordered_set
32. STL: stack، queue و priority_queue
33. تکرارگرها (Iterators)
34. الگوریتم‌های STL (sort، find و غیره)
35. عبارات لامبدا (Lambda Expressions)
36. اشاره‌گرهای هوشمند: unique_ptr، shared_ptr، weak_ptr
37. Move Semantics و rvalue reference
38. اصل RAII و مدیریت منابع
39. کار با فایل با fstream
40. namespace به‌صورت عمیق‌تر
41. const-correctness
42. تبدیل نوع (static_cast، dynamic_cast، const_cast، reinterpret_cast)
43. پروژه چندفایلی، header guard و کامپایل جداگانه
44. مبانی CMake برای اتوماسیون build
45. دیباگ با gdb یا lldb
46. برنامه‌نویسی چندنخی (std::thread، mutex)
47. مقدمه‌ای بر الگوهای طراحی (Singleton، Factory)
48. ویژگی‌های مدرن C++ (C++11 تا C++20: auto، structured bindings و غیره)
49. ابزارهای کتابخانه استاندارد (chrono، optional، variant)
50. پروژه نهایی: ساخت یک برنامه واقعی (مثلاً سیستم مدیریت کتابخانه یا یک بازی کوچک کنسولی) با استفاده از تمام مفاهیم جلسات قبل

## README اصلی پروژه

باید شامل باشد: معرفی دوره، پیش‌نیازها (نصب g++/cmake/gdb)، نحوه کامپایل و اجرا، فهرست کامل ۵۰ جلسه با لینک، نقشه راه یادگیری پیشنهادی، و توضیح ساختار کامیت‌های Git.

## نکات کیفیت مهم

- فارسی روان و طبیعی، نه ترجمه ماشینی؛ اصطلاحات تخصصی انگلیسی کنار فارسی بیاید
- سطح جلسات باید progressive باشد و روی مفاهیم قبلی سوار شود
- تأکید ویژه روی سبک Modern C++ (استفاده از smart pointerها به‌جای new/delete خام هرجا مناسب است)
- تمام کدها واقعاً کامپایل، اجرا و تست شوند
- هر جلسه دقیقاً یک کامیت مجزا در Git
- در پایان، هم ساختار کامل پوشه‌ها (`tree`) و هم `git log --oneline` را نشان بده
