# جلسهٔ ۲ — متغیرها، انواع داده و `namespace`

> در جلسهٔ ۱ اولین برنامه را نوشتیم. حالا می‌خواهیم داده را در حافظه نگه داریم: متغیر، نوع، اندازه، ثابت‌ها و فضای نام.

---

## اهداف این جلسه

تا پایان این جلسه بتوانید:

1. برای هر دادهٔ واقعی (سن، قد، حرف، وضعیت) نوع مناسب انتخاب کنید.
2. تفاوت `const` و `constexpr` و کاربرد `auto` را توضیح دهید.
3. اندازه و بازهٔ انواع پایه را با `sizeof` و `std::numeric_limits` ببینید.
4. بفهمید `std` چیست و چرا `std::cout` می‌نویسیم.
5. تقسیم صحیح را با `static_cast` درست انجام دهید.

---

## ۱. متغیر چیست؟

متغیر یک **نام** برای یک قطعه از حافظه است. وقتی می‌نویسید:

```cpp
int age = 25;
```

کامپایلر جاهایی را برای نگه‌داشتن یک عدد صحیح رزرو می‌کند، آن را `age` صدا می‌زند و مقدار ۲۵ را در آن می‌گذارد. **نوع** (`int`) به کامپایلر می‌گوید چه چیزی در آن خانه ذخیره می‌شود و چه عملیاتی روی آن مجاز است.

سه حالت تعریف:

```cpp
int a;        // تعریف بدون مقدار (مقدار اولیه نامشخص — خطرناک)
int b = 10;   // مقداردهی به سبک C
int c{20};    // مقداردهی یکنواخت (uniform initialization) — سبک مدرن
```

> **قاعدهٔ طلایی:** همیشه متغیر را همان‌جا که تعریف می‌کنید مقدار بدهید. `int a;` و بعد خواندنش، یکی از رایج‌ترین منابع باگ است.

---

## ۲. انواع پایه

| نوع | کاربرد | نمونه | اندازهٔ معمول |
|---|---|---|---|
| `int` | عدد صحیح | `42`، `-7` | ۴ بایت |
| `long long` | عدد صحیح بزرگ | `9000000000LL` | ۸ بایت |
| `double` | عدد اعشاری (دقت دوگانه) | `3.14` | ۸ بایت |
| `float` | اعشاری با دقت کمتر | `3.14f` | ۴ بایت |
| `char` | یک کاراکتر | `'A'`، `'7'` | ۱ بایت |
| `bool` | درست/غلط | `true`، `false` | ۱ بایت |
| `unsigned int` | صحیح بدون علامت | `0` تا `4294967295` | ۴ بایت |

نکته‌های مهم:

- `char` هم عدد است، هم کاراکتر. `'A'` در حقیقت ۶۵ است؛ `static_cast<int>('A')` عدد ۶۵ می‌دهد.
- `float` در مقایسه و محاسبهٔ پول مناسب نیست؛ از `double` استفاده کنید.
- برای شمارش چیزهایی که هرگز منفی نمی‌شوند می‌توان `unsigned` گرفت، اما در محاسبات `unsigned - unsigned` می‌تواند به عدد غول‌آسا تبدیل شود. در این دوره تا وقتی دلیل محکمی ندارید از `int` استفاده می‌کنیم.

---

## ۳. ثابت‌ها: `const` و `constexpr`

مقداری که نباید تغییر کند باید `const` شود؛ کامپایلر جلوی تغییرش را می‌گیرد:

```cpp
const int daysInWeek = 7;
// daysInWeek = 8;  // خطای کامپایل
```

اگر مقدار **در زمان کامپایل** معلوم است، `constexpr` بهتر است؛ هم تضمین می‌دهد که واقعاً ثابت است، هم اجازه می‌دهد در جاهایی مثل اندازهٔ آرایه استفاده شود:

```cpp
constexpr double pi = 3.14159265358979;
constexpr int maxStudents = 30;
int scores[maxStudents];   // مجاز، چون maxStudents در زمان کامپایل معلوم است
```

قاعدهٔ ساده: **اگر می‌توانید `constexpr` بنویسید، بنویسید؛ وگرنه `const`.**

---

## ۴. استنتاج نوع با `auto`

`auto` یعنی «نوع را از مقدار اولیه خودت تشخیص بده»:

```cpp
auto count = 10;      // int
auto price = 9.99;    // double
auto letter = 'A';    // char
auto ok = true;       // bool
```

`auto` کد را کوتاه می‌کند، مخصوصاً در نوع‌های طولانی (`std::vector<std::string>::iterator`). دو هشدار:

- `auto` بدون مقدار اولیه معنا ندارد و خطای کامپایل است.
- `auto x = 1;` و بعد `x = 2.5;` مقدار اعشاری را به `int` تبدیل می‌کند و ۲ می‌ماند. نوع دیگر عوض نمی‌شود.

---

## ۵. فضای نام (`namespace`)

هر اسم در C++ می‌تواند با یک اسم دیگر تصادف کند. `namespace` یک **قفسهٔ نام** است تا اسم‌های هم‌نام کنار هم زندگی کنند. تمام کتابخانهٔ استاندارد C++ داخل فضای نام `std` است؛ به همین دلیل `std::cout` و `std::string` می‌نویسیم.

```cpp
namespace math {
    constexpr double pi = 3.14159;

    double circleArea(double r) {
        return pi * r * r;
    }
}

int main() {
    std::cout << math::circleArea(2.0);  // 12.5664
}
```

می‌توانید فضای نام خودتان را هم بسازید و در جلسهٔ ۴۰ عمیق‌ترش می‌بینیم. الان فقط این را بدانید: `::` عملگر «دسترسی به عضو» است.

> در این دوره `using namespace std;` را در سطح فایل نمی‌نویسیم؛ دلیل کاملش در جلسهٔ ۴۰ می‌آید. نوشتن `std::` صریح، کد را خواناتر و بدون ابهام می‌کند.

---

## ۶. اندازه و بازه: `sizeof` و `std::numeric_limits`

```cpp
#include <limits>

std::cout << sizeof(int);                              // معمولاً 4
std::cout << std::numeric_limits<int>::max();           // 2147483647
std::cout << std::numeric_limits<double>::min();        // کوچک‌ترین مثبت
```

`sizeof` اندازه را **به بایت** می‌دهد و نوعش `std::size_t` است (عددی بدون علامت). این عدد بین سیستم‌ها کمی متفاوت است؛ در کد به جای فرض کردنش، از `sizeof` استفاده کنید.

---

## ۷. تبدیل نوع (cast)

وقتی `int` را بر `int` تقسیم کنید، نتیجه هم `int` است و بخش اعشاری **حذف** می‌شود:

```cpp
int total = 7;
int people = 2;
double wrong = total / people;                          // 3  (نه 3.5)
double right = static_cast<double>(total) / people;     // 3.5
```

`static_cast<double>(total)` یک تبدیل صریح و قابل‌جست‌وجو در کد است. سبک قدیمی `(double)total` هم کار می‌کند ولی در جلسهٔ ۴۲ می‌بینیم چرا `static_cast` امن‌تر است.

### ۸.۳ `03_namespace_auto.cpp`

```cpp
namespace geometry {
    constexpr double pi = 3.14159;
    double circleArea(double r) { return pi * r * r; }
}
```

سپس با `auto` نوع‌ها را می‌گیریم و یک تقسیم صحیح را با `static_cast` درست می‌کنیم:

```cpp
int totalScore = 17;
int students = 2;
auto average = static_cast<double>(totalScore) / students;  // 8.5
```

بدون `static_cast` نتیجه ۸ می‌شد و بخش اعشاری از دست می‌رفت.

## ۹. اشتباهات رایج

1. **استفاده از متغیر مقدارنگرفته**
   ```cpp
   int x;
   std::cout << x;   // مقدار نامشخص — رفتار تعریف‌نشده
   ```
2. **تقسیم صحیح ناخواسته:** `double avg = sum / count;` با دو `int` بخش اعشاری را از دست می‌دهد.
3. **مقایسهٔ `float` با `==`:** `0.1 + 0.2 == 0.3` همیشه درست نیست. برای اعشاری از اختلاف کوچک استفاده کنید (جلسهٔ ۴).
4. **`char` در برابر رشته:** `'A'` کاراکتر است، `"A"` رشته (آرایه‌ای از کاراکترها). این دو یکی نیستند.
5. **`const` را بعد از تعریف گذاشتن:** `int const x = 5;` درست است اما سبک رایج `const int x = 5;` است.
6. **سرریز:** `int` تا حدود ۲.۱ میلیارد است. `int x = 3000000000;` هشدار یا رفتار غلط می‌دهد.

## ۱۰. بهترین شیوه‌ها

- هر متغیر را در **اولین لحظهٔ ممکن** و با مقدار اولیه تعریف کنید.
- نام‌ها گویا و باقاعده باشند: `totalPrice`، `studentCount` (camelCase برای متغیر، مطابق سبک این دوره).
- برای هر عدد ثابتِ معنادار، یک `constexpr` بسازید؛ «عدد جادویی» در کد نگذارید.
- `double` را برای اعشاری انتخاب کنید مگر اینکه حافظه واقعاً مهم باشد.
- `static_cast` را به تبدیل سبک C ترجیح دهید.

---

## ۱۱. خلاصه

- متغیر = نام + نوع + مقدار؛ همیشه مقدار اولیه بدهید.
- `int`، `double`، `char`، `bool` ستون‌های اصلی‌اند؛ `sizeof` اندازه را می‌دهد.
- `const` تغییر را ممنوع می‌کند و `constexpr` ثابت زمان کامپایل است.
- `auto` نوع را از مقدار اولیه می‌گیرد.
- `namespace` از تداخل نام جلوگیری می‌کند؛ کتابخانهٔ استاندارد در `std` است.
- تقسیم دو `int` صحیح است؛ با `static_cast<double>` اعشاری کنید.
