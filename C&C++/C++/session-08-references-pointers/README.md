# جلسهٔ ۸ — reference و pointer

> تا جلسهٔ ۷ هر آرگومان کپی می‌شد. این جلسه یاد می‌گیرید چطور به **خودِ شیء** دسترسی بگیرید — و چرا این کار قدرتمندترین و خطرناک‌ترین بخش C++ است.

---

## اهداف این جلسه

1. تفاوت کپی با دسترسی به شیء اصلی را ببینید.
2. `&` در اعلان را از `&` در عبارت تشخیص دهید.
3. reference را به‌عنوان پارامتر و مقدار بازگشتی به کار ببرید.
4. با `const&` بدون کپی و بدون خطر کار کنید.
5. pointer، `*`، `&` و `nullptr` را بشناسید.
6. بدانید کی reference و کی pointer انتخاب کنید.
7. `swap` واقعی بنویسید و دلیل دامنهٔ خطاهای pointer را بفهمید.

---

## ۱. مشکل: کپی

```cpp
void swapByValue(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

int x = 1, y = 2;
swapByValue(x, y);   // x و y تغییر نمی‌کنند
```

چرا؟ چون `a` و `b` **کپی**های `x` و `y` هستند. تابع کپی‌ها را جابه‌جا می‌کند و با پایان تابع، کپی‌ها از بین می‌روند.

راه‌حل: به تابع بگویید «به خود متغیر دسترسی بده»، نه به کپی آن. دو ابزار برای این کار داریم: **reference** و **pointer**.

---

## ۲. reference چیست؟

reference یک **نام دیگر** برای یک متغیر موجود است. شیء جدیدی ساخته نمی‌شود.

```cpp
int value = 10;
int& ref = value;    // ref نام دومِ value است

ref = 20;            // همان value تغییر می‌کند
std::cout << value;  // 20
```

آدرس هر دو یکی است:

```cpp
std::cout << (&value == &ref);   // true (یا 1)
```

قواعد حتمی:

| قاعده | مثال درست | مثال غلط |
|---|---|---|
| باید در همان تعریف مقدار بگیرد | `int& r = x;` | `int& r;` |
| بعداً به شیء دیگری «چسبانده» نمی‌شود | — | `r = y;` (مقدار کپی می‌شود) |
| reference به reference نداریم | `int& r2 = r;` | — |
| «reference خالی» وجود ندارد | — | `int& r = nullptr;` |

> ⚠️ خطای رایج: تصور اینکه `r = y` باعث می‌شود `r` به `y` اشاره کند. نه! این کار **مقدار** `y` را داخل شیئی که `r` به آن اشاره دارد می‌نویسد.

---

## ۳. `&` دو معنی کاملاً متفاوت دارد

این مهم‌ترین نکتهٔ این جلسه است:

| جای استفاده | معنی | مثال |
|---|---|---|
| در **اعلان** (نوع) | «reference به» | `int& ref = value;` |
| در **عبارت** (مقدار) | «آدرسِ» | `int* p = &value;` |

```cpp
int& ref = value;   // اینجا & بخشی از نوع است
int* p = &value;    // اینجا & عملگر آدرس‌دهی است
```

همین موضوع برای `*` هم هست: در اعلان یعنی «pointer به»، در عبارت یعنی «محتوای آدرس».

| جای استفاده | معنی | مثال |
|---|---|---|
| اعلان | pointer به | `int* p;` |
| عبارت | dereference | `*p = 5;` |

---

## ۴. reference به‌عنوان پارامتر

پارامتر مرجع یعنی تابع روی متغیر اصلی کار می‌کند:

```cpp
void scale(int& value, int factor) {
    value *= factor;
}

int n = 7;
scale(n, 3);        // n می‌شود 21
```

و حالا `swap` واقعی:

```cpp
void swapByRef(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

swapByRef(x, y);    // x و y واقعاً عوض می‌شوند
```

در محل فراخوانی **هیچ علامت اضافه‌ای** نمی‌گذارید (`swapByRef(x, y)`، نه `&x`). این هم راحتی است و هم خطر: از روی کد فراخوانی نمی‌فهمید که تابع مقدار `x` را تغییر می‌دهد.

---

## ۵. `const&`: بدون کپی، بدون تغییر

برای پارامترهای بزرگ (مثل `std::string` یا `std::vector`) کپی گران است. برای اینکه هم کپی نکنید و هم مطمئن باشید تابع تغییرشان نمی‌دهد:

```cpp
void printOnly(const std::string& text) {
    std::cout << text.size();   // فقط خواندن
    // text += "!";             // خطای کامپایل
}
```

**قاعدهٔ طلایی:** هر پارامتر غیر از انواع پایه (`int`، `double`، `char`، `bool`) را `const&` بگیرید، مگر اینکه واقعاً بخواهید تغییرش دهید یا کپی لازم داشته باشید.

| نوع پارامتر | کپی می‌شود؟ | قابل تغییر؟ | چه وقت |
|---|---|---|---|
| `std::string s` | بله | بله (فقط کپی) | وقتی نسخهٔ اصلاح‌شده لازم است |
| `std::string& s` | نه | بله | وقتی باید اصلاح شود |
| `const std::string& s` | نه | نه | **پیش‌فرض برای خواندن** |

---

## ۶. pointer چیست؟

pointer متغیری است که **آدرس** یک شیء را نگه می‌دارد.

```cpp
int value = 42;
int* ptr = &value;    // ptr آدرس value را دارد
std::cout << *ptr;    // 42 — محتوای آن آدرس
*ptr = 100;           // نوشتن در آن آدرس
std::cout << value;   // 100
```

سه عملیات پایه:

| عمل | نوشتار | نتیجه |
|---|---|---|
| گرفتن آدرس | `&value` | آدرس شیء |
| خواندن محتوا | `*ptr` | مقدار شیء |
| نوشتن محتوا | `*ptr = x` | تغییر شیء |

### `nullptr`

pointer می‌تواند به «هیچ‌چیز» اشاره کند:

```cpp
int* nothing = nullptr;

if (nothing == nullptr) { /* بررسی */ }
if (!nothing) { /* همان بررسی، کوتاه‌تر */ }
```

- هرگز `*nothing` را ننویسید → رفتار تعریف‌نشده (اغلب crash با segmentation fault).
- `0` و `NULL` هم قبلاً استفاده می‌شدند؛ از C++11 به بعد **همیشه `nullptr`** بنویسید.

### pointer بدون مقدار اولیه

```cpp
int* p;       // آدرس تصادفی! dereference آن فاجعه است
```

pointer را همیشه همان لحظه مقدار بدهید، حتی اگر `nullptr` باشد.

---

## ۷. reference یا pointer؟

| ویژگی | reference | pointer |
|---|---|---|
| می‌تواند «هیچ‌چیز» باشد | ❌ | ✅ `nullptr` |
| می‌تواند به شیء دیگری اشاره کند | ❌ | ✅ |
| نیاز به `*` برای دسترسی | ❌ | ✅ |
| نیاز به بررسی null | ❌ | ✅ |
| نحو ساده‌تر | ✅ | ❌ |
| برای پارامتر «اختیاری» | ❌ | ✅ |
| برای مالکیت پویا (جلسهٔ ۱۱) | ❌ | ✅ |

**قاعدهٔ عملی:** اگر شیء همیشه وجود دارد و نیازی به تغییر اشاره‌گر نیست → reference. اگر ممکن است نباشد، یا باید اشاره‌گر عوض شود → pointer.

```cpp
void setScore(int& score);          // امتیاز همیشه هست
void setScore(int* score);          // ممکن است نباشد → باید بررسی شود
```

---

## ۸. `const` و pointer

اینجا دو `const` مستقل داریم و خواندنشان از **راست به چپ** کمک می‌کند:

```cpp
const int* p1 = &x;    // pointer به int ثابت: *p1 = 5 ممنوع، p1 = ... مجاز
int* const p2 = &x;    // pointer ثابت به int: *p2 = 5 مجاز، p2 = ... ممنوع
const int* const p3 = &x;  // هر دو ممنوع
```

خواندن از راست: «`p2` یک pointer ثابت است به `int`».

> ⚠️ **خطر بازگشت reference:** هرگز reference به متغیر محلی برنگردانید:
> ```cpp

>     int local = 5;
>     return local;   // reference به حافظهٔ مرده
> }
> ```

## ۱۰. اشتباهات رایج

1. **dangling reference/pointer**: برگرداندن reference یا آدرس متغیر محلی.
2. **dereference کردن pointer تهی** → crash. همیشه قبل از `*p` بررسی کنید (یا بهتر: آن‌قدر طراحی کنید که pointer تهی نداشته باشید).
3. **pointer مقدارنگرفته**: `int* p; *p = 5;` → نوشتن در آدرس تصادفی.
4. **فراموش کردن `&` در فراخوانی**: `swapByRef(x, y)` درست است، `increaseByPointer(x, 5)` خطاست.
5. **`&` اضافه در فراخوانی reference**: `swapByRef(&x, &y)` خطای کامپایل می‌دهد.
6. **انتظار «اتصال مجدد» از reference**: `ref = other;` فقط مقدار را کپی می‌کند.
7. **`int& r = 5;`** → خطا؛ reference به مقدار موقت (در C++ معمولی) مجاز نیست. `const int& r = 5;` مجاز است.
8. **پارامتر بزرگ را با مقدار گرفتن**: کپی بی‌دلیل؛ از `const&` استفاده کنید.

---

## ۱۱. بهترین شیوه‌ها

- پارامتر فقط‌خواندنی و بزرگ → `const&`.
- پارامتر باید تغییر کند → `T&`.
- پارامتر اختیاری یا قابل‌تهی → `T*` و بررسی `nullptr`.
- reference محلی را کوتاه و نزدیک به استفاده نگه دارید؛ نام‌های تکراری زیاد باعث سردرگمی می‌شود.
- برای `swap` از `std::swap` استفاده کنید؛ خودش برای انواع پیچیده بهینه است.
- هرگز آدرس متغیر محلی را از تابع بیرون ندهید.

---

## ۱۲. خلاصه

- reference = نام دوم شیء موجود؛ بدون کپی، بدون `nullptr`، بدون تغییر اشاره.
- `&` در اعلان یعنی reference، در عبارت یعنی آدرس.
- `const&` گزینهٔ پیش‌فرض برای پارامترهای خواندنی است.
- pointer = آدرس؛ `*` دسترسی، `&` گرفتن آدرس، `nullptr` «هیچ».
- دو `const` مستقل در pointer وجود دارد؛ از راست به چپ بخوانید.
- `swap` با مقدار کار نمی‌کند؛ با reference یا pointer کار می‌کند.
