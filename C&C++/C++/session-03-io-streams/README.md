# جلسهٔ ۳ — جریان‌های ورودی و خروجی

> برنامه‌ای که فقط چاپ می‌کند سرگرمی است؛ برنامهٔ واقعی ورودی می‌گیرد. این جلسه دربارهٔ `std::cin`، `getline` و قالب‌بندی خروجی است.

---

## اهداف این جلسه

1. با `std::cin` و `>>` ورودی ساده بخوانید.
2. تفاوت رفتار `>>` و `getline` را بفهمید و مشکل معروف «خط باقی‌مانده» را حل کنید.
3. با `std::cerr` پیام خطا جدا از خروجی معمولی بنویسید.
4. خروجی را با `setw`، `fixed`، `setprecision` و `setfill` قالب‌بندی کنید.
5. شکست ورودی را تشخیص دهید و برنامه کرش نکند.

---

## ۱. `cout` بازبینی کوتاه

```cpp
std::cout << "سلام" << " " << 42 << "\n";
```

`std::cout` یک **جریان** (stream) است: چیزی که داده را به ترتیب می‌گیرد و به مقصد می‌فرستد. `<<` عملگر «درج» است و داده را به جریان می‌ریزد. سه جریان استاندارد داریم:

| جریان | کاربرد |
|---|---|
| `std::cout` | خروجی معمولی (stdout) |
| `std::cerr` | خطا (stderr، بدون بافر) |
| `std::clog` | گزارش‌های عادی (stderr، با بافر) |

`endl` هم خط جدید می‌دهد و هم جریان را flush می‌کند؛ در حلقه‌های طولانی `"\n"` سریع‌تر است و ما از آن استفاده می‌کنیم.

---

## ۲. ورودی با `std::cin` و `>>`

```cpp
int age = 0;
std::cin >> age;          // منتظر می‌ماند تا کاربر عدد و Enter بزند
```

`>>`:
1. فاصله‌ها، تب و خط جدید ابتدای ورودی را **نادیده می‌گیرد**.
2. تا اولین فاصله یا کاراکتر غیرمجاز می‌خواند.
3. داده را به نوع متغیر **تبدیل** می‌کند.

برای چند مقدار:

```cpp
int a = 0, b = 0;
std::cin >> a >> b;     // ورودی: 12 30
```

اگر کاربر به جای عدد حرف بزند، `cin` وارد **حالت خطا** می‌شود:

```cpp
int x = 0;
if (std::cin >> x) {
    std::cout << "عدد خوانده شد: " << x << "\n";
} else {
    std::cerr << "ورودی عدد نبود!\n";
}
```

`std::cin` در شرط `if` به `bool` تبدیل می‌شود: درست اگر خواندن موفق بوده باشد.

---

## ۳. `getline` و مشکل کلاسیک خط باقی‌مانده

`>>` فاصله و `\n` را در ورودی **باقی می‌گذارد**. اگر بعد از آن `getline` صدا بزنید، `getline` همان `\n` باقی‌مانده را می‌خواند و یک رشتهٔ خالی می‌دهد:

```cpp
int age = 0;
std::string name;

std::cin >> age;              // کاربر: 25<Enter>
std::getline(std::cin, name); // name خالی می‌شود! چون \n مانده بود
```

راه‌حل‌ها:

```cpp
std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');  // دور ریختن بقیهٔ خط
```

یا از اول همه‌چیز را با `getline` بخوانید و بعد به عدد تبدیل کنید (جلسهٔ ۱۰). برای شروع، `ignore` کافی است.

```cpp
std::getline(std::cin, fullName);   // کل خط، با فاصله‌ها
```

`getline` تا `\n` می‌خواند و `\n` را مصرف می‌کند (اما در رشته نمی‌گذارد).

## ۴. قالب‌بندی خروجی با `<iomanip>`

```cpp
#include <iomanip>

std::cout << std::fixed << std::setprecision(2);   // دو رقم اعشار
std::cout << 3.14159;                              // 3.14
```

`std::fixed` یعنی «همیشه همین تعداد رقم اعشار»، و `setprecision(2)` تعداد آن را تعیین می‌کند. بدون `fixed`، `setprecision` تعداد **رقم معنی‌دار** کل را می‌دهد.

ساخت جدول با `setw` (حداقل عرض ستون):

```cpp
std::cout << std::setw(10) << std::left  << "نام"
          << std::setw(8)  << std::right << "نمره" << "\n";

std::cout << std::setw(10) << std::left  << "سعید"
          << std::setw(8)  << std::right << 18.5 << "\n";
```

نکته‌ها:

- `setw` فقط روی **یک** خروجی بعدی اثر دارد؛ باید هر بار تکرار شود.
- `left`، `right` و `internal` تنظیم‌های **پایدار** هستند تا وقتی عوضشان کنید.
- `std::setfill('*')` کاراکتر پرکنندهٔ فضای خالی را تعیین می‌کند.
- `setw` تعداد **بایت** را می‌شمارد؛ متن فارسی در UTF-8 چند بایتی است، پس ستون‌های فارسی دقیقاً هم‌تراز نمی‌شوند. برای جدول‌های دقیق از برچسب انگلیسی یا کتابخانهٔ جدول‌بندی استفاده کنید.
- `std::boolalpha` باعث می‌شود `bool` به‌صورت `true`/`false` چاپ شود.
- برای درصد داخل جدول باید `%` را جدا چاپ کنید؛ `setw` عرض عدد را تنظیم می‌کند نه کل رشته.

### ۵.۱ `01_cin_cout.cpp`

دو عدد می‌خواند و جمع، تفاضل، ضرب و تقسیم اعشاری را چاپ می‌کند:

```cpp
double a = 0.0, b = 0.0;
std::cout << "دو عدد: ";
if (!(std::cin >> a >> b)) {          // بررسی موفقیت خواندن
    std::cerr << "ورودی نامعتبر\n";
    return 1;
}
std::cout << "جمع = " << a + b << "\n";
```

اگر تقسیم بر صفر پیش بیاید، با `cerr` هشدار می‌دهیم و از تقسیم صفر جلوگیری می‌کنیم.

### ۵.۲ `02_getline.cpp`

اول یک عدد می‌خوانیم و بعد نام کامل؛ برای اینکه `getline` رشتهٔ خالی نگیرد:

```cpp
std::cin >> age;
std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

std::string fullName;
std::getline(std::cin, fullName);
```

سپس طول نام را با `.size()` چاپ می‌کنیم (جزئیات `std::string` در جلسهٔ ۱۰).

### ۵.۳ `03_formatting.cpp`

یک جدول سه‌ستونی از کالاها با قیمت و تخفیف می‌سازد:

```cpp
std::cout << std::fixed << std::setprecision(2);
std::cout << std::setw(12) << std::left << "کالا"
          << std::setw(10) << std::right << "قیمت"
          << std::setw(10) << "تخفیف" << "\n";
```

`fixed` + `setprecision(2)` باعث می‌شود `1200` به‌صورت `1200.00` چاپ شود.

## ۶. اشتباهات رایج

1. **`getline` بعد از `cin >>`** بدون `ignore` → رشتهٔ خالی.
2. **فراموش کردن بررسی خطای ورودی** → حلقهٔ بی‌پایان یا مقدار صفر.
3. **`cin` در حالت خطا مانده است:** بعد از خطا باید `std::cin.clear()` و `ignore` بزنید، وگرنه هر خواندن بعدی هم شکست می‌خورد.
4. **چاپ عدد اعشاری با ۶ رقم پیش‌فرض** و فکر کردن اینکه مقدار از دست رفته؛ مقدار درست است، نمایش کوتاه است.
5. **`setw` را یک‌بار برای کل ستون نوشتن**؛ `setw` یک‌بارمصرف است.
6. **`endl` در هر تکرار حلقهٔ سنگین**؛ flush بی‌مورد هزینه دارد.

---

## ۷. بهترین شیوه‌ها

- برای متن‌هایی که فاصله دارند همیشه `getline` استفاده کنید.
- پیام‌های خطا را به `std::cerr` بفرستید تا خروجی معمولی قابل پردازش بماند.
- بعد از هر ورودی، معتبر بودنش را بررسی کنید.
- برای نمایش پول و درصد، `fixed` و `setprecision` را در یک‌جا تنظیم کنید.
- برای خواندن تا آخر فایل (مثلاً وقتی ورودی از فایل می‌آید) از `while (std::cin >> x)` استفاده کنید.

---

## ۸. خلاصه

- `>>` فاصله‌ها را رد می‌کند و تا اولین فاصله می‌خواند؛ `getline` یک خط کامل می‌خواند.
- ترکیب این دو نیاز به `cin.ignore` دارد.
- `cin` در شرط `if` موفقیت خواندن را می‌دهد.
- `setw` عرض، `fixed`/`setprecision` دقت اعشار و `setfill` پرکننده را کنترل می‌کنند.
- خطاها به `cerr` می‌روند.
