# جلسهٔ ۹ — آرایه، `std::array` و `std::vector`

> تا حالا هر مقدار یک متغیر داشت. حالا می‌خواهیم ۱۰۰ نمره را نگه داریم — بدون نوشتن ۱۰۰ متغیر.

---

## اهداف این جلسه

1. آرایهٔ خام C را بسازید و پیمایش کنید.
2. بدانید چرا آرایهٔ خام در C++ تقریباً همیشه انتخاب بدی است.
3. `std::vector` را بسازید، پر کنید و پیمایش کنید.
4. تفاوت `[]` و `at()` را بشناسید و بدانید کدام امن است.
5. با `size`، `empty`، `front`، `back`، `push_back`، `pop_back` و `clear` کار کنید.
6. `std::array` را برای اندازهٔ ثابت بشناسید.

---

## ۱. آرایهٔ خام

آرایه مجموعه‌ای از عناصر **هم‌نوع** و **پشت‌سرهم** در حافظه است:

```cpp
int scores[5] = {92, 87, 75, 68, 99};
```

- اندازه باید **ثابت زمان کامپایل** باشد.
- اندیس از **صفر** شروع می‌شود: `scores[0]` تا `scores[4]`.
- دسترسی با `[]` **هیچ بررسی‌ای** ندارد.

مقداردهی:

```cpp
int a[5] = {1, 2};        // بقیه صفر می‌شوند: 1 2 0 0 0
int b[] = {1, 2, 3};      // اندازه از تعداد مقدارها = 3
int c[3] = {};            // همه صفر
```

تعداد عناصر:

```cpp
const std::size_t count = sizeof(scores) / sizeof(scores[0]);
```

`sizeof(scores)` اندازهٔ کل آرایه به بایت است و `sizeof(scores[0])` اندازهٔ یک عنصر؛ تقسیم، تعداد عناصر می‌دهد. این محاسبه فقط جایی کار می‌کند که آرایه **واقعاً آرایه** باشد، نه pointer.

---

## ۲. سه مشکل آرایهٔ خام

### مشکل ۱: اندازه ثابت است

```cpp
int n = 0;
std::cin >> n;
int data[n];      // در C++ استاندارد مجاز نیست (VLA فقط افزونهٔ کامپایلر است)
```

اگر تعداد عناصر را در زمان اجرا می‌دانید، آرایهٔ خام جواب نمی‌دهد.

### مشکل ۲: هیچ بررسی مرزی وجود ندارد

```cpp
int scores[5];
scores[5] = 100;    // خارج از محدوده! کامپایل می‌شود، اجرا فاجعه است
```

این «رفتار تعریف‌نشده» است: ممکن است کار کند، ممکن است دادهٔ متغیر دیگری را خراب کند، ممکن است crash کند. بدترین حالت: **بی‌صدا خراب می‌شود**.

### مشکل ۳: در پارامتر تابع به pointer تبدیل می‌شود

```cpp
void printWrong(int data[]) {   // دقیقاً همان int* data
    std::cout << sizeof(data);  // 8 — اندازهٔ pointer، نه آرایه!
}
```

این تبدیل خودکار **array decay** نام دارد. به همین دلیل تابع نمی‌داند آرایه چند عنصر دارد و معمولاً باید اندازه را جدا بدهید:

```cpp
void print(const int* data, std::size_t count);
```

---

## ۳. `std::array`: آرایه با اندازهٔ ثابت و امن

اگر اندازه ثابت است ولی می‌خواهید رفتار شیء واقعی داشته باشید:

```cpp
#include <array>

std::array<int, 5> scores{92, 87, 75, 68, 99};

std::cout << scores.size();      // 5
std::cout << scores.at(0);       // 92 — با بررسی مرز
for (const int& score : scores) {
    std::cout << score << " ";
}
```

- اندازه را می‌داند (`size()`).
- `at()` بررسی می‌کند.
- کپی و مقایسه با `==` کار می‌کند.
- هنوز اندازه ثابت است و روی stack زندگی می‌کند.

---

## ۴. `std::vector`: انتخاب پیش‌فرض

`std::vector` آرایه‌ای است که **خودش اندازه‌اش را مدیریت می‌کند**:

```cpp
#include <vector>

std::vector<int> numbers{10, 20, 30};
numbers.push_back(40);           // اندازه خودش بزرگ می‌شود
std::cout << numbers.size();     // 4
```

### ساخت

```cpp
std::vector<int> a;                  // خالی
std::vector<int> b(4);               // چهار صفر
std::vector<int> c(3, 7);            // 7 7 7
std::vector<int> d{1, 2, 3};         // مقدار اولیه
std::vector<std::string> names;      // هر نوعی
```

> تفاوت `(4)` و `{4}` مهم است: اولی چهار عنصر صفر می‌سازد، دومی یک عنصر با مقدار ۴.

### عملیات پرکاربرد

| عمل | کد | توضیح |
|---|---|---|
| افزودن به انتها | `v.push_back(x)` | اندازه +۱ |
| حذف از انتها | `v.pop_back()` | اندازه −۱ |
| تعداد عناصر | `v.size()` | `std::size_t` |
| خالی است؟ | `v.empty()` | ترجیح بر `size() == 0` |
| اولین / آخرین | `v.front()` / `v.back()` | مرجع |
| دسترسی سریع | `v[i]` | **بدون** بررسی مرز |
| دسترسی امن | `v.at(i)` | خارج از محدوده → استثنا |
| پاک کردن همه | `v.clear()` | اندازه = ۰ |
| تعیین اندازه | `v.resize(n)` | بزرگ یا کوچک می‌کند |

### `[]` در برابر `at()`

```cpp
std::vector<int> v{3, 8, 15, 22};

v[1];      // 8 — سریع، بدون بررسی؛ v[10] رفتار تعریف‌نشده
v.at(1);   // 8 — کمی کندتر، ولی v.at(10) استثنای std::out_of_range می‌دهد
```

در کد روزمره اگر مطمئنید اندیس معتبر است `[]`، و اگر اندیس از بیرون می‌آید (ورودی کاربر، محاسبه) `at()`.

---

## ۵. پیمایش

سه شکل، سه کاربرد:

```cpp
// ۱) فقط خواندن، بدون کپی
for (const int& value : numbers) {
    std::cout << value;
}

// ۲) تغییر عناصر
for (int& value : numbers) {
    value += 1;
}

// ۳) وقتی اندیس لازم دارید
for (std::size_t i = 0; i < numbers.size(); ++i) {
    std::cout << i << ": " << numbers[i];
}
```

- `for (int value : numbers)` هم درست است ولی **کپی** می‌گیرد؛ برای `int` بی‌اهمیت، برای `std::string` گران.
- `int&` بدون `const` اجازهٔ تغییر می‌دهد.
- اندیس را `std::size_t` بگیرید تا با `size()` هم‌نوع باشد و هشدار `-Wsign-compare` نگیرید.

## ۶. جدول مقایسه

| ویژگی | `int a[5]` | `std::array<int,5>` | `std::vector<int>` |
|---|---|---|---|
| اندازه در زمان اجرا | ❌ | ❌ | ✅ |
| می‌داند چند عنصر دارد | ❌ | ✅ | ✅ |
| بررسی مرز با `at` | ❌ | ✅ | ✅ |
| کپی با `=` | ❌ | ✅ | ✅ |
| بزرگ/کوچک شدن | ❌ | ❌ | ✅ |
| مناسب برای | کد سطح پایین، API قدیمی | اندازه ثابت، بدون تخصیص حافظه | **پیش‌فرض شما** |

**قاعدهٔ عملی:** `std::vector` بزنید. اگر پروفایلینگ نشان داد تخصیص حافظه گلوگاه است و اندازه ثابت است، به `std::array` بروید. آرایهٔ خام فقط وقتی که مجبورید با API زبان C حرف بزنید (`data()` یا `&v[0]` برای همین است).

## ۸. اشتباهات رایج

1. **`<=` در شرط حلقه**: `i <= v.size()` → دسترسی به یک عنصر بعد از آخر.
2. **`sizeof` روی pointer**: بعد از decay دیگر اندازهٔ آرایه نمی‌دهد.
3. **`front()`/`back()`/`pop_back()` روی vector خالی** → رفتار تعریف‌نشده. اول `empty()` را بررسی کنید.
4. **نگه داشتن اندیس بعد از تغییر vector**: با `push_back` ممکن است حافظه جابه‌جا شود و تکرارگرها/آدرس‌ها نامعتبر شوند (جلسهٔ ۲۸).
5. **تفاوت `vector<int> v(4)` و `v{4}`**.
6. **استفاده از `[]` با اندیسی که از ورودی کاربر آمده** → از `at()` استفاده کنید.
7. **حلقه با `int` در برابر `size()`**: هشدار مقایسهٔ علامت‌دار و بی‌علامت.
8. **حذف عنصر وسط vector با حلقهٔ ساده**؛ اندیس‌ها جابه‌جا می‌شوند (در جلسهٔ ۲۸ با `erase` حل می‌شود).

## ۹. بهترین شیوه‌ها

- پیش‌فرض: `std::vector`.
- در توابع، `const std::vector<T>&` بگیرید، نه کپی.
- قبل از `push_back` در حلقه‌های بزرگ، `reserve(n)` بزنید (جزئیات در جلسهٔ ۲۸).
- پیمایش فقط‌خواندنی با `const T&`؛ پیمایش تغییردهنده با `T&`.
- اندیس را `std::size_t` نگه دارید.
- `v.empty()` بخوانید، نه `v.size() == 0`.
- اگر اندازه ثابت و کوچک است و در عملکرد حساس هستید، `std::array`.

---

## ۱۰. خلاصه

- آرایهٔ خام: اندازهٔ ثابت، بدون بررسی مرز، decay به pointer.
- `std::array`: اندازهٔ ثابت + امنیت و رابط شیء.
- `std::vector`: پویا، امن، انتخاب پیش‌فرض.
- `[]` سریع و بی‌بررسی، `at()` بررسی‌کننده و پرتاب‌کنندهٔ `std::out_of_range`.
- پیمایش با `const&` برای خواندن و `&` برای تغییر.
- `size()` مقدار `std::size_t` می‌دهد.
