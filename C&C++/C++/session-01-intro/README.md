## C++ چیست؟

زبان C++ را **بیارنه استراستروپ (Bjarne Stroustrup)** در سال ۱۹۷۹ در آزمایشگاه‌های بل با نام «C با کلاس‌ها» ساخت و بعدها به C++ تغییر نام داد. هدفش این بود که سرعت و کنترل C را نگه دارد، ولی ابزارهای سطح بالاتر برای ساختن نرم‌افزارهای بزرگ اضافه کند.

C++ چند پارادایم را با هم پشتیبانی می‌کند:

- **رویه‌ای (Procedural):** مثل C، با تابع و ساختار کنترلی
- **شیءگرا (Object-Oriented):** کلاس، وراثت، چندریختی
- **جنریک (Generic):** قالب‌ها (Templates)
- **کارکردی (Functional):** لامبدا و الگوریتم‌ها (از C++11 به بعد)

امروز C++ در موتور بازی‌ها (Unreal)، مرورگرها (Chrome)، پایگاه‌داده‌ها (MySQL)، سیستم‌های معاملاتی، نرم‌افزارهای بی‌درنگ و نرم‌افزارهای علمی بیشترین استفاده را دارد.

## تفاوت C++ با C

| موضوع | C | C++ |
|---|---|---|
| ورودی/خروجی | `printf`/`scanf` | `std::cout`/`std::cin` |
| رشته | آرایهٔ `char` و توابع `string.h` | `std::string` با متد و عملگر |
| پارامتر تابع | فقط مقدار یا اشاره‌گر | مرجع (`&`) و مقدار پیش‌فرض و overloading |
| آزادسازی حافظه | `malloc`/`free` | `new`/`delete` و smart pointerها |
| کد مجاز در وسط برنامه | متغیر فقط در ابتدای بلوک (C89) | متغیر هر جای بلوک |
| پارادایم اصلی | رویه‌ای | چند پارادایم (شیءگرا، جنریک…) |

> C++ تقریباً همهٔ کد C را می‌پذیرد، اما C همهٔ کد C++ را نمی‌پذیرد. C++ یک **زبان جدا** است، نه صرفاً نسخهٔ بعدی C؛ پس عادت‌های C را همیشه با احتیاط به C++ منتقل کنید.

## نصب کامپایلر

کامپیوتر کد C++ را مستقیماً اجرا نمی‌کند؛ **کامپایلر** آن را به زبان ماشین ترجمه می‌کند. پرکاربردترین کامپایلر رایگان **g++** است (بخشی از مجموعهٔ GCC).

- **لینوکس (Ubuntu/Debian):** `sudo apt install g++`
- **ویندوز:** بهترین گزینه نصب WSL (Ubuntu) و کار داخل لینوکس است؛ یا MinGW-w64 را نصب کنید و مسیر `bin` آن را به `PATH` اضافه کنید.
- **مک:** با نصب Xcode Command Line Tools، دستور `g++` (در واقع `clang++`) آماده می‌شود.

بررسی نصب:

```bash
g++ --version
```

باید چیزی شبیه `g++ (Ubuntu 15.2.0...) 15.2.0` ببینید. **حداقل نسخهٔ لازم برای این دوره ۱۷ است**، چون همهٔ کدها با استاندارد C++17 کامپایل می‌شوند.

## اولین برنامه: Hello, C++!

فایل `examples/01_hello.cpp`:

```cpp
#include <iostream>  // کتابخانهٔ استاندارد ورودی/خروجی (برای std::cout)

int main() {  // تابع main: هر برنامهٔ C++ از این‌جا شروع می‌شود
    std::cout << "Hello, C++!" << std::endl;  // چاپ پیام و رفتن به خط بعد
    return 0;                                 // کد خروج ۰ یعنی «موفق»
}
```

### توضیح خط‌به‌خط

| بخش کد | توضیح |
|---|---|
| `#include <iostream>` | دستور پیش‌پردازنده است: محتوای فایل هدر `iostream` را (که `std::cout` را معرفی می‌کند) به برنامه اضافه می‌کند. بدون آن کامپایلر نمی‌داند `std::cout` چیست. |
| `int main()` | نقطهٔ شروع هر برنامه. `int` یعنی تابع یک عدد صحیح برمی‌گرداند. **همیشه فقط یک `main` در کل برنامه وجود دارد.** |
| `{` و `}` | بدنهٔ تابع؛ هر چیزی بین این دو، دستورهای `main` است. |
| `std::cout` | جریان خروجی استاندارد روی صفحه. `std` نام **فضای نام (namespace)** کتابخانهٔ استاندارد است و `cout` («character output») داخل آن. |
| `<<` | عملگر درج (insertion): داده را از راست به چپ به `std::cout` می‌فرستد. |
| `"Hello, C++!"` | یک رشتهٔ متنی (string literal) بین دو کوتیشن دوتایی. |
| `std::endl` | پایان خط (end line): خط را می‌شکند **و** بافر خروجی را خالی می‌کند. |
| `;` | پایان هر دستور. فراموش‌کردنش شایع‌ترین خطای مبتدی‌هاست. |
| `return 0;` | کد خروج برنامه به سیستم‌عامل؛ `0` یعنی موفق، هر مقدار دیگر یعنی خطا. |

## کامپایل و اجرا

```bash
# از داخل پوشهٔ session-01-intro
g++ -std=c++17 -Wall -Wextra -o hello examples/01_hello.cpp
./hello
```

خروجی:

```
Hello, C++!
```

معنای پرچم‌ها:

| پرچم | کار |
|---|---|
| `-std=c++17` | انتخاب نسخهٔ استاندارد؛ در این دوره همیشه `c++17` (یا جدیدتر) |
| `-Wall -Wextra` | فعال‌کردن همهٔ هشدارهای مهم. **همیشه استفاده کنید** و هشدارها را خطا بدانید |
| `-o hello` | نام فایل خروجی. بدون آن فایل `a.out` ساخته می‌شود |

> در ویندوز خروجی `hello.exe` نام می‌گیرد و با `.\hello.exe` اجرا می‌شود.

### مراحلی که g++ پشت صحنه انجام می‌دهد

1. **پیش‌پردازش:** `#include`ها جای‌گذاری می‌شوند.
2. **کامپایل:** هر فایل `.cpp` به **کد شیء (object)** تبدیل می‌شود.
3. **لینک:** کد شیء با کتابخانه‌هایی مثل `libstdc++` ترکیب می‌شود و فایل اجرایی ساخته می‌شود.

به همین دلیل دو نوع خطا داریم: **خطای کامپایل** (مثل فراموش کردن `;`) و **خطای لینک** (مثل نبودن `main`). پیام خطاها را دقیق بخوانید؛ شمارهٔ خط و ستون را نشان می‌دهند.

## endl یا \n؟

فایل `examples/02_comments_and_include.cpp` سه شکل چاپ را نشان می‌دهد:

```cpp
std::cout << "خط اول: سلام!" << std::endl;      // خط + خالی کردن بافر
std::cout << "خط دوم: هنوز C++ است؟\n";         // فقط شکستن خط
std::string name = "برنامه‌نویس";
std::cout << "خط سوم: " << name << " خوش آمدی. " << 13 * 2 << "\n";
```

- `\n` کاراکتر «خط جدید» است و سریع‌تر است، چون بافر را خالی نمی‌کند.
- `std::endl` هم `\n` می‌گذارد و هم `flush` می‌کند؛ وقتی خروجی باید فوراً دیده شود (مثلاً لاگ یا برنامهٔ تعاملی) به کار می‌آید.
- در کد واقعی، معمولاً `"\n"` کافی است.

> نکتهٔ مهم در همان فایل: کامنت بلوکی (`/* ... */`) را نمی‌توان تودرتو نوشت؛ اولین نشانهٔ پایان، کامنت را می‌بندد.

## اشتباهات رایج

1. **فراموشی `;`** → `error: expected ';' before ...`
2. **فراموشی `#include <iostream>`** → `error: 'cout' is not a member of 'std'`
3. **نوشتن `cout` بدون `std::`** → همان خطای بالا. یا `std::` بنویسید یا در جلسهٔ ۴۰ راه‌حل‌های درست `using` را می‌بینیم.
4. **`void main()`** → استاندارد می‌گوید `int main()`؛ بعضی کامپایلرها رد می‌کنند.
5. **اجرای فایل `.cpp` به‌جای فایل اجرایی** → `./hello` را اجرا کنید، نه `./hello.cpp`.
6. **نام اشتباه فایل در دستور کامپایل** → `fatal error: examples/01_hello.cpp: No such file or directory`.
7. **`Main` یا `MAIN`** → C++ به بزرگی و کوچکی حروف حساس است.
8. **چاپ شیء بدون `<<` مناسب** → فعلاً موضوع ما نیست؛ در جلسهٔ ۱۸ (`operator<<`) حلش می‌کنیم.

## بهترین شیوه‌ها

- همیشه `-std=c++17 -Wall -Wextra` را در دستور کامپایل بنویسید؛ کد بدون هشدار، کد سالم‌تری است.
- از `std::endl` فقط وقتی لازم است استفاده کنید؛ در چاپ‌های زیاد، `"\n"` سریع‌تر است.
- کد را کوچک شروع کنید: یک فایل، یک `main`، یک خروجی؛ بعد گسترش دهید.
- برای هر تمرین فایل جدا بسازید (`exercise_01.cpp`) و فایل راه‌حل را دست نزنید تا خودتان اول تلاش کنید.
- قبل از اجرا، حتماً کامپایل کنید؛ «برنامه اجرا نمی‌شود» اغلب یعنی «کامپایل نشده است».

## خلاصهٔ جلسه

- C++ زبانی چندپارادایمی و مدرن است؛ خیلی از کدهای C را می‌پذیرد اما متفاوت‌تر از C است.
- `g++ -std=c++17 -Wall -Wextra -o name file.cpp` برنامه را می‌سازد.
- هر برنامه دقیقاً یک `int main()` دارد.
- `std::cout << چیزی` چاپ می‌کند؛ `"\n"` یا `std::endl` خط را می‌شکند.
- `return 0;` خروج موفق را اعلام می‌کند.
