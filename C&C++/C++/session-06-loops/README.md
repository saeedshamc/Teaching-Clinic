# جلسهٔ ۶ — حلقه‌ها: `for`، `while` و `do-while`

> حلقه قلب هر برنامهٔ واقعی است: تکرار تا وقتی کاری تمام شود.

---

## اهداف این جلسه

1. با `for`، `while` و `do-while` هر نوع تکراری را بنویسید.
2. بدانید هر کدام کجا مناسب‌تر است.
3. با `break` و `continue` جریان حلقه را کنترل کنید.
4. حلقهٔ تودرتو بنویسید (جدول ضرب، الگو).
5. از حلقهٔ بی‌پایان و خطاهای مرزی دور بمانید.

---

## ۱. `for`

وقتی تعداد تکرار **معلوم** است:

```cpp
for (int i = 1; i <= 5; ++i) {
    std::cout << i << " ";
}
// خروجی: 1 2 3 4 5
```

سه بخش `for`:

| بخش | نقش | اجرا |
|---|---|---|
| `int i = 1` | مقدار اولیه | یک‌بار، قبل از حلقه |
| `i <= 5` | شرط ادامه | قبل از هر تکرار |
| `++i` | گام | بعد از هر تکرار |

شمارش از صفر (رایج‌ترین حالت در C++):

```cpp
for (int i = 0; i < n; ++i) { ... }   // n بار اجرا، i از 0 تا n-1
```

> **خطای مرزی کلاسیک:** `i <= n` به‌جای `i < n` یک بار اضافه اجرا می‌کند و آرایه را از محدوده بیرون می‌برد.

---

## ۲. `while`

وقتی تعداد تکرار **از قبل معلوم نیست** و به یک شرط بستگی دارد:

```cpp
int n = 1;
while (n <= 5) {
    std::cout << n << " ";
    ++n;
}
```

اگر شرط از ابتدا غلط باشد، بدنه **هیچ‌وقت** اجرا نمی‌شود. اگر شرط هیچ‌وقت غلط نشود، حلقه **بی‌پایان** می‌شود:

```cpp
while (true) {
    // ...
    if (shouldStop) break;   // راه خروج
}
```

خواندن تا پایان ورودی:

```cpp
int value = 0;
while (std::cin >> value) {
    std::cout << value * 2 << "\n";
}
```

این الگو بسیار مهم است: وقتی `cin` به پایان فایل برسد (Ctrl+D)، خواندن شکست می‌خورد و حلقه تمام می‌شود.

---

## ۳. `do-while`

بدنه **حداقل یک‌بار** اجرا می‌شود، چون شرط در پایان بررسی می‌شود:

```cpp
int choice = 0;
do {
    std::cout << "1) ادامه  2) خروج\n";
    std::cout << "انتخاب: ";
} while (std::cin >> choice && choice != 2);
```

کاربرد اصلی: منوها و «تکرار تا وقتی کاربر نخواهد قطع کند».

تفاوت کلیدی با `while`: اگر ورودی از اول نامعتبر باشد، `while` هیچ‌وقت منو را نشان نمی‌دهد، `do-while` یک‌بار نشان می‌دهد.

---

## ۴. `break` و `continue`

```cpp
for (int i = 1; i <= 10; ++i) {
    if (i == 4) continue;   // ۴ را رد کن، بقیه ادامه
    if (i == 7) break;      // کل حلقه را تمام کن
    std::cout << i << " ";  // 1 2 3 5 6
}
```

- `continue` بقیهٔ بدنهٔ همین تکرار را رد می‌کند و به گام بعدی می‌رود.
- `break` از **نزدیک‌ترین** حلقه یا `switch` خارج می‌شود.
- `break` داخل حلقهٔ تودرتو فقط داخلی را می‌شکند، نه هر دو را. برای خروج از هر دو از یک `bool` یا `goto`/تابع استفاده کنید.

---

## ۵. حلقهٔ تودرتو

```cpp
for (int row = 1; row <= 3; ++row) {
    for (int col = 1; col <= 3; ++col) {
        std::cout << row * col << "\t";
    }
    std::cout << "\n";
}
```

خروجی:

```
1	2	3
2	4	6
3	6	9
```

تعداد کل تکرارها = حاصل‌ضرب دو شمارش. حلقهٔ تودرتو برای جدول، ماتریس و الگوهای ستاره‌ای استفاده می‌شود.

### ۶.۱ `01_for.cpp`

```cpp
long long factorial = 1;
for (int i = 1; i <= n; ++i) {
    factorial *= i;
}
```

`long long` انتخاب شده تا `20!` هم جا شود؛ `int` در `13!` سرریز می‌کند.

### ۶.۲ `02_while_do.cpp`

خواندن عدد مثبت تا وقتی کاربر مقدار درست بدهد:

```cpp
int n = 0;
while (true) {
    std::cout << "عدد مثبت: ";
    if (!(std::cin >> n)) { break; }     // ورودی تمام شد
    if (n > 0) { break; }                // معتبر است
    std::cout << "باید بزرگ‌تر از صفر باشد.\n";
}
```

و منوی `do-while` با گزینه‌های جمع کردن عدد، نمایش جمع و خروج.

```cpp
for (int row = 1; row <= 5; ++row) {
    for (int star = 1; star <= row; ++star) {
        std::cout << "*";
    }
    std::cout << "\n";
}
```

## ۷. اشتباهات رایج

1. **فراموش کردن افزایش شمارنده** در `while` → حلقهٔ بی‌پایان.
2. **شرط مرزی `<=` به‌جای `<`** در پیمایش.
3. **`;` بعد از `for`**: `for (int i = 0; i < n; ++i);` بدنهٔ خالی می‌سازد.
4. **تغییر شمارندهٔ `for` داخل بدنه**؛ منطق را غیرقابل‌پیش‌بینی می‌کند.
5. **استفاده از `float` به‌عنوان شمارنده**: `for (float f = 0; f != 1; f += 0.1)` ممکن است هرگز تمام نشود.
6. **`break` فقط از یک سطح خارج می‌شود**، نه از حلقه‌های تودرتو.
7. **سرریز در جمع/ضرب داخل حلقه**؛ نوع متغیر تجمعی را بزرگ انتخاب کنید.

---

## ۸. بهترین شیوه‌ها

- اگر تعداد تکرار معلوم است `for`، اگر به شرط بستگی دارد `while`، اگر باید حداقل یک‌بار اجرا شود `do-while`.
- محدودهٔ حلقه را در متغیرهای `const` نگه دارید (`const int count = 10;`).
- نام شمارنده‌ها گویا باشد: `row`/`col` برای جدول، `i` برای شمارش ساده.
- از `while (true)` تنها با یک خروج مشخص استفاده کنید.
- برای پیمایش مجموعه‌ها در جلسهٔ ۹ به سراغ range-based for می‌رویم.

---

## ۹. خلاصه

- `for` = تعداد معلوم؛ `while` = شرط‌محور؛ `do-while` = حداقل یک‌بار.
- `break` خارج شدن، `continue` رد کردن یک تکرار.
- حلقهٔ تودرتو برای جدول و الگو؛ `break` تنها یک سطح را می‌شکند.
- خطاهای مرزی و فراموشی افزایش، دو دشمن اصلی حلقه‌ها هستند.
- برای خواندن تا پایان ورودی از `while (std::cin >> x)` استفاده کنید.
