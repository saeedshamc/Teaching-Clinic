# جلسهٔ ۴۰ — الگوریتم‌های مرتب‌سازی: حبابی، انتخابی، درجی

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- سه الگوریتم سادهٔ مرتب‌سازی را پیاده‌سازی کنید: Bubble، Selection، Insertion
- پیچیدگی زمانی O(n²) آن‌ها را درک کنید
- با `swap` و حلقه‌های تودرتو کار کنید
- بدانید چرا برای دادهٔ بزرگ از مرتب‌سازی بهتر (جلسهٔ ۴۱) استفاده می‌شود

---

## چرا مرتب‌سازی؟

دادهٔ مرتب جستجو (باینری)، نمایش و تحلیل را بسیار ساده‌تر می‌کند. این سه الگوریتم ساده، پایهٔ درک الگوریتم‌ها هستند (همه O(n²)).

## مرتب‌سازی حبابی (Bubble Sort)

هر پاس، بزرگ‌ترین عنصر را به انتها «حباب» می‌کند؛ عناصر مجاور را مقایسه و جابه‌جا می‌کنیم:

```c
void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j + 1]);
            }
        }
    }
}
```

## مرتب‌سازی انتخابی (Selection Sort)

در هر گام، **کوچک‌ترین عنصرِ باقی‌مانده** را پیدا و به جای درست می‌گذاریم:

```c
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }
        swap(&arr[i], &arr[min_idx]);
    }
}
```

## مرتب‌سازی درجی (Insertion Sort)

هر عنصر را در جای درستش در بخش مرتب‌شده «فرو می‌کنیم» (مثل مرتب کردن دستِ ورق):

```c
void insertion_sort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

## مقایسه

| الگوریتم | بهترین | میانگین | بدترین | حافظهٔ اضافه |
|---|---|---|---|---|
| حبابی | O(n) | O(n²) | O(n²) | O(1) |
| انتخابی | O(n²) | O(n²) | O(n²) | O(1) |
| درجی | O(n) | O(n²) | O(n²) | O(1) |

نکته: درجی برای دادهٔ «تقریباً مرتب» عالی است (O(n)). حبابی به‌ندرت بهترین انتخاب است.

## اشتباهات رایج

1. **خطای مرز در حلقه‌ها** (off-by-one) — `j < n - 1 - i` را دقیق نگه دارید.
2. **فراموش کردن اینکه مقایسه با `>` باشد نه `>=`** — پایداری.
3. **swap اشتباه بدون متغیر موقت.**
4. **فکر کردن اینکه O(n²) برای دادهٔ بزرگ خوب است** — برای n بزرگ، جلسهٔ ۴۱ (Merge/Quick) لازم است.

## بهترین شیوه‌ها

- swap را یک تابع کمکی کنید.
- قبل و بعد از مرتب‌سازی، آرایه را چاپ کنید تا صحت را ببینید.
- با آرایهٔ کوچک (مثلاً ۱۰ عنصر) تست کنید.

## خلاصهٔ جلسه

- حبابی، انتخابی، درجی — سه الگوریتم O(n²).
- هر کدام ایدهٔ متفاوتی دارند: حباب کردن، انتخاب کمینه، فرو کردن.
- برای دادهٔ بزرگ از Merge/Quick Sort استفاده کنید.
