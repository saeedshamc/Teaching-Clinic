# جلسهٔ ۱۰ — بازگشت (Recursion) پایه

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- بازگشت (تابعی که خودش را صدا می‌زند) را بفهمید
- فاکتوریل، فیبوناچی و جمع بازگشتی بنویسید
- «شرط پایه» (base case) و «شرط بازگشتی» را تشخیص دهید
- خطرات بازگشت (پشتهٔ عمیق) را بشناسید

---

## بازگشت چیست؟

تابع بازگشتی تابعی است که **خودش را صدا می‌زند**. هر صدا زدن، یک «نسخهٔ جدید» از تابع با متغیرهای محلی مستقل می‌سازد.

```c
int factorial(int n) {
    if (n <= 1) {
        return 1;          // شرط پایه: توقف
    }
    return n * factorial(n - 1);   // شرط بازگشتی
}
```

## دو بخش ضروری هر تابع بازگشتی

1. **شرط پایه (Base case):** حالتی که بدون صدا زدن خودش جواب می‌دهد — مانع بی‌نهایت شدن.
2. **شرط بازگشتی (Recursive case):** مسئله را به نسخهٔ کوچک‌تر از خودش کاهش می‌دهد.

اگر شرط پایه نباشد یا به آن نرسیم → **سرریز پشته (Stack Overflow)** و کرش.

## فاکتوریل قدم‌به‌قدم

`factorial(4)`:

```
factorial(4) = 4 * factorial(3)
             = 4 * 3 * factorial(2)
             = 4 * 3 * 2 * factorial(1)
             = 4 * 3 * 2 * 1
             = 24
```

## حلقه یا بازگشت؟

- بازگشت برای مسائل «طبیعتاً بازگشتی» (درخت، تقسیم و حل) خوانا است.
- هر بازگشتی را می‌توان با حلقه نوشت و بالعکس.
- بازگشت پشته مصرف می‌کند؛ برای عمق زیاد از حلقه استفاده کنید.

## اشتباهات رایج

1. **فراموش کردن شرط پایه** → بی‌نهایت → stack overflow.
2. **شرط پایه‌ای که هرگز صادق نمی‌شود** (مثلاً `factorial(-1)`).
3. **دوباره‌محاسبه در فیبوناچی:** `fib(n)` با بازگشت ساده، همان مقادیر را بارها حساب می‌کند (آشفتگی نمایی). برای اعداد بزرگ از حلقه استفاده کنید.

## بهترین شیوه‌ها

- همیشه ابتدا شرط پایه را بنویسید.
- مطمئن شوید ورودی در هر گام به شرط پایه نزدیک‌تر می‌شود.
- عمق بازگشت را برای ورودی‌های بزرگ در نظر بگیرید.

## خلاصهٔ جلسه

- بازگشت: تابعی که خودش را صدا می‌زند، با شرط پایه و شرط بازگشتی.
- فاکتوریل و فیبوناچی مثال‌های کلاسیک‌اند.
- بدون شرط پایه → سرریز پشته.

## تمرین‌ها

### تمرین ۱ (ساده)
تابع بازگشتی `sum_to(int n)` بنویسید که مجموع ۱ تا n را برمی‌گرداند: `sum_to(5) == 15`.

### تمرین ۲ (متوسط)
تابع بازگشتی `power(int base, int exp)` بنویسید که `base^exp` را محاسبه کند (با فرض exp >= 0).

راه‌حل‌ها در `exercises/` هستند.
