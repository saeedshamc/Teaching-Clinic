# جلسهٔ ۳ — عملگرها و اولویت آن‌ها

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- عملگرهای حسابی، مقایسه‌ای، منطقی و انتسابی را به کار ببرید
- عملگرهای `++` و `--` و تفاوت پیشوند/پسوند را بدانید
- اولویت عملگرها (Precedence) و نحوهٔ استفاده از پرانتز را توضیح دهید
- عملگرهای ترکیبی مثل `+=` را بشناسید

---

## دسته‌بندی عملگرها

### ۱) عملگرهای حسابی

| عملگر | معنی | مثال |
|---|---|---|
| `+` | جمع | `5 + 2` → 7 |
| `-` | تفریق | `5 - 2` → 3 |
| `*` | ضرب | `5 * 2` → 10 |
| `/` | تقسیم | `5 / 2` → 2 (عدد صحیح!) |
| `%` | باقیمانده | `5 % 2` → 1 |

⚠️ تقسیم دو عدد صحیح، نتیجهٔ صحیح (بدون اعشار) می‌دهد: `7 / 2 == 3`.

### ۲) عملگرهای مقایسه‌ای

`>`، `<`، `>=`، `<=`، `==` (برابری)، `!=` (نابرابری) — نتیجه ۱ (درست) یا ۰ (نادرست) است.

### ۳) عملگرهای منطقی

| عملگر | معنی | مثال |
|---|---|---|
| `&&` | و (هر دو درست) | `(a > 0 && b > 0)` |
| `\|\|` | یا (یکی درست) | `(a > 0 \|\| b > 0)` |
| `!` | نقیض | `!flag` |

### ۴) عملگرهای انتساب ترکیبی

`+=`، `-=`، `*=`، `/=`، `%=` — مثال: `x += 5` معادل `x = x + 5` است.

### ۵) عملگرهای افزایش/کاهش

- `x++` (پسوند): اول مقدار فعلی استفاده می‌شود، بعد x زیاد می‌شود.
- `++x` (پیشوند): اول x زیاد می‌شود، بعد مقدار جدید استفاده می‌شود.

## اولویت عملگرها (Precedence)

عملگرها اولویت مشخصی دارند — مثل ریاضی که `*` بر `+` مقدم است:

1. `()` پرانتز — بالاترین اولویت
2. `++` `--` `!` (یک‌عملوندی)
3. `*` `/` `%`
4. `+` `-`
5. `<` `<=` `>` `>=`
6. `==` `!=`
7. `&&`
8. `||`
9. `=` (انتساب) — پایین‌ترین

**قانون طلایی:** اگر حتی کمی شک دارید، از پرانتز استفاده کنید. `(a + b) * c` خواناتر و امن‌تر از اتکا به حافظه‌سپاری اولویت‌هاست.

## اشتباهات رایج

1. **جای `==` از `=` استفاده کردن** — `if (x = 5)` مقدار ۵ را به x می‌دهد (و همیشه درست است!) به‌جای مقایسه. این یکی از بدترین باگ‌های C است.
2. **تقسیم صحیح:** `5 / 2 == 2` نه ۲.۵.
3. **فراموشی اولویت:** `1 + 2 * 3` برابر ۷ است نه ۹.

## بهترین شیوه‌ها

- همیشه برای ابهام از پرانتز استفاده کنید.
- در مقایسه، ثابت را سمت چپ ننویسید: `if (x == 5)` بهتر از `if (5 == x)` (هرچند این یکی از ترفندهای محافظت است، خوانایی مهم‌تر است).
- از زنجیره‌های طولانی `&&`/`||` بدون پرانتز پرهیز کنید.

## خلاصهٔ جلسه

- عملگرهای حسابی، مقایسه‌ای، منطقی، انتسابی و افزایش/کاهش را دیدید.
- تقسیم صحیح در C بدون اعشار است.
- پرانتز بالاترین اولویت را دارد و ابهام را از بین می‌برد.

## تمرین‌ها

### تمرین ۱ (ساده)
خروجی این عبارت‌ها را بدون کامپایل حدس بزنید، بعد با کد چک کنید: `10 / 3`، `10 % 3`، `(3 + 4) * 2`، `3 + 4 * 2`، `10 > 5 && 3 < 2`، `!(10 > 5)`.

### تمرین ۲ (متوسط)
برنامه‌ای بنویسید که عددی سه‌رقمی بگیرد و ارقام آن را جدا کند (مثلاً ۳۵۷ → ۳، ۵، ۷). راهنمایی: از `% 10` و `/ 10` استفاده کنید.

راه‌حل‌ها در `exercises/` هستند.
