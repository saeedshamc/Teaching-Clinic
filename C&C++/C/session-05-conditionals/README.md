# جلسهٔ ۵ — شرط‌ها (if/else/switch)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `if`، `else if` و `else` تصمیم‌گیری کنید
- از `switch` برای انتخاب بین چند مقدار استفاده کنید
- شرط‌های مرکب با `&&` و `||` بنویسید
- تفاوت `if-else if` و `switch` را بدانید

---

## if / else if / else

```c
if (شرط) {
    // اگر شرط درست بود
} else if (شرط دوم) {
    // وگرنه اگر شرط دوم درست بود
} else {
    // در غیر این صورت
}
```

قوانین:

- شرط به «صفر = نادرست، غیرصفر = درست» ارزیابی می‌شود.
- اگر بدنه فقط یک دستور باشد، آکولاد اختیاری است اما **همیشه بنویسید** تا باگ پیش نیاید.
- ترتیب `else if` مهم است؛ اولین شرط درست اجرا می‌شود.

## شرط سه‌تایی (ternary)

```c
int max = (a > b) ? a : b;   // اگر a بزرگ‌تر بود a، وگرنه b
```

## switch

```c
switch (متغیر) {
    case 1:
        // ...
        break;
    case 2:
        // ...
        break;
    default:
        // وقتی هیچ case هم‌خوان نبود
        break;
}
```

نکات مهم switch:

- فقط با اعداد صحیح و enum کار می‌کند (نه رشته، نه double).
- بدون `break`، اجرا به case بعدی «نشت» می‌کند (fall-through). گاهی عمدی است (دسته‌بندی چند مقدار)، ولی معمولاً باگ است.
- `default` اختیاری است ولی توصیه می‌شود.

## اشتباهات رایج

1. **استفاده از `=` به‌جای `==`:** `if (x = 5)` به x مقدار ۵ می‌دهد و همیشه درست است. اگر ثابت را سمت چپ بنویسید (`if (5 == x)`)، کامپایلر خطای انتساب به ثابت می‌دهد.
2. **فراموش کردن `break` در switch** — fall-through ناخواسته.
3. **مقایسهٔ float با ==** — اعشار دقت محدود دارند؛ `0.1 + 0.2 != 0.3` است. به‌جای آن از بازه استفاده کنید: `fabs(a - b) < 0.0001`.

## بهترین شیوه‌ها

- همیشه برای `else` و آکولادها از سبک یکسان استفاده کنید.
- در `switch` همیشه `default` بگذارید.
- منطق پیچیده را به تابع جدا منتقل کنید (جلسات بعد).

## خلاصهٔ جلسه

- `if/else if/else` برای شرایط، `switch` برای انتخاب چند مقداره.
- شرط سه‌تایی `?:` میان‌بری برای if-else ساده است.
- مراقب `=` به‌جای `==` و `break` فراموش‌شده باشید.
