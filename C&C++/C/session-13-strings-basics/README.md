# جلسهٔ ۱۳ — رشته‌ها (char array) — مبانی

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- رشته را به‌عنوان آرایه‌ای از char و با کاراکتر پایانی `\0` بفهمید
- رشته تعریف کنید، چاپ کنید و با حلقه پیمایش کنید
- رشته را با `fgets` بخوانید و با `%s` چاپ کنید
- با مشکلات سرریز بافر آشنا شوید

---

## رشته در C چیست؟

در C «نوع رشته» نداریم! رشته یک **آرایهٔ char** است که با کاراکتر `\0` (null terminator) تمام می‌شود:

```c
char name[10] = "Ali";   // A l i \0
```

`\0` به برنامه می‌گوید رشته اینجا تمام می‌شود. به همین دلیل یک رشتهٔ n حرفی به `n+1` خانه نیاز دارد.

## دو روش تعریف رشته

```c
char s1[] = "Hello";            // اندازه خودکار: ۶ (۵ حرف + \0)
char s2[20] = "Hello";          // ۲۰ خانه، فقط ۶ تای اول پر است
```

نکته: `"Hello"` یک **رشتهٔ لیترال** است؛ بهتر است برای اشاره‌گر به آن از `const char *` استفاده کنید تا تصادفاً تغییرش ندهید.

## چاپ و خواندن

```c
printf("%s\n", name);           // چاپ
scanf("%19s", buffer);          // خواندن تا فضای خالی (خطرناک اما با طول محدود)
fgets(buffer, 20, stdin);       // خواندن کل خط (امن‌تر)
```

## هشدار امنیتی: سرریز بافر

`scanf("%s", buffer)` بدون محدودیت طول، می‌تواند بیش از ظرفیت آرایه بنویسد و حافظه را خراب کند (buffer overflow) — حملهٔ کلاسیک هکرها! همیشه طول را محدود کنید یا از `fgets` استفاده کنید.

## اشتباهات رایج

1. **فراموش کردن فضای `\0`:** `char s[3] = "Ali";` جا برای `\0` ندارد → رفتار نامشخص.
2. **مقایسهٔ رشته با `==`:** `if (s1 == s2)` آدرس‌ها را مقایسه می‌کند نه محتوا! باید از `strcmp` استفاده کنید (جلسهٔ بعد).
3. **`scanf("%s")` بدون محدودیت طول** — سرریز بافر.
4. **فراموش کردن `\0` در انتهای آرایه‌ای که دستی می‌سازید** — تابع `%s` تا اولین `\0` ادامه می‌دهد و فراتر از آرایه می‌خواند.

## بهترین شیوه‌ها

- برای خواندن خط از کاربر از `fgets` استفاده کنید نه `scanf("%s")`.
- طول بافر را همیشه با `sizeof` بدهید.
- در `printf("%s")` و `scanf` طول را محدود کنید: `%19s` برای بافر ۲۰تایی.

## خلاصهٔ جلسه

- رشته = آرایهٔ char + کاراکتر پایانی `\0`.
- برای n حرف به n+1 خانه نیاز است.
- `fgets` امن‌تر از `scanf("%s")` است.
