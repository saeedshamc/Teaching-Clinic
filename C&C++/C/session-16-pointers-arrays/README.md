# جلسهٔ ۱۶ — اشاره‌گرها و آرایه‌ها

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- بفهمید نام آرایه در C یک اشاره‌گر به عنصر اول است
- آرایه را با اشاره‌گر پیمایش کنید و رابطهٔ `a[i]` و `*(a+i)` را بدانید
- اشاره‌گر حسابی (pointer arithmetic) را درک کنید
- تفاوت آرایه و اشاره‌گر را بشناسید

---

## رابطهٔ آرایه و اشاره‌گر

در C، **نام آرایه به‌عنوان آدرس عنصر اول** رفتار می‌کند:

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;        // p به arr[0] اشاره می‌کند (و نه &arr[0] هم معادل است)
```

پس این‌ها معادل‌اند:

```c
arr[i]   ==  *(arr + i)
&arr[i]  ==  arr + i
```

## اشاره‌گر حسابی (Pointer Arithmetic)

اگر `p` به یک `int` اشاره کند:

- `p + 1` → آدرس عنصر بعدی (به اندازهٔ `sizeof(int)` جلوتر، نه ۱ بایت!)
- `p - 1` → عنصر قبلی
- `p[i]` → همان `*(p + i)`

```c
for (int *q = arr; q < arr + 5; q++) {
    printf("%d ", *q);    // پیمایش با اشاره‌گر
}
```

## تفاوت آرایه و اشاره‌گر

| آرایه | اشاره‌گر |
|---|---|
| بلوک واقعی حافظه است | فقط آدرس نگه می‌دارد |
| `arr` را نمی‌توان دوباره انتساب داد (`arr = p` خطاست) | `p = arr` ممکن است |
| `sizeof(arr)` اندازهٔ کل آرایه | `sizeof(p)` اندازهٔ اشاره‌گر |

وقتی آرایه به تابع داده می‌شود، **به اشاره‌گر نزول می‌کند** (decay)؛ پس داخل تابع `sizeof` روی آن اندازهٔ اشاره‌گر را می‌دهد نه آرایه را. به همین دلیل طول آرایه را همیشه جداگانه پاس می‌دهیم.

## هشدارها

- پیمایش فراتر از انتهای آرایه → undefined behavior.
- `sizeof(arr)` را فقط در همان جایی که آرایه تعریف شده استفاده کنید، نه در تابعی که آرایه را گرفته.

## اشتباهات رایج

1. **`p + 1` را «یک بایت جلوتر» تصور کردن** — به اندازهٔ یک عنصر جلو می‌رود.
2. **تغییر نام آرایه:** `arr++` خطاست؛ `p++` درست است.
3. **گذاشتن `&` اضافه:** `p = &arr` نوعش با `p = arr` فرق دارد (اشاره‌گر به آرایهٔ کامل).
4. **استفاده از `sizeof` روی آرایهٔ نزول‌کرده در تابع.**

## بهترین شیوه‌ها

- برای خوانایی از ایندکس `a[i]` استفاده کنید مگر اینکه دلیل خاصی برای اشاره‌گر داشته باشید.
- وقتی آرایه را به تابع می‌دهید، طول را هم پاس دهید.
- از `p < arr + size` برای شرط پایان پیمایش استفاده کنید.

## خلاصهٔ جلسه

- `arr[i]` همان `*(arr + i)` است؛ نام آرایه = آدرس عنصر اول.
- اشاره‌گر حسابی بر اساس اندازهٔ عنصر است.
- آرایه در تابع به اشاره‌گر نزول می‌کند.
