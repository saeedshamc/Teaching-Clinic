# جلسهٔ ۱۱ — آرایه‌های یک‌بعدی

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- آرایهٔ یک‌بعدی تعریف، مقداردهی و پیمایش کنید
- با ایندکس (شاخص) به عناصر دسترسی پیدا کنید
- از حلقه برای کار با آرایه استفاده کنید و خطای out-of-bounds را بشناسید

---

## آرایه چیست؟

آرایه مجموعه‌ای از **عناصر همنوع** است که پشت‌سرهم در حافظه قرار می‌گیرند. یک آرایهٔ ۵تایی از `int` مثل ۵ اتاق کنار هم است که هر کدام یک `int` نگه می‌دارند.

```c
int scores[5];              // آرایهٔ ۵ عنصری
scores[0] = 90;             // اولین عنصر (شاخص ۰)
scores[4] = 75;             // آخرین عنصر (شاخص ۴)
```

## نکات کلیدی

1. **شاخص از صفر شروع می‌شود:** آرایهٔ n عنصری شاخص‌های `0` تا `n-1` دارد. `scores[5]` خارج از محدوده است!
2. **اندازه باید ثابت باشد** (در C99+ می‌توان VLA هم داشت، ولی بهتر است از ثابت استفاده کنید).
3. مقداردهی اولیه:

```c
int a[5] = {1, 2, 3, 4, 5};      // کامل
int b[5] = {1, 2};               // بقیه صفر می‌شوند: {1,2,0,0,0}
int c[] = {10, 20, 30};          // اندازه از روی مقادیر حدس زده می‌شود: 3
```

## پیمایش با حلقه

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", scores[i]);
}
```

## هشدار مهم: خارج از محدوده (Out of Bounds)

خواندن یا نوشتن خارج از محدودهٔ آرایه **رفتار تعریف‌نشده (undefined behavior)** است: ممکن است مقدار تصادفی بخوانید، برنامه کرش کند یا حافظهٔ مجاور خراب شود (سرریز بافر). کامپایلر معمولاً خطا نمی‌دهد — این خطرناک‌ترین بخش آرایه در C است!

## اشتباهات رایج

1. **شاخص از ۱ شروع کردن** — عنصر اول `[0]` است، نه `[1]`.
2. **استفاده از `a[n]` در آرایهٔ n عنصری** — خارج از محدوده.
3. **فراموش کردن مقداردهی** — عناصر مقداردهی‌نشده مقدار تصادفی دارند (مگر مقداردهی اولیه با `{}` که بقیه را صفر می‌کند).

## بهترین شیوه‌ها

- اندازهٔ آرایه را با `#define` یا `const` تعریف کنید تا در همه‌جا یکسان باشد.
- حلقه‌ها را با `i < SIZE` بنویسید نه `i <= SIZE`.
- از `sizeof(arr) / sizeof(arr[0])` برای محاسبهٔ تعداد عناصر (در همان اسکوپ تعریف) استفاده کنید.

## خلاصهٔ جلسه

- آرایه = عناصر همنوع پشت‌سرهم؛ شاخص از ۰ شروع می‌شود.
- پیمایش با حلقهٔ for انجام می‌شود.
- بیرون از محدوده نروید — undefined behavior!
