# جلسهٔ ۳۴ — لیست پیوندی یک‌طرفه (Singly Linked List)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- ساختار گره (node) و لیست پیوندی یک‌طرفه را بفهمید
- عملیات اصلی: insert، delete، search و print را پیاده‌سازی کنید
- حافظهٔ هر گره را درست مدیریت کنید (malloc/free)
- مقایسهٔ لیست پیوندی با آرایه را بدانید

---

## چرا لیست پیوندی؟

آرایه اندازهٔ ثابت دارد و درج/حذف وسط آن گران است. **لیست پیوندی** زنجیره‌ای از گره‌هاست که هر گره به گرهٔ بعدی اشاره می‌کند — درج/حذف در O(1) با آدرس درست، و اندازهٔ پویا.

## گره چیست؟

```c
typedef struct Node {
    int data;              /* داده */
    struct Node *next;     /* اشاره‌گر به گرهٔ بعدی */
} Node;
```

لیست با یک اشاره‌گر به اولین گره (head) شروع می‌شود؛ گرهٔ آخر `next = NULL` دارد.

## عملیات پایه

```c
/* درج در ابتدا */
Node *prepend(Node *head, int value) {
    Node *new_node = malloc(sizeof(Node));
    if (new_node == NULL) return head;
    new_node->data = value;
    new_node->next = head;
    return new_node;   /* head جدید */
}

/* پیمایش */
void print_list(Node *head) {
    for (Node *p = head; p != NULL; p = p->next) {
        printf("%d -> ", p->data);
    }
    printf("NULL\n");
}

/* آزادسازی همه */
void free_list(Node *head) {
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
}
```

## نکات حیاتی

1. **همیشه NULL بودن head را چک کنید** (لیست خالی).
2. **هنگام حذف، اول next را ذخیره کنید بعد free** — وگرنه به گرهٔ آزادشده دسترسی می‌کنید (dangling).
3. **هر malloc یک free** — در غیر این صورت نشت حافظه.
4. **دسترسی تصادفی O(1) وجود ندارد** — باید پیمایش کرد (O(n)).

## اشتباهات رایج

1. **free کردن گره قبل از ذخیرهٔ next** — گرهٔ بعدی گم می‌شود.
2. **فراموش کردن به‌روزرسانی head بعد از درج ابتدا** — اگر تابع head جدید برگرداند، باید بگیرید.
3. **فراموش کردن `next = NULL` در گرهٔ آخر** — پیمایش بی‌نهایت.
4. **نشت حافظه با free نکردن** — با valgrind (جلسهٔ ۴۷) پیدا می‌شود.

## بهترین شیوه‌ها

- توابعی که head را تغییر می‌دهند، head جدید را برگردانند.
- همیشه free_list در پایان برنامه.
- برای درج/حذف وسط، اشاره‌گر به گرهٔ قبلی را نگه دارید.

## خلاصهٔ جلسه

- لیست پیوندی = گره‌های متصل با next.
- درج ابتدا/حذف/پیمایش/جستجو عملیات اصلی‌اند.
- مدیریت دقیق malloc/free الزامی است.
