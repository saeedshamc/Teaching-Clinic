# جلسهٔ ۲۴ — کار با فایل: مبانی fopen/fread/fwrite

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `fopen` فایل را باز کنید و با `fclose` ببندید
- با `fprintf`/`fscanf` متن بنویسید و بخوانید
- حالت‌های باز کردن (r/w/a) را بشناسید
- با `fgets`/`fputs` خط‌به‌خط کار کنید و خطاها را مدیریت کنید

---

## باز و بسته کردن فایل

```c
FILE *fp = fopen("data.txt", "w");   // w = write (نوشتن، پاک می‌کند)
if (fp == NULL) {
    printf("خطا در باز کردن فایل!\n");
    return 1;
}
fprintf(fp, "سلام دنیا\n");
fclose(fp);
```

حالت‌های مهم:

| حالت | معنی |
|---|---|
| `"r"` | خواندن (فایل باید وجود داشته باشد) |
| `"w"` | نوشتن (ساخته/پاک می‌شود) |
| `"a"` | افزودن به انتها |
| `"r+"` | خواندن و نوشتن (فایل باید باشد) |
| `"w+"` | خواندن و نوشتن (ساخته/پاک می‌شود) |
| `"rb"` / `"wb"` | دودویی (جلسهٔ بعد) |

## نوشتن و خواندن

```c
fprintf(fp, "%d %s\n", age, name);    // مثل printf ولی برای فایل
fscanf(fp, "%d", &age);               // مثل scanf ولی از فایل
fgets(line, sizeof(line), fp);        // خواندن یک خط
fputs(line, fp);                      // نوشتن یک خط
```

## نکات حیاتی

1. **همیشه `fopen` را چک کنید:** `NULL` یعنی خطا (فایل نیست، دسترسی نیست و...).
2. **همیشه `fclose` کنید:** داده‌ها در بافر ممکن است بدون fclose نوشته نشوند.
3. **در انتهای فایل:** `fgets` وقتی به EOF برسد `NULL` برمی‌گرداند — برای حلقهٔ خواندن استفاده کنید.
4. `feof(fp)` فقط بعد از تلاش ناموفق خواندن درست کار می‌کند؛ بهتر است از مقدار بازگشتی خودِ تابع خواندن استفاده کنید.

## اشتباهات رایج

1. **باز کردن با `"r"` فایلی که وجود ندارد** — NULL بدون مدیریت → کرش.
2. **فراموش کردن fclose** — نشت فایل و از دست رفتن داده.
3. **خواندن بیش از حد ظرفیت بافر.**
4. **استفاده از `fscanf("%s")` بدون محدودیت طول** — سرریز بافر.

## بهترین شیوه‌ها

- الگوی استاندارد: باز کن → چک NULL → کار → ببند.
- برای متن از `fgets` به‌جای `fscanf("%s")` استفاده کنید.
- بعد از `fclose`، `fp = NULL` بگذارید.

## خلاصهٔ جلسه

- fopen (با حالت r/w/a) باز می‌کند، fclose می‌بندد.
- fprintf/fscanf متن‌محور، fgets/fputs خط‌محورند.
- چک کردن NULL و بستن فایل اجباری است.
