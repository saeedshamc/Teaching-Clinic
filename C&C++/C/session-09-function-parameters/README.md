# جلسهٔ ۹ — پارامترهای تابع و Pass by Value

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- تفاوت ارسال «با مقدار» (by value) و «با ارجاع» (by reference) را توضیح دهید
- بفهمید چرا تغییر پارامترها داخل تابع، روی متغیر بیرون اثر نمی‌گذارد
- با محدودیت‌های C در ارسال پارامتر آشنا شوید (حل آن در جلسهٔ اشاره‌گرها)

---

## ارسال با مقدار (Pass by Value)

در C همهٔ پارامترها **با مقدار** ارسال می‌شوند؛ یعنی یک **کپی** از مقدار به تابع داده می‌شود:

```c
void increment(int x) {
    x = x + 1;   // فقط کپیِ محلی تغییر می‌کند
}

int main(void) {
    int n = 5;
    increment(n);
    printf("%d\n", n);   // هنوز ۵ است! نه ۶
    return 0;
}
```

چرا؟ چون `x` داخل تابع یک متغیر محلی است که مقدار اولیه‌اش را از `n` کپی گرفته. تغییرش هیچ ربطی به `n` ندارد.

## پس چطور مقدار را تغییر دهیم؟

- **از مقدار برگشتی استفاده کنید:**

```c
int increment(int x) {
    return x + 1;
}
n = increment(n);   // مقدار جدید به n برمی‌گردد
```

- **آدرس را ارسال کنید (با اشاره‌گر):** در جلسهٔ ۱۷ کامل بررسی می‌شود.

## پارامترها و آرگومان‌ها

- **پارامتر (parameter):** متغیر داخل تعریف تابع.
- **آرگومان (argument):** مقداری که هنگام صدا زدن می‌دهید.

```c
int add(int a, int b) { ... }   // a و b پارامترند
add(3, 4);                      // 3 و 4 آرگومان‌اند
```

## ترتیب ارزیابی آرگومان‌ها

ترتیب ارزیابی آرگومان‌ها در C **تعریف‌نشده** است؛ پس `foo(i++, i++)` رفتار نامشخص دارد. از آرگومان‌هایی که «اثر جانبی» دارند در یک صدا زدن اجتناب کنید.

## اشتباهات رایج

1. **انتظار تغییر متغیر بیرونی با pass by value** — شایع‌ترین سردرگمی مبتدی‌ها.
2. **فراموش کردن return و استفاده از مقدار نامشخص.**
3. **استفادهٔ هم‌زمان از `++` در چند آرگومان** — رفتار نامشخص.

## بهترین شیوه‌ها

- تابعی که فقط محاسبه می‌کند، با `return` نتیجه را برگرداند.
- از تغییر متغیرهای سراسری (global) داخل تابع بپرهیزید.
- پارامترهایی که فقط «خوانده» می‌شوند را `const` کنید (در اشاره‌گرها مهم‌تر است).

## خلاصهٔ جلسه

- C پارامترها را با مقدار (کپی) ارسال می‌کند.
- برای گرفتن نتیجه از `return` استفاده کنید.
- تغییر واقعی متغیر بیرونی نیاز به اشاره‌گر دارد (جلسهٔ ۱۷).

## تمرین‌ها

### تمرین ۱ (ساده)
تابع `swap_wrong(int a, int b)` بنویسید که می‌خواهد دو عدد را جابه‌جا کند اما چون by value است، بیرون تغییری نمی‌کند. خروجی را ببینید و دلیل را توضیح دهید.

### تمرین ۲ (متوسط)
تابع `get_sum_and_product(int a, int b, int *sum, int *product)` را با اشاره‌گر پیاده‌سازی کنید (پیش‌نمایش جلسهٔ ۱۷) — اگر بلد نیستید، فعلاً با return یکی از آن‌ها را برگردانید.
