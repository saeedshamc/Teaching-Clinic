# جلسهٔ ۷ — break، continue و goto

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `break` حلقه یا switch را زودتر متوقف کنید
- با `continue` به تکرار بعدی بروید
- بفهمید `goto` چیست و چرا معمولاً باید از آن پرهیز کرد

---

## break

`break` بلافاصله از **نزدیک‌ترین** حلقه یا `switch` بیرون می‌پرد:

```c
for (int i = 0; i < 10; i++) {
    if (i == 5) break;   // حلقه در ۵ متوقف می‌شود
}
```

کاربرد: جستجویی که با یافتن نتیجه باید متوقف شود.

## continue

`continue` بقیهٔ بدنه را رها می‌کند و به **تکرار بعدی** می‌رود:

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // اعداد زوج رد شوند
    printf("%d ", i);           // فقط فردها
}
```

## goto

`goto` به یک برچسب (label) می‌پرد:

```c
goto cleanup;
// ...
cleanup:
    printf("پاک‌سازی\n");
```

موارد استفادهٔ مشروع:

- خروج از چند حلقهٔ تودرتو به‌طور هم‌زمان (با break فقط از یکی خارج می‌شوید).
- الگوی «پاک‌سازی و خروج» در مدیریت خطا (در C رایج است).

هشدار: استفادهٔ بی‌رویه از `goto` کد را به «اسپاگتی» تبدیل می‌کند — فقط برای موارد بالا و با دقت استفاده کنید.

## اشتباهات رایج

1. **break در if داخل حلقه:** `break` فقط از حلقه/switch بیرون می‌پرد، نه از if.
2. **goto به داخل محدودهٔ یک متغیر** — رفتار تعریف‌نشده/خطرناک.
3. **continue در حلقهٔ while که گام آخر بدنه است** — ممکن است گام پرش شود و حلقه بی‌نهایت شود! گام را قبل از continue قرار دهید.

## بهترین شیوه‌ها

- از `break` برای خروج زودهنگام با دلیل واضح استفاده کنید.
- `goto` را محدود به الگوی cleanup/خروج از تودرتو کنید.
- با `continue` گام حلقه را از دست ندهید.

## خلاصهٔ جلسه

- `break`: خروج از حلقه/switch. `continue`: رد شدن به تکرار بعدی.
- `goto`: ابزار قدرتمند اما خطرناک؛ فقط برای موارد خاص.

## تمرین‌ها

### تمرین ۱ (ساده)
با `for` اعداد ۱ تا ۲۰ را چاپ کنید اما اعداد بخش‌پذیر بر ۳ را با `continue` رد کنید و بعد از عدد ۱۵ با `break` متوقف شوید.

### تمرین ۲ (متوسط)
برنامه‌ای بنویسید که اعداد اول ۲ تا ۵۰ را با حلقهٔ تودرتو و `break` چاپ کند (وقتی مقسوم‌علیه‌ای یافت شد break کنید).
