# جلسهٔ ۶ — حلقه‌ها (for/while/do-while)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `for`، `while` و `do-while` تکرار انجام دهید
- تفاوت سه نوع حلقه را بدانید و در جای درست استفاده کنید
- حلقه‌های تودرتو بنویسید و از بی‌نهایت شدن (infinite loop) جلوگیری کنید

---

## حلقهٔ for

زمانی که **تعداد تکرار از قبل مشخص است**:

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}
```

سه بخش دارد: (مقداردهی اولیه؛ شرط ادامه؛ گام). ترتیب اجرا: مقداردهی → شرط → بدنه → گام → شرط → ...

## حلقهٔ while

زمانی که **تکرار تا برقراری یک شرط** ادامه دارد:

```c
int n = 10;
while (n > 0) {
    printf("%d ", n);
    n--;
}
```

اگر شرط اولش نادرست باشد، بدنه یک بار هم اجرا نمی‌شود.

## حلقهٔ do-while

مثل while اما **حداقل یک بار** بدنه اجرا می‌شود (شرط آخر بررسی می‌شود):

```c
int choice;
do {
    printf("انتخاب (1-3): ");
    scanf("%d", &choice);
} while (choice < 1 || choice > 3);
```

مناسب منوهایی که حداقل یک بار باید نمایش داده شوند.

## حلقهٔ بی‌نهایت (infinite loop)

- `while (1) { ... }` یا `for (;;) { ... }` عمدی بی‌نهایت است (مثل سرورها).
- اگر گام یا به‌روزرسانی شرط را فراموش کنید، حلقهٔ ناخواستهٔ بی‌نهایت می‌سازید.

## اشتباهات رایج

1. **فراموش کردن به‌روزرسانی متغیر حلقه** — بی‌نهایت شدن.
2. **شرط خاموش:** `for (i = 0; i <= n; i++)` با `i < n` — خطای off-by-one. مراقب مرزها باشید.
3. **استفاده از `=` به‌جای `==` در شرط حلقه** — دوباره همان دام معروف.
4. **تغییر متغیر حلقه داخل بدنه** — کد غیرقابل پیش‌بینی می‌شود.

## بهترین شیوه‌ها

- اگر تعداد تکرار معلوم است از `for`، وگرنه از `while` استفاده کنید.
- `do-while` فقط وقتی لازم است که بدنه حداقل یک بار اجرا شود.
- متغیر حلقه را داخل `for` اعلان کنید (C99+).

## خلاصهٔ جلسه

- `for` برای تعداد معلوم، `while` برای شرط، `do-while` برای حداقل یک بار اجرا.
- از بی‌نهایت شدن ناخواسته و خطای off-by-one بپرهیزید.
