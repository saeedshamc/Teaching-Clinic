# جلسهٔ ۲۱ — یونیون‌ها (union)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- بفهمید union چیست و با struct چه فرقی دارد
- از union برای ذخیرهٔ «یکی از چند نوع» در یک مکان استفاده کنید
- موارد استفادهٔ عملی union را بشناسید

---

## union چیست؟

`union` مثل struct است، اما **همهٔ اعضا یک حافظهٔ مشترک** دارند؛ یعنی در هر لحظه فقط **یکی** از اعضا معتبر است:

```c
union Number {
    int i;
    float f;
    double d;
};
```

`sizeof(union Number)` برابر اندازهٔ **بزرگ‌ترین** عضو است (نه مجموع اعضا).

## فرق struct و union

| struct | union |
|---|---|
| هر عضو فضای جداگانه دارد | همهٔ اعضا یک فضا را شریک‌اند |
| `sizeof` = مجموع (به‌علاوهٔ padding) | `sizeof` = بزرگ‌ترین عضو |
| همهٔ اعضا هم‌زمان معتبرند | فقط آخرین عضو نوشته‌شده معتبر است |

```c
union Number n;
n.i = 42;      // حالا i معتبر است
n.f = 3.14;    // نوشتن f مقدار i را «خراب» می‌کند!
```

## کاربرد واقعی: نوع پویا (variant/tagged union)

union معمولاً با یک فیلد «نشانگر نوع» (tag) همراه می‌شود تا بدانیم کدام عضو معتبر است:

```c
enum Kind { KIND_INT, KIND_FLOAT };

struct Value {
    enum Kind kind;      // tag
    union { int i; float f; } data;
};
```

این الگو پایهٔ «نوع پویا» در زبان‌هایی مثل Python است.

## اشتباهات رایج

1. **خواندن عضوی که آخرین بار نوشته نشده** — رفتار تعریف‌نشده (معمولاً مقدار بیمعنی).
2. **انتظار اینکه اعضا هم‌زمان معتبر باشند** — مثل struct فکر نکنید.
3. **فراموش کردن tag** — نمی‌دانید کدام عضو معتبر است.

## بهترین شیوه‌ها

- همیشه union را با tag همراه کنید.
- قبل از خواندن، tag را چک کنید.
- در C++ از `std::variant` استفاده می‌شود (مشابه همین الگو).

## خلاصهٔ جلسه

- union = حافظهٔ مشترک بین اعضا؛ فقط آخرین عضو نوشته‌شده معتبر است.
- با tag همراه می‌شود تا نوع درست مشخص باشد.
- اندازه = بزرگ‌ترین عضو.
