# جلسهٔ ۲۶ — دستورات پیش‌پردازنده (#define، #include، ماکروها)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- بدانید پیش‌پردازنده قبل از کامپایل کد را پردازش می‌کند
- با `#define` ثابت و ماکرو تعریف کنید
- با `#include` فایل‌ها را ضمیمه کنید
- با `#ifdef`، `#ifndef`، `#pragma once` گارد هدر بنویسید
- از ماکروهای با آرگومان و تله‌های آن‌ها آگاه باشید

---

## پیش‌پردازنده چیست؟

قبل از کامپایل، **پیش‌پردازنده (preprocessor)** کد را پردازش می‌کند: دستورهایی که با `#` شروع می‌شوند را اجرا می‌کند (جایگزینی، شرطی‌سازی، ضمیمه‌کردن فایل).

## #define برای ثابت

```c
#define PI 3.14159
#define MAX_STUDENTS 100
```

هر جای کد که `PI` نوشته شود، با `3.14159` جایگزین می‌شود. تفاوت با `const`:
- `#define` جایگزینی متنی قبل از کامپایل است (نوع ندارد، خطای نوع نمی‌دهد).
- `const` یک متغیر واقعی با نوع است (در دیباگر دیده می‌شود).
- برای ثابت‌های ساده هر دو خوب‌اند؛ `const` امن‌تر است.

## ماکرو با آرگومان

```c
#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))
```

⚠️ پرانتزهای اضافی لازم‌اند! بدون آن‌ها `SQUARE(2+3)` به `2+3*2+3` تبدیل می‌شود (= 11 نه 25).

## include و گارد هدر

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H
// محتویات
#endif
```

این «گارد هدر» مانع ضمیمه شدن دوبارهٔ همان فایل می‌شود.

## #ifdef و #ifndef

```c
#ifdef DEBUG
    printf("حالت دیباگ فعال است\n");
#endif

#define FEATURE_X
#ifdef FEATURE_X
    // این بخش فعال است
#endif
```

با `gcc -DDEBUG` می‌توان `DEBUG` را از خط فرمان تعریف کرد.

## اشتباهات رایج

1. **ماکرو بدون پرانتز** — اولویت‌بندی خراب.
2. **سمی‌کالن در انتهای #define** — `#define PI 3.14;` باعث `3.14;;` می‌شود.
3. **تغییر ثابت #define** — چون متنی است، جایگزینی‌های عجیب ممکن است.
4. **نداشتن گارد هدر** — تعریف تکراری.

## بهترین شیوه‌ها

- ماکروهای با آرگومان را با حروف بزرگ و پرانتز کامل بنویسید.
- برای ثابت‌های معمولی از `const` استفاده کنید؛ #define را برای ابعاد ثابت و پرچم‌ها نگه دارید.
- همیشه گارد هدر (`#ifndef...`) بگذارید.

## خلاصهٔ جلسه

- #define جایگزینی متنی، #include ضمیمهٔ فایل.
- ماکرو با آرگومان نیاز به پرانتز دارد.
- #ifdef/#ifndef برای کد شرطی و گارد هدر.
