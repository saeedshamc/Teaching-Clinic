# جلسهٔ ۳۲ — اشاره‌گر به تابع (Function Pointers)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- اشاره‌گر به تابع تعریف و استفاده کنید
- تابعی را به‌عنوان آرگومان به تابع دیگر بدهید (callback)
- با typedef اشاره‌گر به تابع را خواناتر کنید
- کاربردهای واقعی (مثل مقایسه در qsort) را ببینید

---

## اشاره‌گر به تابع چیست؟

درست مثل اینکه متغیر آدرس دارد، **تابع هم آدرس دارد** و می‌توان آن را در متغیر نگه داشت:

```c
int add(int a, int b) { return a + b; }

int (*op)(int, int);   // op اشاره‌گر به تابعی است که دو int می‌گیرد و int برمی‌گرداند
op = add;              // آدرس تابع add را بده
int result = op(3, 4); // صدا زدن از طریق اشاره‌گر
```

نکتهٔ نحوی: `int (*op)(int, int)` — پرانتزها مهم‌اند.

## callback — تابع به‌عنوان آرگومان

```c
void apply(int arr[], int size, int (*func)(int)) {
    for (int i = 0; i < size; i++) {
        arr[i] = func(arr[i]);
    }
}
```

حالا می‌توان هر تبدیلی را پاس داد: `apply(arr, n, double_it);`

## typedef برای اشاره‌گر به تابع

```c
typedef int (*BinaryOp)(int, int);

BinaryOp op = add;   // خیلی خواناتر
```

## کاربرد واقعی: qsort

تابع استاندارد `qsort` یک مقایسه‌گر (comparator) می‌گیرد:

```c
int compare_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}
qsort(arr, n, sizeof(int), compare_int);
```

مقایسه‌گر: منفی اگر a<b، صفر اگر برابر، مثبت اگر a>b.

## اشتباهات رایج

1. **فراموش کردن پرانتز:** `int *op(int, int)` یعنی تابعی که اشاره‌گر برمی‌گرداند، نه اشاره‌گر به تابع!
2. **عدم تطابق امضا (signature) تابع با نوع اشاره‌گر** — خطای کامپایل.
3. **صدا زدن `op()` بدون مقداردهی** — کرش.
4. **ناسازگاری نوع در qsort** — حتماً به void* تبدیل کنید.

## بهترین شیوه‌ها

- برای اشاره‌گر به تابع از typedef استفاده کنید.
- از `const` در پارامترهای مقایسه‌گر استفاده کنید.
- قبل از صدا زدن، NULL بودن را چک کنید.

## خلاصهٔ جلسه

- اشاره‌گر به تابع آدرس تابع را نگه می‌دارد و با `()` صدا زده می‌شود.
- callback ها انعطاف و جداسازی می‌دهند.
- qsort با مقایسه‌گر کار می‌کند.
