# جلسهٔ ۲ — متغیرها، انواع دادهٔ پایه و ثابت‌ها (const)

## اهداف یادگیری

در پایان این جلسه شما می‌توانید:

- متغیر تعریف کنید و انواع دادهٔ اصلی C را بشناسید
- `int`، `char`، `float`، `double` و `_Bool` را درست به کار ببرید
- با `const` ثابت تعریف کنید و تفاوت آن با `#define` را بدانید
- با `sizeof` اندازهٔ انواع را ببینید و با `limits.h` حدود آن‌ها را پیدا کنید

---

## متغیر چیست؟

متغیر یک **محفظهٔ نام‌دار در حافظه** است که یک مقدار در آن نگهداری می‌شود. هر متغیر یک **نوع (type)** دارد که مشخص می‌کند چه جور داده‌ای (عدد صحیح، عدد اعشاری، حرف و...) در آن ذخیره می‌شود.

```c
int age;            // اعلان (declaration): یک متغیر صحیح به نام age
age = 25;           // مقداردهی (assignment)
int score = 90;     // اعلان + مقداردهی اولیه (initialization)
```

## انواع دادهٔ پایه

| نوع | اندازهٔ معمول | محدودهٔ معمول | کاربرد |
|---|---|---|---|
| `char` | ۱ بایت | -128 تا 127 (یا 0 تا 255) | یک حرف یا عدد کوچک |
| `int` | ۴ بایت | حدود ±۲.۱ میلیارد | عدد صحیح |
| `float` | ۴ بایت | ~۷ رقم اعشار معنی‌دار | عدد اعشاری (دقت کم) |
| `double` | ۸ بایت | ~۱۵ رقم اعشار معنی‌دار | عدد اعشاری (دقت زیاد) |
| `_Bool` | ۱ بایت | 0 یا 1 | درست/نادرست |

نکته: اندازهٔ دقیق به معماری و کامپایلر بستگی دارد؛ همیشه با `sizeof` بررسی کنید.

## ثابت‌ها (const)

کلمهٔ کلیدی `const` یعنی «این متغیر بعد از مقداردهی اولیه نباید تغییر کند»:

```c
const double PI = 3.14159;
// PI = 4.0;  ← این خط خطای کامپایل می‌دهد
```

## نکات و هشدارهای مهم

1. **مقداردهی‌نشده استفاده نکنید:** خواندن متغیر مقداردهی‌نشده (uninitialized) رفتار تعریف‌نشده (undefined behavior) است و ممکن است عددی تصادفی از حافظه را برگرداند.
2. **سرریز (overflow):** اگر عددی بزرگ‌تر از حد نوع ذخیره شود، «دور می‌زند» و عدد اشتباه می‌شود.
3. **تقسیم عدد صحیح:** `7 / 2` برابر `3` است نه `3.5` — چون هر دو عملوند `int` هستند. برای نتیجهٔ اعشاری حداقل یکی باید اعشاری باشد: `7.0 / 2`.

## بهترین شیوه‌ها

- همیشه متغیر را هنگام اعلان مقداردهی کنید.
- از نام‌های معنی‌دار استفاده کنید: `student_count` نه `x`.
- برای مقادیر ثابت ثابت‌های `const` بسازید.
- برای چاپ `double` از `%f`/`%lf` و برای `float` از `%f` استفاده کنید.

## خلاصهٔ جلسه

- متغیرها محفظه‌های نام‌دار حافظه‌اند و نوعشان تعیین‌کنندهٔ مقدار قابل ذخیره است.
- `int`/`char`/`float`/`double`/`_Bool` انواع پایه هستند.
- `const` مقدار را غیرقابل تغییر می‌کند.
- `sizeof` اندازهٔ یک نوع/متغیر را بر حسب بایت می‌دهد.
