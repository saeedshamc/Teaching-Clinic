# جلسهٔ ۲۲ — شمارشی‌ها (enum)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `enum` مجموعه‌ای از ثابت‌های نام‌دار بسازید
- مقادیر پیش‌فرض و سفارشی enum را بشناسید
- از enum برای خوانایی کد و امنیت منطق استفاده کنید

---

## enum چیست؟

`enum` نوعی است که مجموعه‌ای از **ثابت‌های نام‌دار** را تعریف می‌کند. به‌جای اعداد جادویی، نام‌های معنی‌دار می‌گذاریم:

```c
enum Day { SAT, SUN, MON, TUE, WED, THU, FRI };
```

مقادیر پیش‌فرض از صفر شروع می‌شوند: `SAT = 0`, `SUN = 1`, ... می‌توانید خودتان هم بدهید:

```c
enum Status { OK = 0, ERROR = -1, WARNING = 1 };
```

## چرا enum؟

```c
int state = 2;              // ۲ یعنی چه؟
enum State { IDLE, RUNNING, STOPPED } state = RUNNING;   // واضح!
```

- خوانایی: `if (state == STOPPED)` از `if (state == 2)` بهتر است.
- کاهش اشتباهات تایپی.
- در switch به‌عنوان case استفاده می‌شود.

## نکات

- در C، enum یک عدد صحیح است؛ مقایسه‌اش با int ممکن است.
- مقدار enum را می‌توان در struct و union (tag) استفاده کرد.
- بدون مقداردهی، مقادیر ۰، ۱، ۲، ... می‌شوند.

## اشتباهات رایج

1. **مقادیر جادویی به‌جای enum** — کد غیرقابل‌خواندن.
2. **شروع نکردن از یک مقدار مشخص** وقتی قرارداد دارید (مثلاً ۰ برای «هیچ»).
3. **استفاده از enum برای مقادیر واقعی (مثل درجهٔ حرارت)** — enum برای مجموعهٔ محدود و ثابت است.

## بهترین شیوه‌ها

- برای وضعیت‌ها، روزها، رنگ‌ها و هر مجموعهٔ محدود از enum استفاده کنید.
- نام‌ها را UPPERCASE بنویسید.
- اگر به مقادیر خاصی وابسته‌اید، صریح تعیین کنید.

## خلاصهٔ جلسه

- enum ثابت‌های نام‌دار می‌سازد؛ پیش‌فرض از ۰ شروع می‌شود.
- کد را خوانا و منطق را امن‌تر می‌کند.
- در switch و tag union کاربرد دارد.
