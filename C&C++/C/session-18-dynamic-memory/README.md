# جلسهٔ ۱۸ — تخصیص حافظهٔ پویا: malloc، calloc، realloc، free

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `malloc`، `calloc` و `realloc` حافظه را در زمان اجرا بگیرید
- با `free` حافظه را آزاد کنید و نشت حافظه (memory leak) را بشناسید
- آرایه‌ای با اندازهٔ متغیر بسازید
- از double free و dangling pointer پرهیز کنید

---

## چرا حافظهٔ پویا؟

گاهی تعداد داده‌ها را هنگام نوشتن برنامه نمی‌دانیم (مثلاً تعداد دانشجوها). حافظهٔ پویا در **هیپ (heap)** تخصیص می‌یابد و تا وقتی `free` نشود زنده است.

## توابع اصلی (در <stdlib.h>)

| تابع | کاربرد |
|---|---|
| `malloc(n)` | n بایت تخصیص می‌دهد (مقداردهی نمی‌کند!) |
| `calloc(n, size)` | n عنصر به اندازهٔ size؛ و همه را **صفر** می‌کند |
| `realloc(p, n)` | اندازهٔ بلوک را به n تغییر می‌دهد (محتوا حفظ می‌شود) |
| `free(p)` | بلوک را آزاد می‌کند |

```c
int *arr = malloc(10 * sizeof(int));
if (arr == NULL) {
    // حافظه تمام شد — مدیریت خطا
}
arr[0] = 42;
free(arr);
```

## قوانین طلایی

1. **همیشه نتیجهٔ malloc را چک کنید:** NULL یعنی حافظه نبود.
2. **همیشه free کنید:** هر malloc بدون free = نشت حافظه (memory leak). در برنامه‌های طولانی، حافظه تمام می‌شود.
3. **بعد از free، دیگر استفاده نکنید:** این dangling pointer است → undefined behavior.
4. **دو بار free نکنید** (double free) → کرش.
5. **به اندازهٔ درست ضرب کنید:** `malloc(n * sizeof(int))` نه `malloc(n)`.

## calloc و realloc

```c
int *a = calloc(5, sizeof(int));   // 5 عنصر صفرشده
int *b = realloc(a, 10 * sizeof(int));  // بزرگ‌تر کردن
if (b != NULL) {
    a = b;   // آدرس جدید را بگیر
}
```

## اشتباهات رایج

1. **فراموش کردن free** → نشت حافظه. (با valgrind در جلسهٔ ۴۷ پیدا می‌شود)
2. **استفاده بعد از free** → dangling pointer، کرش تصادفی.
3. **فراموش کردن `* sizeof(int)`** → بافر خیلی کوچک، سرریز.
4. **تغییر آدرسِ ذخیره‌شده و بعد free کردن آدرس اشتباه.**

## بهترین شیوه‌ها

- بعد از `free(p)`، `p = NULL;` بگذارید تا استفادهٔ ناخواسته خطا بدهد.
- اندازه‌ها را با `sizeof` و `size_t` مدیریت کنید.
- تابعی که malloc می‌کند باید به‌وضوح بگوید مالک آزادسازی کیست.

## خلاصهٔ جلسه

- malloc/calloc تخصیص، realloc تغییر اندازه، free آزادسازی.
- هر malloc باید free متناظر داشته باشد.
- نشت حافظه، dangling pointer و double free سه خطای کلاسیک حافظه‌اند.
