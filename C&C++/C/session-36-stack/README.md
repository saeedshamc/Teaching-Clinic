# جلسهٔ ۳۶ — پیاده‌سازی پشته (Stack)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- مفهوم پشته (LIFO) و عملیات push/pop/peek را بفهمید
- پشته را با آرایه پیاده‌سازی کنید
- پشته را با لیست پیوندی پیاده‌سازی کنید
- کاربردهای پشته را بشناسید

---

## پشته چیست؟

پشته ساختار دادهٔ **LIFO** است: آخرین چیزی که وارد می‌شود، اولین چیزی است که خارج می‌شود (مثل دستهٔ بشقاب).

| عملیات | معنی |
|---|---|
| `push(x)` | اضافه کردن به بالای پشته |
| `pop()` | برداشتن از بالای پشته |
| `peek()` / `top()` | دیدن بالای پشته بدون برداشتن |
| `is_empty()` | خالی بودن |

## پیاده‌سازی با آرایه

```c
typedef struct {
    int data[MAX_SIZE];
    int top;   /* ایندکس بالای پشته؛ -1 یعنی خالی */
} Stack;

void init(Stack *s) { s->top = -1; }

void push(Stack *s, int value) {
    if (s->top >= MAX_SIZE - 1) {
        printf("پشته پر است!\n");
        return;
    }
    s->data[++s->top] = value;
}

int pop(Stack *s) {
    if (s->top == -1) {
        printf("پشته خالی است!\n");
        return -1;   /* یا یک مقدار خطا */
    }
    return s->data[s->top--];
}
```

## پیاده‌سازی با لیست پیوندی

head لیست = بالای پشته؛ push = prepend، pop = حذف head. مزیت: بدون محدودیت اندازهٔ ثابت.

## کاربردها

- مدیریت فراخوانی توابع (call stack)
- بررسی تعادل پرانتزها
- تبدیل infix به postfix و ماشین حساب
- قابلیت Undo در ویرایشگرها

## اشتباهات رایج

1. **چک نکردن پر/خالی بودن** — سرریز (stack overflow) یا pop از پشتهٔ خالی (underflow).
2. **فراموش کردن مقداردهی `top = -1` در init.**
3. **استفاده از `top++` به‌جای `++top` در push** — جای اشتباه.
4. **تابع pop روی پشتهٔ خالی** — مقدار نامشخص.

## بهترین شیوه‌ها

- همیشه قبل از pop/peek خالی بودن را چک کنید.
- برای «پر بودن» محدودیت آرایه را مدیریت کنید.
- برای پشتهٔ نامحدود از لیست پیوندی استفاده کنید.

## خلاصهٔ جلسه

- پشته = LIFO؛ push/pop/peek.
- با آرایه (اندازه ثابت) یا لیست پیوندی.
- مراقب overflow/underflow باشید.

## تمرین‌ها

### تمرین ۱ (ساده)
پشتهٔ آرایه‌ای بسازید، ۵ عدد push کنید، سپس همه را pop و چاپ کنید (خروجی معکوس).

### تمرین ۲ (متوسط)
برنامه‌ای بنویسید که با پشته، تعادل پرانتزها در یک رشته را بررسی کند.

راه‌حل‌ها در `exercises/` هستند.
