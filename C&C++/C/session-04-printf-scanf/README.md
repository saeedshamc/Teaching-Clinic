# جلسهٔ ۴ — ورودی/خروجی با printf و scanf

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `printf` انواع مختلف داده را با مشخص‌کنندهٔ درست چاپ کنید
- با `scanf` ورودی از کاربر بگیرید و محدودیت‌های آن را بشناسید
- مشکلات رایج مثل نادیده‌گرفتن مقدار بازگشتی `scanf` و بافر ورودی را مدیریت کنید

---

## چاپ با printf

`printf` متن و متغیرها را روی خروجی استاندارد (معمولاً ترمینال) چاپ می‌کند:

```c
printf("متن %d و %s و %f\n", number, name, value);
```

مشخص‌کننده‌های (format specifier) رایج:

| مشخص‌کننده | نوع |
|---|---|
| `%d` / `%i` | int |
| `%ld` | long |
| `%c` | char (یک حرف) |
| `%s` | رشته (char*) |
| `%f` | float |
| `%lf` | double |
| `%zu` | size_t |
| `%p` | آدرس اشاره‌گر |
| `%%` | خودِ علامت ٪ |

برای محدود کردن ارقام اعشار: `%.2f` یعنی دو رقم اعشار.

## خواندن ورودی با scanf

```c
int age;
printf("سن را وارد کنید: ");
scanf("%d", &age);   // & یعنی آدرس متغیر
```

نکات مهم:

1. **`&` فراموش نشود:** `scanf` مقدار را در آدرس متغیر می‌نویسد؛ پس `&age` لازم است (برای رشته‌ها که خودشان آدرس‌اند، `&` نمی‌خواهیم).
2. **مقدار بازگشتی را چک کنید:** `scanf` تعداد آیتم‌هایی که درست خوانده را برمی‌گرداند. `if (scanf("%d", &n) == 1)` یعنی یک عدد درست خوانده شد.
3. **مشکل بافر:** اگر `scanf` عدد بخواند و بعد `getchar`/`fgets` برای متن استفاده شود، `\n` باقی‌مانده در بافر مشکل می‌سازد.

## هشدار: scanf و امنیت

`scanf("%s", buffer)` بدون تعیین طول، ممکن است **سرریز بافر (buffer overflow)** کند. همیشه طول را محدود کنید: `scanf("%19s", buffer)` برای بافر ۲۰ تایی. (در جلسات بعد با `fgets` امن‌تر کار می‌کنیم.)

## اشتباهات رایج

1. **ناسازگاری نوع با مشخص‌کننده:** `printf("%d", 3.5)` نتیجهٔ نامشخص می‌دهد. همیشه نوع را مطابقت دهید.
2. **فراموش کردن `&` در scanf** — برنامه کرش می‌کند یا رفتار نامشخص دارد.
3. **نادیده‌گرفتن مقدار بازگشتی scanf** — اگر کاربر حرف وارد کند، متغیر مقداردهی نمی‌شود.
4. **scanf("%s") بدون محدودیت طول** — سرریز بافر.

## بهترین شیوه‌ها

- همیشه مقدار بازگشتی `scanf` را چک کنید.
- برای متن از `fgets` به‌جای `scanf("%s")` استفاده کنید.
- در `printf` نوع متغیر را با مشخص‌کننده مطابقت دهید.

## خلاصهٔ جلسه

- `printf` خروجی، `scanf` ورودی را مدیریت می‌کنند.
- مشخص‌کننده‌های `%d`، `%f`، `%lf`، `%c`، `%s` را شناختید.
- `scanf` نیاز به `&` و چک کردن مقدار بازگشتی دارد.
