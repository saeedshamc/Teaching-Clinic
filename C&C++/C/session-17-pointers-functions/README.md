# جلسهٔ ۱۷ — اشاره‌گرها و توابع (Pass by Reference)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با ارسال آدرس (pass by reference شبیه‌سازی‌شده) متغیر را در تابع تغییر دهید
- تابع swap واقعی بنویسید
- تفاوت `int x` و `int *x` را در پارامتر تابع تشخیص دهید
- از `const` در پارامترهای اشاره‌گری استفاده کنید

---

## چرا اشاره‌گر در تابع؟

در جلسهٔ ۹ دیدید که C پارامترها را با مقدار می‌گیرد. اگر آدرس را پاس دهیم، تابع از طریق آن آدرس می‌تواند **خودِ متغیر بیرونی** را تغییر دهد:

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 20;
    swap(&x, &y);       // آدرس‌ها را می‌دهیم
    printf("%d %d\n", x, y);   // 20 10
    return 0;
}
```

## قانون کلی پارامترها

- مقدار را می‌خواهیم فقط بخوانیم و تغییر ندهیم → `int x` (کپی) یا `const int *p` (اشاره‌گر با const)
- می‌خواهیم مقدار ورودی را تغییر دهیم → `int *p` و هنگام صدا زدن `&x`
- آرایه را می‌دهیم → همیشه به‌صورت اشاره‌گر نزول می‌کند؛ `int arr[]` همان `int *arr` است

## const در اشاره‌گر

```c
void print(const int *p) {
    printf("%d\n", *p);   // فقط خواندن، تغییر ممنوع
    // *p = 5;            // خطای کامپایل
}
```

این یعنی «به داده‌ای که اشاره می‌شود دست نزن». قرارداد مهم و خوانایی است.

## خروجی‌های متعدد از تابع

با اشاره‌گر می‌توان چند «خروجی» از یک تابع گرفت (مثل مجموع و حاصل‌ضرب در تمرین جلسهٔ ۹).

## اشتباهات رایج

1. **فراموش کردن `&` هنگام صدا زدن:** `swap(x, y)` → خطای کامپایل (ناسازگاری نوع).
2. **فراموش کردن `*` داخل تابع:** `a = b` به‌جای `*a = *b` → فقط آدرس‌ها عوض می‌شوند، نتیجه خراب.
3. **اعمال const بی‌مورد:** اگر می‌خواهید تغییر دهید، `const` نگذارید.
4. **تغییر پارامتر به‌جای دادهٔ مقصد.**

## بهترین شیوه‌ها

- پارامترهایی که فقط خوانده می‌شوند را `const` کنید.
- وقتی می‌خواهید آرایه را تغییر دهید، اندازه را هم پاس دهید.
- در نام‌گذاری، خروجی‌های اشاره‌گری را مشخص کنید (مثل `*out_sum`).

## خلاصهٔ جلسه

- با پاس دادن آدرس، تابع می‌تواند متغیر بیرونی را تغییر دهد (swap واقعی).
- `int *p` = «می‌خواهم تغییر بدهم»، `const int *p` = «فقط می‌خوانم».
- چند خروجی از یک تابع با اشاره‌گر ممکن است.
