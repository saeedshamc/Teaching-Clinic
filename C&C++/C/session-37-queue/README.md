# جلسهٔ ۳۷ — پیاده‌سازی صف (Queue)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- مفهوم صف (FIFO) و عملیات enqueue/dequeue را بفهمید
- صف را با آرایهٔ حلقوی پیاده‌سازی کنید
- صف را با لیست پیوندی پیاده‌سازی کنید
- کاربردهای صف را بشناسید

---

## صف چیست؟

صف ساختار دادهٔ **FIFO** است: اولین چیزی که وارد می‌شود، اولین چیزی است که خارج می‌شود (مثل صف نانوایی).

| عملیات | معنی |
|---|---|
| `enqueue(x)` | اضافه کردن به انتهای صف |
| `dequeue()` | برداشتن از ابتدای صف |
| `front()` | دیدن ابتدا بدون برداشتن |
| `is_empty()` | خالی بودن |

## صف آرایه‌ای حلقوی (Circular Queue)

اگر فقط از آرایه استفاده کنیم، بعد از چند dequeue فضای ابتدا هدر می‌رود. راه‌حل: **صف حلقوی** — front و back را طوری حرکت می‌دهیم که دور بزنند:

```c
#define MAX 5
typedef struct {
    int data[MAX];
    int front;   /* ابتدای صف */
    int rear;    /* انتهای صف */
    int count;   /* تعداد عناصر */
} Queue;

void enqueue(Queue *q, int v) {
    if (q->count == MAX) { printf("صف پر است!\n"); return; }
    q->data[q->rear] = v;
    q->rear = (q->rear + 1) % MAX;   /* دور زدن */
    q->count++;
}

int dequeue(Queue *q) {
    if (q->count == 0) { printf("صف خالی!\n"); return -1; }
    int v = q->data[q->front];
    q->front = (q->front + 1) % MAX;
    q->count--;
    return v;
}
```

## صف با لیست پیوندی

head = front (dequeue)، tail = rear (enqueue). هر دو عملیات O(1) با نگه‌داشتن tail.

## کاربردها

- صف چاپ (printer queue)
- صف پیام‌ها در سیستم‌عامل
- پیمایش سطحی درخت (BFS)
- بافر (buffer) بین تولیدکننده و مصرف‌کننده

## اشتباهات رایج

1. **چک نکردن پر/خالی بودن** — از دست رفتن داده.
2. **در صف غیرحلقوی، هدر رفتن فضای ابتدا** — با حلقوی حل می‌شود.
3. **فراموش کردن `% MAX` در حرکت front/rear** — خارج از محدوده.
4. **در لیست پیوندی، فراموش کردن به‌روزرسانی tail.**

## بهترین شیوه‌ها

- از شمارندهٔ count برای تشخیص پر/خالی استفاده کنید.
- در صف حلقوی، همیشه mod بگیرید.
- برای صف نامحدود از لیست پیوندی استفاده کنید.

## خلاصهٔ جلسه

- صف = FIFO؛ enqueue/dequeue/front.
- آرایهٔ حلقوی برای اندازهٔ ثابت، لیست پیوندی برای نامحدود.
- مدیریت count و mod حیاتی است.

## تمرین‌ها

### تمرین ۱ (ساده)
صف حلقوی بسازید، ۳ عدد enqueue کنید، یکی dequeue کنید و دوباره enqueue کنید — ببینید چطور دور می‌زند.

### تمرین ۲ (متوسط)
صف را با لیست پیوندی پیاده‌سازی کنید (enqueue در tail، dequeue از head).
