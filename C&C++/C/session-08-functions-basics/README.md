# جلسهٔ ۸ — مبانی توابع (Functions)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- تابع تعریف کنید، صدا بزنید و مقدار برگشتی بگیرید
- تفاوت تعریف (definition) و اعلان (declaration/prototype) را بدانید
- از `return` درست استفاده کنید و توابعی با انواع مختلف بنویسید

---

## تابع چیست؟

تابع یک **بلوک نام‌دار و قابل استفادهٔ مجدد** از کد است. به‌جای تکرار کد، آن را یک بار می‌نویسیم و هرجا لازم شد صدا می‌زنیم.

```c
// تعریف تابع: نوع برگشتی + نام + پارامترها
int add(int a, int b) {
    return a + b;      // مقدار برگشتی
}
```

## اجزای یک تابع

| جزء | مثال | توضیح |
|---|---|---|
| نوع برگشتی | `int` | نوع مقداری که برمی‌گرداند (`void` یعنی چیزی برنمی‌گرداند) |
| نام | `add` | شناسهٔ تابع |
| پارامترها | `int a, int b` | ورودی‌ها (می‌تواند خالی باشد) |
| بدنه | `{ return a + b; }` | دستورات تابع |
| صدا زدن | `add(3, 4)` | استفاده از تابع |

## اعلان (Prototype) در برابر تعریف (Definition)

- **تعریف:** بدنهٔ تابع را دارد.
- **اعلان:** فقط نوع برگشتی، نام و پارامترها را اعلام می‌کند و با `;` تمام می‌شود:

```c
int add(int a, int b);   // اعلان

int main(void) {
    printf("%d\n", add(3, 4));   // حالا می‌توان قبل از تعریف صدا زد
    return 0;
}

int add(int a, int b) {          // تعریف
    return a + b;
}
```

قانون: اگر تابع قبل از صدا زدن تعریف شده باشد، اعلان لازم نیست؛ ولی اعلان زودتر همیشه امن‌تر است.

## مقدار برگشتی void

تابع می‌تواند هیچ چیزی برنگرداند:

```c
void say_hello(void) {
    printf("سلام!\n");
}
```

## اشتباهات رایج

1. **ناسازگاری نوع برگشتی با return** — خطای کامپایل.
2. **فراموش کردن return در مسیری از تابع** — مقدار نامشخص.
3. **صدا زدن تابع قبل از تعریف/اعلان** — خطای implicit declaration (در C99+ خطا است).
4. **return یک مقدار از تابع void** — خطای کامپایل.

## بهترین شیوه‌ها

- هر تابع یک **مسئولیت واحد** داشته باشد و نامش آن را برساند.
- تابع کوتاه نگه دارید؛ اگر بلند شد، بشکنید.
- `main` را بالای فایل بگذارید و توابع کمکی را با اعلان بالای آن تعریف کنید یا فایل هدر بسازید (جلسهٔ ۲۷).

## خلاصهٔ جلسه

- توابع بلوک‌های قابل استفادهٔ مجددند: (نوع برگشتی، نام، پارامتر، بدنه).
- اعلان یعنی بدون بدنه؛ تعریف یعنی با بدنه.
- `return` مقدار را برمی‌گرداند؛ `void` یعنی بدون مقدار.
