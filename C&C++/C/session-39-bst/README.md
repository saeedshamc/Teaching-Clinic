# جلسهٔ ۳۹ — درخت جستجوی دودویی (Binary Search Tree)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- قانون BST را بفهمید: چپ کوچک‌تر، راست بزرگ‌تر
- درج و جستجو را در O(log n) (درخت متعادل) انجام دهید
- حذف در هر سه حالت (برگ، یک فرزند، دو فرزند) را پیاده‌سازی کنید
- بدانید چرا inorder مرتب است

---

## قانون BST

برای هر گره: **همهٔ گره‌های زیردرخت چپ کوچک‌ترند، همهٔ گره‌های زیردرخت راست بزرگ‌ترند** (تکراری‌ها معمولاً راست یا نادیده گرفته می‌شوند).

```c
typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node;
```

## درج

```c
Node *insert(Node *root, int value) {
    if (root == NULL) {
        /* گرهٔ جدید */
    }
    if (value < root->data) {
        root->left = insert(root->left, value);
    } else {
        root->right = insert(root->right, value);
    }
    return root;
}
```

## جستجو

```c
Node *search(Node *root, int value) {
    if (root == NULL || root->data == value) return root;
    if (value < root->data) return search(root->left, value);
    return search(root->right, value);
}
```

هر مرحله نصف درخت را دور می‌اندازیم → O(log n) در درخت متعادل.

## حذف — سه حالت

1. **برگ:** گره را آزاد کن، NULL برگردان.
2. **یک فرزند:** فرزند را بالا بیاور.
3. **دو فرزند:** مقدار گره را با **کوچک‌ترین گرهٔ زیردرخت راست** (جانشین inorder) عوض کن و آن را حذف کن.

```c
Node *find_min(Node *root) {
    while (root && root->left) root = root->left;
    return root;
}
```

## چرا inorder مرتب است؟

چون پیمایش «چپ، ریشه، راست» دقیقاً به ترتیب صعودی مقادیر می‌رود — به همین دلیل BST برای دادهٔ مرتب شدهٔ زنده عالی است.

## هشدار: درخت نامتعادل

اگر مقادیر به‌ترتیب وارد شوند (۱، ۲، ۳، ...)، BST به لیست تبدیل می‌شود و همهٔ عملیات O(n) می‌شوند. راه‌حل: درخت‌های خودمتعادل مثل AVL یا Red-Black (خارج از این دوره).

## اشتباهات رایج

1. **فراموش کردن `return root` در insert** — زیردرخت‌ها گم می‌شوند.
2. **حالت دو فرزند: آزاد کردن گره قبل از جابه‌جایی.**
3. **قرار دادن تکراری‌ها در هر دو سمت** — قانون را یک‌طرفه نگه دارید.
4. **درج ترتیبی → درخت بد** — ورودی تصادفی یا تعادل.

## بهترین شیوه‌ها

- توابع بازگشتی روی درخت ساده‌ترین‌اند.
- حذف را با هر سه حالت جداگانه تست کنید.
- آزادسازی کامل درخت در پایان.

## خلاصهٔ جلسه

- قانون: چپ < گره < راست.
- درج/جستجو O(log n)؛ حذف سه حالت دارد.
- inorder مرتب است؛ درخت نامتعادل = O(n).
