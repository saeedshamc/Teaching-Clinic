# جلسهٔ ۲۷ — پروژهٔ چندفایلی و فایل‌های هدر

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- پروژه را به چند فایل منبع (`.c`) تقسیم کنید
- فایل هدر (`.h`) بسازید و اعلان توابع را در آن بگذارید
- با گارد هدر از تعریف تکراری جلوگیری کنید
- چند فایل را با یک دستور gcc کامپایل کنید

---

## چرا پروژهٔ چندفایلی؟

وقتی برنامه بزرگ می‌شود، نگه‌داشتن همه‌چیز در یک فایل غیرعملی است. تقسیم کار:

- `main.c` — تابع main و منطق اصلی
- `math_utils.c` — توابع ریاضی
- `math_utils.h` — اعلان توابع math_utils (برای استفاده در main.c)

## فایل هدر چیست؟

فایل هدر (`.h`) فقط **اعلان‌ها** (prototype) و ثابت‌ها را دارد، نه بدنهٔ توابع:

```c
// math_utils.h
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);
int multiply(int a, int b);

#endif
```

فایل منبع تعریف (بدنه) را دارد:

```c
// math_utils.c
#include "math_utils.h"

int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }
```

و main:

```c
// main.c
#include <stdio.h>
#include "math_utils.h"

int main(void) {
    printf("%d\n", add(3, 4));
    return 0;
}
```

## گارد هدر (Header Guard)

`#ifndef MATH_UTILS_H / #define MATH_UTILS_H / #endif` مانع می‌شود هدر دو بار ضمیمه شود (که باعث تعریف تکراری می‌شود). در C11 می‌توانید به‌جایش از `#pragma once` استفاده کنید.

## کامپایل چند فایل

```bash
gcc -Wall -Wextra -o program main.c math_utils.c
```

همهٔ فایل‌های .c را یک‌جا به gcc می‌دهیم؛ gcc آن‌ها را به هم پیوند می‌زند.

## اشتباهات رایج

1. **گذاشتن بدنهٔ تابع در هدر** — اگر هدر دو بار include شود، خطای «تعریف تکراری».
2. **فراموش کردن گارد هدر** — همان خطای بالا.
3. **include کردن هدر با `"..."` به‌جای `<...>`** — `"file.h"` برای فایل‌های محلی، `<stdio.h>` برای کتابخانه‌ها.
4. **فراموش کردن یکی از فایل‌های .c در دستور gcc** — خطای «مرجع تعریف‌نشده» در زمان پیوند.

## بهترین شیوه‌ها

- هر فایل .c همنام با خودش یک هدر دارد: `math_utils.c` ↔ `math_utils.h`.
- هدر فقط اعلان، ثابت، typedef و struct دارد.
- همیشه گارد هدر بگذارید.
- برای پروژه‌های بزرگ‌تر از Makefile استفاده کنید (جلسهٔ ۴۵).

## خلاصهٔ جلسه

- پروژه به .c (بدنه) و .h (اعلان) تقسیم می‌شود.
- گارد هدر از include تکراری جلوگیری می‌کند.
- همهٔ .cها در یک دستور gcc داده می‌شوند.
