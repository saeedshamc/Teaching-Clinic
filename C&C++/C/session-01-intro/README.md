## زبان C چیست؟

زبان C یک زبان برنامه‌نویسی **رویه‌ای (Procedural)** و **سطح میانی** است که در سال ۱۹۷۲ توسط **دنیس ریچی (Dennis Ritchie)** در آزمایشگاه‌های بل (Bell Labs) برای نوشتن سیستم‌عامل Unix ساخته شد. C به ما نزدیکی به سخت‌افزار می‌دهد (مثل زبان اسمبلی) اما در عین حال ساختار و خوانایی یک زبان سطح بالا را دارد.

چرا C هنوز مهم است؟

- هستهٔ لینوکس، ویندوز و macOS با C/C++ نوشته شده است.
- تقریباً همهٔ زبان‌های مدرن (Python، JavaScript، Go و...) یا مفسرشان با C نوشته شده‌اند.
- در سیستم‌های نهفته (embedded)، درایورها و برنامه‌های کم‌حافظه، C بی‌رقیب است.
- پایهٔ درک حافظه، اشاره‌گرها و نحوهٔ کار واقعی کامپیوتر است.

## ابزارها: کامپایلر gcc

کامپیوتر زبان ماشین می‌فهمد، نه C. **کامپایلر** برنامهٔ C را به زبان ماشین تبدیل می‌کند. پرکاربردترین کامپایلر، **gcc** (GNU Compiler Collection) است.

### نصب

- **لینوکس (Ubuntu/Debian):** `sudo apt install gcc`
- **ویندوز:** بهترین گزینه نصب WSL (Ubuntu) است، یا MinGW-w64.
- **مک:** با نصب Xcode Command Line Tools، `clang` (مشابه gcc) نصب می‌شود.

پس از نصب، با دستور `gcc --version` مطمئن شوید که نصب شده است.

## اولین برنامه: Hello World

فایل `examples/01_hello_world.c` را باز کنید:

```c
// کامنت تک‌خطی: برنامهٔ معروف Hello World
#include <stdio.h>   // کتابخانهٔ استاندارد ورودی/خروجی

int main(void) {     // نقطهٔ شروع اجرای برنامه
    printf("Hello, World!\n");  // چاپ پیام روی صفحه
    return 0;        // خروج موفق از برنامه
}
```

### توضیح خط‌به‌خط

| خط | توضیح |
|---|---|
| `// کامنت...` | هر چیزی بعد از `//` تا پایان خط، کامنت است و کامپایلر آن را نادیده می‌گیرد. برای توضیح کد استفاده می‌شود. |
| `#include <stdio.h>` | این خط به کامپایلر می‌گوید فایل هدر `stdio.h` را (که تعریف توابع ورودی/خروجی مثل `printf` را دارد) به برنامه اضافه کند. |
| `int main(void)` | هر برنامهٔ C باید دقیقاً یک تابع `main` داشته باشد؛ اجرای برنامه از اینجا شروع می‌شود. `int` یعنی این تابع یک عدد صحیح برمی‌گرداند و `void` یعنی ورودی نمی‌گیرد. |
| `{ ... }` | بدنهٔ تابع؛ دستورات داخل همین آکولادها اجرا می‌شوند. |
| `printf("Hello, World!\n");` | تابع `printf` متن داخل `""` را چاپ می‌کند. `\n` یعنی «برو خط بعد» (newline). هر دستور با `;` تمام می‌شود. |
| `return 0;` | به سیستم‌عامل می‌گوید برنامه با موفقیت (کد ۰) تمام شد. هر مقدار غیرصفر یعنی خطا. |

## کامپایل و اجرا

```bash
# ۱) کامپایل: خروجی با نام hello ساخته می‌شود
gcc -Wall -Wextra -o hello examples/01_hello_world.c

# ۲) اجرا
./hello
```

خروجی:

```
Hello, World!
```

- پرچم `-o hello` نام فایل خروجی را مشخص می‌کند (بدون آن، فایل `a.out` ساخته می‌شود).
- پرچم‌های `-Wall` و `-Wextra` همهٔ هشدارهای مهم را فعال می‌کنند. **همیشه از این دو پرچم استفاده کنید.** یک برنامهٔ خوب باید بدون هیچ هشدار (warning) کامپایل شود.

## اشتباهات رایج مبتدی‌ها

1. **فراموش کردن `;`** — خطای `expected ';'` می‌گیرید. هر دستور با سمی‌کالن تمام می‌شود.
2. **فراموش کردن `#include <stdio.h>`** — خطای «اعلان ضمنی تابع printf» (`implicit declaration of function 'printf'`) می‌گیرید.
3. **نوشتن `main` با حرف بزرگ** — C به بزرگی/کوچکی حروف حساس است؛ `Main` یا `MAIN` معتبر نیستند.
4. **فراموش کردن `return 0;`** — برنامهٔ شما شاید کار کند اما مقدار بازگشتی تعریف‌نشده است.
5. **استفاده از `void main`** — استاندارد می‌گوید `int main(void)` یا `int main(int argc, char *argv[])`.

## بهترین شیوه‌ها (Best Practices)

- همیشه با `-Wall -Wextra` کامپایل کنید و هشدارها را جدی بگیرید.
- برای هر برنامهٔ جدید یک فایل جدا بسازید؛ کد را در یک فایل بزرگ تلنبار نکنید.
- کامنت‌های مفید و فارسی بنویسید (مثل همین دوره!) اما بدیهیات را کامنت نکنید.
- از نام‌گذاری معنی‌دار استفاده کنید: `age` به جای `a`.
- با یک برنامهٔ کوچک شروع کنید، اجرا کنید، بعد گسترشش دهید.

## خلاصهٔ جلسه

- C زبان برنامه‌نویسی رویه‌ای و نزدیک به سخت‌افزار است.
- `gcc -Wall -Wextra -o name file.c` یک برنامه را کامپایل می‌کند.
- هر برنامهٔ C با تابع `main` شروع می‌شود.
- `printf` برای چاپ، `return 0` برای خروج موفق است.
