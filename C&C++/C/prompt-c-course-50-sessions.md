# پرامپت — تولید دوره آموزشی C (۵۰ جلسه)

می‌خوام یک دوره آموزشی کامل و جامع زبان C برای من بسازی، شامل ۵۰ جلسه، از سطح مطلقاً صفر تا سطح حرفه‌ای (شامل ساختمان داده، الگوریتم و برنامه‌نویسی سیستمی پایه). تمام توضیحات باید به **زبان فارسی** باشد. خروجی باید شامل فایل‌های کد اجرایی + یک README آموزشی و روان برای هر جلسه باشد.

## ساختار کلی پوشه‌بندی

```
c/
├── README.md                     (فهرست کلی دوره، معرفی، پیش‌نیازها، نحوه استفاده)
├── session-01-intro/
│   ├── README.md
│   ├── examples/
│   │   ├── 01_example.c
│   │   ├── 02_example.c
│   │   └── ...
│   └── exercises/
│       └── exercise_01.c
├── session-02-.../
│   └── ... (همین ساختار)
...
├── session-50-.../
│   └── ...
```

هر جلسه باید پوشه مستقل خودش را داشته باشد با نام‌گذاری واضح (مثلاً `session-15-pointers-basics`).

## الزام Git و کامیت‌ها

- ابتدا یک ریپازیتوری Git با `git init` در ریشه پروژه بساز و یک `.gitignore` مناسب برای پروژه‌های C (فایل‌های باینری، `*.o`، `a.out` و غیره) اضافه کن.
- **بعد از تکمیل کامل هر جلسه** (README + `examples/` + `exercises/` نوشته و تست‌شده)، یک کامیت جداگانه برای همان جلسه ثبت کن.
- پیام کامیت مثلاً: `git commit -m "session 01: مقدمه‌ای بر C و راه‌اندازی محیط"`
- دقیقاً ۵۰ کامیت جداگانه (به‌علاوه یک کامیت اولیه برای اسکلت پروژه) باید در تاریخچه وجود داشته باشد؛ هیچ‌وقت چند جلسه با هم ادغام نشود.
- در پایان کار خروجی `git log --oneline` را نشان بده.

## محتوای هر جلسه

1. **README.md اختصاصی جلسه** شامل:
   - عنوان جلسه و اهداف یادگیری به فارسی
   - توضیح مفهومی از صفر — مثل اینکه مخاطب هیچ پیش‌زمینه‌ای ندارد
   - توضیح **خط‌به‌خط یا بخش‌به‌بخش** هر کد نمونه، دقیقاً کنار همان بخش از کد
   - نکات رایج اشتباهات و به‌خصوص برای C: مسائل حافظه (memory leak، dangling pointer، buffer overflow) هرجا مرتبط است
   - بهترین شیوه‌ها (Best Practices)
   - خلاصه پایان جلسه و لینک به فایل‌های `examples/`
   - حداقل ۱ تا ۲ تمرین عملی با سطح‌بندی (ساده / متوسط)

2. **فایل‌های کد واقعی و قابل کامپایل** (`.c`) در `examples/`:
   - با `gcc` قابل کامپایل و اجرای بدون خطا یا هشدار (`-Wall -Wextra`)
   - کامنت‌های فارسی داخل کد
   - کد تمیز و استاندارد؛ همه‌ی کدها واقعاً کامپایل و اجرا و تست شوند

3. **تمرین‌ها** در `exercises/` با راه‌حل جدا یا در بخش قابل‌تاشدن README.

## سرفصل پیشنهادی ۵۰ جلسه (قابل تنظیم توسط خودت اگر منطقی‌تر است)

1. مقدمه‌ای بر C، تاریخچه، نصب gcc، کامپایل و اجرای اولین برنامه
2. متغیرها، انواع داده پایه و ثابت‌ها (const)
3. عملگرها و اولویت آن‌ها
4. ورودی/خروجی با printf و scanf
5. شرط‌ها (if/else/switch)
6. حلقه‌ها (for/while/do-while)
7. break، continue و goto
8. مبانی توابع (Functions)
9. پارامترهای تابع و pass by value
10. بازگشت (Recursion) پایه
11. آرایه‌های یک‌بعدی
12. آرایه‌های چندبعدی
13. رشته‌ها (char array) مبانی
14. توابع رشته‌ای (string.h)
15. مبانی اشاره‌گرها (Pointers)
16. اشاره‌گرها و آرایه‌ها
17. اشاره‌گرها و توابع (pass by reference)
18. تخصیص حافظه پویا: malloc، calloc، realloc، free
19. ساختارها (struct)
20. struct تودرتو و آرایه‌ای از struct
21. یونیون‌ها (union)
22. شمارشی‌ها (enum)
23. typedef
24. کار با فایل: مبانی fopen/fread/fwrite
25. کار با فایل پیشرفته: fseek و فایل باینری
26. دستورات پیش‌پردازنده (#define، #include، ماکروها)
27. پروژه چندفایلی و فایل‌های هدر (header files)
28. کلاس‌های ذخیره‌سازی (static، extern، auto، register)
29. عملگرهای بیتی (Bitwise)
30. آرگومان‌های خط فرمان (argc، argv)
31. مدیریت خطا (errno، perror)
32. اشاره‌گر به تابع (Function Pointers)
33. اشاره‌گر void و برنامه‌نویسی جنریک ساده
34. لیست پیوندی یک‌طرفه (Singly Linked List)
35. لیست پیوندی دوطرفه و حلقوی
36. پیاده‌سازی پشته (Stack)
37. پیاده‌سازی صف (Queue)
38. مبانی درخت دودویی (Binary Tree)
39. درخت جستجوی دودویی (Binary Search Tree)
40. الگوریتم‌های مرتب‌سازی: حبابی، انتخابی، درجی
41. الگوریتم‌های مرتب‌سازی: ادغامی (Merge Sort) و سریع (Quick Sort)
42. الگوریتم‌های جستجو: خطی و دودویی
43. مبانی جدول هش (Hash Table)
44. بازگشت پیشرفته (Backtracking)
45. Makefile و اتوماسیون build
46. دیباگ با gdb
47. مدیریت درست حافظه و کار با valgrind
48. مبانی برنامه‌نویسی چندنخی (pthreads)
49. مقدمه‌ای بر شبکه و سوکت‌ها (sockets) در C
50. پروژه نهایی: ساخت یک برنامه واقعی (مثلاً یک shell ساده یا موتور کوچک پایگاه‌داده مبتنی بر فایل) با استفاده از تمام مفاهیم جلسات قبل

## README اصلی پروژه

باید شامل باشد: معرفی دوره، پیش‌نیازها (نصب gcc/make/gdb)، نحوه کامپایل و اجرا، فهرست کامل ۵۰ جلسه با لینک، نقشه راه یادگیری پیشنهادی، و توضیح ساختار کامیت‌های Git.

## نکات کیفیت مهم

- فارسی روان و طبیعی، نه ترجمه ماشینی؛ اصطلاحات تخصصی انگلیسی کنار فارسی بیاید
- سطح جلسات باید progressive باشد و روی مفاهیم قبلی سوار شود
- تمرکز ویژه روی مدیریت حافظه در C، چون منبع اصلی باگ‌های مبتدی‌هاست — هرجا لازم بود صریح هشدار بده
- تمام کدها واقعاً کامپایل، اجرا و تست شوند
- هر جلسه دقیقاً یک کامیت مجزا در Git
- در پایان، هم ساختار کامل پوشه‌ها (`tree`) و هم `git log --oneline` را نشان بده
