# جلسهٔ ۱۹ — ساختارها (struct)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `struct` چند دادهٔ مرتبط را در یک نوع بسته‌بندی کنید
- از اعضای struct با `.` (نقطه) استفاده کنید
- struct را مقداردهی کنید، به تابع بدهید و برگردانید
- تفاوت struct و آرایه را بدانید

---

## struct چیست؟

`struct` به شما اجازه می‌دهد چند مقدار با انواع مختلف را در **یک واحد** کنار هم بگذارید:

```c
struct Student {
    char name[50];
    int age;
    double gpa;
};
```

این اعلان فقط «قالب» را تعریف می‌کند؛ هنوز متغیری نساخته. برای ساخت:

```c
struct Student s1;              // متغیر از نوع struct Student
s1.age = 20;                    // دسترسی با نقطه
strcpy(s1.name, "Ali");
```

## مقداردهی اولیه

```c
struct Student s2 = {"Sara", 22, 18.5};
```

اعضا به ترتیب تعریف پر می‌شوند.

## struct و تابع

struct را می‌توان با مقدار (کپی) به تابع داد یا برگرداند:

```c
void print_student(struct Student s) {
    printf("%s, %d ساله، معدل %.2f\n", s.name, s.age, s.gpa);
}
```

توجه: پاس دادن struct با مقدار، کل ساختار را کپی می‌کند — برای structهای بزرگ از اشاره‌گر استفاده کنید (جلسهٔ بعد).

## نکات

- بعد از تعریف struct، معمولاً `;` لازم است.
- عضو آرایه داخل struct (مثل `char name[50]`) با `=` قابل انتساب نیست — باید `strcpy` یا مقداردهی اولیه کرد.
- دو struct هم‌نوع را می‌توان با `=` به هم داد (کپی عضو‌به‌عضو).

## اشتباهات رایج

1. **فراموش کردن `;` بعد از اعلان struct** — خطای کامپایل عجیب.
2. **استفاده از `=` برای کپی رشتهٔ عضو** — باید `strcpy`.
3. **اعلان struct بدون ساخت متغیر و بعد انتظار استفاده.**
4. **فراموش کردن کلمهٔ `struct` در C:** در C باید `struct Student s;` بنویسید (در C++ فقط `Student s;` است).

## بهترین شیوه‌ها

- نام struct را با حرف بزرگ شروع کنید: `struct Student`.
- برای کاهش تایپ از typedef استفاده کنید (جلسهٔ ۲۳).
- structهایی با مسئولیت واحد طراحی کنید.

## خلاصهٔ جلسه

- struct چند دادهٔ مرتبط را گروه‌بندی می‌کند.
- دسترسی به اعضا با `.`.
- می‌توان با مقدار پاس داد/برگرداند.

## تمرین‌ها

### تمرین ۱ (ساده)
struct برای کتاب (عنوان، نویسنده، سال) بسازید، یک نمونه مقداردهی و چاپ کنید.

### تمرین ۲ (متوسط)
struct برای نقطهٔ مختصات (x, y) بسازید و تابعی بنویسید که فاصلهٔ دو نقطه را با قضیهٔ فیثاغورس محاسبه کند.
