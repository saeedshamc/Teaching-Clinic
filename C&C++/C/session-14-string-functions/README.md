# جلسهٔ ۱۴ — توابع رشته‌ای (string.h)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- از توابع مهم `string.h` استفاده کنید: strlen، strcpy، strcat، strcmp، strchr
- تفاوت نسخه‌های محدود (`strncpy`، `strncat`، `strncmp`) را بدانید
- مشکلات امنیتی `strcpy` و `strcat` را بشناسید

---

## کتابخانهٔ string.h

با `#include <string.h>` این توابع در دسترس‌اند:

| تابع | کاربرد |
|---|---|
| `strlen(s)` | طول رشته (بدون `\0`) |
| `strcpy(dest, src)` | کپی کامل src در dest |
| `strncpy(dest, src, n)` | کپی حداکثر n کاراکتر |
| `strcat(dest, src)` | الحاق src به انتهای dest |
| `strncat(dest, src, n)` | الحاق حداکثر n کاراکتر |
| `strcmp(s1, s2)` | مقایسهٔ لغوی؛ ۰ اگر برابر |
| `strncmp(s1, s2, n)` | مقایسهٔ n کاراکتر اول |
| `strchr(s, c)` | پیدا کردن اولین جای حرف c |
| `strstr(hay, needle)` | پیدا کردن زیررشته |

## مقایسه با strcmp

```c
if (strcmp(a, b) == 0) {
    printf("برابرند\n");
}
```

مقدار بازگشتی: ۰ اگر برابر، منفی اگر `a < b`، مثبت اگر `a > b` (مقایسهٔ لغوی بر اساس کد ASCII).

## هشدار امنیتی جدی

`strcpy` و `strcat` **هیچ بررسی ظرفیت نمی‌کنند!** اگر منبع بزرگ‌تر از مقصد باشد → سرریز بافر. همیشه مطمئن شوید بافر مقصد جا دارد یا از نسخهٔ محدود (`strncpy`/`strncat`) استفاده کنید. (توجه: `strncpy` خودش هم نکات دارد — اگر به `\0` نرسید، بقیه را پر می‌کند و حتماً `\0` نمی‌گذارد؛ در C11 بهتر است از `strcpy_s` یا `snprintf` استفاده شود.)

## اشتباهات رایج

1. **مقایسه با `==` به‌جای `strcmp`** — آدرس‌ها مقایسه می‌شوند.
2. **`strcpy` بدون جا** — سرریز بافر.
3. **`strcat` به بافری که از قبل پر است** — سرریز.
4. **نادیده گرفتن مقدار بازگشتی `strcmp`** (مثلاً `if (strcmp(a,b))` یعنی «برابر نیستند» چون ۰ = نادرست).

## بهترین شیوه‌ها

- قبل از `strcpy`/`strcat` ظرفیت بافر را بررسی کنید.
- برای قالب‌بندی و کپی امن، `snprintf(dest, size, "%s", src)` جایگزین خوبی است.
- با `strncpy` بعد از آن حتماً `dest[size-1] = '\0'` را بگذارید.

## خلاصهٔ جلسه

- `strlen`، `strcpy`، `strcat`، `strcmp` ابزارهای اصلی رشته‌اند.
- مقایسهٔ درست فقط با `strcmp`.
- `strcpy`/`strcat` بدون مراقبت = سرریز بافر.
