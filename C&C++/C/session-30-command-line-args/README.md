# جلسهٔ ۳۰ — آرگومان‌های خط فرمان (argc، argv)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- با `argc` و `argv` آرگومان‌های خط فرمان را بگیرید
- برنامه‌ای بنویسید که ورودی خط فرمان را پردازش کند
- آرگومان‌های عددی را با `atoi`/`strtol` تبدیل کنید
- ورودی‌های نامعتبر را مدیریت کنید

---

## argc و argv

```c
int main(int argc, char *argv[]) {
    // ...
}
```

- `argc` (argument count): تعداد آرگومان‌ها (نام برنامه هم شمرده می‌شود).
- `argv` (argument vector): آرایهٔ رشته‌ها؛ `argv[0]` نام برنامه است، `argv[1]` اولین آرگومان.

```bash
./program hello world
# argc = 3
# argv[0] = "./program"
# argv[1] = "hello"
# argv[2] = "world"
```

## مثال: جمع دو عدد از خط فرمان

```c
int main(int argc, char *argv[]) {
    if (argc != 3) {
        printf("استفاده: %s <عدد۱> <عدد۲>\n", argv[0]);
        return 1;
    }
    int a = atoi(argv[1]);
    int b = atoi(argv[2]);
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}
```

## تبدیل رشته به عدد

- `atoi(s)` — سریع ولی بدون تشخیص خطا (رشتهٔ نامعتبر → ۰).
- `strtol(s, &end, 10)` — امن‌تر؛ `end` را چک کنید.

## نکات

- همیشه تعداد آرگومان‌ها را چک کنید (خطای index out of bounds اگر کمتر باشد).
- `argc` همیشه حداقل ۱ است (`argv[0]`).
- آرگومان‌ها همیشه رشته‌اند؛ برای عدد باید تبدیل کنید.

## اشتباهات رایج

1. **خواندن `argv[i]` بدون چک کردن `i < argc`** — کرش (out of bounds).
2. **استفاده از `atoi` بدون چک** — ورودی نامعتبر بی‌صدا صفر می‌شود.
3. **نادیده گرفتن `argv[0]`** — برای پیام راهنما مفید است.
4. **فرض اینکه argv[1] همیشه وجود دارد** — ممکن است برنامه بدون آرگومان اجرا شود.

## بهترین شیوه‌ها

- در ابتدای برنامه تعداد آرگومان‌ها را بررسی و پیام «استفاده» چاپ کنید.
- برای اعداد از `strtol` و چک کردن خطا استفاده کنید.
- `argc != تعداد موردنیاز` را دقیق بررسی کنید.

## خلاصهٔ جلسه

- argc تعداد، argv آرایهٔ رشته‌های ورودی؛ argv[0] نام برنامه.
- قبل از استفاده، تعداد را چک کنید.
- رشته → عدد با atoi/strtol.
