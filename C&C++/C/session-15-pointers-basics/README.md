# جلسهٔ ۱۵ — مبانی اشاره‌گرها (Pointers)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- بفهمید اشاره‌گر چیست: متغیری که آدرس خانهٔ حافظه را نگه می‌دارد
- با `&` (آدرس‌گرفتن) و `*` (درفرست‌کردن/dereference) کار کنید
- اشاره‌گر بسازید، مقداردهی کنید و با دقت استفاده کنید
- مفهوم dangling pointer و null pointer را بشناسید

---

## اشاره‌گر چیست؟

هر متغیر یک آدرس در حافظه دارد. **اشاره‌گر (pointer)** متغیری است که به‌جای مقدار، **آدرسِ** یک متغیر دیگر را نگه می‌دارد:

```c
int x = 10;        // یک متغیر معمولی
int *p = &x;       // p آدرسِ x را نگه می‌دارد
printf("%d\n", *p);  // درفرست: مقدارِ خانه‌ای که p به آن اشاره می‌کند = 10
```

- `&x` → آدرس x
- `int *p` → اعلان اشاره‌گر به int
- `*p` → مقدارِ خانهٔ مقصد (dereference)

## مثال تصویری

```
x  (خانهٔ 0x100) :  10
p  (خانهٔ 0x200) :  0x100   ← آدرس x
*p → مقدار خانه 0x100 → 10
```

## قوانین مهم

1. **نوع اشاره‌گر با نوع مقصد هماهنگ باشد:** `int *` برای `int`، `double *` برای `double`.
2. **اشاره‌گر بدون مقداردهی = رفتار نامشخص:** `int *p; *p = 5;` → کرش یا خرابی حافظه. همیشه اول مقداردهی کنید.
3. **NULL:** اشاره‌گری که به هیچ‌جا اشاره نمی‌کند را `NULL` کنید و قبل از استفاده چک کنید.

## هشدارها: dangling pointer و wild pointer

- **Wild pointer:** اشاره‌گر مقداردهی‌نشده — آدرس تصادفی. استفاده = فاجعه.
- **Dangling pointer:** اشاره‌گر به حافظه‌ای که دیگر معتبر نیست (مثلاً بعد از `free` یا بعد از اتمام تابع و متغیر محلی). استفاده از آن undefined behavior است.
- **Null pointer dereference:** `*p` وقتی `p == NULL` → کرش (segmentation fault).

## اشتباهات رایج

1. **فراموش کردن `&`:** `int *p = x;` → خطای کامپایل (ناسازگاری نوع).
2. **فراموش کردن `*` هنگام درفرست.**
3. **استفاده از اشاره‌گر مقداردهی‌نشده.**
4. **`p` و `*p` را اشتباه گرفتن:** `p` آدرس است، `*p` مقدار.

## بهترین شیوه‌ها

- اشاره‌گر را همیشه مقداردهی کنید (به یک متغیر یا NULL).
- قبل از درفرست، null بودن را چک کنید.
- نام اشاره‌گر را با `p` یا `ptr` شروع کنید تا خوانا باشد.

## خلاصهٔ جلسه

- اشاره‌گر = متغیرِ نگه‌دارندهٔ آدرس.
- `&` آدرس می‌دهد، `*` مقدار خانهٔ مقصد را می‌خواند/می‌نویسد.
- اشاره‌گر مقداردهی‌نشده و dangling خطرناک‌ترین منابع باگ در C هستند.

## تمرین‌ها

### تمرین ۱ (ساده)
دو متغیر `a` و `b` تعریف کنید، اشاره‌گر `p` را به `a` بدهید، مقدار `a` را از طریق `*p` تغییر دهید و نتیجه را چاپ کنید.

### تمرین ۲ (متوسط)
برنامه‌ای بنویسید که آدرس و مقدار چند متغیر از انواع مختلف را با `%p` چاپ کند و تفاوت اندازهٔ اشاره‌گرها را بررسی کند.
