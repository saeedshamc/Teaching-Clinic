# جلسهٔ ۳۳ — اشاره‌گر void و برنامه‌نویسی جنریک ساده

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- `void *` را بشناسید: اشاره‌گر «بدون نوع» که به هر نوعی می‌تواند اشاره کند
- از `void *` در توابع جنریک (مثل qsort و memcpy) استفاده کنید
- با `memcpy` و `memcmp` داده را بدون توجه به نوع کپی/مقایسه کنید

---

## void * چیست؟

`void *` اشاره‌گری است که **نوع داده‌ای که به آن اشاره می‌شود را مشخص نمی‌کند**. می‌تواند آدرس هر چیزی را بگیرد:

```c
int x = 10;
double d = 3.14;

void *ptr = &x;    // آدرس int
ptr = &d;          // حالا آدرس double — مجاز است!
```

برای استفاده از داده، باید به نوع درست **بازگردانده (cast)** شود:

```c
int *ip = (int *)ptr;   // یا در C: int *ip = ptr;
printf("%d\n", *ip);
```

## چرا void *؟

توابع عمومی که با هر نوع کار می‌کنند (جنریک):

- `qsort` — هر آرایه‌ای را مرتب می‌کند
- `memcpy` — هر بلوک حافظه را کپی می‌کند
- `memset` — هر بلوک را با مقدار مشخص پر می‌کند

```c
memcpy(dest, src, count * sizeof(type));
```

## توابع حافظهٔ عمومی

| تابع | کار |
|---|---|
| `memcpy(d, s, n)` | کپی n بایت از s به d |
| `memmove(d, s, n)` | مثل memcpy اما برای مناطق هم‌پوشان امن |
| `memset(p, c, n)` | n بایت را با مقدار c پر می‌کند |
| `memcmp(a, b, n)` | مقایسهٔ n بایت |

## هشدارها

1. **void * را نمی‌توان درفرست کرد:** `*ptr` خطاست — اول باید cast کنید.
2. **حساب اشاره‌گری روی void * ممنوع است:** `ptr + 1` در C استاندارد مجاز نیست (در GNU پسوند دارد).
3. **اندازهٔ داده را دقیق بدهید:** memcpy با n اشتباه = سرریز بافر.
4. **هم‌پوشانی را با memmove مدیریت کنید.**

## اشتباهات رایج

1. **cast کردن void * به نوع اشتباه** — دادهٔ بیمعنی یا کرش.
2. **`*ptr` مستقیم روی void *** — خطای کامپایل.
3. **memcpy با اندازهٔ اشتباه** — سرریز.
4. **در C++ برای cast نیاز به static_cast است؛ در C ساده است.**

## بهترین شیوه‌ها

- قبل از cast، بدانید واقعاً چه نوعی آن‌جاست.
- اندازه‌ها را با `sizeof` محاسبه کنید.
- برای کپی مناطق هم‌پوشان از `memmove` استفاده کنید.

## خلاصهٔ جلسه

- void * = اشاره‌گر بی‌نوع؛ برای جنریک بودن توابع.
- استفاده: cast به نوع درست + دسترسی.
- memcpy/memset/memcmp توابع حافظهٔ عمومی‌اند.
