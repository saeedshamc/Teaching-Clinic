# جلسهٔ ۱۲ — آرایه‌های چندبعدی

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- آرایهٔ دو بعدی (ماتریس) و سه بعدی تعریف و مقداردهی کنید
- با حلقهٔ تودرتو ماتریس را پیمایش کنید
- آرایهٔ دو بعدی را به تابع بدهید (و محدودیت آن را بدانید)

---

## آرایهٔ دو بعدی چیست؟

آرایهٔ دو بعدی مثل یک **جدول** است: سطر و ستون دارد. در حافظه هم عناصر سطر به سطر پشت‌سرهم ذخیره می‌شوند (row-major).

```c
int matrix[3][4];    // ۳ سطر و ۴ ستون
matrix[0][0] = 5;    // خانهٔ سطر ۰، ستون ۰
```

مقداردهی اولیه:

```c
int m[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

## پیمایش با حلقهٔ تودرتو

```c
for (int i = 0; i < ROWS; i++) {
    for (int j = 0; j < COLS; j++) {
        printf("%d ", m[i][j]);
    }
    printf("\n");
}
```

حلقهٔ بیرونی = سطرها، حلقهٔ داخلی = ستون‌ها.

## عبور آرایه به تابع

وقتی آرایهٔ دو بعدی به تابع می‌دهید، باید **تعداد ستون‌ها را مشخص کنید**:

```c
void print_matrix(int m[][COLS], int rows) {
    for (int i = 0; i < rows; i++) { ... }
}
```

چون آرایه به‌صورت «اشاره‌گر به سطر» نزول می‌کند، کامپایلر برای یافتن خانهٔ `m[i][j]` باید طول سطر را بداند.

## هشدارها

- در آرایهٔ چندبعدی هم خارج از محدوده رفتن = undefined behavior.
- آرایهٔ سه بعدی: `int cube[2][3][4];` — مثل چند ماتریس روی هم.

## اشتباهات رایج

1. **جابه‌جا کردن شاخص سطر و ستون** — خانهٔ اشتباه.
2. **فراموش کردن ابعاد هنگام عبور به تابع** — خطای کامپایل یا رفتار اشتباه.
3. **آرایهٔ خیلی بزرگ روی پشته (stack)** — برای ماتریس‌های بزرگ از حافظهٔ پویا استفاده کنید (جلسهٔ ۱۸).

## بهترین شیوه‌ها

- ابعاد را `#define` کنید.
- برای خوانایی، نام سطر/ستون را در نام متغیر بیاورید: `table[row][col]`.

## خلاصهٔ جلسه

- آرایهٔ ۲ بعدی = جدول سطر/ستون؛ پیمایش با حلقهٔ تودرتو.
- در تابع، تعداد ستون‌ها باید مشخص باشد.
