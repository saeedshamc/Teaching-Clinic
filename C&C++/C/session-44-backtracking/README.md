# جلسهٔ ۴۴ — بازگشت پیشرفته (Backtracking)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- الگوی Backtracking را درک کنید: «امتحان کن، اگر نشد برگرد»
- مسئلهٔ N-Queen را حل کنید
- جستجوی مسیر در یک maze (لابیرنت) را پیاده‌سازی کنید
- از آرایهٔ علامت‌گذاری (visited) برای جلوگیری از حلقهٔ بی‌نهایت استفاده کنید

---

## Backtracking چیست؟

**Backtracking** یک روش بازگشتی برای جستجوی همهٔ راه‌حل‌های ممکن است: در هر قدم یک انتخاب می‌کنیم، جلو می‌رویم، و اگر به بن‌بست رسیدیم «برمی‌گردیم» و انتخاب بعدی را امتحان می‌کنیم. به همین دلیل به آن «بازگشت به عقب» می‌گویند.

الگوی کلی:

```c
int solve(مشخصاتِ وضعیت) {
    if (به راه‌حل رسیدیم)  return 1;
    if (وضعیت نامعتبر)     return 0;

    for (هر انتخاب ممکن) {
        انجام انتخاب;
        if (solve(وضعیت جدید)) return 1;   // راه پیدا شد
        لغو انتخاب;                        // BACKTRACK!
    }
    return 0;   // هیچ انتخابی جواب نداد
}
```

## مسئلهٔ N-Queen

۸ وزیر را طوری روی شطرنج ۸×۸ بگذارید که هیچ‌دوتایی به هم حمله نکنند. (هر ردیف را یکی‌یکی پر می‌کنیم؛ هر وزیر باید در ستون متفاوت و دو قطر متفاوت باشد.)

```c
int is_safe(int board[N][N], int row, int col) {
    /* ستون */
    for (int i = 0; i < row; i++) {
        if (board[i][col]) return 0;
    }
    /* قطر اصلی (بالا-چپ) */
    for (int i = row, j = col; i >= 0 && j >= 0; i--, j--) {
        if (board[i][j]) return 0;
    }
    /* قطر فرعی (بالا-راست) */
    for (int i = row, j = col; i >= 0 && j < N; i--, j++) {
        if (board[i][j]) return 0;
    }
    return 1;
}
```

تابع اصلی:

```c
int solve_nqueens(int board[N][N], int row) {
    if (row == N) return 1;            // همهٔ وزیرها جا گرفتند

    for (int col = 0; col < N; col++) {
        if (is_safe(board, row, col)) {
            board[row][col] = 1;       // وزیر بگذار
            if (solve_nqueens(board, row + 1)) {
                return 1;
            }
            board[row][col] = 0;       // BACKTRACK — وزیر را بردار
        }
    }
    return 0;
}
```

نکتهٔ مهم: بعد از شکست، باید خانه را به حالت اول برگردانیم (`board[row][col] = 0`) — وگرنه مسیرهای بعدی آلوده می‌شوند.

## جستجوی مسیر در Maze

از خانهٔ شروع به مقصد می‌رویم؛ `visited` جلوی رفتن دوباره به یک خانه را می‌گیرد (جلوگیری از حلقهٔ بی‌نهایت):

```c
int solve_maze(int maze[][COLS], int visited[][COLS], int r, int c) {
    if (خارج از محدوده یا دیوار یا قبلاً دیده شده) return 0;
    if (رسیدیم به مقصد) return 1;

    visited[r][c] = 1;                 // علامت بزن
    if (solve_maze(...r+1, c...)) return 1;   // پایین
    if (solve_maze(...r-1, c...)) return 1;   // بالا
    if (solve_maze(...r, c+1...)) return 1;   // راست
    if (solve_maze(...r, c-1...)) return 1;   // چپ
    return 0;                          // بن‌بست
}
```

## اشتباهات رایج

1. **فراموش کردن «لغو انتخاب» (backtrack)** — شایع‌ترین باگ؛ بعد از شکست باید حالت را برگردانید.
2. **فراموش کردن `visited`** → حلقهٔ بی‌نهایت در maze.
3. **شرط مرز اشتباه** در maze (بررسی `r < 0 || r >= ROWS`).
4. **تست فقط یک راه‌حل** — در مسئله‌هایی که همهٔ راه‌حل‌ها لازم‌اند، بعد از پیدا کردن یکی return نکنید.
5. **پاس دادن آرایهٔ بزرگ با value** — همیشه با اشاره‌گر/آرایهٔ ضمنی پاس دهید تا کپی نشود.

## بهترین شیوه‌ها

- اول نسخهٔ «یک راه‌حل» را بنویسید، بعد همهٔ راه‌حل‌ها.
- با N کوچک (۴ یا ۸) تست کنید و تعداد راه‌حل‌ها را بشمارید (N=8 → ۹۲ راه‌حل).
- ترتیب حرکت‌ها را ثابت نگه دارید تا خروجی قابل‌پیش‌بینی باشد.
- برای maze اول با یک لابیرنت کوچک ۵×۵ شروع کنید.

## خلاصهٔ جلسه

- Backtracking = بازگشت + امتحان همهٔ انتخاب‌ها + لغو انتخاب در صورت شکست.
- N-Queen و Maze دو مثال کلاسیک هستند.
- `visited` و لغو انتخاب، دو ابزار ضروری این الگوریتم‌اند.
