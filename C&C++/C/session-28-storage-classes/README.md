# جلسهٔ ۲۸ — کلاس‌های ذخیره‌سازی (static، extern، auto، register)

## اهداف یادگیری

در پایان این جلسه می‌توانید:

- کلاس‌های ذخیره‌سازی C را بشناسید: auto، register، static، extern
- تفاوت متغیر محلی `static` و معمولی را بفهمید
- با `extern` از متغیرهای سراسری فایل‌های دیگر استفاده کنید
- scope (محدوده) و lifetime (طول عمر) متغیر را توضیح دهید

---

## کلاس‌های ذخیره‌سازی

| کلمه | معنی |
|---|---|
| `auto` | متغیر محلی معمولی (پیش‌فرض — به‌ندرت صریح می‌نویسیم) |
| `register` | پیشنهاد نگه‌داری در رجیستر CPU (امروزه کامپایلر خودش تصمیم می‌گیرد) |
| `static` | محلی: طول عمر تا پایان برنامه، ولی scope فقط همان تابع. سراسری: محدود به همان فایل. |
| `extern` | اعلام می‌کند متغیر/تابع در جای دیگر تعریف شده است |

## static محلی — حالت ماندگار

```c
void counter(void) {
    static int count = 0;   // فقط یک بار مقداردهی می‌شود!
    count++;
    printf("%d ", count);
}
```

`count` بین صدا زدن‌های تابع **حالتش حفظ می‌شود** چون در حافظهٔ ایستا (static storage) زندگی می‌کند، نه پشته.

## extern — استفاده از متغیر فایل دیگر

```c
// file1.c
int global_counter = 0;    // تعریف

// file2.c
extern int global_counter; // اعلام: در جای دیگر تعریف شده
```

## قواعد مهم

- متغیر محلی غیرstatic در هر صدا زدن تابع **از نو ساخته و نابود** می‌شود.
- متغیر سراسری از تعریف تا پایان فایل معتبر است.
- `static` روی تابع، تابع را به همان فایل محدود می‌کند (قابل دیدن از فایل‌های دیگر نیست).
- در فایل هدر نباید تعریف متغیر بگذارید (باید extern + تعریف در یک .c باشد).

## اشتباهات رایج

1. **استفاده از متغیر محلی static بدون فهم «یک بار مقداردهی»** — مقدار اولیه فقط بار اول اعمال می‌شود.
2. **تعریف متغیر در هدر** — با چند include، تعریف تکراری.
3. **نادیده گرفتن تفاوت scope و lifetime.**
4. **استفاده از `register` برای گرفتن آدرس** — `&x` روی register مجاز نیست.

## بهترین شیوه‌ها

- از متغیرهای سراسری کم استفاده کنید؛ ترجیحاً با اشاره‌گر پاس دهید.
- `static` محلی برای شمارنده‌ها و کش‌های کوچک مفید است.
- برای حالت‌های مشترک بین فایل‌ها، extern را در هدر و تعریف را در یک .c بگذارید.

## خلاصهٔ جلسه

- auto/register برای محلی‌ها، static برای طول عمر بلند یا محدودیت فایل، extern برای دیدن تعریف از جای دیگر.
- static محلی فقط یک بار مقداردهی می‌شود.
- متغیر سراسری در هدر تعریف نمی‌شود.

## تمرین‌ها

### تمرین ۱ (ساده)
تابع `counter` با static محلی بسازید که هر بار صدا زدن، عدد را افزایش دهد و ۵ بار آن را صدا بزنید.

### تمرین ۲ (متوسط)
در دو فایل، متغیر سراسری را در یکی تعریف و در دیگری با extern استفاده کنید.
