# تمرین‌های جلسه ۲۶ — پروژه Responsive Navbar

## کلاسی (۳۰ دقیقه)

1. **navbar پایه:** با Flexbox لوگو و ۴ لینک بسازید.
2. **media query:** زیر ۷۶۸px لینک‌ها مخفی و hamburger نمایش داده شود.
3. **checkbox hack:** بدون JS منو باز/بسته شود.
4. **sticky:** header هنگام scroll بالای صفحه بماند.

## خانه (۴۵ دقیقه)

5. **CTA button:** لینک «ثبت‌نام» با استایل دکمه در navbar.
6. **focus-visible:** با Tab بین لینک‌ها حرکت کنید — outline واضح باشد.
7. **پروژه کامل:** hero + ۳ card + footer مانند `04_full_responsive_nav.html`.
8. **RTL:** متن فارسی و `dir="rtl"` — تراز لوگو و hamburger درست باشد.

## نکات

- `list-style: none` برای `ul`
- `position: relative` روی `.navbar` برای dropdown موبایل
- `aria-label` روی `nav` و `label` hamburger
- تست در ۳۲۰px عرض
