# تمرین‌های جلسه ۴ — قالب‌بندی متن

## کلاسی (۳۰ دقیقه)

### ۱. اخبار کوتاه
یک خبر با strong برای تیتر inline، em برای نقل‌قول کوتاه.

### ۲. فروشگاه
محصول با قیمت قدیم del و جدید ins + small برای یادداشت.

### ۳. blockquote
نقل‌قول از یک شخصیت IT با footer و cite.

### ۴. راهنمای تگ
پاراگرaph که سه تگ HTML را با code نشان دهد.

---

## خانه (۴۵ دقیقه)

### ۵. واژه‌نامه mini
۵ اصطلاح با abbr و title (HTML، CSS، URL، …).

### ۶. مقاله ویرایش‌شده
دو پاراگرaph — یکی با del/ins نشان‌دهنده ویرایش.

### ۷. فرمول و علامت
sub/sup در یک پاراگرaph علمی یا ریاضی.

### ۸. مقایسه
جدول متنی: کی strong بزنیم، کی b؟ (۳ مثال هر کدام)
