# Exercise 1: Environment Setup and Folder Organization

## Task
Set up a proper development environment and organize a project folder structure according to best practices.

## Requirements

1. **Create a new project folder** called `my-practice-site` in a location of your choice

2. **Create the following folder structure** inside your project folder:
   - `css/` (for CSS files)
   - `images/` (for image files)
   - `js/` (for JavaScript files)

3. **Create the following files** in the appropriate locations:
   - `index.html` in the root folder
   - `style.css` in the `css/` folder
   - `script.js` in the `js/` folder

4. **Verify your setup**:
   - Open the project folder in VS Code
   - Install the Live Server extension if you haven't already
   - Open `index.html` with Live Server
   - Confirm that a browser tab opens with your page

5. **Test Live Server**:
   - Make a small change to `index.html` (add any text)
   - Save the file
   - Verify that the browser automatically refreshes with your changes

## Hints

- Remember that `index.html` should be in the root folder, not in a subfolder
- Use lowercase letters and hyphens for file and folder names
- The folder structure should be: `my-practice-site/`, `css/`, `images/`, `js/`

## Success Criteria

- [ ] Project folder created with correct name
- [ ] All three subfolders created (css, images, js)
- [ ] index.html in root folder
- [ ] style.css in css folder
- [ ] script.js in js folder
- [ ] Project opens in VS Code
- [ ] Live Server opens the page in a browser
- [ ] Live Server automatically refreshes on save
