# تمرین‌های جلسه ۱ — مقدمه وب و محیط توسعه

## کلاسی (۳۰ دقیقه)

### ۱. صفحه معرفی
فایل `intro.html` بسازید با:
- `<title>`: «معرفی [نام شما]»
- `<h1>`: نام کامل
- دو `<p>`: شهر و یک جمله انگیزشی

### ۲. کامنت بخش‌بندی
بالای هر بخش اصلی با `<!-- -->` برچسب بگذارید (مثلاً «بخش معرفی»).

### ۳. ساختار پوشه
پوشه `my-first-site` با این ساختار:
```
my-first-site/
├── index.html
├── css/        (خالی)
└── images/     (خالی)
```

### ۴. DevTools
صفحه را باز کنید، F12 بزنید و در تب Elements تگ `<h1>` را پیدا کنید.

---

## خانه (۴۵ دقیقه)

### ۵. مقایسه مرورگر
همان `index.html` را در Chrome و Firefox (یا Edge) باز کنید؛ تفاوتی می‌بینید؟

### ۶. View Source
View Page Source را باز کنید و تفاوت با تب Elements را یک پارagraph توضیح دهید.

### ۷. README پروژه
فایل `README.md` در پوشه پروژه: نام، هدف سایت، لیست صفحات آینده.

### ۸. قالب شخصی
از `04_project_template.html` کپی بگیرید و metaهای `description` و `author` را پر کنید.
