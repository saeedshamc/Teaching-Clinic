سه لایه توسعه وب

HTML — ساختار

HTML محتوا و معنا را تعریف می‌کند: عنوان، پاراگراف، لیست.

CSS — ظاهر

CSS رنگ، فونت و چیدمان را کنترل می‌کند. در جلسه‌های بعدی CSS را یاد می‌گیریم.

JavaScript — رفتار

JavaScript صفحه را تعاملی می‌کند: منو، فرم، انیمیشن.

تشبیه: HTML = اسکلت، CSS = رنگ دیوار، JS = کلید برق.
