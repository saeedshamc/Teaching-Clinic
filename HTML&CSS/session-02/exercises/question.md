# تمرین‌های جلسه ۲ — ساختار سند HTML

## کلاسی (۳۰ دقیقه)

### ۱. سند کامل
فایلی با تمام بخش‌های استاندارد: DOCTYPE، html با lang/dir، head کامل، body با h1 و ۳ p.

### ۲. title و description
title: «رزومه [نام]» — description: یک جمله درباره مهارت‌هایتان.

### ۳. تمرین nesting
یک پاراگرaph با `<strong>` و `<em>` تو در تو — بدون خطای بستن.

### ۴. Validator
سند را در validator.w3.org بررسی و خطاها را برطرف کنید.

---

## خانه (۴۵ دقیقه)

### ۵. دو صفحه مرتبط
`index.html` و `about.html` — head یکسان، body متفاوت.

### ۶. lang مخلوط
یک پاراگرaph انگلیسی با `lang="en"` داخل body فارسی.

### ۷. گزارش Quirks
صفحه بدون DOCTYPE بسازید، با DevTools مقایسه کنید (یک پاراگرaph گزارش).

### ۸. قالب head
فایل `head-snippet.html` فقط با محتوای head برای کپی در پروژه‌های بعد.
