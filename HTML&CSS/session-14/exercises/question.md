# تمرین‌های جلسه ۱۴ — سلکتورهای CSS

## کلاسی (۳۰ دقیقه)

### ۱. کارت محصول
صفحه HTML با سه `<div class="product-card">` بسازید. با CSS:
- همه `h2`ها رنگ `#2c3e50`
- `.product-card` پس‌زمینه سفید و سایه
- `.product-card.featured` border طلایی

### ۲. فرم ثبت‌نام
فرم با `input[type="text"]`، `input[type="password"]`، `input[required]`.
attribute selector برای border متفاوت.

### ۳. منوی ناوبری
`<nav id="main-nav">` با لینک‌ها. `#main-nav` پس‌زمینه تیره؛ `.active` برای لینک فعال.

---

## خانه (۴۵ دقیقه)

### ۴. صفحه مقالات
لیست `<article class="post">` — element + class ترکیبی: `article.post h2`.

### ۵. تحقیق
تفاوت class و id از نظر HTML validity و CSS specificity (۱۰ خط).
