# تمرین‌های جلسه ۷ — تصاویر

## کلاسی (۳۰ دقیقه)

### ۱. گالری ساده
۳ img با alt مناسب از images/.

### ۲. figure
یک figure با figcaption.

### ۳. ابعاد
width و height روی همه تصاویر.

### ۴. lazy
loading="lazy" روی تصویر دوم و سوم.

## خانه (۴۵ دقیقه)

### ۵. صفحه محصول
تصویر محصول + figure + توضیح.

### ۶. alt بد vs خوب
دو نسخه — alt ضعیف و قوی — مقایسه در گزارش.

### ۷. لینک تصویری
a دور img — alt لینک = alt تصویر.

### ۸. SVG
لوگوی SVG در img با alt «لوگوی سایت».
