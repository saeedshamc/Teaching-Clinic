کار با پاراگراف

HTML مخفف HyperText Markup Language است. این زبان ساختار صفحات وب را تعریف می‌کند و پایه کار هر توسعه‌دهنده front-end است.

هر عنصر p یک بلوک مستقل است. مرورگر قبل و بعد p فاصله پیش‌فرض می‌گذارد. در جلسه‌های CSS این فاصله را کنترل می‌کنیم.

پاراگراف کوتاه سوم برای نمایش فاصله بین بلوک‌ها.
