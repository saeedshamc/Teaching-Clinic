# جلسه ۳: عناصر متنی — عنوان، پاراگراف و جداکننده (۱.۵ ساعت)

## 🎯 اهداف یادگیری

پس از این جلسه می‌توانید:
- از `<h1>` تا `<h6>` برای سلسله‌مراتب عنوان استفاده کنید
- پاراگراف با `<p>` بنویسید
- شکست خط با `<br>` و خط افقی با `<hr>` ایجاد کنید
- سلسله‌مراتب heading را برای SEO و دسترس‌پذیری رعایت کنید
- تفاوت block elements و فاصله‌گذاری پیش‌فرض را بدانید

## ۱. عناصر متنی block

**Block elements** معمولاً کل عرض را می‌گیرند و خط جدید شروع می‌کنند (قبل از CSS).

عناصر این جلسه: `h1`–`h6`, `p`, `hr` — و `br` استثنا (inline).

---

## ۲. عناوین — `<h1>` تا `<h6>`

```html
<h1>عنوان اصلی صفحه</h1>
<h2>بخش اول</h2>
<h3>زیربخش</h3>
<h4>سطح چهار</h4>
<h5>سطح پنج</h5>
<h6>کوچک‌ترین سطح</h6>
```

### ۲.۱. قوانین heading

| قانون | دلیل |
|-------|------|
| **یک h1** در هر صفحه (معمولاً) | موضوع اصلی صفحه |
| **بدون پرش سطح** | h1 → h3 ❌؛ h1 → h2 → h3 ✅ |
| **برای ساختار نه اندازه** | اندازه با CSS (جلسه ۱۳+) |
| **ترتیب منطقی** | screen reader از headings ناوبری می‌کند |

### ۲.۲. مثال ساختار مقاله

```html
<h1>آموزش HTML</h1>
<h2>مقدمه</h2>
<p>...</p>
<h2>عناصر متنی</h2>
<h3>عناوین</h3>
<p>...</p>
<h3>پاراگراف</h3>
<p>...</p>
```

---

## ۳. پاراگراف — `<p>`

```html
<p>HTML زبان نشانه‌گذاری است. با تگ‌ها ساختار می‌سازیم.</p>
<p>هر p یک بلوک متن جدا است. فاصله بین pها پیش‌فرض مرورگر است.</p>
```

**نکته:** برای چند خط در **یک** پاراگراف از `<br>` استفاده کنید، نه چند `<p>` کوتاه پشت سر هم (مگر معنا جدا باشد).

### ۳.۱. p خالی

```html
<p></p>  <!-- بی‌فایده — از br یا margin CSS استفاده کنید -->
```

---

## ۴. شکست خط — `<br>`

```html
<p>
    خط اول<br>
    خط دوم در همان پاراگراف
</p>
```

- **Void element** — تگ بسته ندارد (`<br>` یا `<br />`)
- برای **شعر، آدرس، امضا** مناسب
- ❌ برای فاصله بین بخش‌ها — از heading یا CSS استفاده کنید

### ۴.۱. br زیاد = بوی CSS

اگر بیش از ۲–۳ br پشت سر هم دارید، احتمالاً باید margin/padding با CSS تنظیم شود.

---

## ۵. خط افقی — `<hr>`

```html
<h2>بخش اول</h2>
<p>متن بخش...</p>
<hr>
<h2>بخش دوم</h2>
<p>متن بخش...</p>
```

- **Thematic break** — تغییر موضوع یا بخش
- void element
- در HTML5 معنایی است نه فقط خط تزئینی

---

## ۶. ترکیب عناصر — مثال کامل

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>عناصر متنی</title>
</head>
<body>
    <h1>راهنمای HTML</h1>
    <p>HTML پایه ساخت صفحات وب است.</p>

    <hr>

    <h2>فصل ۱: شروع</h2>
    <p>در این فصل با ساختار آشنا می‌شوید.</p>
    <h3>۱.۱ نصب</h3>
    <p>VS Code را نصب کنید.</p>
</body>
</html>
```

## ۷. دسترس‌پذیری (Accessibility)

- Screen reader headings را فهرست می‌کند — سطح‌ها را رعایت کنید
- h1 موضوع صفحه را خلاصه کند
- p برای بلوک‌های خوانا — نه div با متن plain

## ۹. اشتباهات رایج

| اشتباه | مشکل | راه‌حل |
|--------|------|--------|
| h1 برای هر خط بزرگ | ساختار خراب | فقط برای عنوان واقعی |
| چند h1 | SEO/ a11y گیج | یک h1 |
| br برای فاصله عمودی | نگهداری سخت | CSS margin |
| heading فقط bold | معنا از دست می‌رود | از h استفاده کنید |
| p داخل p | نامعتبر | جدا کنید |

### ❌ heading برای bold

```html
<h4>توجه!</h4>  <!-- اگر بخش نیست، اشتباه -->
<p><strong>توجه!</strong></p>  <!-- برای تأکید درون پاراگراف -->
```

## ۱۰. بهترین شیوه‌ها

1. **Outline منطقی** — سند را مثل فهرست کتاب بنویسید
2. **h1 = عنوان صفحه** — مطابق title یا نزدیک آن
3. **hr برای تغییر موضوع** — نه decoration بی‌معنا
4. **br کم** — فقط جایی که معنا یک پاراگراف است
5. **پیش‌نمایش** — outline را در DevTools یا افزونه heading map ببینید
