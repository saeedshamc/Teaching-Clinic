# تمرین‌های جلسه 38 — دسترسی‌پذیری (a11y)

## کلاسی (۳۰ دقیقه)

1. صفحه با header، nav، main، footer — skip link اضافه کنید.
2. سه تصویر: alt محتوایی، تزئینی، لینک تصویری.
3. دکمه منو با aria-expanded.

---

## خانه (۴۵ دقیقه)

4. دو جفت رنگ — یکی AA، یکی رد.
5. Tab بزنید — focus outline اضافه کنید.
6. heading hierarchy را اصلاح کنید.
