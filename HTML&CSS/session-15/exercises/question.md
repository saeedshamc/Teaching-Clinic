# تمرین‌های جلسه ۱۵

## کلاسی
1. جدول با `tr:nth-child(even)` zebra stripe
2. لیست با `li:first-child` و `li:last-child` استایل متفاوت
3. دکمه با `:hover` و `:active` و `:focus-visible`

## خانه
4. breadcrumb با `::after { content: " / "; }` روی li به جز last
5. `:not()` برای استایل همه دکمه‌ها به جز `.disabled`
