# جلسه ۰۸: رشته‌ها (Strings) — ۱۲۰ دقیقه

## پیش‌نیازها
انواع داده، آرایه‌ها، شرط و حلقه.

## اهداف قابل‌اندازه‌گیری
می‌توانید رشته را بسازید و درون‌یابی کنید، متن UTF-8 را با `mb_*` پردازش کنید، جست‌وجو و جایگزینی انجام دهید و خروجی HTML را درست escape کنید.

## چرا مهم است؟
نام، پیام، URL و محتوای صفحه رشته‌اند؛ خطای کاراکتر یا escape می‌تواند هم تجربهٔ کاربر و هم امنیت را خراب کند.

## مفهوم عمیق
رشته (String) در PHP دنباله‌ای از بایت‌هاست، نه الزاماً نویسه‌ها. بنابراین `strlen('سلام')` تعداد بایت‌ها را می‌دهد؛ برای متن فارسی از `mb_strlen` و `mb_substr` با `UTF-8` استفاده کنید. تک‌نقل‌قول درون‌یابی نمی‌کند، دونقل‌قول می‌کند و Heredoc برای متن چندخطی مناسب است.

## اشتباه‌های رایج
1. استفاده از `strlen` برای شمارش نویسه‌های فارسی.
2. چسباندن ورودی کاربر مستقیم به HTML؛ هنگام خروجی از `htmlspecialchars` استفاده کنید.
3. بررسی نتیجهٔ `strpos` با `== false`؛ موقعیت صفر را با `=== false` تفکیک کنید.
4. sanitize کردن زودهنگام داده و از دست‌دادن مقدار اصلی؛ validate در مرز ورودی و escape در مرز خروجی.

## مثال گام‌به‌گام و قابل اجرا
[01-strings.php](./examples/01-strings.php) متن فارسی را نرمال، خلاصه و برای HTML امن می‌کند:

```bash
php examples/01-strings.php
```

## الگوی بهتر
متن را با encoding مشخص نگه دارید، عملیات زبانی را با `mb_*` انجام دهید و escape را متناسب با context خروجی (HTML، URL یا JSON) انتخاب کنید.

## تمرین‌ها
### آسان
یک نام را trim کنید و تعداد نویسه‌هایش را چاپ کنید.

### چالشی
تابع خلاصه‌ساز UTF-8 بنویسید که متن کوتاه را دست‌نخورده و متن بلند را با `…` برگرداند.

## راهنمای حل
از `trim`، `mb_strlen` و `mb_substr` استفاده کنید؛ طول نهایی و سه‌نقطه را در قرارداد تابع مشخص کنید.

## خودآزمایی
1. تفاوت تک‌نقل‌قول و دونقل‌قول چیست؟
2. چرا `mb_strlen` برای فارسی لازم است؟
3. `strpos` در صورت یافتن ابتدای رشته چه می‌دهد؟
4. escape با validation چه تفاوتی دارد؟
5. برای خروجی HTML از چه تابعی استفاده می‌کنیم؟
6. `trim` چه چیزی را تغییر می‌دهد؟

## جمع‌بندی و پل جلسهٔ بعد
رشته را با encoding و context درست پردازش کردید. جلسهٔ بعد این منطق را در توابع کوچک و قابل‌آزمون بسته‌بندی می‌کنیم.
