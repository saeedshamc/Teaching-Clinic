# جلسه ۰۴: عملگرها در PHP

## 🎯 اهداف یادگیری

در پایان این جلسه، شما خواهید توانست:
- با انواع عملگرهای ریاضی در PHP کار کنید
- عملگرهای مقایسه‌ای را بشناسید و استفاده کنید
- عملگرهای منطقی را در شرایط پیچیده استفاده کنید
- اولویت عملگرها را درک کنید
- از عملگرهای اختصاص و افزایش/کاهش استفاده کنید

## 🧮 عملگرهای ریاضی (Arithmetic Operators)

عملگرهای ریاضی برای انجام عملیات ریاضی روی اعداد استفاده می‌شوند.

| عملگر | نام | مثال | نتیجه |
|--------|-----|------|--------|
| `+` | جمع | `$a + $b` | جمع `$a` و `$b` |
| `-` | تفریق | `$a - $b` | تفریق `$b` از `$a` |
| `*` | ضرب | `$a * $b` | ضرب `$a` در `$b` |
| `/` | تقسیم | `$a / $b` | تقسیم `$a` بر `$b` |
| `%` | باقیمانده | `$a % $b` | باقیمانده تقسیم `$a` بر `$b` |
| `**` | توان | `$a ** $b` | `$a` به توان `$b` |

### مثال‌های عملگرهای ریاضی

فایل: [`examples/01-arithmetic-operators.php`](./examples/01-arithmetic-operators.php)

```php
<?php
// تعریف متغیرها
$a = 10;
$b = 3;

// عملگرهای پایه
echo "Addition: " . ($a + $b) . "\n";      // 13
echo "Subtraction: " . ($a - $b) . "\n";   // 7
echo "Multiplication: " . ($a * $b) . "\n"; // 30
echo "Division: " . ($a / $b) . "\n";      // 3.333...
echo "Modulus: " . ($a % $b) . "\n";       // 1

// عملگر توان
echo "Exponentiation: " . ($a ** $b) . "\n"; // 1000 (10^3)

// ترکیب عملگرها
$c = 5;
$result = ($a + $b) * $c;
echo "Combined: " . $result . "\n";  // (10 + 3) * 5 = 65

// تقسیم با دقت اعشاری
$division = 10 / 3;
echo "Precision division: " . number_format($division, 2) . "\n"; // 3.33
?>
```

**توضیح کد:**
- عملگر `%` (مودولو) باقیمانده تقسیم را برمی‌گرداند.
- عملگر `**` (توان) در PHP 5.6+ اضافه شده است.
- `number_format()` برای فرمت‌دهی اعداد اعشاری استفاده می‌شود.

## ⚖️ عملگرهای مقایسه‌ای (Comparison Operators)

عملگرهای مقایسه‌ای برای مقایسه دو مقدار استفاده می‌شوند و نتیجه آن‌ها همیشه `true` یا `false` است.

| عملگر | نام | مثال | نتیجه |
|--------|-----|------|--------|
| `==` | مساوی | `$a == $b` | `true` اگر `$a` برابر `$b` باشد |
| `===` | کاملا مساوی | `$a === $b` | `true` اگر `$a` برابر `$b` باشد و نوع آن‌ها نیز یکسان باشد |
| `!=` | نامساوی | `$a != $b` | `true` اگر `$a` نامساوی `$b` باشد |
| `!==` | کاملا نامساوی | `$a !== $b` | `true` اگر `$a` نامساوی `$b` باشد یا نوع آن‌ها متفاوت باشد |
| `<` | کوچکتر از | `$a < $b` | `true` اگر `$a` کوچکتر از `$b` باشد |
| `>` | بزرگتر از | `$a > $b` | `true` اگر `$a` بزرگتر از `$b` باشد |
| `<=` | کوچکتر یا مساوی | `$a <= $b` | `true` اگر `$a` کوچکتر یا مساوی `$b` باشد |
| `>=` | بزرگتر یا مساوی | `$a >= $b` | `true` اگر `$a` بزرگتر یا مساوی `$b` باشد |
| `<=>` | فضاپیمایی (Spaceship) | `$a <=> $b` | `-1`, `0`, یا `1` |

### مثال‌های عملگرهای مقایسه‌ای

فایل: [`examples/02-comparison-operators.php`](./examples/02-comparison-operators.php)

```php
<?php
$a = 10;
$b = "10";
$c = 5;

// عملگرهای مساوی
echo "a == b: " . var_export($a == $b, true) . "\n";    // true (مقادیر مساوی هستند)
echo "a === b: " . var_export($a === $b, true) . "\n";  // false (مقادیر مساوی اما انواع متفاوت)

// عملگرهای نامساوی
echo "a != b: " . var_export($a != $b, true) . "\n";    // false
echo "a !== b: " . var_export($a !== $b, true) . "\n";  // true

// عملگرهای مقایسه‌ای
$num1 = 10;
$num2 = 20;
echo "num1 < num2: " . var_export($num1 < $num2, true) . "\n";   // true
echo "num1 > num2: " . var_export($num1 > $num2, true) . "\n";   // false
echo "num1 <= num2: " . var_export($num1 <= $num2, true) . "\n"; // true

// عملگر فضاپیمایی (Spaceship)
// اگر $a < $b: -1
// اگر $a == $b: 0
// اگر $a > $b: 1
$spaceship = $num1 <=> $num2;
echo "Spaceship (10 <=> 20): $spaceship\n";  // -1

$spaceship2 = 20 <=> 10;
echo "Spaceship (20 <=> 10): $spaceship2\n"; // 1

$spaceship3 = 10 <=> 10;
echo "Spaceship (10 <=> 10): $spaceship3\n"; // 0
?>
```

**توضیح کد:**
- `==` تنها مقادیر را مقایسه می‌کند.
- `===` هم مقادیر و هم انواع را مقایسه می‌کند.
- عملگر `<=>` (فضاپیمایی) در PHP 7+ اضافه شده است.
- `var_export()` برای نمایش مقادیر بولین به صورت رشته استفاده می‌شود.

## 🔗 عملگرهای منطقی (Logical Operators)

عملگرهای منطقی برای ترکیب شرایط استفاده می‌شوند.

| عملگر | نام | مثال | نتیجه |
|--------|-----|------|--------|
| `&&` | AND | `$a && $b` | `true` اگر هر دو `$a` و `$b` true باشند |
| `||` | OR | `$a || $b` | `true` اگر حداقل یکی از `$a` یا `$b` true باشد |
| `!` | NOT | `!$a` | `true` اگر `$a` false باشد |
| `and` | AND | `$a and $b` | مشابه `&&` اما اولویت پایین‌تری دارد |
| `or` | OR | `$a or $b` | مشابه `||` اما اولویت پایین‌تری دارد |
| `xor` | XOR | `$a xor $b` | `true` اگر تنها یکی از `$a` یا `$b` true باشد |

### مثال‌های عملگرهای منطقی

فایل: [`examples/03-logical-operators.php`](./examples/03-logical-operators.php)

```php
<?php
$a = true;
$b = false;
$c = true;

// عملگر AND (&&)
echo "a && b: " . var_export($a && $b, true) . "\n";  // false
echo "a && c: " . var_export($a && $c, true) . "\n";  // true

// عملگر OR (||)
echo "a || b: " . var_export($a || $b, true) . "\n";  // true
echo "b || b: " . var_export($b || $b, true) . "\n";  // false

// عملگر NOT (!)
echo "!a: " . var_export(!$a, true) . "\n";    // false
echo "!b: " . var_export(!$b, true) . "\n";    // true

// عملگر XOR (xor)
echo "a xor b: " . var_export($a xor $b, true) . "\n";  // true
echo "a xor c: " . var_export($a xor $c, true) . "\n";  // false

// مثال عملی: بررسی سن و مجوز
$age = 25;
$hasLicense = true;
$canDrive = ($age >= 18) && $hasLicense;
echo "Can drive: " . var_export($canDrive, true) . "\n";  // true

// بررسی ورود به سایت
$isLoggedIn = false;
$isAdmin = true;
$canAccess = $isLoggedIn || $isAdmin;
echo "Can access: " . var_export($canAccess, true) . "\n";  // true
?>
```

**توضیح کد:**
- `&&` و `||` اولویت بالاتری نسبت به `and` و `or` دارند.
- عملگر `xor` زمانی `true` برمی‌گرداند که تنها یکی از عملوندها `true` باشد.

## 🔄 عملگرهای اختصاص و افزایش/کاهش (Assignment and Increment/Decrement Operators)

### عملگرهای اختصاص

| عملگر | مثال | معادل | توضیح |
|--------|------|--------|--------|
| `=` | `$a = $b` | - | اختصاص `$b` به `$a` |
| `+=` | `$a += $b` | `$a = $a + $b` | جمع و اختصاص |
| `-=` | `$a -= $b` | `$a = $a - $b` | تفریق و اختصاص |
| `*=` | `$a *= $b` | `$a = $a * $b` | ضرب و اختصاص |
| `/=` | `$a /= $b` | `$a = $a / $b` | تقسیم و اختصاص |
| `%=` | `$a %= $b` | `$a = $a % $b` | باقیمانده و اختصاص |
| `.=` | `$a .= $b` | `$a = $a . $b` | اتصال رشته و اختصاص |

### مثال‌های عملگرهای اختصاص

فایل: [`examples/04-assignment-operators.php`](./examples/04-assignment-operators.php)

```php
<?php
$a = 10;
$b = 5;

// عملگرهای جمع و تفریق
$a += $b;  // $a = $a + $b
echo "a += b: $a\n";  // 15

$a -= $b;  // $a = $a - $b
echo "a -= b: $a\n";  // 10

// عملگرهای ضرب و تقسیم
$a *= $b;  // $a = $a * $b
echo "a *= b: $a\n";  // 50

$a /= $b;  // $a = $a / $b
echo "a /= b: $a\n";  // 10

// عملگر باقیمانده
$a %= $b;  // $a = $a % $b
echo "a %= b: $a\n";  // 0

// عملگر اتصال رشته
$str1 = "Hello";
$str2 = " World";
$str1 .= $str2;  // $str1 = $str1 . $str2
echo "String concatenation: $str1\n";  // "Hello World"
?>
```

### عملگرهای افزایش و کاهش

| عملگر | نام | مثال | معادل | نتیجه |
|--------|-----|------|--------|--------|
| `++$a` | پیش‌افزایش | `++$a` | `$a = $a + 1` | اول افزایش می‌یابد، سپس استفاده می‌شود |
| `$a++` | پس‌افزایش | `$a++` | `$a = $a + 1` | اول استفاده می‌شود، سپس افزایش می‌یابد |
| `--$a` | پیش‌کاهش | `--$a` | `$a = $a - 1` | اول کاهش می‌یابد، سپس استفاده می‌شود |
| `$a--` | پس‌کاهش | `$a--` | `$a = $a - 1` | اول استفاده می‌شود، سپس کاهش می‌یابد |

### مثال‌های عملگرهای افزایش/کاهش

فایل: [`examples/05-increment-decrement.php`](./examples/05-increment-decrement.php)

```php
<?php
// پیش‌افزایش و پس‌افزایش
$a = 5;
echo "Initial a: $a\n";

$b = ++$a;  // اول $a را 1 افزایش می‌دهد، سپس $b = $a
echo "After ++a: a = $a, b = $b\n";  // a = 6, b = 6

$c = $a++;  // اول $c = $a، سپس $a را 1 افزایش می‌دهد
echo "After a++: a = $a, c = $c\n";  // a = 7, c = 6

// پیش‌کاهش و پس‌کاهش
$d = 10;
echo "\nInitial d: $d\n";

$e = --$d;  // اول $d را 1 کاهش می‌دهد، سپس $e = $d
echo "After --d: d = $d, e = $e\n";  // d = 9, e = 9

$f = $d--;  // اول $f = $d، سپس $d را 1 کاهش می‌دهد
echo "After d--: d = $d, f = $f\n";  // d = 8, f = 9

// استفاده در آرایه‌ها
$numbers = [1, 2, 3];
$index = 0;
echo "\nArray example:\n";
echo "numbers[" . $index++ . "]: " . $numbers[$index - 1] . "\n";  // index = 0, سپس 1
echo "numbers[" . $index++ . "]: " . $numbers[$index - 1] . "\n";  // index = 1, سپس 2
?>
```

**توضیح کد:**
- `++$a`: پیش‌افزایش — اول متغیر را افزایش می‌دهد، سپس مقدار آن را برمی‌گرداند.
- `$a++`: پس‌افزایش — اول مقدار متغیر را برمی‌گرداند، سپس آن را افزایش می‌دهد.
- همین قانون برای `--$a` و `$a--` نیز صدق می‌کند.

## 📊 اولویت عملگرها (Operator Precedence)

در PHP، عملگرها اولویت‌های متفاوتی دارند. این بدان معنی است که برخی عملگرها قبل از دیگران ارزیابی می‌شوند.

### جدول اولویت عملگرها (از بالا به پایین)

| اولویت | عملگرها |
|---------|----------|
| بالا | `++`, `--`, `!` |
| | `*`, `/`, `%` |
| | `+`, `-`, `.` |
| | `<`, `<=`, `>`, `>=` |
| | `==`, `!=`, `===`, `!==` |
| | `&&` |
| | `||` |
| پایین | `=`, `+=`, `-=`, و... |
| | `and`, `or`, `xor` |

### مثال‌های اولویت عملگرها

فایل: [`examples/06-operator-precedence.php`](./examples/06-operator-precedence.php)

```php
<?php
$a = 5;
$b = 10;
$c = 2;

// مثال ۱: ضرب قبل از جمع انجام می‌شود
$result1 = $a + $b * $c;
echo "5 + 10 * 2 = $result1\n";  // 25 (10 * 2 = 20, سپس 5 + 20 = 25)

// مثال ۲: استفاده از پرانتز برای تغییر اولویت
$result2 = ($a + $b) * $c;
echo "(5 + 10) * 2 = $result2\n";  // 30

// مثال ۳: مقایسه و منطقی
$x = 5;
$y = 10;
$z = 15;

$result3 = $x < $y && $y < $z;
echo "5 < 10 && 10 < 15: " . var_export($result3, true) . "\n";  // true

// مثال ۴: اولویت AND نسبت به OR
$result4 = true || false && false;
echo "true || false && false: " . var_export($result4, true) . "\n";  // true (&& اول ارزیابی می‌شود)

// مثال ۵: اولویت افزایش نسبت به جمع
$num = 5;
$sum = $num++ + $num;
echo "5++ + 5++: $sum\n";  // 11 (اول 5 + 5 = 10، سپس num = 6)

// برای نتیجه 5 + 6 = 11، باید از پرانتز استفاده کنید
$num2 = 5;
$sum2 = $num2++ + ++$num2;
echo "5++ + ++5: $sum2\n";  // 12 (اول num2=5، سپس num2=6، سپس ++num2=7، 5+7=12)
?>
```

**توضیح کد:**
- عملگرهای ریاضی (`*`, `/`, `%`) اولویت بالاتری نسبت به (`+`, `-`) دارند.
- عملگرهای مقایسه‌ای اولویت بالاتری نسبت به عملگرهای منطقی دارند.
- عملگر `&&` اولویت بالاتری نسبت به `||` دارد.
- **همیشه از پرانتز استفاده کنید** تا کد خود را خوانا‌تر کنید و از ابهام جلوگیری کنید.

## ⚠️ نکات رایج و اشتباهات

### اشتباهات رایج

#### ۱. اشتباه در اولویت عملگرها
```php
// اشتباه: فرض کردن اولویت اشتباه
$result = 5 + 10 * 2;  // 25 (درست: 10 * 2 = 20, سپس 5 + 20 = 25)

// درست: استفاده از پرانتز برای وضوح
$result = (5 + 10) * 2;  // 30
```

#### ۲. اشتباه در استفاده از `==` و `===`
```php
// اشتباه: استفاده از == برای مقایسه نوع
if ("123" == 123) {
    echo "Equal";  // این اجرا می‌شود، اما انواع متفاوت هستند
}

// درست: استفاده از === برای مقایسه نوع
if ("123" === 123) {
    echo "Equal";  // این اجرا نمی‌شود
} else {
    echo "Not equal or different types";
}
```

#### ۳. اشتباه در عملگرهای افزایش/کاهش
```php
// اشتباه: فرض کردن ترتیب اشتباه
$a = 5;
$b = $a++;
echo "a = $a, b = $b";  // a = 6, b = 5 (نه 6)

// درست: درک ترتیب اجرا
$a = 5;
$b = ++$a;
echo "a = $a, b = $b";  // a = 6, b = 6
```

#### ۴. اشتباه در اتصال رشته‌ها
```php
// اشتباه: فراموش کردن عملگر .
$str = "Hello" " World";  // خطا

// درست: استفاده از عملگر .
$str = "Hello" . " World";  // درست
```

### بهترین شیوه‌ها

1. **همیشه از پرانتز برای وضوح استفاده کنید**:
   ```php
   // بد
   $result = $a + $b * $c;
   
   // خوب
   $result = $a + ($b * $c);
   ```

2. **از `===` و `!==` برای مقایسه دقیق استفاده کنید**:
   ```php
   // بد
   if ($userId == "123") { ... }
   
   // خوب
   if ($userId === 123) { ... }
   ```

3. **از عملگرهای اختصاص مختصر استفاده کنید**:
   ```php
   // بد
   $a = $a + $b;
   
   // خوب
   $a += $b;
   ```

4. **از عملگر فضاپیمایی (`<=>`) برای مقایسه‌های ساده استفاده کنید**:
   ```php
   // بد
   if ($a < $b) {
       $result = -1;
   } elseif ($a == $b) {
       $result = 0;
   } else {
       $result = 1;
   }
   
   // خوب
   $result = $a <=> $b;
   ```

### تمرین ۲: بررسی شرایط

### تمرین ۳: عملگرهای اختصاص و افزایش

**صورت تمرین:**
یک اسکریپت PHP بنویسید که:
1. متغیر `$counter` را با مقدار 0 تعریف کند.
2. با استفاده از عملگرهای افزایش، مقدار آن را به 10 برساند (در 5 مرحله).

## 📢 نکته پایانی

عملگرها **ابزارهای اصلی** برای انجام عملیات روی داده‌ها هستند. درک صحیح عملگرها و اولویت آن‌ها به شما کمک می‌کند تا کدهای کارآمدتر و خوانا‌تری بنویسید.

**نکته مهم:** همیشه اولویت عملگرها را در نظر بگیرید و در صورت شک، از پرانتز استفاده کنید تا کد خود را خوانا‌تر کنید.

در جلسه بعدی، با **شرط‌ها (if/else/switch)** آشنا خواهیم شد! 🚀
