# جلسه ۲۲: تاریخ و زمان در PHP (۷۵ دقیقه)

**محیط فرض:** PHP 8.2+

## پیش‌نیازها
جلسات ۰۳ و ۰۸.

## اهداف قابل‌اندازه‌گیری
با `DateTimeImmutable` کار می‌کنید؛ timezone تنظیم می‌کنید؛ قالب‌بندی و مقایسه انجام می‌دهید؛ و می‌دانید چرا `time()` خام به‌تنهایی برای منطق پیچیده کافی نیست.

## چرا مهم است؟
نشست، انقضای توکن، گزارش و زمان ایجاد رکورد همه به زمان وابسته‌اند. اشتباه timezone باگ‌های مرزی می‌سازد.

## مفهوم عمیق
ترجیح آموزشی: `DateTimeImmutable` (بدون mutate پنهان).

```php
$now = new DateTimeImmutable('now', new DateTimeZone('Asia/Tehran'));
echo $now->format('Y-m-d H:i:s');
```

برای ذخیرهٔ بین‌المللی اغلب UTC نگه می‌دارید و در نمایش تبدیل می‌کنید.

## اشتباه‌های رایج
1. قاطی کردن timezone سرور و کاربر.
2. mutate کردن `DateTime` و تعجب از تغییر متغیر قبلی.
3. مقایسهٔ رشته‌ای تاریخ به‌جای شیء.

## مثال گام‌به‌گام

```bash
php session-22-datetime/examples/01-datetime.php
```

Immutable + timezone صریح + فرمت ISO8601 برای تبادل.
