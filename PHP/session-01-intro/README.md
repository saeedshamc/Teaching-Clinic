## 📚 معرفی PHP

### PHP چیست؟

**PHP** (مخفف **Hypertext Preprocessor**) یک زبان برنامه‌نویسی **مفسری** و **سرور-ساید** (Server-Side) است که به طور گسترده برای توسعه وب استفاده می‌شود. کدهای PHP روی سرور اجرا می‌شوند و خروجی آن‌ها (معمولاً HTML) به مرورگر کاربر ارسال می‌شود.

### ویژگی‌های اصلی PHP

1. **سرور-ساید (Server-Side)**: کدها روی سرور اجرا می‌شوند، نه روی مرورگر کاربر.
2. **مفسری (Interpreted)**: نیازی به کامپایل ندارد؛ کدها به صورت مستقیم اجرا می‌شوند.
3. **متن‌باز (Open Source)**: رایگان و با جامعه کاربری بزرگ.
4. **ساده و انعطاف‌پذیر**: سینتکس ساده و یادگیری آسان.
5. **پشتیبانی گسترده**: توسط اکثر سرورهای وب پشتیبانی می‌شود.

### کاربردهای PHP

- ساخت وب‌سایت‌های دینامیک (Dynamic Websites)
- سیستم‌های مدیریت محتوا (CMS) مانند وردپرس، جوملا
- فریم‌ورک‌های وب مانند لاراول، سیمفونی
- APIها و سرویس‌های وب
- اسکریپت‌های خط فرمان (Command Line Scripts)

## 🛠️ راه‌اندازی محیط توسعه

### روش ۱: نصب PHP به صورت مستقل

#### روی ویندوز

1. **دانلود PHP**:
   به سایت [php.net/downloads](https://www.php.net/downloads.php) بروید و نسخه **Thread Safe** برای ویندوز دانلود کنید.

2. **نصب PHP**:
   - فایل ZIP را در یک پوشه (مثلاً `C:\php`) استخراج کنید.
   - پوشه `php` را به متغیر محیطی `PATH` اضافه کنید.

3. **تست نصب**:
   ```bash
   php -v
   ```
   اگر نسخه PHP نمایش داده شد، نصب موفقیت‌آمیز بوده است.

#### روی لینوکس (اوبونتو/دبیان)

```bash
# به‌روزرسانی لیست پکیج‌ها
sudo apt update

# نصب PHP
sudo apt install php

# نصب ماژول‌های اضافی (اختیاری)
sudo apt install php-cli php-fpm php-json php-mysql php-curl php-gd php-mbstring

# تست نصب
php -v
```

#### روی مک

```bash
# نصب با Homebrew
brew install php

# تست نصب
php -v
```

### روش ۲: استفاده از XAMPP/Laragon (پیشنهادی برای مبتدیان)

#### XAMPP

1. **دانلود**: از سایت [apachefriends.org](https://www.apachefriends.org/) دانلود کنید.
2. **نصب**: برنامه را نصب کنید (تمام گزینه‌ها را انتخاب کنید).
3. **راه‌اندازی**:
   - XAMPP Control Panel را باز کنید.
   - روی دکمه **Start** برای Apache کلیک کنید.
   - فایل‌های PHP خود را در پوشه `htdocs` قرار دهید.
   - در مرورگر به آدرس `http://localhost/name-of-your-file.php` بروید.

#### Laragon

1. **دانلود**: از سایت [laragon.org](https://laragon.org/) دانلود کنید.
2. **نصب**: برنامه را نصب کنید.
3. **راه‌اندازی**:
   - Laragon را باز کنید.
   - روی دکمه **Start All** کلیک کنید.
   - پوشه پروژه خود را در پوشه `www` قرار دهید.
   - در مرورگر به آدرس `http://your-project-name.test` بروید.

## 🚀 اولین اسکریپت PHP

### ساختار پایه یک فایل PHP

یک فایل PHP می‌تواند شامل ترکیبی از کدهای PHP و HTML باشد. کدهای PHP داخل **تگ‌های PHP** قرار می‌گیرند:

```php
<?php
    // کدهای PHP اینجا نوشته می‌شوند
    echo "Hello, World!";
?>
```

### مثال ۱: Hello World

فایل: [`examples/01-hello-world.php`](./examples/01-hello-world.php)

```php
<?php
// این یک کامنت یک‌خطی است
/*
   این یک کامنت
   چندخطی است
*/

// دستور echo برای چاپ خروجی استفاده می‌شود
echo "Hello, World!\n";

// دستور print نیز مشابه echo عمل می‌کند
print "Welcome to PHP!\n";

// می‌توانیم چندین خط را با هم چاپ کنیم
echo "Line 1\nLine 2\nLine 3\n";
?>
```

**توضیح کد:**
- `<?php` و `?>`: تگ‌های باز و بسته PHP
- `//` و `/* */`: کامنت‌ها در PHP
- `echo` و `print`: دستورات چاپ خروجی
- `\n`: کاراکتر خط جدید (Newline)

**نحوه اجرا:**
```bash
php examples/01-hello-world.php
```

**خروجی مورد انتظار:**
```
Hello, World!
Welcome to PHP!
Line 1
Line 2
Line 3
```

### مثال ۲: اطلاعات پایه PHP

فایل: [`examples/02-php-info.php`](./examples/02-php-info.php)

```php
<?php
// نمایش نسخه PHP
phpversion();

// نمایش اطلاعات کامل PHP
phpinfo();
?>
```

**توضیح کد:**
- `phpversion()`: نسخه PHP را برمی‌گرداند
- `phpinfo()`: اطلاعات کامل درباره تنظیمات PHP را نمایش می‌دهد

**نکته:**
- `phpinfo()` در محیط وب بسیار مفید است، اما در محیط خط فرمان خروجی زیادی تولید می‌کند.

---

### مثال ۳: استفاده از PHP در HTML

فایل: [`examples/03-php-in-html.php`](./examples/03-php-in-html.php)

```php
<!DOCTYPE html>
<html>
<head>
    <title>PHP in HTML</title>
</head>
<body>
    <h1>Welcome to PHP</h1>
    
    <?php
        // کد PHP داخل HTML
        echo "<p>This is generated by PHP!</p>";
        echo "<p>Current date: " . date('Y-m-d') . "</p>";
    ?>
    
    <p>This is static HTML.</p>
</body>
</html>
```

**توضیح کد:**
- می‌توانید کدهای PHP را داخل فایل‌های HTML قرار دهید.
- `date('Y-m-d')`: تاریخ فعلی را به فرمت سال-ماه-روز برمی‌گرداند
- `.`: عملگر اتصال رشته‌ها (Concatenation)

**نحوه اجرا در مرورگر:**
1. فایل را در پوشه `htdocs` (XAMPP) یا `www` (Laragon) قرار دهید.
2. در مرورگر به آدرس `http://localhost/php-course/session-01-intro/examples/03-php-in-html.php` بروید.

## ⚠️ نکات رایج و اشتباهات

### اشتباهات رایج

1. **فراموش کردن تگ‌های PHP**:
   ```php
   <!-- اشتباه -->
   echo "Hello";
   
   <!-- درست -->
   <?php echo "Hello"; ?>
   ```

2. **استفاده از `;` در پایان دستورات**:
   در PHP، تمام دستورات باید با `;` ختم شوند.
   ```php
   echo "Hello"  // اشتباه
   echo "Hello"; // درست
   ```

3. **حساسیت به حروف بزرگ/کوچک**:
   PHP به حروف بزرگ/کوچک حساس است (Case-Sensitive).
   ```php
   $name = "Ali";
   echo $Name; // خطا: متغیر $Name تعریف نشده است
   ```

### بهترین شیوه‌ها

1. **همیشه از `<?php` استفاده کنید**:
   از `<?` یا `%>` استفاده نکنید؛ این تگ‌ها ممکن است در برخی سرورها غیرفعال باشند.

2. **کدهای خود را کامنت‌گذاری کنید**:
   کامنت‌ها به شما و دیگران کمک می‌کنند تا کد را در آینده درک کنند.

3. **از ویرایشگر مناسب استفاده کنید**:
   ویرایشگرهایی مانند VS Code با افزونه PHP Intelephense به شما در نوشتن کدهای تمیز کمک می‌کنند.

## 📝 تمرین‌های عملی

### تمرین ۱: ایجاد یک صفحه خوش‌آمدگویی

**صورت تمرین:**
یک فایل PHP ایجاد کنید که پیام خوش‌آمدگویی زیر را نمایش دهد:
```
Welcome to PHP Course!
Today is: [تاریخ فعلی]
```

**راهنمایی:**
- از تابع `date()` برای دریافت تاریخ فعلی استفاده کنید.
- فرمت تاریخ را می‌توانید با پارامترهای مختلف تنظیم کنید (مثلاً `'Y-m-d'` برای سال-ماه-روز).

**فایل تمرین:** [`exercises/exercise-01.php`](./exercises/exercise-01.php)

<details>
<summary>🔍 نمایش راه‌حل</summary>

```php
<?php
// تمرین ۱: صفحه خوش‌آمدگویی
echo "Welcome to PHP Course!\n";
echo "Today is: " . date('Y-m-d') . "\n";
?>
```
</details>

---

### تمرین ۲: نمایش اطلاعات سرور

**صورت تمرین:**
یک فایل PHP ایجاد کنید که اطلاعات زیر را نمایش دهد:
- نسخه PHP
- نام سرور (اگر در محیط وب هستید)
- آدرس IP سرور (اگر در محیط وب هستید)

**راهنمایی:**
- از تابع `phpversion()` برای دریافت نسخه PHP استفاده کنید.
- از متغیرهای سراسری `$_SERVER` برای دریافت اطلاعات سرور استفاده کنید.

**فایل تمرین:** [`exercises/exercise-02.php`](./exercises/exercise-02.php)

<details>
<summary>🔍 نمایش راه‌حل</summary>

```php
<?php
// تمرین ۲: نمایش اطلاعات سرور
echo "PHP Version: " . phpversion() . "\n";

// در محیط وب، این اطلاعات در دسترس هستند
if (isset($_SERVER['SERVER_NAME'])) {
    echo "Server Name: " . $_SERVER['SERVER_NAME'] . "\n";
}

if (isset($_SERVER['SERVER_ADDR'])) {
    echo "Server IP: " . $_SERVER['SERVER_ADDR'] . "\n";
}
?>
```
</details>
