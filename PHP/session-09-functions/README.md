# جلسه ۰۹: توابع (Functions) — ۱۲۰ دقیقه

## پیش‌نیازها
متغیر، نوع داده، آرایه و رشته.

## اهداف قابل‌اندازه‌گیری
می‌توانید تابع type-safe با پارامتر پیش‌فرض و مقدار بازگشتی بنویسید، scope را توضیح دهید، callback و closure به‌کار ببرید و منطق را به واحدهای قابل‌آزمون تقسیم کنید.

## چرا مهم است؟
تابع نامی برای یک مسئولیت می‌سازد، تکرار را کم و آزمون و تغییر کد را ساده می‌کند.

## مفهوم عمیق
تابع (Function) قراردادی میان ورودی و خروجی است. با `declare(strict_types=1)`، type declarationها رفتار قابل‌پیش‌بینی‌تری دارند. متغیرهای بیرون به‌طور خودکار وارد scope تابع نمی‌شوند؛ closure با `use` مقدار لازم را صریح می‌گیرد. پارامتر مرجعی فقط وقتی مناسب است که تغییر ورودی بخشی روشن از قرارداد باشد.

## اشتباه‌های رایج
1. تابعی که هم محاسبه و هم چاپ می‌کند؛ مقدار را برگردانید و خروجی را جدا کنید.
2. استفاده از `global` و ایجاد وابستگی پنهان.
3. ننوشتن نوع بازگشتی یا بازگرداندن انواع ناسازگار.
4. تابع بسیار بلند با چند مسئولیت.

## مثال گام‌به‌گام و قابل اجرا
[01-functions.php](./examples/01-functions.php) subtotal، تخفیف و total را با توابع خالص می‌سازد:

```bash
php examples/01-functions.php
```

## الگوی بهتر
تابع کوچک، نام‌دار و خالص (Pure function) بنویسید: برای ورودی یکسان خروجی یکسان بدهد و state بیرونی را تغییر ندهد.

## تمرین‌ها
### آسان
تابع `isEven(int $number): bool` را بنویسید.

### چالشی
تابع `groupBy(array $items, callable $keySelector): array` بسازید و کاربران را بر اساس شهر گروه‌بندی کنید.

## راهنمای حل
در تمرین آسان از باقی‌ماندهٔ تقسیم استفاده کنید. در تمرین چالشی، برای هر item کلید callback را بگیرید و با `$groups[$key][] = $item` اضافه کنید.

## خودآزمایی
1. parameter و argument چه تفاوتی دارند؟
2. `return` چه اثری دارد؟
3. scope محلی چیست؟
4. closure چگونه دادهٔ بیرونی را می‌گیرد؟
5. تابع خالص چه مزیتی دارد؟
6. `callable` چه نوع مقادیری را می‌پذیرد؟

## جمع‌بندی و پل جلسهٔ بعد
منطق را به قراردادهای کوچک تقسیم کردید. جلسهٔ بعد این توابع را روی ورودی واقعی فرم و مرز نامطمئن HTTP به‌کار می‌بریم.
