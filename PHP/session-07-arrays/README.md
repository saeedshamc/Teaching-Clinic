# جلسه ۰۷: آرایه‌ها (Arrays) — ۱۲۰ دقیقه

## پیش‌نیازها
متغیرها، شرط‌ها، حلقه‌ها و اجرای فایل با `php filename.php`.

## اهداف قابل‌اندازه‌گیری
در پایان می‌توانید آرایهٔ اندیسی، انجمنی و چندبعدی بسازید؛ با `foreach` پیمایش کنید؛ داده را با `array_map`، `array_filter` و `usort` تبدیل، پالایش و مرتب کنید؛ و بدون خطای کلید ناموجود مقدار بخوانید.

## چرا مهم است؟
نتیجهٔ پایگاه‌داده، ورودی فرم، تنظیمات و پاسخ API معمولاً مجموعه‌ای از داده‌هاست. تسلط بر آرایه، پایهٔ پردازش این داده‌ها در PHP است.

## مفهوم عمیق
آرایه (Array) در PHP یک **ordered map** است: هر کلید `int|string` به یک مقدار اشاره می‌کند و ترتیب درج حفظ می‌شود. آرایه می‌تواند اندیسی (`['PHP']`)، انجمنی (`['name' => 'Sara']`) یا چندبعدی باشد.

خواندن امن با عملگر هم‌گذاری تهی (Null coalescing) انجام می‌شود: `$user['city'] ?? 'نامشخص'`. توابعی مانند `array_map` آرایهٔ تازه می‌سازند؛ ولی `sort` همان آرایه را تغییر می‌دهد و کلیدها را بازشماری می‌کند.

## اشتباه‌های رایج
1. خواندن کلید تعریف‌نشده؛ از `??` یا `array_key_exists` استفاده کنید.
2. تصور اینکه `sort()` آرایه برمی‌گرداند؛ خروجی آن `bool` است.
3. استفاده از `in_array` بدون حالت strict؛ پارامتر سوم را `true` بگذارید.
4. باقی‌گذاشتن متغیر مرجعی پس از `foreach (&$value)`؛ آن را `unset` کنید.

## مثال گام‌به‌گام و قابل اجرا
[01-arrays.php](./examples/01-arrays.php) دادهٔ محصولات را تعریف، موجودها را پالایش، قیمت نهایی را محاسبه، مرتب و گزارش می‌کند:

```bash
php examples/01-arrays.php
```

## الگوی بهتر
عملیات را به زنجیرهٔ **ورودی → پالایش → تبدیل → مرتب‌سازی → خروجی** تقسیم کنید. دادهٔ ورودی را بی‌دلیل تغییر ندهید و برای رکوردها کلیدهای نام‌دار به‌کار ببرید.

## تمرین‌ها
### آسان
آرایه‌ای از پنج نمره بسازید و کمینه، بیشینه و میانگین را چاپ کنید.

### چالشی
فهرستی از سفارش‌ها با `customer`, `total`, `status` بسازید؛ سفارش‌های `paid` را نگه دارید، مجموع فروش و سه سفارش گران‌تر را گزارش کنید.

## راهنمای حل
برای تمرین آسان از `min`، `max`، `array_sum` و `count` استفاده کنید. برای تمرین چالشی از `array_filter`، سپس `array_sum(array_column(...))` و `usort` استفاده کنید؛ آرایهٔ خالی را پیش از تقسیم بررسی کنید.

## خودآزمایی
1. تفاوت آرایهٔ اندیسی و انجمنی چیست؟
2. `isset` برای مقدار `null` چه نتیجه‌ای دارد؟
3. چه زمانی `array_key_exists` مناسب‌تر است؟
4. تفاوت `array_map` و `array_filter` چیست؟
5. چرا حالت strict در `in_array` مهم است؟
6. `usort` ورودی را تغییر می‌دهد؟

## جمع‌بندی و پل جلسهٔ بعد
اکنون می‌توانید مجموعه‌های ساخت‌یافته را قابل‌پیش‌بینی پردازش کنید. جلسهٔ بعد همین مهارت را برای متن‌های UTF-8 و رشته‌ها به‌کار می‌گیرد.
