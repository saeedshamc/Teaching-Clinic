# جلسه ۲۱: include/require و سازمان فایل (۷۵ دقیقه)

**محیط فرض:** PHP 8.2+

## پیش‌نیازها
جلسات ۰۲ و ۰۹.

## اهداف قابل‌اندازه‌گیری
تفاوت `include`/`require` و نسخهٔ `_once` را می‌دانید؛ مسیر را با `__DIR__` می‌سازید؛ و یک `config.php` + `helpers.php` جدا می‌کنید.

## چرا مهم است؟
بدون سازمان فایل، کپی‌پیست و باگ مسیر شروع می‌شود.

## مفهوم عمیق
- `require`: فایل اجباری؛ نبودن = Fatal
- `include`: هشدار و ادامه (برای اختیاری)
- `_once`: جلوگیری از تعریف دوباره

```php
require __DIR__ . '/../lib/helpers.php';
```

## اشتباه‌های رایج
1. مسیر نسبی وابسته به cwd.
2. require حلقه‌ای متقابل.
3. تعریف تابع در فایلی که چندبار include می‌شود بدون `_once`.

## مثال گام‌به‌گام
```bash
php session-21-include-require/examples/app.php
```

## الگوی بهتر
بعداً Composer autoload؛ تا آن موقع `_once` + `__DIR__`.

## تمرین‌ها
### آسان
تابع `e()` را در helpers بگذارید و در app استفاده کنید.

### چالشی
config آرایه تنظیمات را برگرداند و app آن را چاپ کند.

## راهنمای حل
`return [...]` از config و `$config = require ...`.

## خودآزمایی
1. تفاوت require و include؟
2. `_once` چرا؟
3. `__DIR__` چیست؟
4. cwd چه مشکلی می‌سازد؟
5. چه وقت به Composer مهاجرت کنیم؟
6. حلقهٔ require یعنی چه؟
