# جلسه ۱۴: کار با فایل‌ها (۹۰ دقیقه)

**محیط فرض:** PHP 8.2+ · مجوز نوشتن در پوشهٔ examples

## پیش‌نیازها
جلسات ۱۱–۱۳.

## اهداف قابل‌اندازه‌گیری
می‌توانید فایل را بخوانید/بنویسید؛ بین `file_get_contents` و استریم تفاوت بگذارید؛ مسیر را امن بسازید؛ و خطای IO را مدیریت کنید.

## چرا مهم است؟
لاگ، آپلود، کش فایل و import CSV همه به IO وابسته‌اند. مسیر ناامن = Path Traversal.

## مفهوم عمیق
```php
$path = __DIR__ . '/data.txt';
file_put_contents($path, "سلام\n", LOCK_EX);
$text = file_get_contents($path);
```
هرگز ورودی کاربر را مستقیم به مسیر بچسبانید بدون سفید‌لیست/basename.

## اشتباه‌های رایج
1. اعتماد به نام فایل کاربر بدون `basename`.
2. ننوشتن بررسی نتیجهٔ `file_put_contents === false`.
3. باز کردن فایل در حلقه بدون بستن.

## مثال گام‌به‌گام
```bash
php session-14-files/examples/01-files.php
```

## الگوی بهتر
مسیر پایه را ثابت کنید (`__DIR__.'/storage'`) و فقط نام امن نسبی را اجازه دهید.

## تمرین‌ها
### آسان
آرایه‌ای از خطوط را در فایل بنویسید و دوباره بخوانید.

### چالشی
تابعی که فقط فایل‌های داخل `storage/` را می‌خواند و اگر `../` بود رد می‌کند.

## راهنمای حل
`realpath` را با پیشوند storage مقایسه کنید.

## خودآزمایی
1. LOCK_EX چه می‌کند؟
2. Path traversal یعنی چه؟
3. چرا `__DIR__` مفید است؟
4. تفاوت file_get_contents و fread؟
5. چه وقت استریم بهتر است؟
6. چگونه نام فایل کاربر را امن کنیم؟

## جمع‌بندی و پل جلسهٔ بعد
فایل‌ها را امن‌تر می‌نویسید. جلسهٔ بعد session و cookie به‌صورت امن.
