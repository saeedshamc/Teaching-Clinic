# 🎓 دوره آموزشی کامل PHP — از صفر تا حرفه‌ای

> یک دوره **رایگان** و **کامل** برای یادگیری زبان PHP از مبانی تا سطح پیشرفته، به زبان فارسی

---

## 📚 معرفی دوره

این دوره برای **مبتدیان مطلق** تا **برنامه‌نویسانی** که می‌خواهند مهارت‌های خود را در PHP تقویت کنند، طراحی شده است. در این دوره، شما با **۲۰ جلسه عملی** از صفر شروع می‌کنید و تا ساخت یک پروژه واقعی با PHP پیش می‌روید.

### 🎯 مخاطب هدف
- افراد بدون هیچ پیش‌زمینه‌ای در برنامه‌نویسی
- توسعه‌دهندگان فرانت‌اند که می‌خواهند بک‌اند یاد بگیرند
- دانشجویان و جویندگان کار در حوزه وب
- هر کسی که می‌خواهد به سرعت و به صورت عملی PHP یاد بگیرد

## 🚀 نحوه اجرا و تست کدها

### روش ۱: استفاده از سرور داخلی PHP
```bash
# رفتن به پوشه جلسه مورد نظر
cd php-course/session-01-intro/examples

# اجرا کردن فایل PHP
php 01-hello-world.php
```

### روش ۲: استفاده از XAMPP/Laragon
1. پوشه `php-course` را در پوشه `htdocs` (برای XAMPP) یا `www` (برای Laragon) کپی کنید.
2. سرور آپاچی را راه‌اندازی کنید.
3. در مرورگر خود به آدرس زیر بروید:
   ```
   http://localhost/php-course/session-01-intro/examples/01-hello-world.php
   ```
