# جلسه ۲۰: مینی‌اپ تمرینی — دفترچه یادداشت CLI (۱۲۰ دقیقه)

**محیط فرض:** PHP 8.2+ · بدون نیاز به پروژهٔ بیرونی ریپو

## پیش‌نیازها
جلسات ۰۷، ۱۴، ۱۶–۱۹.

## اهداف قابل‌اندازه‌گیری
می‌توانید یک مینی‌اپ آموزشی داخل همین پوشه بسازید/اجرا کنید که یادداشت را در SQLite ذخیره کند؛ لیست/افزودن داشته باشد؛ و ورودی را validate کند.

## چرا مهم است؟
ترکیب مهارت‌ها بدون دست زدن به پروژه‌های ازقبل‌موجود ریپو.

## مفهوم عمیق
اپ از سه بخش است: ورودی CLI، لایهٔ ذخیره (PDO SQLite فایل محلی)، خروجی متنی. همین الگو بعداً به وب منتقل می‌شود.

## اشتباه‌های رایج
1. قاطی کردن UI و SQL در یک تابع غول.
2. مسیر فایل DB نسبی مبهم — از `__DIR__` استفاده کنید.
3. قبول عنوان خالی.

## مثال گام‌به‌گام
```bash
cd session-20-final-project/examples
php notes.php add "خرید نان"
php notes.php list
```

## الگوی بهتر
دستورات را با `match` روی argv جدا کنید؛ DB را یک‌بار migrate کنید.

## تمرین‌ها
### آسان
دستور `count` برای تعداد یادداشت‌ها.

### چالشی
دستور `delete <id>` با prepared statement.

## راهنمای حل
`DELETE FROM notes WHERE id = ?` و گزارش rowCount.

## خودآزمایی
1. چرا SQLite برای مینی‌اپ آموزشی خوب است؟
2. argv چیست؟
3. migrate یعنی چه؟
4. کجا validate کنیم؟
5. چرا پروژهٔ بیرونی ریپو را دست نمی‌زنیم؟
6. چطور به نسخهٔ وب ارتقا می‌دهید؟

## جمع‌بندی و پل
مینی‌اپ جمع‌بندی شد. جلسات تکمیلی ۲۱–۲۳: include/require، تاریخ/زمان، احراز هویت با password_hash.
