# تمرین‌های جلسه ۴۳ — Locks و Atomic

## آسان
1. `ReentrantLock` با `lock()`/`unlock()` برای counter بسازید.
2. `AtomicInteger` برای increment بدون lock تست کنید.

## متوسط
3. `tryLock` را برای non-blocking increment استفاده کنید.
4. `AtomicBoolean` با `compareAndSet` برای flag استفاده کنید.

## سخت
5. `AtomicReference` برای update امن object استفاده کنید.
6. `AtomicIntegerArray` برای آرایهٔ اتمیک بسازید.
