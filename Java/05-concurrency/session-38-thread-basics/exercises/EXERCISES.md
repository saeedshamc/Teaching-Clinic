# تمرین‌های جلسه ۳۸ — Thread Basics

## آسان
1. کلاس `MyThread` با `extends Thread` بسازید و `run()` را override کنید.
2. دو thread بسازید و `start()` کنید — خروجی را ببینید.

## متوسط
3. `Thread.sleep` را در `run()` استفاده کنید.
4. `join()` را برای انتظار thread استفاده کنید.

## سخت
5. `Thread.currentThread()` را برای چاپ نام thread فعلی استفاده کنید.
6. thread را `interrupt()` کنید و `InterruptedException` را مدیریت کنید.
