# تمرین‌های جلسه ۳۹ — Runnable و Lambda

## آسان
1. `Runnable` با lambda بسازید و در `Thread` اجرا کنید.
2. `Task implements Runnable` بسازید و `run()` را override کنید.

## متوسط
3. method reference برای متد static و instance تست کنید.
4. `Thread` با نام دلخواه بسازید.

## سخت
5. lambda که `Thread.sleep` دارد بنویسید و چند thread بسازید.
6. `Runnable` را به متد `execute(Runnable)` پاس دهید — callback pattern.
