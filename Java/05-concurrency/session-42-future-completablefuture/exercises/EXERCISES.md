# تمرین‌های جلسه ۴۲ — Future و CompletableFuture

## آسان
1. `CompletableFuture.supplyAsync` برای محاسبهٔ ساده استفاده کنید.
2. `thenApply` برای transform نتیجه استفاده کنید.

## متوسط
3. `thenCompose` برای chain کردن دو async operation استفاده کنید.
4. `thenCombine` برای ترکیب دو future استفاده کنید.

## سخت
5. `exceptionally` برای مدیریت خطا در chain استفاده کنید.
6. `allOf` و `anyOf` را برای چند future تست کنید.
