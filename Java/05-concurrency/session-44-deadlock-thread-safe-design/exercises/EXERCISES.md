# تمرین‌های جلسه ۴۴ — Deadlock و Thread-Safe Design

## آسان
1. deadlock را با دو lock تو در تو شبیه‌سازی کنید.
2. lock ordering را برای جلوگیری از deadlock پیاده کنید.

## متوسط
3. immutable class `Color` با `final` fields بسازید.
4. `ConcurrentHashMap` را برای thread-safe map استفاده کنید.

## سخت
5. `CopyOnWriteArrayList` را برای read-heavy list تست کنید.
6. `tryLock` با timeout برای جلوگیری از deadlock استفاده کنید.
