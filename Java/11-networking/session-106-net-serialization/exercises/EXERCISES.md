# تمرین‌های جلسه ۱۰۶ — Network Serialization

## آسان
1. `Message` class با `Serializable` بسازید.
2. `ObjectOutputStream.writeObject()` برای send object استفاده کنید.

## متوسط
3. `ObjectInputStream.readObject()` برای receive object استفاده کنید.
4. `transient` برای sensitive fields استفاده کنید.

## سخت
5. `serialVersionUID` برای version compatibility استفاده کنید.
6. `NotSerializableException` را handle کنید.
