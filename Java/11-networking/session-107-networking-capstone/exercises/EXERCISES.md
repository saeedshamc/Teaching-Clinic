# تمرین‌های جلسه ۱۰۷ — Networking Capstone

## آسان
1. `MessageProtocol` با `sendString`/`receiveString` بسازید.
2. `MessagingServer` با `ServerSocket` و `ClientHandler` بسازید.

## متوسط
3. `ChatMessage` با `Serializable` برای message objects بسازید.
4. `broadcast` برای send به همهٔ clients استفاده کنید.

## سخت
5. `username` را به‌عنوان first message برای identification استفاده کنید.
6. `length-prefixed` protocol برای reliable messaging پیاده کنید.
