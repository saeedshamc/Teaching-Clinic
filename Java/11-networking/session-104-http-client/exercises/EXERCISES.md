# تمرین‌های جلسه ۱۰۴ — HTTP Client

## آسان
1. `HttpClient` با `connectTimeout` بسازید.
2. `HttpRequest` برای GET request بسازید.

## متوسط
3. `send` برای synchronous request استفاده کنید.
4. `BodyHandlers.ofString()` برای response parsing استفاده کنید.

## سخت
5. `sendAsync` برای async request استفاده کنید.
6. `POST` با `BodyPublishers.ofString` برای JSON body استفاده کنید.
