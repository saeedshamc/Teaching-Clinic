# پروژهٔ جلسه ۷۶ — Hello Android

یک برنامهٔ Android ساده بسازید که:
- `MainActivity` با `setContentView`
- `activity_main.xml` با `LinearLayout`
- `TextView` برای title
- `Button` برای click
- `EditText` برای input
- `TextView` برای output
- در `main` اجرا کنید (روی emulator)

نمونه:
```
[Hello Android!]
[Enter name: _____]
[Button: Greet]
→ "Hello, Ali!"
```

## صورت پروژه
پاسخ در `solution/` — MainActivity.java + activity_main.xml + AndroidManifest.xml.
