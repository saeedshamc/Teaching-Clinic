# تمرین‌های جلسه ۷۶ — Android Setup

## آسان
1. Android Studio را نصب کنید و اولین project را بسازید.
2. `MainActivity` با `setContentView` بنویسید.

## متوسط
3. `activity_main.xml` با `LinearLayout`, `TextView`, `Button` بسازید.
4. `findViewById` و `setOnClickListener` را استفاده کنید.

## سخت
5. `AndroidManifest.xml` را برای `MainActivity` تنظیم کنید.
6. Emulator را برای testing راه‌اندازی کنید.
