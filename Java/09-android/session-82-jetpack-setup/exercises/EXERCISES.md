# تمرین‌های جلسه ۸۲ — Jetpack Setup

## آسان
1. `ViewModel` با `MutableLiveData` بسازید.
2. `LiveData` را در Activity observe کنید.

## متوسط
3. `ViewModelProvider` برای get ViewModel استفاده کنید.
4. `setValue` برای update LiveData استفاده کنید.

## سخت
5. `postValue` برای background thread update استفاده کنید.
6. `Repository` pattern برای data layer اضافه کنید.
