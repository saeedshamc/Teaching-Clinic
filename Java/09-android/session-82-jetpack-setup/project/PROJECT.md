# پروژهٔ جلسه ۸۲ — MVVM Counter App

یک counter app با MVVM بسازید که:
- `ViewModel` با `LiveData` برای counter
- `Activity` با `observe` برای UI update
- `Button` برای increment/decrement
- `TextView` برای display counter
- `Repository` pattern برای data layer

نمونه:
```
[Counter: 5]
[Button: +1] [Button: -1] [Button: Reset]
```

## صورت پروژه
پاسخ در `solution/` — CounterViewModel.java + CounterActivity.java + layout.
