# تمرین‌های جلسه ۸۹ — Hilt و DataStore

## آسان
1. `@HiltAndroidApp` را در Application class استفاده کنید.
2. `@AndroidEntryPoint` و `@Inject` را در Activity استفاده کنید.

## متوسط
3. `@Module` و `@Provides` برای dependencies استفاده کنید.
4. `DataStore` برای preferences استفاده کنید.

## سخت
5. `preferencesDataStore` برای DataStore setup استفاده کنید.
6. `Flow` برای reactive preferences استفاده کنید.
