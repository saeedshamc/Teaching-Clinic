# پروژهٔ جلسه ۷۹ — لیست مخاطبین با RecyclerView

یک لیست مخاطبین بسازید که:
- `RecyclerView` برای scrollable list
- `MyAdapter` با `ViewHolder`
- `LinearLayoutManager` برای vertical
- `item_layout.xml` برای هر item
- `TextView` برای name, phone, email
- `Button` برای delete
- `notifyDataSetChanged` برای updates

نمونه:
```
[Ali | 123-4567 | Delete]
[Sara | 987-6543 | Delete]
[Reza | 555-1234 | Delete]
```

## صورت پروژه
پاسخ در `solution/` — ContactAdapter.java + item_contact.xml + ContactListActivity.java.
