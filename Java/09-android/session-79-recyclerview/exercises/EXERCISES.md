# تمرین‌های جلسه ۷۹ — RecyclerView

## آسان
1. `RecyclerView` را در layout اضافه کنید.
2. `MyAdapter` با `ViewHolder` بسازید.

## متوسط
3. `LinearLayoutManager` برای vertical list استفاده کنید.
4. `onBindViewHolder` برای data binding استفاده کنید.

## سخت
5. `notifyDataSetChanged` برای dynamic updates استفاده کنید.
6. `GridLayoutManager` برای grid layout استفاده کنید.
