# تمرین‌های جلسه ۸۸ — Coroutines و Flow

## آسان
1. `suspend` function با `delay` بسازید.
2. `launch` برای fire-and-forget coroutine استفاده کنید.

## متوسط
3. `async` برای deferred result استفاده کنید.
4. `Flow` برای reactive streams استفاده کنید.

## سخت
5. `StateFlow` برای UI state در ViewModel استفاده کنید.
6. `viewModelScope` برای lifecycle-aware coroutines استفاده کنید.
