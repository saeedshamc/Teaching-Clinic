# تمرین‌های جلسه ۹۲ — BroadcastReceiver و Permissions

## آسان
1. `MyReceiver` با `onReceive` برای battery events بسازید.
2. `registerReceiver` برای dynamic broadcast استفاده کنید.

## متوسط
3. `sendBroadcast` برای custom broadcast استفاده کنید.
4. `requestPermissions` برای runtime permission استفاده کنید.

## سخت
5. `ActivityResultLauncher` برای modern permission request استفاده کنید.
6. `checkSelfPermission` برای check permission استفاده کنید.
