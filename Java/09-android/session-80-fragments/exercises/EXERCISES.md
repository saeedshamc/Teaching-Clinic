# تمرین‌های جلسه ۸۰ — Fragments

## آسان
1. `MyFragment` با `onCreateView` بسازید.
2. `fragment_my.xml` برای fragment layout بسازید.

## متوسط
3. `FragmentTransaction` برای add/replace fragment استفاده کنید.
4. `OnFragmentInteractionListener` برای communication استفاده کنید.

## سخت
5. چند fragment را با `add`/`hide`/`show` مدیریت کنید.
6. `FragmentManager.findFragmentById` برای access fragment استفاده کنید.
