# تمرین‌های جلسه ۸۶ — WorkManager

## آسان
1. `MyWorker` با `doWork` بسازید.
2. `OneTimeWorkRequest` برای one-time work استفاده کنید.

## متوسط
3. `PeriodicWorkRequest` برای recurring work استفاده کنید.
4. `Constraints` برای network/battery conditions استفاده کنید.

## سخت
5. `Data` برای input/output data استفاده کنید.
6. `WorkManager.cancelAllWork()` برای cancel work استفاده کنید.
