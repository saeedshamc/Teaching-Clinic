# تمرین‌های جلسه ۷۸ — Layouts و XML

## آسان
1. `LinearLayout` با `orientation="vertical"` بسازید.
2. `match_parent` و `wrap_content` را برای width/height استفاده کنید.

## متوسط
3. `ConstraintLayout` با `layout_constraintTop_toTopOf` استفاده کنید.
4. `FrameLayout` برای overlay استفاده کنید.

## سخت
5. nested `LinearLayout` برای complex UI بسازید.
6. `dp` و `sp` را برای units استفاده کنید.
