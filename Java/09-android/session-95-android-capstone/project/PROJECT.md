# پروژهٔ جلسه ۹۵ — اپ نهایی Android (Capstone)

یک اپ Android کامل بسازید که شامل:
- [ ] `Item` model با Room entity
- [ ] `ItemDao`, `ItemDatabase` برای local storage
- [ ] `ItemRepository` برای data layer
- [ ] `AppViewModel` با LiveData
- [ ] `ItemAdapter` برای RecyclerView
- [ ] `FinalApp` با Navigation, WorkManager, Notifications
- [ ] `Hilt` برای DI
- [ ] `DataStore` برای settings
- [ ] `Retrofit` برای remote API

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
