# تمرین‌های جلسه ۹۰ — Jetpack Capstone

## آسان
1. `Task` entity با `@Entity` بسازید.
2. `TaskDao` با `@Query` برای getAllTasks بسازید.

## متوسط
3. `TaskRepository` برای data layer بسازید.
4. `TaskViewModel` با `LiveData` بسازید.

## سخت
5. `TaskActivity` با RecyclerView و observe بسازید.
6. `WorkManager` برای background sync اضافه کنید.
