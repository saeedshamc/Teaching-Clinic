# پروژهٔ جلسه ۹۰ — سیستم مدیریت وظایف کامل (Jetpack)

یک سیستم مدیریت وظایف کامل بسازید که:
- [ ] `Task` entity با Room
- [ ] `TaskDao` با queries
- [ ] `TaskDatabase` برای Room
- [ ] `TaskRepository` برای data layer
- [ ] `TaskViewModel` با LiveData
- [ ] `TaskActivity` با RecyclerView
- [ ] `TaskAdapter` برای display
- [ ] `addTask`, `updateTask`, `deleteTask` methods
- [ ] `WorkManager` برای background sync
- [ ] `Navigation` برای multi-screen

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
