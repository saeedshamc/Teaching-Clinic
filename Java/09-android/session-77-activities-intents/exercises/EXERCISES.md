# تمرین‌های جلسه ۷۷ — Activities و Intents

## آسان
1. `MainActivity` با `startActivity` برای `SecondActivity` بنویسید.
2. `SecondActivity` را در manifest اضافه کنید.

## متوسط
3. `startActivityForResult` برای result استفاده کنید.
4. `onActivityResult` را override کنید.

## سخت
5. `Intent` با extras برای data passing استفاده کنید.
6. `ActivityResultLauncher` برای modern approach استفاده کنید.
