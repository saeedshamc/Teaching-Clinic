# پروژهٔ جلسه ۹۱ — سیستم Music Service

یک Music Service بسازید که:
- `MusicService` با `startForegroundService`
- `Notification` برای foreground service
- `MediaPlayer` برای music playback (simulation)
- `ServiceActivity` برای start/stop/pause
- `START_STICKY` برای restart

نمونه:
```
[Play] → Start foreground service with notification
[Pause] → Pause music
[Stop] → Stop service
```

## صورت پروژه
پاسخ در `solution/` — MusicService.java + MusicActivity.java.
