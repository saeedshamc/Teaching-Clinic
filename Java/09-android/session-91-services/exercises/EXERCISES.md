# تمرین‌های جلسه ۹۱ — Services

## آسان
1. `MyService` با `onStartCommand` بسازید.
2. `startService` و `stopService` را استفاده کنید.

## متوسط
3. `bindService` با `ServiceConnection` استفاده کنید.
4. `LocalBinder` برای client-server communication استفاده کنید.

## سخت
5. `startForegroundService` با notification استفاده کنید.
6. `START_STICKY` برای restart if killed استفاده کنید.
