# پروژهٔ جلسه ۸۵ — اپ CRUD با Retrofit

یک اپ CRUD با Retrofit بسازید که:
- `ApiService` با `@GET`, `@POST`, `@PUT`, `@DELETE`
- `User` model برای API
- `RetrofitClient` برای instance
- `ApiActivity` با buttons برای CRUD
- `Callback` برای async handling
- `TextView` برای display results

نمونه:
```
[Get Users] → List of users
[Create User] → New user created
[Update User] → User updated
[Delete User] → User deleted
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
