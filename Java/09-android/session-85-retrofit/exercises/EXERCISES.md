# تمرین‌های جلسه ۸۵ — Retrofit

## آسان
1. `ApiService` با `@GET` و `@POST` بسازید.
2. `RetrofitClient` با `baseUrl` و `GsonConverterFactory` بسازید.

## متوسط
3. `api.getUsers().enqueue()` برای async call استفاده کنید.
4. `Callback` با `onResponse` و `onFailure` پیاده کنید.

## سخت
5. `@Path` و `@Body` برای parameterized requests استفاده کنید.
6. `Call.execute()` برای synchronous call استفاده کنید.
