# پروژهٔ جلسه ۸۱ — سیستم مدیریت مخاطبین کامل (Legacy)

یک سیستم مدیریت مخاطبین کامل بسازید که:
- [ ] `Contact` model با همهٔ فیلدها
- [ ] `ContactAdapter` با `ViewHolder`
- [ ] `MainActivity` با RecyclerView
- [ ] `AddContactActivity` برای add contact
- [ ] `ContactDetailFragment` برای details
- [ ] `Intent` برای navigation و data passing
- [ ] `FragmentTransaction` برای fragment management
- [ ] `onActivityResult` برای handle result

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
