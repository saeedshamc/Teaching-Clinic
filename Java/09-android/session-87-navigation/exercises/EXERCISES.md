# تمرین‌های جلسه ۸۷ — Navigation Component

## آسان
1. `nav_graph.xml` با `startDestination` بسازید.
2. `NavHostFragment` را در layout اضافه کنید.

## متوسط
3. `NavController` برای navigate استفاده کنید.
4. `argument` برای pass data بین fragments استفاده کنید.

## سخت
5. `safeArgs` برای type-safe arguments استفاده کنید.
6. `popBackStack` برای back navigation استفاده کنید.
