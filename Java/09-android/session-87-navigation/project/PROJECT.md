# پروژهٔ جلسه ۸۷ — ناوبری چند صفحه‌ای

یک سیستم ناوبری چند صفحه‌ای بسازید که:
- `nav_graph.xml` با چند fragment
- `HomeFragment` با buttons برای navigation
- `DetailFragment` با arguments
- `SettingsFragment` برای settings
- `NavController` برای navigate
- `NavHostFragment` در layout

نمونه:
```
[Home] → [Detail (itemId=42)] → [Settings]
[Back] → [Home]
```

## صورت پروژه
پاسخ در `solution/` — nav_graph.xml + fragments + activity.
