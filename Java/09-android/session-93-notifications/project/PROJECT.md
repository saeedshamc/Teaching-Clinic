# پروژهٔ جلسه ۹۳ — سیستم Notification کامل

یک سیستم notification کامل بسازید که:
- `NotificationChannel` برای Android 8+
- `NotificationHelper` برای utilities
- `NotificationCompat` برای notifications
- `PendingIntent` برای actions
- `BigTextStyle` برای rich notifications
- `addAction` برای multiple actions
- `NotificationManagerCompat` برای notify

نمونه:
```
[Simple Notification] → Basic notification
[Rich Notification] → Big text + actions
[Custom Action] → Action button in notification
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
