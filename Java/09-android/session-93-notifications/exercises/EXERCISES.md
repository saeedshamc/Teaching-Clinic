# تمرین‌های جلسه ۹۳ — Notifications

## آسان
1. `NotificationChannel` برای Android 8+ بسازید.
2. `NotificationCompat.Builder` برای simple notification استفاده کنید.

## متوسط
3. `PendingIntent` برای notification action استفاده کنید.
4. `NotificationManagerCompat` برای notify استفاده کنید.

## سخت
5. `NotificationCompat.BigTextStyle` برای rich notification استفاده کنید.
6. `addAction` برای multiple actions استفاده کنید.
