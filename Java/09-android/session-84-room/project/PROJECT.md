# پروژهٔ جلسه ۸۴ — سیستم مدیریت مخاطبین با Room

یک سیستم مدیریت مخاطبین بسازید که:
- `Contact` entity با `@Entity`, `@PrimaryKey`
- `ContactDao` با `@Query`, `@Insert`, `@Update`, `@Delete`
- `AppDatabase` با `@Database`
- `ContactRepository` برای data layer
- `ContactViewModel` با `LiveData`
- `ContactActivity` با RecyclerView

نمونه:
```
[Contacts: 3]
[Ali | 123-4567 | Friends]
[Sara | 987-6543 | Family]
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
