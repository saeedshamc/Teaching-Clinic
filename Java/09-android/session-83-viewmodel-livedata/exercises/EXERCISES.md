# تمرین‌های جلسه ۸۳ — ViewModel و LiveData

## آسان
1. `ViewModel` با `MutableLiveData` بسازید.
2. `LiveData` را در Activity observe کنید.

## متوسط
3. `setValue` و `postValue` را برای update LiveData استفاده کنید.
4. `observe` با lifecycle awareness را تست کنید.

## سخت
5. `Transformations.map` برای transform LiveData استفاده کنید.
6. `MediatorLiveData` برای combine چند LiveData استفاده کنید.
