# تمرین‌های جلسه ۴۹ — Streams Advanced

## آسان
1. `Collectors.joining` برای الحاق نام‌ها با `", "` استفاده کنید.
2. `Collectors.groupingBy` برای گروه‌بندی بر اساس department استفاده کنید.

## متوسط
3. `Collectors.partitioningBy` برای تقسیم به دو گروه (adult/young) استفاده کنید.
4. `Collectors.toMap` برای تبدیل List به Map استفاده کنید.

## سخت
5. `flatMap` برای flatten کردن `List<List<Integer>>` استفاده کنید.
6. `summaryStatistics` برای آمار سنی استفاده کنید.
