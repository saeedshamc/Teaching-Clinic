# تمرین‌های جلسه ۴۸ — Streams Basics

## آسان
1. `List<String>` را با `filter` بر اساس طول فیلتر کنید.
2. `List<Integer>` را با `map` به مربع تبدیل کنید.

## متوسط
3. `stream().count()` و `findFirst()` را تست کنید.
4. `sorted()` و `distinct()` را استفاده کنید.

## سخت
5. `anyMatch`, `allMatch`, `noneMatch` را با چند شرط تست کنید.
6. `limit` و `skip` را برای pagination استفاده کنید.
