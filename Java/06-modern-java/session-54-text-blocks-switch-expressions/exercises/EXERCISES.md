# تمرین‌های جلسه ۵۴ — Text Blocks و Switch Expressions

## آسان
1. text block برای JSON چندخطی بسازید.
2. switch expression برای `day` به `Weekend`/`Weekday` بنویسید.

## متوسط
3. `formatted()` را برای interpolation در text block استفاده کنید.
4. `yield` را برای complex switch case استفاده کنید.

## سخت
5. text block برای HTML template بسازید.
6. switch expression روی enum با `case RED, GREEN ->` بنویسید.
