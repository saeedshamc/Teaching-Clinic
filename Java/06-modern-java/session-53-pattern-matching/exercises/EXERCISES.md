# تمرین‌های جلسه ۵۳ — Pattern Matching

## آسان
1. `if (obj instanceof String s)` را برای type check استفاده کنید.
2. `instanceof` pattern را برای `Person` record استفاده کنید.

## متوسط
3. `instanceof` pattern با `&&` برای compound condition استفاده کنید.
4. sealed types + instanceof pattern برای exhaustive check بنویسید.

## سخت
5. `switch` expression با `case Circle c ->` را برای Shape بنویسید (نیازمند Java 21+).
6. `record pattern` را برای `Point(int x, int y)` استفاده کنید (نیازمند Java 21+).
