# تمرین‌های جلسه ۴۶ — Lambda

## آسان
1. `Runnable` با lambda بسازید.
2. `Calculator` interface با `calculate(int,int)` و lambda برای add بسازید.

## متوسط
3. lambda با block body و return بنویسید.
4. lambda را به متد `process(String, Processor)` پاس دهید.

## سخت
5. `Predicate<T>` interface بسازید و lambda برای `isEven`, `isPositive` بنویسید.
6. lambda که exception می‌دهد را با try-catch داخل body بنویسید.
