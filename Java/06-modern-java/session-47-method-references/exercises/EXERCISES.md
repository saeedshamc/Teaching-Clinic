# تمرین‌های جلسه ۴۷ — Method References

## آسان
1. `String::length` را به‌عنوان `Function<String,Integer>` استفاده کنید.
2. `System.out::println` را برای `forEach` استفاده کنید.

## متوسط
3. `ArrayList::new` را به‌عنوان `Supplier` استفاده کنید.
4. `Comparator.comparing(Person::getAge)` برای sort استفاده کنید.

## سخت
5. `this::method` و `super::method` را تست کنید.
6. method reference برای constructor با پارامتر (`Person::new`) استفاده کنید.
