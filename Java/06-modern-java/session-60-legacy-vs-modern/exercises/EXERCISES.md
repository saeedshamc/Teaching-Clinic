# تمرین‌های جلسه ۶۰ — Legacy vs Modern

## آسان
1. جدول مرجع Legacy → Modern را کامل کنید.
2. `Vector` → `ArrayList` و `Hashtable` → `HashMap` را تست کنید.

## متوسط
3. `Date`/`Calendar` → `java.time` را migrate کنید.
4. `StringBuffer` → `StringBuilder` را migrate کنید.

## سخت
5. یک کد legacy کامل را modern کنید — حداقل ۵ API.
6. تصمیم بگیرید چه زمانی از legacy استفاده می‌کنید — سناریوهای واقعی.
