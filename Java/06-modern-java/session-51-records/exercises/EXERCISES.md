# تمرین‌های جلسه ۵۱ — Records

## آسان
1. `record Point(int x, int y)` بسازید و accessorها را تست کنید.
2. `record Person(String name, int age)` با compact constructor و validation بسازید.

## متوسط
3. `record Circle(double radius)` با `area()` و `diameter()` methods بسازید.
4. `record Address` و `record Employee` (nested) بسازید.

## سخت
5. `record` را در `List` ذخیره کنید و با stream پردازش کنید.
6. `record` را با `Serializable` ترکیب کنید.
