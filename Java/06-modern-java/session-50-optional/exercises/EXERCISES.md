# تمرین‌های جلسه ۵۰ — Optional

## آسان
1. `Optional.of("Hello")` و `Optional.empty()` بسازید و `isPresent` را تست کنید.
2. `Optional.ofNullable(null)` را تست کنید.

## متوسط
3. `map` و `flatMap` را برای transform استفاده کنید.
4. `orElse` و `orElseGet` را برای default استفاده کنید.

## سخت
5. `orElseThrow` را برای fail-fast استفاده کنید.
6. `Optional` را در stream برای `findFirst` استفاده کنید.
