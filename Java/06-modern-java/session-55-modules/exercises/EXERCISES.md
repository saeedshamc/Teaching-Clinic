# تمرین‌های جلسه ۵۵ — Modules

## آسان
1. `module-info.java` با `module com.example.test` بسازید.
2. `javac --module-path` را برای compile استفاده کنید.

## متوسط
3. `exports` را برای یک package اضافه کنید.
4. `requires java.sql` را اضافه کنید.

## سخت
5. دو module بسازید — یکی `requires` و `exports` دیگری.
6. `opens` را برای reflection تست کنید.
