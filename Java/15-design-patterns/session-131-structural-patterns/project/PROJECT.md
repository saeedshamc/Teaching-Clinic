# پروژهٔ جلسه ۱۳۱ — سیستم با Structural Patterns

یک سیستم با Structural Patterns بسازید:
- `Adapter` برای incompatible interfaces
- `Decorator` برای dynamic behavior addition
- `Facade` برای simplified interface
- `Composite` برای tree structure
- `Proxy` برای lazy loading یا access control

نمونه:
```
Adapter: Old printer → New printer
Coffee: Simple + Milk + Sugar + Whipped Cream
Facade: one call → multiple subsystems
Composite: tree with leaves and branches
```

پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
