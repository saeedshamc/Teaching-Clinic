# تمرین‌های جلسه ۱۳۱ — Structural Patterns

## آسان
1. `Adapter` برای `OldPrinter` → `NewPrinter` بسازید.
2. `Decorator` برای `Coffee` با `MilkDecorator` بسازید.

## متوسط
3. `Facade` برای `ComplexSubsystem` با `SimpleFacade` بسازید.
4. `Composite` برای tree structure با `Leaf` و `Composite` بسازید.

## سخت
5. `Proxy` برای lazy loading یا access control استفاده کنید.
6. `Bridge` برای separating abstraction از implementation استفاده کنید.
