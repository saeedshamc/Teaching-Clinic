# پروژهٔ جلسه ۱۳۵ — سیستم فروشگاه با Design Patterns

یک سیستم فروشگاه کامل با design patterns بسازید:
- [ ] `Singleton` برای `DatabaseConnection`
- [ ] `Factory` برای `Product` creation
- [ ] `Builder` برای `Order` complex object
- [ ] `Decorator` برای `Product` با discounts
- [ ] `Facade` برای `OrderProcessing`
- [ ] `Adapter` برای `PaymentGateway`
- [ ] `Observer` برای `OrderStatus` notifications
- [ ] `Strategy` برای `PaymentMethod`
- [ ] `Command` برای `OrderActions`

نمونه:
```
Order created with Builder
Product discounted with Decorator
Payment processed with Strategy
Notifications sent with Observer
Order actions with Command
Order processing with Facade
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
