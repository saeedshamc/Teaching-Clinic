# تمرین‌های جلسه ۱۳۵ — Design Patterns Capstone

## آسان
1. `Singleton` برای `DatabaseConnection` بسازید.
2. `Factory` برای `Product` creation بسازید.

## متوسط
3. `Builder` برای `Order` complex object بسازید.
4. `Decorator` برای `Product` با discounts بسازید.

## سخت
5. `Observer` برای `OrderStatus` notifications بسازید.
6. `Strategy` برای `PaymentMethod` selection بسازید.
7. `Command` برای `OrderActions` (cancel, refund) بسازید.
8. `Facade` برای `OrderProcessing` complex subsystem بسازید.
