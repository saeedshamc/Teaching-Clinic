# تمرین‌های جلسه ۱۳۲ — Behavioral Patterns

## آسان
1. `Observer` با `attach`/`detach`/`notify` بسازید.
2. `Strategy` با `PaymentStrategy` interface بسازید.

## متوسط
3. `Command` با `execute`/`undo` برای `Light` بسازید.
4. `Chain of Responsibility` با `Handler` chain بسازید.

## سخت
5. `Iterator` برای custom collection استفاده کنید.
6. `Mediator` برای complex interactions استفاده کنید.
