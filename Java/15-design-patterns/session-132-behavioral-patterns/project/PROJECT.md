# پروژهٔ جلسه ۱۳۲ — سیستم با Behavioral Patterns

یک سیستم با Behavioral Patterns بسازید:
- `Observer` برای publish-subscribe
- `Strategy` برای payment methods
- `Command` برای undoable actions
- `Chain of Responsibility` برای request processing
- `Mediator` برای chat communication

نمونه:
```
Observer: news published to 3 observers
Strategy: credit card vs PayPal vs Bitcoin
Command: light on/off with undo
Chain: auth → validation → logging → response
```
