# پروژهٔ جلسه ۱۳۰ — سیستم مدیریت اشیاء با Creational Patterns

یک سیستم مدیریت اشیاء با Creational Patterns بسازید:
- `Singleton` برای `DatabaseConnection`
- `Factory` برای `Shape` objects
- `Builder` برای `User` objects
- `Abstract Factory` برای related objects
- `Prototype` برای object cloning

نمونه:
```
DatabaseConnection: same instance = true
Shape: Drawing circle
User: User{name='Ali', email='ali@mail.com'}
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
