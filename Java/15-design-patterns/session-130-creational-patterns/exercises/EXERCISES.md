# تمرین‌های جلسه ۱۳۰ — Creational Patterns

## آسان
1. `Singleton` با private constructor و `getInstance` بسازید.
2. `Factory` با `createShape` method بسازید.

## متوسط
3. `Builder` با fluent API برای `User` بسازید.
4. `Builder.build()` با validation برای required fields استفاده کنید.

## سخت
5. `Abstract Factory` برای related objects بسازید.
6. `Prototype` با `clone()` برای object copying استفاده کنید.
