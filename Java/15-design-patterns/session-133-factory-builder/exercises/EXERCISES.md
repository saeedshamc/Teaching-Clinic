# تمرین‌های جلسه ۱۳۳ — Factory & Builder

## آسان
1. `Factory Method` با `createDocument` برای `Pdf`, `Word`, `Text` بسازید.
2. `Builder` با fluent API برای `Computer` بسازید.

## متوسط
3. `Abstract Factory` برای `UIFactory` با `Windows` و `Mac` بسازید.
4. `Builder.build()` با validation برای required fields استفاده کنید.

## سخت
5. `Prototype` با `clone()` برای `Document` object copying استفاده کنید.
6. `Deep copy` vs `Shallow copy` را در `clone()` در نظر بگیرید.
