# تمرین‌های جلسه ۱۴۶ — Message Queues

## آسان
1. `MessageQueueDemo` با `BlockingQueue` برای in-memory queue استفاده کنید.
2. `Producer` و `Consumer` threads برای async processing بسازید.

## متوسط
3. `RabbitMQProducer` با `queueDeclare` و `basicPublish` استفاده کنید.
4. `RabbitMQConsumer` با `basicConsume` و `DeliverCallback` استفاده کنید.

## سخت
5. `KafkaProducer` با `ProducerRecord` برای distributed streaming استفاده کنید.
6. `Pub/Sub` pattern برای multiple consumers استفاده کنید.
