# تمرین‌های جلسه ۱۴۵ — CI/CD

## آسان
1. `.github/workflows/java.yml` با GitHub Actions بسازید.
2. `Jenkinsfile` با pipeline stages بسازید.

## متوسط
3. `.gitlab-ci.yml` با `build`, `test`, `deploy` stages بسازید.
4. `docker build` و `docker push` در CI/CD pipeline استفاده کنید.

## سخت
5. `secrets` برای Docker Hub credentials استفاده کنید.
6. `only`/`if` conditions برای branch-specific deploy استفاده کنید.
