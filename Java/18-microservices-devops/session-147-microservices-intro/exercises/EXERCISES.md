# تمرین‌های جلسه ۱۴۷ — Microservices Intro

## آسان
1. `UserService` با `getUser`, `getAllUsers`, `createUser` بسازید.
2. `ProductService` با `getProduct`, `getAllProducts`, `createProduct` بسازید.

## متوسط
3. `OrderService` با `getOrder`, `getUserOrders`, `createOrder` بسازید.
4. `GatewayConfig` با `RouteLocator` برای API Gateway بسازید.

## سخت
5. `@FeignClient` برای service-to-service communication استفاده کنید.
6. `Circuit Breaker` با `fallback` برای resilience استفاده کنید.
