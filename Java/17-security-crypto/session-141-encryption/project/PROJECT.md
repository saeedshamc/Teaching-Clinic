# پروژهٔ جلسه ۱۴۱ — سیستم رمزنگاری

یک سیستم رمزنگاری بسازید:
- `SymmetricEncryptionDemo` با `AES` برای symmetric encryption
- `AsymmetricEncryptionDemo` با `RSA` برای asymmetric encryption
- `EncryptionUtils` با `generateKey`, `generateIV`, `encrypt`, `decrypt`
- `SecureMessage` با `encrypt`/`decrypt` برای messages
- `KeyManager` برای key generation و storage

نمونه:
```
Plaintext: Hello, World!
Key: abc123...
IV: def456...
Encrypted: xyz789...
Decrypted: Hello, World!
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/` را گسترش دهید.
