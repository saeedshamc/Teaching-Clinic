# تمرین‌های جلسه ۱۴۱ — Encryption

## آسان
1. `SymmetricEncryptionDemo` با `AES` برای symmetric encryption استفاده کنید.
2. `AsymmetricEncryptionDemo` با `RSA` برای asymmetric encryption استفاده کنید.

## متوسط
3. `EncryptionUtils` با `generateKey`, `generateIV`, `encrypt`, `decrypt` بسازید.
4. `Cipher` با `AES/CBC/PKCS5Padding` برای encryption استفاده کنید.

## سخت
5. `KeyStore` برای secure key storage استفاده کنید.
6. `Certificate` برای public key distribution استفاده کنید.
