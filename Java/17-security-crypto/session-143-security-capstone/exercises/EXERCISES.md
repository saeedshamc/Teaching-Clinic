# تمرین‌های جلسه ۱۴۳ — Security Capstone

## آسان
1. `SecureUserService` با `register` و `authenticate` بسازید.
2. `User` model با `username`, `email`, `password` بسازید.

## متوسط
3. `AuthService` با `login`, `register`, `validateToken` بسازید.
4. `SecureController` با `register`, `login`, `getAllUsers` بسازید.

## سخت
5. `PBKDF2` برای password hashing استفاده کنید.
6. `JWT` برای token generation استفاده کنید.
7. `Bearer` token در `Authorization` header استفاده کنید.
