# تمرین‌های جلسه ۱۴۰ — Hashing & Passwords

## آسان
1. `HashDemo` با `MessageDigest` برای SHA-256 استفاده کنید.
2. `PBKDF2Demo` با `PBEKeySpec` برای password hashing استفاده کنید.

## متوسط
3. `SecurePasswordStorage` با `salt:hash` format برای storage استفاده کنید.
4. `verifyPassword` برای password verification استفاده کنید.

## سخت
5. `BCrypt` با `spring-security-crypto` برای password hashing استفاده کنید.
6. `Argon2` برای modern password hashing استفاده کنید.
