# پروژهٔ جلسه ۱۴۸ — سیستم مدیریت کارکنان با Swing

یک سیستم مدیریت کارکنان با Swing بسازید:
- [ ] `Employee` model با `id`, `name`, `department`, `salary`
- [ ] `EmployeeService` با CRUD operations
- [ ] `EmployeeDAO` برای data persistence
- [ ] `MainFrame` با `JTable`, `JButton`, `JTextField`
- [ ] `EmployeeDialog` برای add/edit employee
- [ ] `SearchPanel` برای search/filter
- [ ] `Refresh` button برای reload data

```

  - Department: [____]

```
