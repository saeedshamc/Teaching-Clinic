# تمرین‌های جلسه ۱۴۸ — Desktop App Capstone

## آسان
1. `Employee` model با `id`, `name`, `department`, `salary` بسازید.
2. `EmployeeService` با CRUD operations بسازید.

## متوسط
3. `MainFrame` با `JTable`, `JButton`, `JTextField` برای UI بسازید.
4. `EmployeeDialog` برای add/edit employee بسازید.

## سخت
5. `SearchPanel` برای search/filter employees استفاده کنید.
6. `EmployeeDAO` برای data persistence استفاده کنید.
