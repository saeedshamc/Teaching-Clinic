# تمرین‌های جلسه ۱۵۰ — REST Backend Capstone

## آسان
1. `Product` entity با JPA + validation بسازید.
2. `ProductRepository` با `JpaRepository` و derived queries بسازید.

## متوسط
3. `ProductService` با `@Transactional` برای CRUD بسازید.
4. `ProductController` با `@RestController` برای REST API بسازید.

## سخت
5. `JwtUtil` برای JWT token generation استفاده کنید.
6. `WebSocketConfig` برای real-time notifications استفاده کنید.
7. `SecurityConfig` برای authorization استفاده کنید.
