# تمرین‌های جلسه ۱۴۹ — Android App Capstone

## آسان
1. `Task` entity با `id`, `title`, `description`, `isCompleted`, `priority` بسازید.
2. `TaskDao` با `getAllTasks`, `insertTask`, `updateTask`, `deleteTask` بسازید.

## متوسط
3. `TaskViewModel` با `StateFlow` برای UI state بسازید.
4. `TaskRepository` با `getAllTasks`, `insertTask`, `updateTask` بسازید.

## سخت
5. `TaskScreen` با `LazyColumn`, `FAB`, `Checkbox` برای UI بسازید.
6. `AddTaskScreen` برای create/edit task بسازید.
