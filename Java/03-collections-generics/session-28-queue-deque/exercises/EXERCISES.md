# تمرین‌های جلسه ۲۸ — Queue و Deque

## آسان
1. `Queue<Integer>` بسازید و ۵ عدد اضافه/خارج کنید — FIFO را ببینید.
2. `PriorityQueue` بسازید و ۵ عدد را به ترتیب sorted بیرون بیاورید.

## متوسط
3. `Deque` بسازید و `offerFirst`/`offerLast`/`pollFirst`/`pollLast` را تست کنید.
4. `ArrayDeque` را به‌عنوان Stack استفاده کنید — `push`/`pop`.

## سخت
5. شبیه‌سازی صف بانک — مشتری‌ها را با `Queue` مدیریت کنید.
6. `PriorityQueue` با comparator سفارشی (نزولی) بسازید — جلسهٔ ۳۰.
