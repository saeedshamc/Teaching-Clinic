# تمرین‌های جلسه ۲۹ — Generics

## آسان
1. کلاس `Pair<K,V>` با `key` و `value` بسازید.
2. متد generic `swap` بنویسید که دو عنصر را جابه‌جا کند.

## متوسط
3. متد `max` با `<T extends Comparable<T>>` بنویسید.
4. `List<? extends Number>` را برای sum استفاده کنید.

## سخت
5. کلاس `GenericRepository<T>` با `add`, `find`, `delete` بسازید.
6. `List<? super Integer>` را برای add استفاده کنید — چرا `? super` لازم است؟
