# تمرین‌های جلسه ۲۵ — List و ArrayList

## آسان
1. `List<Integer>` بسازید و ۵ عدد اضافه کنید؛ مجموع را حساب کنید.
2. `List<String>` بسازید و با `for-each` چاپ کنید.

## متوسط
3. `List.of` بسازید و سعی کنید add کنید — خطا را ببینید.
4. `Arrays.asList` بسازید و `set` را تست کنید.

## سخت
5. `LinkedList` بسازید و `addFirst`/`addLast` را تست کنید.
6. لیستی از `Student` (کلاس) بسازید و با `get` به فیلدها دسترسی پیدا کنید.
