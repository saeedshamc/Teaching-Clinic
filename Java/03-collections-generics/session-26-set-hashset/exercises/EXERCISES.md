# تمرین‌های جلسه ۲۶ — Set و HashSet

## آسان
1. `Set<Integer>` بسازید و ۱۰ عدد تصادفی اضافه کنید؛ duplicateها را ببینید.
2. `TreeSet` بسازید و ۵ عدد را مرتب چاپ کنید.

## متوسط
3. دو Set بسازید و union/intersection/difference را محاسبه کنید.
4. `LinkedHashSet` بسازید و ترتیب درج را نشان دهید.

## سخت
5. لیستی از String با duplicate بسازید و با Set uniqueها را استخراج کنید.
6. `Set<Student>` بسازید که `equals`/`hashCode` را override کرده باشد تا duplicate بر اساس id تشخیص داده شود.
