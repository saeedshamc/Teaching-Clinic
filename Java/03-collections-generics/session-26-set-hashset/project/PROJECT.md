# پروژهٔ جلسه ۲۶ — سیستم تگ‌ها

یک سیستم تگ‌گذاری بسازید که:
- `Set<String>` برای نگهداری تگ‌های یکتا
- `Map<String, Integer>` برای شمارش تگ‌ها (tag → count)
- متدهای `addTag`, `removeTag`, `getTagCount`, `displayAll`
- در `main` چند تگ اضافه/حذف کنید و آمار را نشان دهید

نمونه:
```
Tags: [java, python, web, java]
Counts: java=2, python=1, web=1
```

## صورت پروژه
پاسخ در `solution/TagSystem.java` — از `HashSet` و `HashMap` استفاده کنید (Map در جلسهٔ بعد می‌آید ولی می‌توانید preview کنید).
