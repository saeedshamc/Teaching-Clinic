# تمرین‌های جلسه ۲۷ — Map و HashMap

## آسان
1. `Map<String, Integer>` بسازید و ۳ دانش‌آموز با سن اضافه کنید.
2. `getOrDefault` را برای شمارش کلمات استفاده کنید.

## متوسط
3. `LinkedHashMap` بسازید و ترتیب درج را نشان دهید.
4. `TreeMap` بسازید و مرتب‌سازی بر اساس key را ببینید.

## سخت
5. `Map<String, List<Integer>>` بسازید — هر key لیستی از اعداد دارد.
6. شمارش frequency کلمات در جمله با `Map<String, Integer>` پیاده کنید.
