# تمرین‌های جلسه ۳۰ — Comparator و Iterator

## آسان
1. `List<Integer>` بسازید و با `Collections.sort` مرتب کنید.
2. `Iterator` برای پیمایش و چاپ استفاده کنید.

## متوسط
3. `Comparator` برای مرتب‌سازی بر اساس نام (نزولی) بنویسید.
4. `Comparator.comparingInt` را برای سن استفاده کنید.

## سخت
5. `List<Student>` را با چند فیلد مرتب کنید (age, سپس name).
6. `Iterator.remove()` را برای حذف امن در حین پیمایش تست کنید.
