# تمرین‌های جلسه ۹۶ — JDBC Basics

## آسان
1. `DriverManager.getConnection` برای اتصال به SQLite استفاده کنید.
2. `Statement` با `executeQuery` برای SELECT استفاده کنید.

## متوسط
3. `PreparedStatement` با `setString`/`setInt` برای INSERT استفاده کنید.
4. `ResultSet` با `next()` و `getString` برای خواندن داده استفاده کنید.

## سخت
5. `try-with-resources` برای همهٔ JDBC resources استفاده کنید.
6. `executeUpdate` برای INSERT/UPDATE/DELETE و تعداد rows را چاپ کنید.
