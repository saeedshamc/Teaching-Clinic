# تمرین‌های جلسه ۹۹ — Transactions

## آسان
1. `setAutoCommit(false)` و `commit()` را برای transaction استفاده کنید.
2. `rollback()` را برای error handling استفاده کنید.

## متوسط
3. `transfer` با `debit` و `credit` در یک transaction پیاده کنید.
4. `setTransactionIsolation` برای isolation level استفاده کنید.

## سخت
5. `Savepoint` برای partial rollback استفاده کنید.
6. insufficient funds check را در transaction اضافه کنید.
