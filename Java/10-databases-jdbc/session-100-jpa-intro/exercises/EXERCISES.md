# تمرین‌های جلسه ۱۰۰ — JPA Intro

## آسان
1. `@Entity` و `@Id` برای `User` entity بسازید.
2. `persistence.xml` برای configuration بسازید.

## متوسط
3. `em.persist()` برای INSERT استفاده کنید.
4. `em.find()` برای SELECT by id استفاده کنید.

## سخت
5. `em.createQuery()` برای JPQL query استفاده کنید.
6. `em.merge()` برای UPDATE و `em.remove()` برای DELETE استفاده کنید.
