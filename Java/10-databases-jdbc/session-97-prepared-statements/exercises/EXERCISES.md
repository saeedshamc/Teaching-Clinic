# تمرین‌های جلسه ۹۷ — PreparedStatement

## آسان
1. `PreparedStatement` با `setString` برای INSERT استفاده کنید.
2. `setNull` برای insert مقدار NULL استفاده کنید.

## متوسط
3. `addBatch` و `executeBatch` برای insert گروهی استفاده کنید.
4. `RETURN_GENERATED_KEYS` برای گرفتن id ساخته‌شده استفاده کنید.

## سخت
5. SQL Injection را با `PreparedStatement` جلوگیری کنید.
6. `CallableStatement` برای stored procedure استفاده کنید.
