# تمرین‌های جلسه ۱۰۱ — Hibernate

## آسان
1. `SessionFactory` و `Session` را برای CRUD استفاده کنید.
2. `session.persist()` برای INSERT استفاده کنید.

## متوسط
3. `session.createQuery()` برای HQL استفاده کنید.
4. `CriteriaBuilder` برای type-safe queries استفاده کنید.

## سخت
5. `FetchType.LAZY` و `Eager` را برای relationships استفاده کنید.
6. `session.update()` و `session.delete()` برای UPDATE/DELETE استفاده کنید.
