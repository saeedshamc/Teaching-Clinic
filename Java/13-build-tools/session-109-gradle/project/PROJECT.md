# پروژهٔ جلسه ۱۰۹ — پروژهٔ Gradle با Dependencies

یک پروژهٔ Gradle بسازید که:
- `build.gradle` با `plugins`, `repositories`, `dependencies`
- `settings.gradle` برای project settings
- `MyApp.java` با main method
- `MyAppTest.java` برای unit tests
- `gradlew build`, `gradlew test`, `gradlew run` commands

نمونه:
```
$ gradlew build
BUILD SUCCESSFUL
$ gradlew test
MyAppTest > testAdd PASSED
$ gradlew run
=== Gradle Project ===
```

## صورت پروژه
پاسخ در `solution/` — build.gradle + settings.gradle + MyApp.java + MyAppTest.java.
