# تمرین‌های جلسه ۱۰۹ — Gradle

## آسان
1. `build.gradle` با `plugins { id 'java' }` بسازید.
2. `gradlew build` را اجرا کنید.

## متوسط
3. Dependencies با `implementation` و `testImplementation` اضافه کنید.
4. `repositories { mavenCentral() }` برای dependencies استفاده کنید.

## سخت
5. Custom task برای `runApp` بسازید.
6. `sourceCompatibility` و `targetCompatibility` را برای Java 17 تنظیم کنید.
