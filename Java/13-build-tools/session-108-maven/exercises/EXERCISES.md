# تمرین‌های جلسه ۱۰۸ — Maven

## آسان
1. `pom.xml` با `groupId`, `artifactId`, `version` بسازید.
2. `mvn compile` را اجرا کنید.

## متوسط
3. Dependency با `scope=compile` و `scope=test` اضافه کنید.
4. `mvn package` برای build jar استفاده کنید.

## سخت
5. `mvn dependency:tree` برای show dependencies استفاده کنید.
6. Plugin برای custom build configuration استفاده کنید.
