# تمرین‌های جلسه ۱۱۰ — Build Capstone

## آسان
1. `pom.xml` با dependencies برای full app بسازید.
2. `build.gradle` با `plugins`, `repositories`, `dependencies` بسازید.

## متوسط
3. `UserService` با CRUD operations پیاده کنید.
4. `UserDao` با JDBC برای database operations پیاده کنید.

## سخت
5. `Main.java` با REST API endpoints پیاده کنید.
6. `UserServiceTest` با JUnit برای unit tests بنویسید.
