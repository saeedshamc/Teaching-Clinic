# تمرین‌های جلسه ۰۳ — Git و GitHub

## آسان
1. `git config --global user.name` و `user.email` را تنظیم و با `git config --list` تأیید کنید.
2. یک پوشهٔ تست بسازید، `git init` کنید، یک فایل اضافه و commit کنید.

## متوسط
3. یک ریپوی GitHub بسازید و با SSH یا Token push کنید.
4. فایل `.gitignore` جاوا را بسازید و یک فایل `.class` را نادیده بگیرید.

## سخت
5. یک شاخهٔ `feature/x` بسازید، commit کنید، به main merge کنید و push کنید.
6. `git log --oneline --graph` را بررسی و تاریخچه را توضیح دهید.
