# پروژهٔ جلسه ۰۳ — اولین ریپوی Java

یک ریپوی GitHub بسازید که شامل:
- [ ] `git config --global` تنظیم شده
- [ ] پروژهٔ Java با `src/` و `.gitignore`
- [ ] حداقل ۲ commit (`initial` + یک تغییر)
- [ ] push به GitHub با SSH یا Token موفق

## صورت پروژه
در `project/solution/` یک `README.md` بنویسید که مراحل را توضیح دهد و لینک ریپو را بگذارید.
