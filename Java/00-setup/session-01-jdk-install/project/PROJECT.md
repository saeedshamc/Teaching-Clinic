# پروژهٔ جلسه ۰۱ — چک‌لیست راه‌اندازی

یک چک‌لیست از نصب کامل JDK تهیه کنید که هر مورد را با دستور واقعی تست کرده باشید:

- [ ] `java -version` خروجی می‌دهد
- [ ] `javac -version` خروجی می‌دهد
- [ ] `JAVA_HOME` تنظیم است (`echo %JAVA_HOME%` / `echo $JAVA_HOME`)
- [ ] `java` و `javac` در PATH هستند
- [ ] یک برنامهٔ Hello World با javac/java بدون IDE اجرا شد
- [ ] ترمینال جدید باز شده و متغیرها هنوز کار می‌کنند

## صورت پروژه
پروژه ساده است — خروجی هر دستور را در `setup-checklist.txt` بنویسید و اگر موردی fail شد، راه‌حل را هم بنویسید.
