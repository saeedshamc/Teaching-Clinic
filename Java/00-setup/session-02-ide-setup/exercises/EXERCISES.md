# تمرین‌های جلسه ۰۲ — نصب IDE

## آسان
1. IntelliJ IDEA Community را نصب و یک پروژهٔ Java بسازید؛ `HelloIDE` را Run کنید.
2. در VS Code پکیج Extension Pack for Java را نصب و همان برنامه را اجرا کنید.

## متوسط
3. یک breakpoint روی `System.out.println` بگذارید و Debug کنید؛ مقادیر متغیرها را در Debug panel ببینید.
4. `mvn -v` یا `gradle -v` را اجرا کنید و خروجی را ثبت کنید.

## سخت
5. پروژه را به Git متصل کنید و اولین commit را بزنید (مقدمات جلسهٔ ۰۳).
6. AVD بسازید و یک اپ خالی Android را روی Emulator اجرا کنید.
