# پروژهٔ جلسه ۰۲ — راه‌اندازی محیط توسعه

یک پروژهٔ Java واقعی بسازید که شامل این موارد باشد:

- [ ] پروژه در IntelliJ یا VS Code ساخته شده و Run می‌شود
- [ ] ساختار `src/com/yourname/` با پکیج رعایت شده
- [ ] حداقل یک breakpoint Debug شده
- [ ] `mvn -v` یا `gradle -v` کار می‌کند
- [ ] (اختیاری) AVD ساخته شده و Hello World روی آن اجرا شده

## صورت پروژه
خروجی Run و screenshot پنل Debug را در `project-notes.md` بنویسید.
