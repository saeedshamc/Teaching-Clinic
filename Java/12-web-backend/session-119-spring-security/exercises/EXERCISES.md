# تمرین‌های جلسه ۱۱۹ — Spring Security

## آسان
1. `SecurityConfig` با `SecurityFilterChain` بسازید.
2. `PasswordEncoder` با `BCryptPasswordEncoder` بسازید.

## متوسط
3. `UserDetailsService` برای user loading پیاده کنید.
4. `@PreAuthorize` برای method-level security استفاده کنید.

## سخت
5. `JwtUtil` برای JWT token generation/validation استفاده کنید.
6. `hasRole('ADMIN')` و `isAuthenticated()` برای authorization استفاده کنید.
