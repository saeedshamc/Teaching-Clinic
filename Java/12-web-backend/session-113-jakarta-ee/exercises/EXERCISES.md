# تمرین‌های جلسه ۱۱۳ — Jakarta EE

## آسان
1. `UserResource` با `@Path` و `@GET` بسازید.
2. `UserService` با `@ApplicationScoped` بسازید.

## متوسط
3. `@POST`, `@PUT`, `@DELETE` برای CRUD بسازید.
4. `@PathParam` برای path parameters استفاده کنید.

## سخت
5. `@Inject` برای CDI dependency injection استفاده کنید.
6. `Response` برای HTTP status codes استفاده کنید.
