# تمرین‌های جلسه ۱۱۱ — Servlets

## آسان
1. `HelloServlet` با `doGet` برای HTML response بسازید.
2. `@WebServlet` annotation برای mapping استفاده کنید.

## متوسط
3. `doPost` با `getParameter` برای form data استفاده کنید.
4. `setContentType` و `getWriter` برای response تنظیم کنید.

## سخت
5. `UserServlet` با CRUD operations بسازید.
6. `sendRedirect` برای redirect استفاده کنید.
