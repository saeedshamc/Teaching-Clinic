# تمرین‌های جلسه ۱۱۸ — Spring Data JPA

## آسان
1. `User` entity با `@Entity`, `@Id`, `@GeneratedValue` بسازید.
2. `UserRepository` با `JpaRepository` بسازید.

## متوسط
3. Derived queries `findByName`, `findByAgeGreaterThan` استفاده کنید.
4. `@Query` برای custom JPQL query استفاده کنید.

## سخت
5. `countByAgeGreaterThan`, `existsByEmail` برای count/exists استفاده کنید.
6. `Optional<User>` برای single result استفاده کنید.
