# تمرین‌های جلسه ۱۱۵ — Spring MVC

## آسان
1. `UserController` با `@GetMapping` برای list users بسازید.
2. `users.html` با Thymeleaf `th:each` برای list rendering بسازید.

## متوسط
3. `@PostMapping` برای create user با `@ModelAttribute` بسازید.
4. `@PathVariable` برای user ID در URL استفاده کنید.

## سخت
5. `UserApiController` با `@RestController` برای REST API بسازید.
6. `redirect:/users` برای redirect after POST استفاده کنید.
