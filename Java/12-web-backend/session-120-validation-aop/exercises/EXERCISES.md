# تمرین‌های جلسه ۱۲۰ — Validation & AOP

## آسان
1. `@NotNull`, `@Size`, `@Email` برای `ValidatedUser` استفاده کنید.
2. `@Valid` برای `@RequestBody` validation استفاده کنید.

## متوسط
3. `@Aspect` با `@Before` و `@After` برای logging استفاده کنید.
4. `@Around` برای measure execution time استفاده کنید.

## سخت
5. `@AfterThrowing` برای exception logging استفاده کنید.
6. Custom validation annotation با `ConstraintValidator` بسازید.
