# تمرین‌های جلسه ۱۲۳ — Backend Capstone 1

## آسان
1. `User` entity با JPA annotations بسازید.
2. `UserRepository` با `JpaRepository` بسازید.

## متوسط
3. `UserService` با `@Transactional` برای CRUD بسازید.
4. `UserController` با `@RestController` برای REST API بسازید.

## سخت
5. `SecurityConfig` با `SecurityFilterChain` برای authorization بسازید.
6. `@Valid` برای input validation استفاده کنید.
