# تمرین‌های جلسه ۱۱۲ — JSP

## آسان
1. `index.jsp` با `<%= %>` expression بسازید.
2. `<%@ page %>` directive برای content type استفاده کنید.

## متوسط
3. `users.jsp` با `c:forEach` برای list rendering استفاده کنید.
4. `${param.name}` برای access request parameters استفاده کنید.

## سخت
5. `RequestDispatcher.forward()` برای servlet → JSP navigation استفاده کنید.
6. `c:if` و `c:choose` برای conditional rendering استفاده کنید.
