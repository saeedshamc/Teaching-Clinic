# تمرین‌های جلسه ۱۱۴ — Spring Core

## آسان
1. `@Component` برای `UserDao` بسازید.
2. `@Service` برای `UserService` بسازید.

## متوسط
3. `@Autowired` برای constructor injection استفاده کنید.
4. `@Configuration` و `@Bean` برای manual bean definition استفاده کنید.

## سخت
5. `@ComponentScan` برای auto-discovery استفاده کنید.
6. `ApplicationContext` برای bean lifecycle مدیریت کنید.
