# تمرین‌های جلسه ۱۱۶ — Spring Boot

## آسان
1. `@SpringBootApplication` برای entry point بسازید.
2. `application.properties` برای config بسازید.

## متوسط
3. `spring-boot-starter-web` برای REST API استفاده کنید.
4. `@RestController` برای JSON endpoints بسازید.

## سخت
5. `spring-boot-starter-data-jpa` برای database integration استفاده کنید.
6. Profiles برای environment-specific config استفاده کنید.
