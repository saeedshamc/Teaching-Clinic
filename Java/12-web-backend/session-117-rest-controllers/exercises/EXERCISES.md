# تمرین‌های جلسه ۱۱۷ — REST Controllers

## آسان
1. `@RestController` با `@GetMapping` برای list users بسازید.
2. `@PostMapping` با `@RequestBody` برای create user بسازید.

## متوسط
3. `@PathVariable` برای user ID در URL استفاده کنید.
4. `@RequestParam` برای query parameters استفاده کنید.

## سخت
5. `ResponseEntity` برای HTTP status codes استفاده کنید.
6. `@RestControllerAdvice` برای global error handling استفاده کنید.
