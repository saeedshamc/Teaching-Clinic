# پروژهٔ جلسه ۱۲ — تبدیل‌گر واحدها

یک برنامه بنویسید که:
- مقدار `double` و واحد (`c`/`f`/`k`) را از `args` بگیرد
- دما را بین سلسیوس/فارنهایت تبدیل کند
- طول را بین متر/فوت تبدیل کند
- با `printf` نتیجه را با ۲ رقم اعشار چاپ کند

نمونه:
```
java Converter 100 c f   → 212.00°F
java Converter 1 k m     → 1000.00m
```

## صورت پروژه
پاسخ در `solution/Converter.java` — از `Double.parseDouble` و `switch` برای واحدها استفاده کنید.
