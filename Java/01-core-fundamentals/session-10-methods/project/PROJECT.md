# پروژهٔ جلسه ۱۰ — ماشین‌حساب پیشرفته

یک کلاس `Calculator` بسازید که متدهای زیر را داشته باشد:
- `add(int,int)`، `subtract`، `multiply`، `divide` — با overloading برای `int` و `double`
- `power(int base, int exp)` — با حلقه یا recursion
- `factorial(int n)` — با recursion
- `isPrime(int n)` — boolean
- در `main` همه را تست کنید

نمونه:
```
add(3,4)=7, add(1.5,2.5)=4.0
power(2,10)=1024
factorial(5)=120
isPrime(17)=true, isPrime(18)=false
```

## صورت پروژه
پاسخ در `solution/Calculator.java` — از overloading و recursion استفاده کنید.
