# تمرین‌های جلسه ۱۳ — Varargs و Args

## آسان
1. `main` بنویسید که `args` را بگیرد و تعداد و محتوایش را چاپ کند.
2. متد `print(String... words)` بنویسید که همه را با فاصله چاپ کند.

## متوسط
3. متد `sum(int... nums)` بنویسید که مجموع آرگومان‌ها را برگرداند.
4. متد `log(String level, String... msgs)` با ترکیب پارامتر + varargs بنویسید.

## سخت
5. با `args` یک برنامه بنویسید که نام فایل و چند کلمه را بگیرد و خلاصه چاپ کند.
6. overload `print` برای `int...` و `String...` بسازید و ambiguity را تست کنید.
