# پروژهٔ جلسه ۱۳ — ماشین‌حساب آرگومان‌ها

یک برنامه بنویسید که:
- از `args` چند عدد بگیرد (`java Sum 1 2 3 4 5`)
- مجموع، میانگین، بیشترین و کمترین را با `varargs` متد حساب کند
- اگر آرگومان نبود پیام usage بدهد

نمونه:
```
java Sum 10 20 30
Sum: 60, Avg: 20.0, Max: 30, Min: 10
```

## صورت پروژه
پاسخ در `solution/SumArgs.java` — از `int... nums` و `DoubleStream` یا حلقه استفاده کنید.
