# پروژهٔ جلسه ۱۱ — فرم ثبت‌نام

یک فرم ثبت‌نام کنسولی بنویسید که:
- نام (String)، سن (int)، قد (double) بگیرد
- ایمیل را با `next()` بگیرد و چک کند `@` دارد
- با `printf` خروجی قالب‌دار چاپ کند
- اگر ورودی نامعتبر بود پیام خطا بدهد

نمونه:
```
Name: Ali
Age: 20
Height: 1.75
Email: ali@mail.com
---
Name: Ali, Age: 20, Height: 1.75m, Email: ali@mail.com
```

پاسخ در `solution/SignupForm.java` — از `Scanner` و `printf` استفاده کنید.
