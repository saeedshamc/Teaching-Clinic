# تمرین‌های جلسه ۱۱ — ورودی/خروجی کنسول

## آسان
1. `System.out.printf` را با `%d`, `%s`, `%.2f` تست کنید.
2. با `Scanner` نام و سن کاربر را بگیرید و چاپ کنید.

## متوسط
3. برنامه‌ای بنویسید که سه عدد بگیرد و میانگین را با `%.2f` چاپ کند.
4. تلهٔ `nextInt`+`nextLine` را بازتولید کنید و با `sc.nextLine()` اضافی رفعش کنید.

## سخت
5. با `hasNextInt()` قبل از `nextInt()` چک کنید که ورودی عدد است؛ اگر نیست پیام خطا بدهید.
6. یک جدول با `printf` چاپ کنید — نام، سن، نمره با ستون‌های aligned.
