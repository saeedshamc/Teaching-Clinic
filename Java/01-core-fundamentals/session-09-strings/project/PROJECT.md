# پروژهٔ جلسه ۰۹ — شمارندهٔ کلمات

برنامه‌ای بنویسید که:
- یک رشتهٔ چندکلمه‌ای بگیرد (مثلاً "Ali Rezaei is a student")
- تعداد کلمات را بشمارد
- طول هر کلمه را چاپ کند
- با `StringBuilder` کلمات را برعکس چاپ کند

نمونه:
```
Words: 5
Word 1: Ali (3)
...
Reversed: student a is Rezaei Ali
```

## صورت پروژه
پاسخ در `solution/WordCounter.java` — از `split(" ")` برای کلمات و `StringBuilder` برای reverse استفاده کنید.
