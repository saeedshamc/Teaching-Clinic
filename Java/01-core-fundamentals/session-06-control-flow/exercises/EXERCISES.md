# تمرین‌های جلسه ۰۶ — کنترل جریان

## آسان
1. با `if/else` برنامه‌ای بنویسید که عدد را مثبت/منفی/صفر تشخیص دهد.
2. با `switch` نام روز هفته (رشته) را به معادل فارسی چاپ کنید.

## متوسط
3. با `switch expression` یک ماشین‌حساب ساده (`+ - * /`) روی دو عدد بنویسید.
4. با early return تابعی بنویسید که اگر ورودی null یا خالی بود return کند.

## سخت
5. switch کلاسیک با `break` و fall-through را عمداً بسازید تا ببینید چه اتفاقی می‌افتد، بعد با arrow syntax معادلش را بنویسید.
6. یک enum (مقدماتی) بسازید و روی آن switch کنید — فاز ۲ enum را عمیق می‌کنیم.
