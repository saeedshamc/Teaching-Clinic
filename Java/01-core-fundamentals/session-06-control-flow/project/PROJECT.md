# پروژهٔ جلسه ۰۶ — سیستم نمره‌دهی

یک سیستم نمره‌دهی بنویسید که:
- نمرهٔ ۰ تا ۱۰۰ را بگیرد
- با `if/else if` معادل حرفی (A/B/C/D/F) را چاپ کند
- با `switch` پیام مناسب هر grade را بدهد
- اگر نمره خارج از بازه بود پیام خطا بدهد

نمونه:
```
score=95 → A → Excellent!
score=75 → C → Average
score=40 → F → Failed
score=105 → Error: invalid score
```

## صورت پروژه
پاسخ در `solution/GradeSystem.java` — از `Scanner` برای ورودی استفاده کنید (جلسهٔ ۱۱ جزئیات بیشتری دارد).
