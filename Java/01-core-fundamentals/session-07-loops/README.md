- حلقهٔ پیشرفته `for-each` را بشناسید (آرایه/کالکشن — جلسهٔ ۰۸)

## درس

### for

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);   // 0 1 2 3 4
}
```
سه بخش: `init` (یک‌بار) → `condition` (هر تکرار) → `update` (هر تکرار بعد از بدنه).

### while

```java
int n = 0;
while (n < 5) {
    System.out.println(n);
    n++;
}
```
- شرط قبل از هر تکرار چک می‌شود؛ اگر از اول false باشد هیچ‌وقت اجرا نمی‌شود.

### do-while

```java
int n = 0;
do {
    System.out.println(n);
    n++;
} while (n < 5);
```
- بدنه **حداقل یک‌بار** اجرا می‌شود، بعد شرط چک می‌شود — برای وقتی مطمئن نیستید چند بار باید اجرا شود.

### break و continue

```java
for (int i = 0; i < 10; i++) {
    if (i == 3) continue;   // این تکرار را رد کن، برو بعدی
    if (i == 7) break;      // از حلقه خارج شو
    System.out.println(i);  // 0 1 2 4 5 6
}
```

### حلقهٔ تو در تو (nested)

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.print(i * j + "\t");
    }
    System.out.println();
}
// جدول ضرب ۳×۳
```

### الگوهای رایج
- شمارنده: `for (int i = 0; i < n; i++)`
- معکوس: `for (int i = n - 1; i >= 0; i--)`
- گام دلخواه: `for (int i = 0; i < 100; i += 10)`
- روی آرایه: `for-each` (جلسهٔ ۰۸) یا index loop

## کد مهم

`src/LoopsDemo.java` — هر سه حلقه، break/continue، nested loop، الگوهای پرکاربرد.

## خطاهای رایج
- **حلقهٔ بی‌نهایت**: فراموش کردن `i++` یا شرط همیشه true.
- `while` که شرطش به متغیر داخل بدنه وابسته است ولی به‌روز نمی‌شود.
- `break` در `if` داخل حلقه → فقط از if خارج می‌شود نه حلقه (مفید است!).
- `for` روی `int` در Java نسخهٔ قدیمی `for (int i : arr)` نیست — آن for-each است.

## جمع‌بندی
- `for` برای شمارنده مشخص، `while` برای شرط پویا، `do-while` برای حداقل یک‌بار.
- `break` خروج، `continue` پرش به تکرار بعد.
- حلقهٔ تو در تو برای جدول‌ها و گریدها.

**جلسهٔ بعد:** آرایه‌ها (Arrays).
