# پروژهٔ جلسه ۰۷ — شمارش معکوس موشک

برنامه‌ای بنویسید که:
- عدد را از `args[0]` بگیرد (مثلاً ۱۰)
- با `for` معکوس از آن عدد تا ۱ بشمارد و هر عدد را چاپ کند
- بعد از ۱ بنویسد "Liftoff!"
- اگر عدد نامعتبر بود پیام خطا بدهد

نمونه:
```
java Countdown 5
5
4
3
2
1
Liftoff!
```

## صورت پروژه
پاسخ در `solution/Countdown.java` — از `Integer.parseInt(args[0])` برای تبدیل رشته به عدد استفاده کنید.
