# تمرین‌های جلسه ۰۷ — حلقه‌ها

## آسان
1. با `for` اعداد ۱ تا ۱۰ را چاپ کنید.
2. با `while` فاکتوریل عدد ۵ را حساب کنید (120).

## متوسط
3. با `do-while` عدد را آن‌قدر تقسیم بر ۲ کنید تا فرد شود و تعداد تقسیم‌ها را چاپ کنید.
4. جدول ضرب ۱۰×۱۰ را با nested loop چاپ کنید.

## سخت
5. برنامه‌ای بنویسید که اعداد اول ۱ تا ۱۰۰ را با `for` و `break`/`continue` پیدا کند.
6. الگویFizzBuzz: برای ۱ تا ۳۰ چاپ کنید — ۳ بخش‌پذیر بر ۳ "Fizz"، بر ۵ "Buzz"، بر ۱۵ "FizzBuzz"، وگرنه عدد.
