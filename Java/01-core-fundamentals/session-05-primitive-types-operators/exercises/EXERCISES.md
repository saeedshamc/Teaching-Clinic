# تمرین‌های جلسه ۰۵ — تایپ‌ها و عملگرها

## آسان
1. `int x = 7, y = 2` را تعریف کنید و `x/y` و `x/(double)y` را چاپ کنید — تفاوت را توضیح دهید.
2. با عملگرهای `&&` و `||` نتیجهٔ `true && false || true` را حساب و چاپ کنید.

## متوسط
3. برنامه‌ای بنویسید که با `%` فرد یا زوج بودن عدد را تشخیص دهد.
4. با `<<` و `>>` عدد ۱ را ۳ بار شیفت دهید و نتیجه را چاپ کنید (باید ۸ شود).

## سخت
5. بدون if، با عملگر بیتی `&` و mask چک کنید آیا عدد زوج است یا نه.
6. تقدم عملگرها را با `1 + 2 * 3 == 7` و `(1 + 2) * 3 == 9` تست کنید و توضیح دهید.
