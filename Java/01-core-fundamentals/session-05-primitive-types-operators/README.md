## درس

### تایپ‌های primitive

| تایپ | اندازه | بازه | مثال |
|---|---|---|---|
| `byte` | ۸-bit | -128..127 | `byte b = 100;` |
| `short` | ۱۶-bit | -32768..32767 | `short s = 1000;` |
| `int` | ۳۲-bit | ±2.1 میلیارد | `int age = 25;` |
| `long` | ۶۴-bit | خیلی بزرگ | `long big = 9_000_000_000L;` |
| `float` | ۳۲-bit | اعشار | `float f = 1.5f;` |
| `double` | ۶۴-bit | اعشار | `double d = 19.99;` |
| `char` | ۱۶-bit | یک کاراکتر | `char c = 'A';` |
| `boolean` | — | true/false | `boolean ok = true;` |

نکته: `byte`/`short` فقط برای پس‌انداز حافظه در آرایه‌های بزرگ — در محاسبات معمول `int`/`double` کافی است.

### Boxing / Unboxing (مرور — فاز ۲ عمیق می‌شود)
```java
Integer boxed = 42;        // boxing: int → Integer
int unboxed = boxed;       // unboxing: Integer → int
```

### عملگرهای حسابی
`+ - * / %` — برای int تقسیم صحیح است (`7/2=3`)، برای double اعشاری (`7.0/2=3.5`).

### عملگرهای مقایسه‌ای
`== != < > <= >=` — نتیجه boolean.
`===` در Java وجود ندارد (برخلاف JS).

### عملگرهای منطقی
`&&` (AND)، `||` (OR)، `!` (NOT) — short-circuit: اگر `false && x` باشد x ارزیابی نمی‌شود.

### عملگرهای بیتی
`& | ^ ~ << >> >>>` — روی bitها کار می‌کنند؛ برای flag و رمزنگاری (فاز ۱۰).

### عملگرهای compound و increment
```java
int x = 10;
x += 5;      // x = x + 5  → 15
x++;         // x = x + 1  → 16
++x;         // همان ولی prefix (در عبارت تفاوت دارد)
x *= 2;      // *=، -=، /=، %= هم همین‌طور
```

### تقدم عملگرها (مهم‌ترین‌ها)
`()` → `++/--` → unary → `* / %` → `+ -` → shift → relational → equality → `&` → `^` → `|` → `&&` → `||` → ternary → assignment.

## خطاهای رایج
- `7 / 2 = 3` نه `3.5` — اگر اعشار می‌خواهید `7.0 / 2`.
- `=` (assign) با `==` (compare) اشتباه.
- `boolean` نمی‌تواند عدد باشد و `int` نمی‌تواند boolean.
- `char` با `""` (double quote) → رشته است نه char.
