# پروژهٔ جلسه ۰۵ — ماشین‌حساب ساده

یک ماشین‌حساب بنویسید که:
- دو عدد `double` و یک عملگر (`+ - * /`) از `args` بگیرد
- نتیجه را چاپ کند
- اگر تقسیم بر صفر شد `Infinity` یا خطای مناسب بدهد
- از `%` برای باقیمانده هم پشتیبانی کند

نمونه اجرا:
```bash
java Calc 10 3 +    → 13.0
java Calc 10 3 /    → 3.3333333333333335
java Calc 10 3 %    → 1.0
```

## صورت پروژه
پاسخ در `solution/Calc.java` — از `Double.parseDouble(args[0])` برای تبدیل رشته به عدد استفاده کنید.
