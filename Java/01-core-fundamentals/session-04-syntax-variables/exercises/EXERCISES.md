# تمرین‌های جلسه ۰۴ — ساختار فایل و متغیرها

## آسان
1. یک فایل `Basics.java` بسازید که سه متغیر `int`، `double`، `String` تعریف و چاپ کند.
2. نام متغیرها را با camelCase بنویسید و خروجی را با `+` بسازید.

## متوسط
3. یک کلاس با `static final double PI = 3.14159` و متدی که مساحت دایره حساب کند بنویسید.
4. عمداً `class MyClass` را در فایل `WrongName.java` بگذارید و خطا را بخوانید.

## سخت
5. یک فایل با `package com.yourname.demo` بسازید و مسیر پوشهٔ آن را درست کنید؛ با `javac -d out` کامپایل و با نام کامل اجرا کنید.
