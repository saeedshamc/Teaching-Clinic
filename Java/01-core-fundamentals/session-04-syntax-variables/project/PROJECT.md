# پروژهٔ جلسه ۰۴ — کارت دانش‌آموز

یک کلاس `StudentCard` بسازید که:
- فیلدهای `firstName`، `lastName`، `age`، `gpa` را داشته باشد
- یک ثابت `MAX_AGE = 100` تعریف کند
- متد `print()` داشته باشد که اطلاعات را چاپ کند
- در `main` یک نمونه بسازید و صدا بزنید

## صورت پروژه
خروجی نمونه:
```
Student: Ali Ahmadi, age=20, gpa=17.5
```
پاسخ در `solution/StudentCard.java`.
