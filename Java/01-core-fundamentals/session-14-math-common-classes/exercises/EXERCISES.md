# تمرین‌های جلسه ۱۴ — Math و کلاس‌های رایج

## آسان
1. `Math.max`, `Math.min`, `Math.abs` را با چند مقدار تست کنید.
2. `Random.nextInt(100)` را ۱۰ بار صدا بزنید و محدوده را چک کنید.

## متوسط
3. با `BigInteger` فاکتوریل ۵۰ را حساب کنید (بزرگ‌تر از long).
4. با `BigDecimal` قیمت + مالیات ۹٪ را حساب کنید.

## سخت
5. برنامه‌ای بنویسید که ۱۰۰ عدد تصادفی ۱ تا ۱۰۰ بسازد و بیشترین/کمترین/میانگین را حساب کند.
6. با `Calendar` ۳۰ روز بعد از امروز را چاپ کنید.
