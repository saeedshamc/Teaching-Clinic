# پروژهٔ جلسه ۰۸ — دفترچهٔ نمرات

یک آرایهٔ دوبعدی `grades[5][3]` بسازید که:
- ۵ دانش‌آموز × ۳ نمره داشته باشد
- میانگین هر دانش‌آموز را حساب و چاپ کند
- بیشترین میانگین را پیدا کند
- با `Arrays.sort` نمرات هر دانش‌آموز را مرتب کنید

نمونه خروجی:
```
Student 0 avg=17.0
Student 1 avg=15.5
...
Top student: 0 with avg 18.3
```

## صورت پروژه
پاسخ در `solution/GradeBook.java` — از آرایهٔ `double[][]` استفاده کنید و `Arrays.stream` برای میانگین (یا حلقهٔ ساده).
