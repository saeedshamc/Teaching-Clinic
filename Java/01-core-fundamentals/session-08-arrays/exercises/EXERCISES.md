# تمرین‌های جلسه ۰۸ — آرایه‌ها

## آسان
1. آرایه‌ای از ۵ عدد بسازید و مجموع آن‌ها را با `for` حساب کنید.
2. آرایه‌ای از نام‌ها بسازید و با `for-each` چاپ کنید.

## متوسط
3. آرایهٔ دوبعدی ۳×۳ بسازید و قطر اصلی (i==j) را چاپ کنید.
4. با `Arrays.sort` آرایه را مرتب و با `binarySearch` یک عنصر را پیدا کنید.

## سخت
5. آرایهٔ دو بعدی نامنظم ( ragged ) بسازید — هر سطر طول متفاوت — و مجموع هر سطر را چاپ کنید.
6. با `Arrays.copyOf` آرایه را کپی و سپس در کپی تغییر دهید؛ مطمئن شوید آرایهٔ اصلی تغییر نکرده.
