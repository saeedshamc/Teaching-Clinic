# تمرین‌های جلسه ۱۵ — Capstone فاز ۱

## آسان
1. به `GradeManager` قابلیت «حذف دانش‌آموز با id» اضافه کنید.
2. تعداد دانش‌آموزان و میانگین کلی کلاس را چاپ کنید.

## متوسط
3. با `Scanner` به‌جای دادهٔ ثابت، دانش‌آموزان را از کاربر بگیرید.
4. فیلتر کنید — فقط دانش‌آموزانی که میانگین بالای ۱۴ دارند را نشان دهید.

## سخت
5. با `Arrays.sort` و `Comparator` (بعداً فاز ۲) مرتب‌سازی را حرفه‌ای‌تر کنید.
6. خروجی را به فایل `report.txt` هم بنویسید (File I/O در فاز ۳).
