# پروژهٔ جلسه ۱۵ — سیستم نمره‌دهی کامل

یک سیستم کنسولی کامل بسازید که:
- [ ] دانش‌آموز اضافه کند (نام، id، ۵ نمره)
- [ ] لیست را با میانگین و grade حرفی نشان دهد
- [ ] بر اساس میانگین مرتب کند
- [ ] دانش‌آموز را با نام/id جستجو کند
- [ ] آمار کلی کلاس را چاپ کند
- [ ] خروجی جدول‌وار با `printf` باشد

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/GradeManager.java` را گسترش دهید یا نسخهٔ کامل‌تری بنویسید.
