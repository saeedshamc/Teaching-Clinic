# تمرین‌های جلسه ۱۲۹ — Testing Capstone

## آسان
1. `UserService` با business logic بسازید.
2. `UserServiceTest` با Mockito برای unit tests بنویسید.

## متوسط
3. `UserControllerTest` با `@WebMvcTest` برای MVC slice tests بنویسید.
4. `UserRepositoryTest` با `@DataJpaTest` برای JPA slice tests بنویسید.

## سخت
5. `UserIntegrationTest` با `@SpringBootTest` برای full integration tests بنویسید.
6. `TestRestTemplate` برای HTTP testing استفاده کنید.
