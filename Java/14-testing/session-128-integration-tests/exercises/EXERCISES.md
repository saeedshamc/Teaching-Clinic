# تمرین‌های جلسه ۱۲۸ — Integration Tests

## آسان
1. `@SpringBootTest` برای full context integration test استفاده کنید.
2. `TestRestTemplate` برای HTTP testing استفاده کنید.

## متوسط
3. `@DataJpaTest` برای JPA slice test استفاده کنید.
4. `@WebMvcTest` برای MVC slice test استفاده کنید.

## سخت
5. `MockMvc` برای controller testing استفاده کنید.
6. `@MockBean` برای mocking in slice tests استفاده کنید.
