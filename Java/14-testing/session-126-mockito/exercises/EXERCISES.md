# تمرین‌های جلسه ۱۲۶ — Mockito

## آسان
1. `@Mock` و `@InjectMocks` برای dependencies استفاده کنید.
2. `when().thenReturn()` برای stub behavior استفاده کنید.

## متوسط
3. `verify()` برای verify interactions استفاده کنید.
4. `doReturn`/`doThrow` برای void methods استفاده کنید.

## سخت
5. `ArgumentMatchers` برای flexible matching استفاده کنید.
6. `@Spy` برای partial mocking استفاده کنید.
