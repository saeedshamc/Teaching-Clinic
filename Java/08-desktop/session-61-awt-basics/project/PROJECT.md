# پروژهٔ جلسه ۶۱ — ماشین‌حساب ساده AWT

یک ماشین‌حساب ساده بسازید که:
- `TextField` برای نمایش نتیجه
- `Button` برای اعداد ۰-۹ و عملیات +,-,*,/
- `ActionListener` برای هر دکمه
- `GridLayout` برای چیدمان
- در `main` برنامه را اجرا کنید

نمونه:
```
[7] [+] [2] [=] → 9
```

## صورت پروژه
پاسخ در `solution/CalculatorAWT.java` — از AWT و GridLayout استفاده کنید.
