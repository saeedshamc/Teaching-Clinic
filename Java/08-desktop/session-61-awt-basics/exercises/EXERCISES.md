# تمرین‌های جلسه ۶۱ — AWT Basics

## آسان
1. `Frame` با `Button` بسازید — `setSize`, `setVisible` را استفاده کنید.
2. `Label` و `TextField` اضافه کنید.

## متوسط
3. `FlowLayout`, `BorderLayout`, `GridLayout` را تست کنید.
4. `ActionListener` با lambda برای Button استفاده کنید.

## سخت
5. `WindowAdapter` برای close event استفاده کنید.
6. `Checkbox` با `ItemListener` تست کنید.
