# تمرین‌های جلسه ۶۷ — JavaFX Setup

## آسان
1. `Application` را extend کنید و `start(Stage)` را override کنید.
2. `VBox` با `Label` و `Button` بسازید.

## متوسط
3. `Scene` و `Stage` را برای نمایش app استفاده کنید.
4. `setOnAction` برای Button event استفاده کنید.

## سخت
5. `HBox` و `BorderPane` را برای layout تست کنید.
6. CSS-like styling با `setStyle` استفاده کنید.
