# پروژهٔ جلسه ۶۷ — Hello JavaFX

یک برنامهٔ JavaFX ساده بسازید که:
- `VBox` با `Label`, `Button`, `TextField`
- `Button` برای تغییر text label
- `TextField` برای input
- `setStyle` برای basic styling
- در `main` اجرا کنید

نمونه:
```
[Welcome to JavaFX]
[TextField: _____]
[Button: Greet]
→ "Hello, Ali!"
```

## صورت پروژه
پاسخ در `solution/HelloJavaFX.java` — از JavaFX controls استفاده کنید.
