# پروژهٔ جلسه ۷۲ — دانلود فایل با Progress

یک سیستم دانلود فایل شبیه‌سازی‌شده بسازید که:
- `Task` برای download simulation
- `ProgressBar` برای progress
- `Label` برای status
- `Button` برای start/cancel
- `Platform.runLater` برای UI updates
- `Service` برای reusable download

نمونه:
```
[Download file.zip...]
[ProgressBar: ████████░░ 80%]
[Status: Downloading... 8/10]
```

## صورت پروژه
پاسخ در `solution/DownloadApp.java` — از Task و ProgressBar استفاده کنید.
