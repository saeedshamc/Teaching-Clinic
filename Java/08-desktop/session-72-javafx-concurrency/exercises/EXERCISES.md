# تمرین‌های جلسه ۷۲ — JavaFX Concurrency

## آسان
1. `Task` با `updateProgress` و `updateMessage` بسازید.
2. `Platform.runLater` برای UI update از background استفاده کنید.

## متوسط
3. `Service` برای reusable task استفاده کنید.
4. `ExecutorService` برای multiple async tasks استفاده کنید.

## سخت
5. `CompletableFuture` با `Platform.runLater` برای async chain استفاده کنید.
6. `Task` با exception handling (`setOnFailed`) استفاده کنید.
