# تمرین‌های جلسه ۶۴ — Swing Events

## آسان
1. `JButton` با `ActionListener` lambda بسازید.
2. `JCheckBox` با `ItemListener` تست کنید.

## متوسط
3. `MouseAdapter` برای mouse click/enter/exit استفاده کنید.
4. `KeyAdapter` برای key press/release استفاده کنید.

## سخت
5. `MouseMotionListener` برای mouse drag استفاده کنید.
6. چند listener روی یک component استفاده کنید.
