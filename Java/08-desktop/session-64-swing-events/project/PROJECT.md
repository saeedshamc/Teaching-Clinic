# پروژهٔ جلسه ۶۴ — ماشین‌حساب با Keyboard Events

یک ماشین‌حساب بسازید که:
- `JTextField` برای display
- `KeyListener` برای keyboard input (0-9, +, -, *, /, =)
- `ActionListener` برای button click
- `MouseListener` برای clear on right-click
- `GridLayout` برای buttons

نمونه:
```
User types: 5 + 3 = → 8
User clicks: [7] → 7
User right-clicks: → Clear
```

## صورت پروژه
پاسخ در `solution/CalculatorEvents.java` — از keyboard و mouse events استفاده کنید.
