# تمرین‌های جلسه ۷۴ — SWT Basics

## آسان
1. `Display` و `Shell` بسازید — `shell.open()` و event loop را اضافه کنید.
2. `Button` و `Label` اضافه کنید.

## متوسط
3. `GridLayout` برای layout استفاده کنید.
4. `SWT.Selection` listener برای Button استفاده کنید.

## سخت
5. `Composite` برای nested containers استفاده کنید.
6. `Table` یا `Tree` برای complex widgets تست کنید.
