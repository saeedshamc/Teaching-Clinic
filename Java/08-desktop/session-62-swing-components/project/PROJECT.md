# پروژهٔ جلسه ۶۲ — فرم ثبت‌نام Swing

یک فرم ثبت‌نام بسازید که:
- `JTextField` برای نام، ایمیل، رمز
- `JPasswordField` برای رمز
- `JCheckBox` برای terms
- `JButton` برای submit
- `JOptionPane` برای validation و success message
- `GridLayout` برای چیدمان

نمونه:
```
Name: [____]
Email: [____]
Password: [____]
☐ I agree to terms
[Submit]
→ "Registration successful!"
```

## صورت پروژه
پاسخ در `solution/RegistrationForm.java` — از Swing و JOptionPane استفاده کنید.
