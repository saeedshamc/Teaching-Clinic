# تمرین‌های جلسه ۶۲ — Swing Components

## آسان
1. `JFrame` با `JPanel` و `JButton` بسازید.
2. `SwingUtilities.invokeLater` را برای EDT استفاده کنید.

## متوسط
3. `JLabel`, `JTextField`, `JCheckBox`, `JComboBox` را اضافه کنید.
4. `JOptionPane.showMessageDialog` برای پیام استفاده کنید.

## سخت
5. `JOptionPane.showConfirmDialog` برای تأیید استفاده کنید.
6. `JOptionPane.showInputDialog` برای ورودی استفاده کنید.
