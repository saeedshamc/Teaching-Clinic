# پروژهٔ جلسه ۶۶ — سیستم مدیریت وظایف کامل

یک سیستم مدیریت وظایف کامل بسازید که:
- [ ] `Task` model با همهٔ فیلدها
- [ ] `JTable` برای نمایش
- [ ] `JTree` برای filter بر اساس priority
- [ ] `JTabbedPane` برای All/Pending/Completed
- [ ] `JTextField`/`JTextArea` برای افزودن
- [ ] `JComboBox` برای priority
- [ ] `JButton` برای add/complete/delete
- [ ] `LocalDate` برای due date
- [ ] sort بر اساس due date

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/TaskManagerDemo.java` را گسترش دهید.
