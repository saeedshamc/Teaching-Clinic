# تمرین‌های جلسه ۶۶ — Swing Capstone

## آسان
1. `Task` model با id, title, priority, status بسازید.
2. `DefaultTableModel` برای نمایش وظایف استفاده کنید.

## متوسط
3. `addTask`, `completeTask`, `deleteTask` را پیاده کنید.
4. `JTree` برای filter بر اساس priority استفاده کنید.

## سخت
5. `JTabbedPane` برای All/Pending/Completed tabs اضافه کنید.
6. `dueDate` را با `LocalDate` و sort بر اساس آن اضافه کنید.
