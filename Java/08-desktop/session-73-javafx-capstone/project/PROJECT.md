# پروژهٔ جلسه ۷۳ — سیستم مدیریت مخاطبین JavaFX کامل

یک سیستم مدیریت مخاطبین کامل بسازید که:
- [ ] `Contact` model با Property fields
- [ ] `TableView` با `TableColumn` و `ObservableList`
- [ ] `BorderPane` برای ساختار اصلی
- [ ] `VBox` برای form
- [ ] `HBox` برای toolbar
- [ ] `ComboBox` برای category
- [ ] `PieChart` برای statistics
- [ ] `Button` برای add/delete/search
- [ ] `Task` برای async operations
- [ ] CSS styling

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/ContactManagerFX.java` را گسترش دهید.
