# تمرین‌های جلسه ۶۹ — JavaFX Layout و FXML

## آسان
1. `VBox`, `HBox`, `BorderPane` را برای layout استفاده کنید.
2. `GridPane` با `setHgap`/`setVgap` برای form بسازید.

## متوسط
3. `Hgrow`/`Vgrow` را برای responsive layout استفاده کنید.
4. FXML file با `BorderPane` و `fx:controller` بسازید.

## سخت
5. `LoginController` با `@FXML` fields و `handleLogin` بنویسید.
6. `FlowPane` برای dynamic layout استفاده کنید.
