# پروژهٔ جلسه ۶۹ — داشبورد JavaFX با FXML

یک داشبورد JavaFX بسازید که:
- `BorderPane` برای ساختار اصلی
- `VBox` برای sidebar
- `GridPane` برای form
- `HBox` برای toolbar
- FXML file برای UI definition
- `Controller` برای logic
- `Hgrow`/`Vgrow` برای responsive

نمونه:
```
[Header — HBox]
[Sidebar | Content — GridPane]
[Footer — HBox]
```

## صورت پروژه
پاسخ در `solution/` — FXML + Controller + Main.
