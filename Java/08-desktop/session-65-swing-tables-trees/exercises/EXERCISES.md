# تمرین‌های جلسه ۶۵ — Swing Tables و Trees

## آسان
1. `JTable` با `DefaultTableModel` و چند row بسازید.
2. `JTree` با `DefaultMutableTreeNode` بسازید.

## متوسط
3. `model.addRow()` و `model.removeRow()` را تست کنید.
4. `TreeSelectionListener` برای انتخاب node استفاده کنید.

## سخت
5. `TableModelListener` برای track کردن تغییرات استفاده کنید.
6. `JTree` با `DefaultTreeModel` برای dynamic updates استفاده کنید.
