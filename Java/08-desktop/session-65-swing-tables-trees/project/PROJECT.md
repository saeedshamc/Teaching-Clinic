# پروژهٔ جلسه ۶۵ — سیستم مدیریت مخاطبین

یک سیستم مدیریت مخاطبین بسازید که:
- `JTable` برای نمایش مخاطبین (name, phone, email)
- `JTree` برای دسته‌بندی (Friends, Family, Work)
- `DefaultTableModel` برای editable table
- `TreeSelectionListener` برای filter کردن table بر اساس category
- `JButton` برای add/remove contact

نمونه:
```
[Tree: Friends | Family | Work]
[Table: Name | Phone | Email]
```

## صورت پروژه
پاسخ در `solution/ContactManager.java` — از JTable و JTree استفاده کنید.
