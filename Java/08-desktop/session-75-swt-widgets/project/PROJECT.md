# پروژهٔ جلسه ۷۵ — سیستم مدیریت داده SWT

یک سیستم مدیریت داده SWT بسازید که:
- `Table` برای نمایش داده‌ها
- `Tree` برای دسته‌بندی
- `TabFolder` برای tabs (Data, Settings, Help)
- `Menu` برای menu bar (File, Edit, Help)
- `GridData` برای responsive layout
- `Text`, `Combo`, `Button` برای form

نمونه:
```
[Menu: File | Edit | Help]
[TabFolder: Data | Settings | Help]
[Table: Name | Phone | Email]
[Tree: Categories]
```

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/SWTWidgetsDemo.java` را گسترش دهید.
