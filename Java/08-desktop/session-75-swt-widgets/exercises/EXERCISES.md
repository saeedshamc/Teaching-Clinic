# تمرین‌های جلسه ۷۵ — SWT Widgets

## آسان
1. `Table` با `TableColumn` و `TableItem` بسازید.
2. `Tree` با `TreeItem` برای hierarchy بسازید.

## متوسط
3. `TabFolder` با چند `TabItem` بسازید.
4. `Menu` با `MenuItem` برای menu bar بسازید.

## سخت
5. `GridData` با `grabExcessHorizontalSpace` برای responsive layout استفاده کنید.
6. `SWT` widgets را با event listeners ترکیب کنید.
