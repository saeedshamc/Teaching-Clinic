# پروژهٔ جلسه ۷۰ — سیستم drag & drop با CSS

یک سیستم drag & drop بسازید که:
- `ListView` برای source items
- `ListView` برای target items
- `setOnDragDetected` برای drag start
- `setOnDragOver` و `setOnDrop` برای drop target
- CSS styling برای visual feedback
- `getStyleClass` برای dynamic styling

نمونه:
```
[Available items] → drag → [Selected items]
Item 1 → Selected: Item 1
```

## صورت پروژه
پاسخ در `solution/DragDropDemo.java` — از drag & drop و CSS استفاده کنید.
