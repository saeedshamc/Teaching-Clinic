# تمرین‌های جلسه ۷۰ — JavaFX Events و CSS

## آسان
1. `setOnAction` برای Button استفاده کنید.
2. `setStyle` برای inline CSS استفاده کنید.

## متوسط
3. `getStyleClass().add("class")` برای CSS class استفاده کنید.
4. `:hover` و `:pressed` pseudo-classes را در CSS file تست کنید.

## سخت
5. Drag & Drop را با `startDragAndDrop` و `setOnDrop` پیاده کنید.
6. `addEventFilter` را برای intercept کردن event قبل از handler استفاده کنید.
