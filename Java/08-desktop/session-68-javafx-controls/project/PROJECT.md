# پروژهٔ جلسه ۶۸ — فرم ثبت‌نام JavaFX

یک فرم ثبت‌نام بسازید که:
- `TextField` برای نام، ایمیل
- `PasswordField` برای رمز
- `CheckBox` برای terms
- `ComboBox` برای country
- `ListView` برای نمایش registered users
- `Button` برای submit
- `ObservableList` برای users

نمونه:
```
Name: [____] Email: [____]
Password: [____]
☐ Terms | Country: [Iran ▼]
[Submit]
Registered users:
- Ali (ali@mail.com)
```

## صورت پروژه
پاسخ در `solution/RegistrationJavaFX.java` — از JavaFX controls و ObservableList استفاده کنید.
