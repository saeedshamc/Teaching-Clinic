# تمرین‌های جلسه ۶۸ — JavaFX Controls

## آسان
1. `TextField`, `PasswordField`, `CheckBox` را اضافه کنید.
2. `ComboBox` با چند option بسازید.

## متوسط
3. `ListView` با `ObservableList` بسازید.
4. `setOnAction` برای Button استفاده کنید.

## سخت
5. `selectedProperty().addListener` برای CheckBox استفاده کنید.
6. `getSelectionModel().selectedItemProperty()` برای ListView استفاده کنید.
