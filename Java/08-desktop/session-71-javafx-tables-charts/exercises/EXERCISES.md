# تمرین‌های جلسه ۷۱ — JavaFX Tables و Charts

## آسان
1. `TableView` با `TableColumn` و `ObservableList` بسازید.
2. `PieChart` با چند `PieChart.Data` بسازید.

## متوسط
3. `BarChart` با `XYChart.Series` بسازید.
4. `LineChart` با چند series بسازید.

## سخت
5. `TableView` با editable cells (`setCellFactory`) استفاده کنید.
6. `Chart` را با dynamic data update کنید.
