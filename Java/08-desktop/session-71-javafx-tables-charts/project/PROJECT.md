# پروژهٔ جلسه ۷۱ — داشبورد آماری JavaFX

یک داشبورد آماری بسازید که:
- `TableView` برای داده‌های خام
- `PieChart` برای distribution
- `BarChart` برای مقایسه
- `LineChart` برای trend
- `ObservableList` برای dynamic data
- چند `XYChart.Series` برای مقایسه

نمونه:
```
[Table: Product | Sales | Profit]
[PieChart: Market share]
[BarChart: Sales by region]
[LineChart: Monthly trend]
```

## صورت پروژه
پاسخ در `solution/StatsDashboard.java` — از TableView و Charts استفاده کنید.
