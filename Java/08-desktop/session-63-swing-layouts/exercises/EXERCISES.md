# تمرین‌های جلسه ۶۳ — Swing Layouts

## آسان
1. `BorderLayout` با NORTH/SOUTH/EAST/WEST/CENTER بسازید.
2. `FlowLayout` با چند button بسازید.

## متوسط
3. `GridLayout(3,3)` برای calculator buttons استفاده کنید.
4. `BoxLayout` با `Y_AXIS` و `createVerticalGlue` استفاده کنید.

## سخت
5. `CardLayout` برای tab-like panels استفاده کنید.
6. nested panels برای complex layout بسازید.
