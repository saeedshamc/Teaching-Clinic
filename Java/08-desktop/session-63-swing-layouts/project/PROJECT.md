# پروژهٔ جلسه ۶۳ — داشبورد با Layoutهای مختلف

یک داشبورد بسازید که:
- `BorderLayout` برای ساختار اصلی (header, content, footer)
- `GridLayout` برای statistics cards
- `FlowLayout` برای filters
- `CardLayout` برای tab switching
- `BoxLayout` برای sidebar

نمه:
```
[Header — BorderLayout.NORTH]
[Sidebar | Content | Stats]
[Footer — BorderLayout.SOUTH]
```

## صورت پروژه
پاسخ در `solution/Dashboard.java` — از چند layout استفاده کنید.
