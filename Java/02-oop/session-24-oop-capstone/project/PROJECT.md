# پروژهٔ جلسه ۲۴ — سیستم کتابخانهٔ کامل

یک سیستم کتابخانهٔ کامل بسازید که:
- [ ] کلاس‌های `Book`, `Member`, `Library` با encapsulation
- [ ] enum `BookStatus` برای وضعیت
- [ ] interface `Borrowable`, `Searchable`
- [ ] borrow/return با چک وضعیت
- [ ] جستجو بر اساس عنوان/نویسنده
- [ ] آمار و گزارش
- [ ] حداقل ۵ کتاب و ۳ عضو در دادهٔ نمونه

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/LibrarySystem.java` را گسترش دهید.
