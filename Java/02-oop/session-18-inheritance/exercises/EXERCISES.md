# تمرین‌های جلسه ۱۸ — ارث‌بری

## آسان
1. کلاس `Vehicle` با `speed` و متد `move()` بسازید و `Car` و `Bike` را extends کنید.
2. با `super` سازندهٔ والد را در فرزند صدا بزنید.

## متوسط
3. متد `describe()` را در والد و فرزند override کنید و `super.describe()` را صدا بزنید.
4. کلاس `final` بسازید که نتوان آن را extend کرد — خطا را ببینید.

## سخت
5. سه سطح ارث‌بری (Grandparent → Parent → Child) با override در هر سطح بسازید.
6. `final` روی متد بگذارید و سعی کنید override کنید — compile error را ببینید.
