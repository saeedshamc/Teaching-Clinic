# تمرین‌های جلسه ۲۲ — Enum

## آسان
1. enum `Day` با ۷ روز هفته بسازید و `values()` را چاپ کنید.
2. enum `Direction` با `NORTH, SOUTH, EAST, WEST` و متد `opposite()` بسازید.

## متوسط
3. enum `HttpStatus` با کدها (200, 404, 500) و label بسازید.
4. `valueOf` را با try/catch برای ورودی نامعتبر تست کنید.

## سخت
5. enum با abstract method بسازید — هر مقدار متد متفاوتی دارد (مثل Operation).
6. enum را در switch expression استفاده کنید و نتیجه برگردانید.
