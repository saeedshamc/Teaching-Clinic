# تمرین‌های جلسه ۲۰ — کلاس‌های Abstract

## آسان
1. کلاس `abstract Employee` با `name`, `id` و `abstract double calculateSalary()` بسازید؛ `FullTime` و `PartTime` را پیاده کنید.
2. متد `printDetails()` در abstract class بنویسید که از `calculateSalary()` استفاده کند.

## متوسط
3. Template Method pattern را با `abstract ReportGenerator` پیاده کنید.
4. abstract class با concrete field و method بسازید که فرزند از آن‌ها استفاده کند.

## سخت
5. سه سطح abstract: `abstract Animal` → `abstract Mammal` → `Dog`/`Cat` بسازید.
6. abstract class با `final` template method و abstract hook methods بسازید.
