# تمرین‌های جلسه ۲۱ — Interfaceها

## آسان
1. interface `Flyable` با `fly()` بسازید و `Bird`, `Airplane` را implements کنید.
2. interface `Swimmable` با `swim()` بسازید و `Fish`, `Duck` را implements کنید.

## متوسط
3. کلاس `Duck` که هم `Flyable` هم `Swimmable` را implements کند بسازید.
4. `default` method در interface بنویسید که در کلاس override شود.

## سخت
5. `static` method در interface بنویسید و از بیرون صدا بزنید.
6. polymorphism با interface — آرایه‌ای از `Flyable` بسازید و `fly()` را صدا بزنید.
