# پروژهٔ جلسه ۲۱ — سیستم رسانه‌ها

یک سیستم رسانه بسازید که:
- interface `Playable` با `play()`, `pause()`, `stop()`
- interface `Recordable` با `record()`
- `AudioPlayer`, `VideoPlayer` را implements کنید
- `MediaController` که `Playable` را می‌گیرد و کنترل می‌کند
- در `main` چند رسانه بسازید و کنترل کنید

نمونه:
```
Playing audio: Music.mp3
Paused at 00:30
Stopped
```

## صورت پروژه
پاسخ در `solution/MediaSystem.java` — از interface و polymorphism استفاده کنید.
