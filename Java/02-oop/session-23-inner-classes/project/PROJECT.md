# پروژهٔ جلسه ۲۳ — ماشین‌حساب با inner class

یک ماشین‌حساب بسازید که:
- outer class `Calculator` با فیلد `result`
- inner class `Operation` که به `result` دسترسی دارد
- متدهای `add`, `subtract`, `multiply`, `divide` در inner class
- در `main` چند عملیات انجام دهید و نتیجه را نشان دهید

نمونه:
```
10 + 5 = 15
15 - 3 = 12
```

## صورت پروژه
پاسخ در `solution/Calculator.java` — از inner class برای دسترسی به stateOuter استفاده کنید.
