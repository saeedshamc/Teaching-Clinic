# تمرین‌های جلسه ۲۳ — Inner Classes

## آسان
1. کلاس `Outer` با inner class `Inner` بسازید که به فیلد Outer دسترسی داشته باشد.
2. static nested class بسازید که بدون outer instance ساخته شود.

## متوسط
3. anonymous class برای interface `Runnable` بسازید.
4. local class داخل متد بسازید.

## سخت
5. inner class که به فیلد private Outer دسترسی دارد بسازید.
6. چند anonymous class برای interfaceهای مختلف بسازید.
