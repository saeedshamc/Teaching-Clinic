# پروژهٔ جلسه ۱۹ — سیستم اشکال

یک سیستم اشکال بسازید که:
- کلاس پایهٔ `Shape` با `name` و متد `area()` و `perimeter()`
- `Circle`, `Rectangle`, `Triangle` را extends کنید با override
- آرایه‌ای از `Shape` بسازید و مساحت/محیط هرکدام را چاپ کنید
- با `instanceof` نوع هر شکل را تشخیص دهید و ویژگی خاصش را نشان دهید

نمونه:
```
Circle (r=5): area=78.54, perimeter=31.42
Rectangle (w=4,h=6): area=24.0, perimeter=20.0
Triangle (b=3,h=4): area=6.0, perimeter=12.0
```

## صورت پروژه
پاسخ در `solution/ShapeSystem.java` — از polymorphism و instanceof استفاده کنید.
