# تمرین‌های جلسه ۱۷ — سازنده و Encapsulation

## آسان
1. کلاس `Student` با سه overload سازنده بسازید (نام، نام+سن، نام+سن+نمره).
2. getter/setter برای `name` و `age` با validation بنویسید.

## متوسط
3. کلاس `Wallet` با `balance` (private) و متدهای `addMoney`/`spendMoney` با چک موجودی بسازید.
4. immutable class `Color` با `r`, `g`, `b` (final) بسازید.

## سخت
5. کلاس `Book` با `title`, `author`, `price` بسازید که `price` فقط با متد `setPrice` قابل تغییر باشد و validation داشته باشد.
6. `this()` chaining را با سه سازندهٔ مختلف نشان دهید.
