# تمرین‌های جلسه ۱۶ — کلاس و آبجکت

## آسان
1. کلاس `Book` با فیلدهای `title`, `author`, `price` و متد `display()` بسازید.
2. دو نمونهٔ `Book` بسازید و متد `display()` را صدا بزنید.

## متوسط
3. کلاس `Rectangle` با `width`, `height` و متدهای `area()` و `perimeter()` بسازید.
4. getter/setter با validation برای `age` (۰ تا ۱۵۰) اضافه کنید.

## سخت
5. کلاس `BankAccount` با `balance` (private)، `deposit`، `withdraw` (با چک موجودی) بسازید.
6. آرایه‌ای از ۵ `BankAccount` بسازید و مجموع موجودی‌ها را حساب کنید.
