# پروژهٔ جلسه ۱۶ — سیستم کتابخانهٔ ساده

یک کلاس `LibraryBook` بسازید که:
- فیلدهای `title`, `author`, `isbn`, `available` (boolean) داشته باشد
- متدهای `borrow()` و `returnBook()` با چک وضعیت
- متد `display()` که اطلاعات را چاپ کند
- در `main` ۳ کتاب بسازید، یکی را borrow کنید و وضعیت را نشان دهید

نمونه:
```
Book: Java Guide by Ali — ISBN:123 — Available
After borrow: Not available
After return: Available
```

## صورت پروژه
پاسخ در `solution/LibraryBook.java` — از getter/setter و boolean برای وضعیت استفاده کنید.
