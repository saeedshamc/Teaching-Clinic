# تمرین‌های جلسه ۳۴ — NIO.2 Paths

## آسان
1. `Paths.get` با چند بخش بسازید و `getFileName`, `getParent` را چاپ کنید.
2. `Files.write` و `Files.readAllLines` را تست کنید.

## متوسط
3. `resolve` و `normalize` را با چند مسیر تست کنید.
4. `Files.exists`, `Files.size`, `Files.isDirectory` را چاپ کنید.

## سخت
5. `Files.walk` را برای لیست فایل‌های یک پوشه به‌صورت بازگشتی استفاده کنید.
6. `Files.copy` و `Files.move` را تست کنید.
