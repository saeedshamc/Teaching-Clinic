# پروژهٔ جلسه ۳۴ — جستجوی فایل

یک برنامه بنویسید که:
- یک پوشه را به‌صورت بازگشتی جستجو کند (`Files.walk`)
- فایل‌های `.java` را پیدا کند
- حجم هر فایل را چاپ کند
- بزرگ‌ترین فایل را پیدا کند

نمونه:
```
Found 5 .java files:
- Main.java (2.5 KB)
- Utils.java (1.2 KB)
...
Largest: Main.java (2.5 KB)
```

## صورت پروژه
پاسخ در `solution/FileFinder.java` — از `Files.walk` و `Files.size` استفاده کنید.
