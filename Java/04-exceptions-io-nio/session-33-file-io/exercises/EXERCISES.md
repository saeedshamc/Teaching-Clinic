# تمرین‌های جلسه ۳۳ — File I/O

## آسان
1. `File` بسازید و `exists()`, `length()`, `getName()` را چاپ کنید.
2. با `FileWriter` یک فایل بنویسید و با `FileReader` بخوانید.

## متوسط
3. با `BufferedReader` فایل را خط به خط بخوانید و شماره‌گذاری کنید.
4. با `PrintWriter` و `printf` خروجی قالب‌دار بنویسید.

## سخت
5. لیست فایل‌های یک پوشه را با `listFiles()` بگیرید و حجم هرکدام را چاپ کنید.
6. فایل را append کنید — `FileWriter(file, true)`.
