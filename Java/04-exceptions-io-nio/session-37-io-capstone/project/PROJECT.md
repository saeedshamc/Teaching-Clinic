# پروژهٔ جلسه ۳۷ — سیستم مدیریت فایل کامل

یک سیستم مدیریت فایل کامل بسازید که:
- [ ] لیست فایل‌های `.txt` در پوشه
- [ ] خواندن فایل با شماره‌گذاری خط
- [ ] append به فایل
- [ ] جستجو در همهٔ فایل‌ها
- [ ] آمار فایل (خط/کلمه/کاراکتر)
- [ ] مدیریت خطا با try-with-resources
- [ ] حداقل ۳ فایل `.txt` در دادهٔ نمونه

## صورت پروژه
پاسخ در `solution/` — می‌توانید `src/TextFileManager.java` را گسترش دهید.
