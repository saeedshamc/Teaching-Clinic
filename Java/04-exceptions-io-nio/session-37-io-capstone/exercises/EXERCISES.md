# تمرین‌های جلسه ۳۷ — Capstone IO

## آسان
1. به `TextFileManager` متد `deleteFile` اضافه کنید.
2. متد `renameFile` اضافه کنید.

## متوسط
3. با `Files.walk` فایل‌های `.java` را هم پیدا کنید.
4. آمار کلی همهٔ فایل‌ها (تعداد، حجم کل) را چاپ کنید.

## سخت
5. `Serializable` برای ذخیرهٔ تنظیمات (last directory, filters) اضافه کنید.
6. با `FileChannel` کپی باینری فایل را هم پشتیبانی کنید.
