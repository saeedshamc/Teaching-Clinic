# تمرین‌های جلسه ۳۱ — Exception

## آسان
1. `try-catch` برای `ArithmeticException` (تقسیم بر صفر) بنویسید.
2. `finally` را تست کنید که همیشه اجرا می‌شود.

## متوسط
3. custom exception `InvalidPasswordException` بسازید و در متد `validate` استفاده کنید.
4. `throws` را روی متد بگذارید و در `main` catch کنید.

## سخت
5. چند catch با ترتیب درست (خاص → عمومی) بنویسید.
6. `try-finally` بدون catch بنویسید — exception را دوباره پرتاب کنید.
