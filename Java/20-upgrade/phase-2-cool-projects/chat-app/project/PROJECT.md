# پروژهٔ توسعه — چت پیشرفته

نسخهٔ ترمینال را به این موارد گسترش دهید:

## الزامات
- [ ] **رابط گرافیکی Swing:** `ChatClientGUI` با `JTextArea` (پیام‌ها)، `JTextField` (ورود)، `JList` (کاربران آنلاین)
- [ ] **اتاق‌های متعدد:** سرور اتاق‌ها را مدیریت کند (`/join room1`، `/rooms`)
- [ ] **پیام خصوصی:** `/w username message` — فقط برای یک کاربر
- [ ] **تایپ indication:** وقتی کسی تایپ می‌کند به بقیه «X در حال نوشتن...» برود (اختیاری — نیازمند پیام جداگانه)
- [ ] **سرور چندپورت/HTTPS:** یا حداقل پورت قابل تنظیم با آرگومان

## معیار پذیرش
- حداقل ۳ کلاینت هم‌زمان بدون کرش
- پیام خصوصی واقعاً فقط برای گیرنده برود
- Swing UI بدون فریز (خواندن socket در thread جدا — `SwingWorker`)

## صورت پروژه
پاسخ در `solution/` — پیاده‌سازی کامل.
