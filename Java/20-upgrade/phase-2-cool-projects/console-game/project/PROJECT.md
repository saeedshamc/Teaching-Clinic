# پروژهٔ توسعه — ماجراجویی پیشرفته

نسخهٔ فعلی را به این موارد گسترش دهید:

## الزامات
- [ ] **معما:** یک پازل متنی («عدد ۳ رقمی را حدس بزن» یا «ترتیب کلیدها») که کلید/گنج را باز می‌کند
- [ ] **نبرد نوبتی:** موجودیت‌ها با HP — `attack`/`flee`/`use potion`
- [ ] **ذخیره/بارگذاری:** `save.txt` با وضعیت (جان، طلا، آیتم‌ها، اتاق فعلی)
- [ ] **چند پایان:** ۳ پایان بر اساس انتخاب‌ها (Python? نه — Java خالص)
- [ ] **NPC:** یک کاراکتر که دیالوگ دارد و راهنمایی می‌کند

## معیار پذیرش
- حداقل ۲ ساعت گیم‌پلی بدون تکرار
- save/load واقعاً کار کند (بستن و باز کردن برنامه)
- NPC دیالوگ معنادار داشته باشد

## صورت پروژه
پاسخ در `solution/` — پیاده‌سازی کامل.
