# Mini Market — سامانهٔ فروشگاهی کنسولی

POS کامل با موجودی، فاکتور، گزارش فروش و ذخیره‌سازی فایل — بدون dependency.

## اجرا
```bash
javac -d out src/MiniMarket.java
java -cp out MiniMarket
```

## قابلیت‌ها
- منوی فارسی: فروش، موجودی، تاریخچه، گزارش، افزودن کالا
- کسر خودکار موجودی هنگام فروش
- فاکتور با تاریخ و جمع کل
- گزارش: تعداد فاکتور، مجموع فروش، پرفروش‌ترین کالاها
- هشدار موجودی کم (< ۵)
- ذخیره/بازیابی در `minimarket_data.txt`
