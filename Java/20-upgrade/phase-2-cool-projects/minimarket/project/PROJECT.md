# پروژهٔ توسعه — Mini Market گرافیکی

نسخهٔ کنسولی را به Swing گرافیکی گسترش دهید:

## الزامات
- [ ] `MainFrame` با `JTabbedPane`: فروش (POS)، انبار، فاکتورها، گزارش‌ها
- [ ] POS: انتخاب کالا از `JComboBox`/جدول + دکمه‌های +/− + سبد خرید `JTable`
- [ ] جستجوی کالا با تایپ (`DocumentListener` روی search field)
- [ ] چاپ فاکتور با `Printable` یا ذخیره PDF ساده
- [ ] نمودار فروش روزانه با `JPanel.paintComponent`
- [ ] چند کاربر با نقش فروشنده/مدیر (`login` ساده + سطح دسترسی)

## معیار پذیرش
- فروش کامل از UI بدون خطا
- موجودی همگام با کنسول (همان فایل داده)
- گزارش با نمودار

## صورت پروژه
پاسخ در `solution/` — پیاده‌سازی کامل.
