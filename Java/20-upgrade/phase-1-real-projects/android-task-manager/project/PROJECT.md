# پروژهٔ توسعه — نسخهٔ کامل Task Manager

پروژهٔ پایه را به این موارد گسترش دهید:

## الزامات
- [ ] **یادآوری/ددلاین:** فیلد `dueDate` و `reminderTime` در Task + نمایش در UI
- [ ] **دسته‌بندی:** فیلد `category` (کار/شخصی/خرید) + فیلدتر در UI
- [ ] **آمار:** صفحهٔ Stats با نمودار دایره‌ای (Material3 `Canvas` یا کتابخانهٔ chart)
- [ ] **تکمیل گروهی:** انتخاب چندتایی + «علامت‌گذاری به‌عنوان انجام‌شده»
- [ ] **خروجی:** Share task به‌صورت متن (`ACTION_SEND`)
- [ ] **DataStore:** ذخیرهٔ آخرین فیلتر/ترتیب انتخابی کاربر
- [ ] **تست:** حداقل یک `Robolectric`/unit test برای ViewModel
