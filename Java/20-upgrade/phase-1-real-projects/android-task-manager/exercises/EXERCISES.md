# تمرین‌های پروژهٔ Android Task Manager

پیش‌نیاز: باز کردن پروژه در Android Studio و Sync Gradle.

## آسان
1. اپ را روی emulator اجرا کنید — لیست خالی + FAB را ببینید.
2. با FAB یک وظیفه بسازید، checkbox را بزنید و ببینید خط‌خورده می‌شود.
3. برنامه را ببندید و دوباره باز کنید — داده‌ها باید بمانند (Room).

## متوسط
4. اولویت را در فرم تغییر دهید و ترتیب نمایش در لیست را چک کنید.
5. روی یک وظیفه کلیک کنید و ویرایش کنید.
6. از کشوی ناوبری/TopAppBar یک آمار «X وظیفهٔ باز» اضافه کنید.

## سخت
7. جستجو/فیلتر اضافه کنید: یک `SearchBar` که لیست را بر اساس عنوان فیلتر کند
   (در DAO یک `@Query` با `LIKE` اضافه کنید و در ViewModel یک `StateFlow<String>` برای کوئری نگه دارید).
8. اعلان با `WorkManager`: هر روز ساعت ۹ یادآوری «شما N وظیفهٔ باز دارید»
   (به‌جای Notification واقعی می‌توانید یک `Toast`/`Log` بگذارید).
9. تم تاریک/روشن با `isSystemInDarkTheme()` و دکمهٔ تغییر در Settings.
