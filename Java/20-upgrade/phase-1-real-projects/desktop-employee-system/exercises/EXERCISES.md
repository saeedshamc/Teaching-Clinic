# تمرین‌های پروژهٔ Employee Management System

## آسان
1. برنامه را اجرا کنید و ۳ کارمند اضافه کنید — بررسی کنید `employees.csv` ساخته می‌شود.
2. جستجو را با نام و با دپارتمان تست کنید. فیلتر دپارتمان را امتحان کنید.

## متوسط
3. دکمهٔ «خروجی CSV» را بزنید و فایل خروجی را با Excel باز کنید.
4. کارمندی را ویرایش کنید (مثلاً حقوق) و دوباره برنامه را اجرا کنید — تغییرات باید بماند.
5. یک کارمند را حذف کنید و بررسی کنید `active=false` در فایل CSV است (حذف نرم).

## سخت
6. مرتب‌سازی جدول با کلیک روی هدر ستون‌ها را اضافه کنید (`TableRowSorter`).
7. دکمهٔ «بازیابی» برای کارمند حذف‌شده (active=false → true) اضافه کنید.
8. خروجی PDF ساده با `Printable` یا گزارش متنی اضافه کنید.
