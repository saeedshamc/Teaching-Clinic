# پروژهٔ توسعه — نسخهٔ کامل Employee System

نسخهٔ پایه (`src/`) را به این موارد گسترش دهید:

## الزامات
- [ ] **گزارش‌گیری پیشرفته:** میانگین/بیشترین/کمترین حقوق هر دپارتمان، نمودار میله‌ای با `JPanel` سفارشی `paintComponent`
- [ ] **چندقابلیتی:** تب‌های `JTabbedPane` — کارکنان، گزارش‌ها، تنظیمات (مسیر فایل داده)
- [ ] **پشتیبان‌گیری:** دکمهٔ «Backup» که کپی از `employees.csv` با تاریخ می‌سازد
- [ ] **ورود اطلاعات گروهی:** دکمهٔ «Import CSV» با `JFileChooser`
- [ ] **تم تیره/روشن:** `UIManager.setLookAndFeel` + دکمهٔ تغییر تم

## معیار پذیرش
- همهٔ داده‌ها بعد از بستن و باز کردن برنامه باقی بمانند
- جستجو، فیلتر، مرتب‌سازی، خروجی همه کار کنند
- برنامه بدون خطای uncaught اجرا شود

## صورت پروژه
پاسخ در `solution/` — پیاده‌سازی کامل این الزامات.
