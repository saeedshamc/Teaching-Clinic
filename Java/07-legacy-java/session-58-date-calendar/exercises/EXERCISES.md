# تمرین‌های جلسه ۵۸ — Date و Calendar

## آسان
1. `Date` بسازید و `getTime()` را تست کنید.
2. `Calendar.getInstance()` و `set()` را تست کنید.

## متوسط
3. `Calendar.add()` برای add/subtract days/months استفاده کنید.
4. `LocalDate.now()` و `LocalDate.of()` را تست کنید.

## سخت
5. `Duration.between` برای محاسبهٔ فاصله بین دو datetime استفاده کنید.
6. `Period.between` برای محاسبهٔ فاصله بین دو date استفاده کنید.
