# پروژهٔ جلسه ۵۸ — سیستم تقویم با java.time

یک سیستم تقویم بسازید که:
- `LocalDate` برای تاریخ‌ها
- `LocalTime` برای زمان‌ها
- `LocalDateTime` برای رویدادها
- `Duration` برای محاسبهٔ مدت
- `Period` برای محاسبهٔ فاصله
- متدهای `addEvent`, `getUpcoming`, `daysUntil`
- در `main` چند رویداد اضافه کنید و گزارش چاپ کنید

نمونه:
```
Events: 3
Next event: Meeting in 5 days
Days until birthday: 30
```

## صورت پروژه
پاسخ در `solution/CalendarSystem.java` — از java.time استفاده کنید.
