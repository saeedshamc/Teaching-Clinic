# تمرین‌های جلسه ۵۷ — Vector و Hashtable

## آسان
1. `Vector` بسازید و `add`, `get`, `size` را تست کنید.
2. `Hashtable` بسازید و `put`, `get` را تست کنید.

## متوسط
3. `Enumeration` را برای iteration روی Vector استفاده کنید.
4. `Hashtable.keys()` و `Hashtable.elements()` را تست کنید.

## سخت
5. `Vector` و `ArrayList` را برای performance مقایسه کنید.
6. `Hashtable` null key را تست کنید — چه اتفاقی می‌افتد؟
