# پروژهٔ جلسه ۵۷ — سیستم نام‌گذاری با Hashtable

یک سیستم نام‌گذاری بسازید که:
- `Hashtable<String, String>` برای name→phone
- `Vector<String>` برای لیست نام‌ها
- `Enumeration` برای iteration
- متدهای `addContact`, `findByName`, `listAll`
- در `main` چند مخاطب اضافه کنید و لیست کنید

نمونه:
```
Contacts: 3
Ali → 123-4567
Sara → 987-6543
...
```

## صورت پروژه
پاسخ در `solution/PhoneBookLegacy.java` — از Hashtable و Vector استفاده کنید.
