# پروژهٔ جلسه ۵۶ — مایگریشن کد قدیمی

یک کد قدیمی را به modern Java مایگریت کنید:
- `Vector<String>` → `ArrayList<String>`
- `Hashtable<String,Integer>` → `HashMap<String,Integer>`
- `Enumeration` → `Iterator`
- `Date` → `LocalDateTime`
- `StringBuffer` → `StringBuilder`

نمونه:
```
Before: Vector[Ali, Sara, Reza]
After: ArrayList[Ali, Sara, Reza]
```

## صورت پروژه
پاسخ در `solution/MigrationDemo.java` — هر دو نسخه را نشان دهید.
