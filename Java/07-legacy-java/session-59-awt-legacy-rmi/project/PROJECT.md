# پروژهٔ جلسه ۵۹ — مقایسهٔ Legacy و Modern GUI

یک مقایسه بنویسید که:
- AWT `Frame` با `Button` بسازید (فقط برای یادگیری)
- همان UI را با Swing `JFrame` بسازید
- تفاوت‌ها را در کامنت بنویسید
- RMI vs REST را در کامنت مقایسه کنید

نمونه:
```
AWT: native components, platform-specific
Swing: pure Java, consistent
RMI: complex, Java-only
REST: simple, language-agnostic
```
