# تمرین‌های جلسه ۱۳۶ — JVM Memory Model

## آسان
1. `MemoryDemo` با stack و heap variables بسازید.
2. `HeapDemo` با `Runtime.getRuntime()` برای memory info استفاده کنید.

## متوسط
3. `StackOverflowDemo` با infinite recursion برای `StackOverflowError` بسازید.
4. `-Xms`, `-Xmx` flags برای heap tuning استفاده کنید.

## سخت
5. `-XX:+PrintGCDetails` برای GC logging استفاده کنید.
6. `-XX:+HeapDumpOnOutOfMemoryError` برای heap dump استفاده کنید.
