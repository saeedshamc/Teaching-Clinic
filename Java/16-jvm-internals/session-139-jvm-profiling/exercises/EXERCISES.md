# تمرین‌های جلسه ۱۳۹ — JVM Profiling

## آسان
1. `ProfilingDemo` با `System.currentTimeMillis()` برای timing استفاده کنید.
2. `ThreadDumpDemo` با multiple threads برای `jstack` استفاده کنید.

## متوسط
3. `jcmd <pid> JFR.start` برای Java Flight Recorder استفاده کنید.
4. `jmap -dump` برای heap dump استفاده کنید.

## سخت
5. `jvisualvm` برای GUI profiling استفاده کنید.
6. `async-profiler` برای low-overhead profiling استفاده کنید.
