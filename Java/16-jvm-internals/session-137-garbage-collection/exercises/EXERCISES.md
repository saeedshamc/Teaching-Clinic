# تمرین‌های جلسه ۱۳۷ — Garbage Collection

## آسان
1. `GCDemo` با `System.gc()` برای force GC استفاده کنید.
2. `MemoryPressure` با `List<byte[]>` برای memory pressure بسازید.

## متوسط
3. `-Xms`, `-Xmx` flags برای heap tuning استفاده کنید.
4. `-XX:+UseG1GC` برای G1 GC algorithm استفاده کنید.

## سخت
5. `-Xlog:gc*` برای GC logging استفاده کنید.
6. `-XX:+HeapDumpOnOutOfMemoryError` برای heap dump استفاده کنید.
