# جلسه 9: رشته‌ها و Unicode (2 ساعت)

## 🎯 اهداف یادگیری
- متدهای پرکاربرد رشته را روی متن واقعی اجرا کنید
- جستجو و جایگزینی را بدون regex پیچیده انجام دهید
- Template Literal را برای خروجی چندخطی به کار ببرید
- تفاوت `length` با شمارش نویسه‌های Unicode را توضیح دهید

---

## 1. رشته در JavaScript

رشته **immutable** است: متدها رشتهٔ جدید می‌سازند، اصل را عوض نمی‌کنند.

```javascript
const name = "علی";
const upper = name.toUpperCase();
console.log(name);  // "علی" — عوض نشده
console.log(upper);
```

---

## 2. متدهای روزمره

| متد | کار |
|-----|-----|
| `trim()` | حذف فاصلهٔ ابتدا و انتها |
| `slice(start, end)` | برش |
| `split(جداکننده)` | تبدیل به آرایه |
| `includes(متن)` | آیا وجود دارد؟ |
| `replace` / `replaceAll` | جایگزینی |
| `padStart` / `padEnd` | پر کردن طول |

```javascript
"  سلام  ".trim();           // "سلام"
"JavaScript".slice(0, 4);    // "Java"
"a,b,c".split(",");          // ["a", "b", "c"]
"42".padStart(5, "0");       // "00042"
```

`substring` هم وجود دارد؛ برای کد جدید معمولاً `slice` کافی و خواناتر است.

---

## 3. جستجو

```javascript
const text = "سلام دنیا";
text.includes("دنیا");     // true
text.startsWith("سلام");   // true
text.indexOf("دنیا");      // 5
text.replace("دنیا", "علی");
```

`replace` فقط **اولین** مورد را عوض می‌کند. برای همه: `replaceAll`.

---

## 4. Template Literal

از جلسه 1 دیدید. اینجا کاربرد عملی:

```javascript
const user = { name: "سارا", role: "مدرس" };
const html = `
  <article>
    <h2>${user.name}</h2>
    <p>${user.role}</p>
  </article>
`;
```

داخل `${}` می‌توانید عبارت بنویسید: شرط سه‌تایی، فراخوانی تابع، محاسبه.

---

## 5. Unicode پایه

`length` تعداد واحدهای UTF-16 است، نه لزوماً تعداد نویسه‌ای که چشم می‌بیند.

```javascript
"سلام".length;        // 4
"👨‍💻".length;         // بیشتر از 1
[..."سلام"].length;   // تعداد code point
```

برای متن فارسی معمولاً `length` با تعداد حروف یکی است. مشکل بیشتر با ایموجی و نویسه‌های ترکیبی است.

---

## 6. تمرین‌ها

### تمرین 1
تابعی بنویسید که فاصلهٔ اضافه را `trim` کند و اولین حرف را بزرگ کند.

### تمرین 2
متنی بگیرید و همهٔ «ی» را با `replaceAll` عوض نکنید؛ فقط بررسی کنید `includes` برای یک کلمه کار می‌کند.

### تمرین 3 (چالش)
با Template Literal یک فاکتور چندخطی بسازید (نام کالا، تعداد، جمع).

---

## 7. نکات مهم

1. ✅ رشته را mutate نکنید؛ نتیجهٔ متد را در متغیر جدید بگذارید
2. ✅ برای همهٔ جایگزینی‌ها `replaceAll` (نه حلقهٔ دستی)
3. ❌ روی `length` ایموجی برای شمارش کاراکتر تکیه نکنید
