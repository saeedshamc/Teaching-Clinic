# جلسه 24: مینی‌اپ Notes (2 ساعت)

## 🎯 اهداف یادگیری
- یک اپ کوچک با ماژول + DOM + localStorage بسازید
- منبع حقیقت را آرایه نگه دارید و UI را از روی آن بکشید
- افزودن، انجام‌شدن، حذف و ماندگاری را کامل کنید
- مسیر ورود به دورهٔ React را بدانید

---

## 1. چرا این پروژه؟

جلسات ۹–۲۳ را در یک صفحه جمع می‌کند: ماژول، رویداد، فرم، storage، immutability لایه‌ای.

محیط: مرورگر + Live Server (به‌خاطر `type="module"`).

---

## 2. فایل‌ها

| فایل | نقش |
|------|-----|
| `storage.js` | خواندن/نوشتن JSON |
| `notes.js` | قوانین داده (add/toggle/remove) |
| `script.js` | رویدادها و render |
| `index.html` | اسکلت UI |

---

## 3. مدل داده

```javascript
{ id, text, done }
```

`id` را با `crypto.randomUUID()` یا `Date.now()` بسازید.

---

## 4. تمرین‌ها

### آسان
یک یادداشت اضافه کنید، صفحه را رفرش کنید؛ باید بماند.

### چالش
فیلتر «فقط انجام‌نشده» بدون خراب کردن storage.

---

## 5. بعد از این دوره

پوشهٔ [`Reactjs/`](../../Reactjs/) در همین ریپو: کامپوننت، props، state. ذهنیت «داده جدا، UI تابع داده» همین‌جاست.
