## 2. لایهٔ کوچک API

```javascript
async function getPosts() {
    const res = await fetch("https://jsonplaceholder.typicode.com/posts?_limit=8");
    if (!res.ok) throw new Error("HTTP " + res.status);
    return res.json();
}
```

منطق شبکه را از منطق DOM جدا کنید — همان تفکیک جلسه 16.
