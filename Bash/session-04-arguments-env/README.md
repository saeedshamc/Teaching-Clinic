# جلسه ۴: آرگومان‌های خط فرمان و متغیرهای محیطی

## اهداف یادگیری

در این جلسه یاد می‌گیرید:
- چگونه از آرگومان‌های خط فرمان استفاده کنید
- تفاوت بین $@ و $*
- چگونه متغیرهای محیطی (Environment Variables) را بخوانید و تنظیم کنید
- چگونه متغیرهای محیطی را برای اسکریپت‌های فرزند تنظیم کنید
- چگونه آرگومان‌ها را اعتبارسنجی کنید
- استفاده از getopts برای گزینه‌های پیشرفته

## آرگومان‌های خط فرمان

آرگومان‌های خط فرمان به شما اجازه می‌دهند داده‌ها را هنگام اجرای اسکریپت به آن بدهید:

```bash
./script.sh arg1 arg2 arg3
```

### متغیرهای آرگومان

```bash
$0      # نام اسکریپت
$1      # اولین آرگومان
$2      # دومین آرگومان
$3      # سومین آرگومان
...
$9      # نهمین آرگومان
$#      # تعداد کل آرگومان‌ها
$@      # تمام آرگومان‌ها به صورت جداگانه
$*      # تمام آرگومان‌ها به صورت یک رشته
```

## مثال ۱: آرگومان‌های پایه

فایل [examples/01-basic-arguments.sh](examples/01-basic-arguments.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

echo "نام اسکریپت: $0"
echo "تعداد آرگومان‌ها: $#"
echo -e "\nآرگومان‌ها:"

# نمایش هر آرگومان به صورت جداگانه
for arg in "$@"; do
    echo "  - $arg"
done

# نمایش آرگومان‌های خاص
if [ $# -ge 1 ]; then
    echo -e "\nاولین آرگومان: $1"
fi

if [ $# -ge 2 ]; then
    echo "دومین آرگومان: $2"
fi

if [ $# -ge 3 ]; then
    echo "سومین آرگومان: $3"
fi
```

### توضیح خط به خط:

- `$0` - نام فایل اسکریپت را نمایش می‌دهد
- `$#` - تعداد آرگومان‌ها را نمایش می‌دهد
- `for arg in "$@"` - روی تمام آرگومان‌ها حلقه می‌زند
- `"$@"` - تمام آرگومان‌ها را به صورت جداگانه برمی‌گرداند
- `$1, $2, $3` - آرگومان‌های اول، دوم و سوم را نمایش می‌دهد
- `[ $# -ge 1 ]` - بررسی می‌کند که آیا حداقل 1 آرگومان وجود دارد

## تفاوت بین $@ و $*

### $@ - آرگومان‌های جداگانه

```bash
for arg in "$@"; do
    echo "$arg"
done
```

### $* - یک رشته واحد

```bash
for arg in "$*"; do
    echo "$arg"
done
```

## مثال ۲: تفاوت $@ و $*

فایل [examples/02-at-vs-asterisk.sh](examples/02-at-vs-asterisk.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

echo "آرگومان‌های داده شده: $@"
echo -e "\n--- استفاده از \$@ ---"
for arg in "$@"; do
    echo "آرگومان: $arg"
done

echo -e "\n--- استفاده از \$* ---"
for arg in "$*"; do
    echo "آرگومان: $arg"
done

# مثال با فاصله در آرگومان
echo -e "\n--- مثال با فاصله ---"
./script.sh "Hello World" "Bash Scripting"
```

### توضیح خط به خط:

- `"$@"` - هر آرگومان را جداگانه حفظ می‌کند (مهم برای آرگومان‌های با فاصله)
- `"$*"` - تمام آرگومان‌ها را به یک رشته تبدیل می‌کند
- این تفاوت وقتی مهم است که آرگومان‌ها حاوی فاصله باشند

## متغیرهای محیطی (Environment Variables)

متغیرهای محیطی متغیرهایی هستند که در تمام فرآیندهای فرزند قابل دسترسی هستند.

### مشاهده متغیرهای محیطی

```bash
env          # نمایش تمام متغیرهای محیطی
printenv     # نمایش تمام متغیرهای محیطی
echo $HOME   # نمایش یک متغیر خاص
echo $PATH   # نمایش مسیر اجرایی
echo $USER   # نمایش نام کاربر
```

### متغیرهای محیطی رایج

```bash
$HOME       # پوشه خانگی کاربر
$PATH       # مسیرهای جستجو برای دستورات
$USER       # نام کاربر
$SHELL      # Shell پیش‌فرض
$PWD        # مسیر جاری
$LANG       # زبان سیستم
$HOSTNAME   # نام میزبان
```

## مثال ۳: متغیرهای محیطی

فایل [examples/03-environment-variables.sh](examples/03-environment-variables.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

echo "--- متغیرهای محیطی رایج ---"
echo "پوشه خانگی: $HOME"
echo "نام کاربر: $USER"
echo "Shell: $SHELL"
echo "مسیر جاری: $PWD"
echo "زبان: $LANG"
echo "نام میزبان: $HOSTNAME"
echo "PATH: $PATH"

echo -e "\n--- تمام متغیرهای محیطی ---"
env | head -10
```

### توضیح خط به خط:

- `$HOME` - پوشه خانگی کاربر را نمایش می‌دهد
- `$USER` - نام کاربر را نمایش می‌دهد
- `$SHELL` - Shell پیش‌فرض را نمایش می‌دهد
- `$PWD` - مسیر جاری را نمایش می‌دهد
- `$LANG` - زبان سیستم را نمایش می‌دهد
- `$HOSTNAME` - نام میزبان را نمایش می‌دهد
- `$PATH` - مسیرهای جستجو را نمایش می‌دهد
- `env` - تمام متغیرهای محیطی را نمایش می‌دهد
- `head -10` - فقط 10 خط اول را نمایش می‌دهد

## تنظیم متغیرهای محیطی

### متغیر محلی (فقط برای اسکریپت جاری)

```bash
MY_VAR="value"
```

### متغیر محیطی (برای اسکریپت‌های فرزند)

```bash
export MY_VAR="value"
```

### تنظیم موقت برای یک دستور

```bash
MY_VAR="value" command
```

## مثال ۴: تنظیم متغیرهای محیطی

فایل [examples/04-setting-env-vars.sh](examples/04-setting-env-vars.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# تعریف متغیر محلی
LOCAL_VAR="این یک متغیر محلی است"
echo "متغیر محلی: $LOCAL_VAR"

# تعریف متغیر محیطی
export EXPORTED_VAR="این یک متغیر محیطی است"
echo "متغیر محیطی: $EXPORTED_VAR"

# نمایش متغیرهای محیطی جدید
echo -e "\n--- متغیرهای محیطی جدید ---"
env | grep VAR

# تست در اسکریپت فرزند
echo -e "\n--- تست در اسکریپت فرزند ---"
bash -c 'echo "متغیر محلی در فرزند: $LOCAL_VAR"'
bash -c 'echo "متغیر محیطی در فرزند: $EXPORTED_VAR"'
```

### توضیح خط به خط:

- `LOCAL_VAR="..."` - متغیر محلی تعریف می‌کند (فقط در این اسکریپت)
- `export EXPORTED_VAR="..."` - متغیر محیطی تعریف می‌کند (در اسکریپت‌های فرزند هم قابل دسترسی)
- `env | grep VAR` - متغیرهای حاوی VAR را پیدا می‌کند
- `bash -c '...'` - یک دستور bash در یک فرآیند فرزند اجرا می‌کند
- متغیر محلی در فرزند قابل دسترسی نیست
- متغیر محیطی در فرزند قابل دسترسی است

## اعتبارسنجی آرگومان‌ها

همیشه باید آرگومان‌ها را اعتبارسنجی کنید تا از خطا جلوگیری شود.

## مثال ۵: اعتبارسنجی آرگومان‌ها

فایل [examples/05-argument-validation.sh](examples/05-argument-validation.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# بررسی اینکه آیا آرگومان داده شده است
if [ $# -eq 0 ]; then
    echo "خطا: هیچ آرگومانی داده نشده است"
    echo "استفاده: $0 <نام>"
    exit 1
fi

NAME=$1

# بررسی اینکه آیا آرگومان خالی نیست
if [ -z "$NAME" ]; then
    echo "خطا: آرگومان نمی‌تواند خالی باشد"
    exit 1
fi

# بررسی تعداد آرگومان‌ها
if [ $# -gt 1 ]; then
    echo "هشدار: فقط اولین آرگومان استفاده می‌شود"
fi

echo "سلام، $NAME!"
```

### توضیح خط به خط:

- `[ $# -eq 0 ]` - بررسی می‌کند که آیا آرگومانی وجود ندارد
- `echo "استفاده: $0 <نام>"` - نحوه استفاده صحیح را نمایش می‌دهد
- `exit 1` - اسکریپت را با کد خطا (1) خاتمه می‌دهد
- `[ -z "$NAME" ]` - بررسی می‌کند که آیا متغیر خالی است
- `[ $# -gt 1 ]` - بررسی می‌کند که آیا بیش از 1 آرگومان وجود دارد

## استفاده از getopts برای گزینه‌های پیشرفته

getopts برای پارس کردن گزینه‌های خط فرمان (مثل -a, -b, --option) استفاده می‌شود.

## مثال ۶: استفاده از getopts

فایل [examples/06-getopts.sh](examples/06-getopts.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# متغیرهای پیش‌فرض
NAME="کاربر"
VERBOSE=false

# پارس کردن گزینه‌ها
while getopts "n:v" opt; do
    case $opt in
        n)
            NAME="$OPTARG"
            ;;
        v)
            VERBOSE=true
            ;;
        \?)
            echo "استفاده: $0 [-n نام] [-v]"
            exit 1
            ;;
    esac
done

echo "سلام، $NAME!"

if [ "$VERBOSE" = true ]; then
    echo "حالت verbose فعال است"
    echo "تعداد آرگومان‌ها: $#"
    echo "آرگومان‌های اضافی: ${@:OPTIND}"
fi
```

### توضیح خط به خط:

- `while getopts "n:v" opt` - گزینه‌های -n و -v را پارس می‌کند
- `case $opt in` - بر اساس گزینه تصمیم می‌گیرد
- `n)` - وقتی گزینه -n داده شود
- `NAME="$OPTARG"` - مقدار بعد از -n را در NAME ذخیره می‌کند
- `v)` - وقتی گزینه -v داده شود (بدون مقدار)
- `VERBOSE=true` - حالت verbose را فعال می‌کند
- `\?)` - برای گزینه‌های نامعتبر
- `${@:OPTIND}` - آرگومان‌های باقی‌مانده بعد از گزینه‌ها

## نکات رایج اشتباهات (Common Pitfalls)

### ۱. فراموش کردن اعتبارسنجی آرگومان‌ها

❌ اشتباه:
```bash
echo "سلام $1"  # اگر آرگومان داده نشود، خالی چاپ می‌شود
```

✅ درست:
```bash
if [ $# -eq 0 ]; then
    echo "خطا: آرگومان لازم است"
    exit 1
fi
echo "سلام $1"
```

### ۲. فراموش کردن quote در $@ و $*

❌ اشتباه:
```bash
for arg in $@; do  # آرگومان‌های با فاصله جدا می‌شوند
    echo "$arg"
done
```

✅ درست:
```bash
for arg in "$@"; do  # آرگومان‌های با فاصله حفظ می‌شوند
    echo "$arg"
done
```

### ۳. استفاده از $* به جای $@ در حلقه

❌ اشتباه:
```bash
for arg in "$*"; do  # تمام آرگومان‌ها به عنوان یک رشته
    echo "$arg"
done
```

✅ درست:
```bash
for arg in "$@"; do  # هر آرگومان جداگانه
    echo "$arg"
done
```

### ۴. فراموش کردن export برای متغیرهای محیطی

❌ اشتباه:
```bash
MY_VAR="value"
bash -c 'echo $MY_VAR'  # چاپ نمی‌کند
```

✅ درست:
```bash
export MY_VAR="value"
bash -c 'echo $MY_VAR'  # چاپ می‌کند: value
```

## بهترین شیوه‌ها (Best Practices)

1. **همیشه آرگومان‌ها را اعتبارسنجی کنید** - برای جلوگیری از خطا
2. **از "$@" به جای $@ استفاده کنید** - برای حفظ فاصله در آرگومان‌ها
3. **پیام استفاده واضح بنویسید** - وقتی آرگومان‌ها نادرست هستند
4. **از getopts برای گزینه‌های پیچیده استفاده کنید** - برای اسکریپت‌های حرفه‌ای
5. **متغیرهای محیطی را با caution استفاده کنید** - می‌توانند روی سایر برنامه‌ها تأثیر بگذارند
