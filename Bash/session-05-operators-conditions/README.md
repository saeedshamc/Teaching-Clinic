# جلسه ۵: عملگرها، شرط‌ها و مقایسه‌ها

## اهداف یادگیری

در این جلسه یاد می‌گیرید:
- عملگرهای مقایسه‌ای در Bash
- عملگرهای منطقی (AND, OR, NOT)
- دستور if و ساختارهای شرطی
- دستور case برای مقایسه‌های چندگانه
- تست فایل‌ها و دایرکتوری‌ها
- تست رشته‌ها و اعداد

## عملگرهای مقایسه‌ای

### مقایسه اعداد

```bash
-eq     # برابر (equal)
-ne     # نامساوی (not equal)
-gt     # بزرگتر از (greater than)
-lt     # کوچکتر از (less than)
-ge     # بزرگتر یا مساوی (greater or equal)
-le     # کوچکتر یا مساوی (less or equal)
```

### مقایسه رشته‌ها

```bash
=       # برابر
==      # برابر (در [[ ]])
!=      # نامساوی
<       # کوچکتر از (ترتیب الفبایی)
>       # بزرگتر از (ترتیب الفبایی)
-z      # رشته خالی
-n      # رشته غیر خالی
```

## مثال ۱: مقایسه اعداد

فایل [examples/01-number-comparison.sh](examples/01-number-comparison.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

NUM1=10
NUM2=20

echo "عدد اول: $NUM1"
echo "عدد دوم: $NUM2"

# مقایسه با if
if [ $NUM1 -eq $NUM2 ]; then
    echo "$NUM1 برابر با $NUM2 است"
elif [ $NUM1 -lt $NUM2 ]; then
    echo "$NUM1 کوچکتر از $NUM2 است"
else
    echo "$NUM1 بزرگتر از $NUM2 است"
fi
```

### توضیح خط به خط:

- `[ $NUM1 -eq $NUM2 ]` - بررسی برابری دو عدد
- `if ...; then` - شروع بلوک شرطی
- `elif ...; then` - شرط دیگر اگر شرط قبلی غلط باشد
- `else` - اگر هیچ شرطی درست نباشد
- `fi` - پایان بلوک if

## مثال ۲: مقایسه رشته‌ها

فایل [examples/02-string-comparison.sh](examples/02-string-comparison.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

NAME1="علی"
NAME2="رضا"

echo "نام اول: $NAME1"
echo "نام دوم: $NAME2"

# مقایسه رشته‌ها
if [ "$NAME1" = "$NAME2" ]; then
    echo "نام‌ها یکسان هستند"
else
    echo "نام‌ها متفاوت هستند"
fi

# بررسی رشته خالی
EMPTY=""
if [ -z "$EMPTY" ]; then
    echo "متغیر EMPTY خالی است"
fi

if [ -n "$NAME1" ]; then
    echo "متغیر NAME1 غیر خالی است"
fi
```

### توضیح خط به خط:

- `[ "$NAME1" = "$NAME2" ]` - بررسی برابری دو رشته (نکته: فاصله دور = مهم است)
- `[ -z "$EMPTY" ]` - بررسی اینکه آیا رشته خالی است
- `[ -n "$NAME1" ]` - بررسی اینکه آیا رشته غیر خالی است
- همیشه رشته‌ها را در quote بگذارید

## عملگرهای منطقی

```bash
-a      # AND (در [ ])
-o      # OR (در [ ])
!       # NOT
&&      # AND (در [[ ]] یا دستورات)
||      # OR (در [[ ]] یا دستورات)
```

## مثال ۳: عملگرهای منطقی

فایل [examples/03-logical-operators.sh](examples/03-logical-operators.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

AGE=25
HAS_LICENSE=true

# بررسی با AND
if [ $AGE -ge 18 ] && [ "$HAS_LICENSE" = true ]; then
    echo "شما می‌توانید رانندگی کنید"
else
    echo "شما نمی‌توانید رانندگی کنید"
fi

# بررسی با OR
SCORE=85
if [ $SCORE -ge 90 ] || [ $SCORE -eq 100 ]; then
    echo "نمره عالی!"
elif [ $SCORE -ge 75 ]; then
    echo "نمره خوب"
else
    echo "نیاز به تلاش بیشتر"
fi

# استفاده از NOT
if [ ! "$HAS_LICENSE" = true ]; then
    echo "شما گواهینامه ندارید"
fi
```

### توضیح خط به خط:

- `[ $AGE -ge 18 ] && [ "$HAS_LICENSE" = true ]` - هر دو شرط باید درست باشند
- `[ $SCORE -ge 90 ] || [ $SCORE -eq 100 ]` - حداقل یکی از شرط‌ها باید درست باشد
- `[ ! "$HAS_LICENSE" = true ]` - negation (معکوس کردن شرط)

## دستور if

ساختار کامل if:

```bash
if [ condition ]; then
    # کد اگر شرط درست باشد
elif [ condition ]; then
    # کد اگر شرط دوم درست باشد
else
    # کد اگر هیچ شرطی درست نباشد
fi
```

## مثال ۴: ساختار if کامل

فایل [examples/04-if-structure.sh](examples/04-if-structure.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

read -p "نام کاربری: " USERNAME
read -p "سن: " AGE

# بررسی سن
if [ $AGE -lt 18 ]; then
    echo "شما نوجوان هستید"
elif [ $AGE -ge 18 ] && [ $AGE -lt 30 ]; then
    echo "شما جوان هستید"
elif [ $AGE -ge 30 ] && [ $AGE -lt 60 ]; then
    echo "شما میانسال هستید"
else
    echo "شما مسن هستید"
fi

# بررسی نام کاربری
if [ -z "$USERNAME" ]; then
    echo "نام کاربری نمی‌تواند خالی باشد"
elif [ ${#USERNAME} -lt 3 ]; then
    echo "نام کاربری باید حداقل 3 کاراکتر باشد"
else
    echo "نام کاربری معتبر است: $USERNAME"
fi
```

### توضیح خط به خط:

- `read -p "..." USERNAME` - ورودی از کاربر می‌گیرد
- `[ $AGE -lt 18 ]` - بررسی سن کمتر از 18
- `[ $AGE -ge 18 ] && [ $AGE -lt 30 ]` - بررسی سن بین 18 تا 30
- `${#USERNAME}` - طول رشته USERNAME را برمی‌گرداند
- `[ ${#USERNAME} -lt 3 ]` - بررسی اینکه آیا طول کمتر از 3 است

## دستور case

دستور case برای مقایسه یک مقدار با چندین گزینه استفاده می‌شود:

```bash
case "$variable" in
    pattern1)
        # کد
        ;;
    pattern2)
        # کد
        ;;
    *)
        # کد پیش‌فرض
        ;;
esac
```

## مثال ۵: استفاده از case

فایل [examples/05-case-statement.sh](examples/05-case-statement.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

read -p "یک رنگ را وارد کنید (قرمز/آبی/سبز/زرد): " COLOR

case "$COLOR" in
    "قرمز"|"red")
        echo "شما قرمز را انتخاب کردید - رنگ عشق و هیجان!"
        ;;
    "آبی"|"blue")
        echo "شما آبی را انتخاب کردید - رنگ آرامش!"
        ;;
    "سبز"|"green")
        echo "شما سبز را انتخاب کردید - رنگ طبیعت!"
        ;;
    "زرد"|"yellow")
        echo "شما زرد را انتخاب کردید - رنگ خوشبختی!"
        ;;
    *)
        echo "رنگ نامعتبر است"
        ;;
esac
```

### توضیح خط به خط:

- `case "$COLOR" in` - شروع بلوک case
- `"قرمز"|"red")` - تطبیق با "قرمز" یا "red" (| به معنی OR است)
- `;;` - پایان هر case
- `*)` - case پیش‌فرض (اگر هیچ کدام تطبیق نداشت)
- `esac` - پایان بلوک case

## تست فایل‌ها

Bash عملگرهای قدرتمندی برای تست فایل‌ها دارد:

```bash
-f file     # فایل معمولی وجود دارد
-d dir      # دایرکتوری وجود دارد
-e file     # فایل یا دایرکتوری وجود دارد
-r file     # فایل قابل خواندن است
-w file     # فایل قابل نوشتن است
-x file     # فایل قابل اجرا است
-s file     # فایل غیر خالی است
```

## مثال ۶: تست فایل‌ها

فایل [examples/06-file-tests.sh](examples/06-file-tests.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

FILE="/etc/passwd"

if [ -f "$FILE" ]; then
    echo "فایل $FILE وجود دارد"
    
    if [ -r "$FILE" ]; then
        echo "فایل قابل خواندن است"
    fi
    
    if [ -w "$FILE" ]; then
        echo "فایل قابل نوشتن است"
    else
        echo "فایل قابل نوشتن نیست"
    fi
else
    echo "فایل $FILE وجود ندارد"
fi

# تست دایرکتوری
DIR="/tmp"
if [ -d "$DIR" ]; then
    echo "$DIR یک دایرکتوری است"
fi

# تست فایل خالی
EMPTY_FILE="/tmp/empty_test.txt"
touch "$EMPTY_FILE"

if [ -f "$EMPTY_FILE" ]; then
    if [ -s "$EMPTY_FILE" ]; then
        echo "فایل غیر خالی است"
    else
        echo "فایل خالی است"
    fi
fi

rm "$EMPTY_FILE"
```

### توضیح خط به خط:

- `[ -f "$FILE" ]` - بررسی اینکه آیا فایل معمولی وجود دارد
- `[ -r "$FILE" ]` - بررسی قابلیت خواندن
- `[ -w "$FILE" ]` - بررسی قابلیت نوشتن
- `[ -d "$DIR" ]` - بررسی اینکه آیا دایرکتوری است
- `[ -s "$FILE" ]` - بررسی اینکه آیا فایل غیر خالی است
- `touch "$EMPTY_FILE"` - ایجاد فایل خالی
- `rm "$EMPTY_FILE"` - حذف فایل

## استفاده از [[ ]]

`[[ ]]` نسخه مدرن‌تر و قدرتمندتر از `[ ]` است:

```bash
# پشتیبانی از && و || داخلی
if [[ $AGE -ge 18 && $HAS_LICENSE == true ]]; then
    echo "OK"
fi

# پشتیبانی از تطبیق الگو (pattern matching)
if [[ $NAME == A* ]]; then
    echo "نام با A شروع می‌شود"
fi
```

## مثال ۷: استفاده از [[ ]]

فایل [examples/07-double-brackets.sh](examples/07-double-brackets.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

NAME="Ali"
AGE=25

# استفاده از && و || در [[ ]]
if [[ $AGE -ge 18 && $NAME == "Ali" ]]; then
    echo "شرط برقرار است"
fi

# تطبیق الگو
if [[ $NAME == A* ]]; then
    echo "نام با A شروع می‌شود"
fi

# تطبیق با regex
if [[ $NAME =~ ^[A-Z] ]]; then
    echo "نام با حرف بزرگ شروع می‌شود"
fi
```

### توضیح خط به خط:

- `[[ $AGE -ge 18 && $NAME == "Ali" ]]` - استفاده از && داخل [[ ]]
- `[[ $NAME == A* ]]` - تطبیق الگو (A* = هر چیزی که با A شروع شود)
- `[[ $NAME =~ ^[A-Z] ]]` - تطبیق با regex (شروع با حرف بزرگ)

## نکات رایج اشتباهات (Common Pitfalls)

### ۱. فراموش کردن فاصله در [ ]

❌ اشتباه:
```bash
if [$AGE -gt 18]; then  # خطا!
```

✅ درست:
```bash
if [ $AGE -gt 18 ]; then
```

### ۲. استفاده از = برای مقایسه اعداد

❌ اشتباه:
```bash
if [ $AGE = 18 ]; then  # برای رشته‌هاست
```

✅ درست:
```bash
if [ $AGE -eq 18 ]; then  # برای اعداد
```

### ۳. فراموش کردن quote برای رشته‌ها

❌ اشتباه:
```bash
if [ $NAME = Ali Reza ]; then  # خطا!
```

✅ درست:
```bash
if [ "$NAME" = "Ali Reza" ]; then
```

### ۴. استفاده از < و > در [ ]

❌ اشتباه:
```bash
if [ $AGE < 18 ]; then  # خطا!
```

✅ درست:
```bash
if [ $AGE -lt 18 ]; then  # یا در [[ ]]
if [[ $AGE < 18 ]]; then
```

## بهترین شیوه‌ها (Best Practices)

1. **همیشه از فاصله در [ ] استفاده کنید** - فاصله دور عملگرها الزامی است
2. **رشته‌ها را همیشه quote کنید** - برای جلوگیری از مشکلات با فاصله
3. **از [[ ]] به جای [ ] استفاده کنید** - قدرتمندتر و مدرن‌تر
4. **از case برای مقایسه‌های چندگانه استفاده کنید** - خواناتر از ifهای متعدد
5. **متغیرها را قبل از استفاده تست کنید** - برای جلوگیری از خطا
