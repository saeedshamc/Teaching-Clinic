## متغیرها در Bash

متغیرها در Bash برای ذخیره اطلاعات استفاده می‌شوند. نام متغیرها باید با حرف یا زیرخط (_) شروع شود و می‌تواند شامل حروف، اعداد و زیرخط باشد.

### تعریف متغیر

```bash
NAME="علی"
AGE=25
CITY="تهران"
```

⚠️ **نکته مهم**: در تعریف متغیر، هیچ فاصله‌ای نباید حول علامت مساوی باشد.

### استفاده از متغیر

```bash
echo $NAME
echo "نام: $NAME"
echo "سن: $AGE"
```

## مثال ۱: متغیرهای پایه

فایل [examples/01-basic-variables.sh](examples/01-basic-variables.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# تعریف متغیرهای مختلف
NAME="علی"
AGE=25
CITY="تهران"
JOB="برنامه‌نویس"

# استفاده از متغیرها
echo "نام: $NAME"
echo "سن: $AGE"
echo "شهر: $CITY"
echo "شغل: $JOB"

# ترکیب متغیرها
echo -e "\nمعرفی کامل:"
echo "$NAME، $AGE ساله، در $CITY زندگی می‌کند و $JOB است."
```

### توضیح خط به خط:

- `NAME="علی"` - متغیر NAME را با مقدار "علی" تعریف می‌کند
- `AGE=25` - متغیر AGE را با مقدار 25 تعریف می‌کند
- `echo "نام: $NAME"` - مقدار متغیر NAME را چاپ می‌کند
- `echo -e "\n"` - یک خط خالی چاپ می‌کند
- `echo "$NAME، $AGE ساله..."` - چند متغیر را در یک جمله ترکیب می‌کند

## Quoting در Bash

در Bash سه نوع quoting وجود دارد که هر کدام رفتار متفاوتی دارند:

### ۱. Double Quotes ("")

متغیرها و دستورات داخل آن تفسیر می‌شوند:

```bash
NAME="علی"
echo "سلام $NAME"  # خروجی: سلام علی
echo "امروز $(date)"  # خروجی: امروز [تاریخ]
```

### ۲. Single Quotes ('')

همه چیز به صورت literal در نظر گرفته می‌شود:

```bash
NAME="علی"
echo 'سلام $NAME'  # خروجی: سلام $NAME
echo 'امروز $(date)'  # خروجی: امروز $(date)
```

### ۳. Backticks (`) یا $()

برای اجرای دستورات و استفاده از خروجی آن‌ها:

```bash
echo "امروز: $(date)"
echo "مسیر جاری: `pwd`"
```

## مثال ۲: انواع Quoting

فایل [examples/02-quoting.sh](examples/02-quoting.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

NAME="علی"
CURRENT_DIR=$(pwd)
CURRENT_DATE=$(date)

# Double Quotes - متغیرها تفسیر می‌شوند
echo "Double Quotes:"
echo "  نام: $NAME"
echo "  مسیر: $CURRENT_DIR"
echo "  تاریخ: $CURRENT_DATE"

# Single Quotes - متغیرها تفسیر نمی‌شوند
echo -e "\nSingle Quotes:"
echo '  نام: $NAME'
echo '  مسیر: $CURRENT_DIR'
echo '  تاریخ: $CURRENT_DATE'

# Backticks - اجرای دستورات
echo -e "\nBackticks:"
echo "  مسیر: `pwd`"
echo "  کاربر: `whoami`"
echo "  فایل‌ها: `ls | wc -l`"

# ترکیب quoting
echo -e "\nترکیب quoting:"
echo "نام کاربر: '$(whoami)'"
echo "مسیر: \"$CURRENT_DIR\""
```

### توضیح خط به خط:

- `CURRENT_DIR=$(pwd)` - خروجی دستور pwd را در متغیر ذخیره می‌کند
- `echo "نام: $NAME"` - متغیر تفسیر می‌شود
- `echo 'نام: $NAME'` - متغیر تفسیر نمی‌شود
- `echo "مسیر: \`pwd\`"` - دستور داخل backticks اجرا می‌شود
- `echo "نام کاربر: '$(whoami)'"` - ترکیب double و single quotes

## ورودی از کاربر

### دستور read

دستور `read` برای گرفتن ورودی از کاربر استفاده می‌شود:

```bash
read NAME              # گرفتن ورودی و ذخیره در NAME
read -p "نام: " NAME   # نمایش پیام قبل از گرفتن ورودی
read -s PASSWORD       # گرفتن ورودی مخفی (برای رمز عبور)
```

## مثال ۳: ورودی تعاملی

فایل [examples/03-interactive-input.sh](examples/03-interactive-input.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# گرفتن نام با پیام
read -p "لطفاً نام خود را وارد کنید: " NAME

# گرفتن سن
read -p "لطفاً سن خود را وارد کنید: " AGE

# گرفتن شهر
read -p "لطفاً شهر خود را وارد کنید: " CITY

# چاپ خروجی
echo -e "\n--- اطلاعات شما ---"
echo "نام: $NAME"
echo "سن: $AGE"
echo "شهر: $CITY"

# محاسبه سال تولد
CURRENT_YEAR=$(date +%Y)
BIRTH_YEAR=$((CURRENT_YEAR - AGE))
echo "سال تولد تقریبی: $BIRTH_YEAR"
```

### توضیح خط به خط:

- `read -p "..." NAME` - پیام را نمایش می‌دهد و ورودی را در NAME ذخیره می‌کند
- `echo -e "\n---"` - خط خالی و سپس جداکننده چاپ می‌کند
- `date +%Y` - سال جاری را برمی‌گرداند
- `$((CURRENT_YEAR - AGE))` - عملیات ریاضی انجام می‌دهد

## متغیرهای خاص Bash

Bash متغیرهای خاصی دارد که به صورت خودکار مقداردهی می‌شوند:

```bash
$0      # نام اسکریپت
$1-$9   # آرگومان‌های اسکریپت
$#      # تعداد آرگومان‌ها
$@      # تمام آرگومان‌ها به صورت جداگانه
$*      # تمام آرگومان‌ها به صورت یک رشته
$?      # کد خروجی آخرین دستور
$$      # PID فرآیند جاری
$!      # PID آخرین فرآیند پس‌زمینه
```

## مثال ۴: متغیرهای خاص

فایل [examples/04-special-variables.sh](examples/04-special-variables.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

echo "--- متغیرهای خاص ---"
echo "نام اسکریپت: $0"
echo "تعداد آرگومان‌ها: $#"
echo "آرگومان‌ها: $@"
echo "PID اسکریپت: $$"

# اجرای یک دستور برای تست $?
echo -e "\nاجرای یک دستور موفق:"
ls /tmp > /dev/null 2>&1
echo "کد خروجی: $?"

# اجرای یک دستور ناموفق
echo -e "\nاجرای یک دستور ناموفق:"
ls /nonexistent > /dev/null 2>&1
echo "کد خروجی: $?"
```

### توضیح خط به خط:

- `$0` - نام فایل اسکریپت را نمایش می‌دهد
- `$#` - تعداد آرگومان‌های داده شده به اسکریپت را نمایش می‌دهد
- `$@` - تمام آرگومان‌ها را نمایش می‌دهد
- `$$` - شناسه فرآیند (PID) اسکریپت را نمایش می‌دهد
- `$?` - کد خروجی آخرین دستور را نمایش می‌دهد (0 = موفق، غیر 0 = ناموفق)
- `> /dev/null 2>&1` - خروجی را مخفی می‌کند

## عملیات ریاضی

Bash از عملیات ریاضی با استفاده از `$((...))` یا `let` پشتیبانی می‌کند:

```bash
RESULT=$((5 + 3))        # 8
RESULT=$((10 - 4))       # 6
RESULT=$((6 * 7))        # 42
RESULT=$((20 / 4))       # 5
RESULT=$((20 % 3))       # 2 (باقی‌مانده)
```

## مثال ۵: عملیات ریاضی

فایل [examples/05-arithmetic.sh](examples/05-arithmetic.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# تعریف متغیرهای عددی
NUM1=10
NUM2=5

# عملیات ریاضی
SUM=$((NUM1 + NUM2))
DIFF=$((NUM1 - NUM2))
PRODUCT=$((NUM1 * NUM2))
DIVISION=$((NUM1 / NUM2))
MODULO=$((NUM1 % NUM2))

echo "عدد اول: $NUM1"
echo "عدد دوم: $NUM2"
echo -e "\n--- نتایج ---"
echo "جمع: $SUM"
echo "تفریق: $DIFF"
echo "ضرب: $PRODUCT"
echo "تقسیم: $DIVISION"
echo "باقی‌مانده: $MODULO"

# محاسبه مساحت مستطیل
read -p "طول مستطیل: " LENGTH
read -p "عرض مستطیل: " WIDTH
AREA=$((LENGTH * WIDTH))
echo "مساحت مستطیل: $AREA"
```

### توضیح خط به خط:

- `$((NUM1 + NUM2))` - عملیات جمع را انجام می‌دهد
- `$((NUM1 - NUM2))` - عملیات تفریق را انجام می‌دهد
- `$((NUM1 * NUM2))` - عملیات ضرب را انجام می‌دهد
- `$((NUM1 / NUM2))` - عملیات تقسیم صحیح را انجام می‌دهد
- `$((NUM1 % NUM2))` - باقی‌مانده تقسیم را محاسبه می‌کند
- `read -p "..." LENGTH` - ورودی را از کاربر می‌گیرد
- `$((LENGTH * WIDTH))` - مساحت را محاسبه می‌کند

## نکات رایج اشتباهات (Common Pitfalls)

### ۱. فاصله در تعریف متغیر

❌ اشتباه:
```bash
NAME = "علی"  # خطا!
```

✅ درست:
```bash
NAME="علی"
```

### ۲. فراموش کردن $ در استفاده از متغیر

❌ اشتباه:
```bash
NAME="علی"
echo NAME  # چاپ می‌کند: NAME
```

✅ درست:
```bash
NAME="علی"
echo $NAME  # چاپ می‌کند: علی
```

### ۳. استفاده از single quotes برای تفسیر متغیر

❌ اشتباه:
```bash
NAME="علی"
echo 'سلام $NAME'  # چاپ می‌کند: سلام $NAME
```

✅ درست:
```bash
NAME="علی"
echo "سلام $NAME"  # چاپ می‌کند: سلام علی
```

### ۴. فاصله در عملیات ریاضی

❌ اشتباه:
```bash
RESULT = $((5 + 3))  # خطا!
```

✅ درست:
```bash
RESULT=$((5 + 3))
```

## بهترین شیوه‌ها (Best Practices)

1. **همیشه از double quotes استفاده کنید** - مگر اینکه نیاز به literal داشته باشید
2. **نام متغیرها را با حروف بزرگ بنویسید** - برای تشخیص آسان‌تر
3. **از نام‌های معنادار استفاده کنید** - مثلاً USER_NAME به جای N
4. **قبل از استفاده، متغیر را تعریف کنید** - برای جلوگیری از خطا
5. **از $((...)) برای عملیات ریاضی استفاده کنید** - خواناتر از let
