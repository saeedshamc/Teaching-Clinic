# جلسه ۱: مقدمه‌ای بر Shell و Bash

## اهداف یادگیری

در این جلسه یاد می‌گیرید:
- Shell چیست و چه کاربردی دارد
- Bash چیست و چرا محبوب‌ترین Shell است
- چگونه Bash را نصب و پیکربندی کنید
- اولین اسکریپت Bash خود را بنویسید و اجرا کنید
- ساختار پایه‌ای یک اسکریپت Bash را درک کنید

## Shell چیست؟

Shell (پوسته) یک برنامه است که به عنوان رابط بین کاربر و سیستم‌عامل عمل می‌کند. وقتی شما در ترمینال دستوری تایپ می‌کنید، Shell آن دستور را می‌فهمد، تفسیر می‌کند و به سیستم‌عامل می‌دهد تا اجرا شود.

### انواع Shell

چندین نوع Shell وجود دارد:
- **Bash** (Bourne Again Shell) - محبوب‌ترین و پرکاربردترین
- **Zsh** (Z Shell) - پیشرفته‌تر با امکانات بیشتر
- **Fish** -友好 و کاربرپسند
- **PowerShell** - مخصوص ویندوز
- **sh** - Shell اصلی یونیکس

### چرا Bash؟

Bash به دلایل زیر محبوب است:
- در اکثر سیستم‌های لینوکس به صورت پیش‌فرض نصب است
- سازگاری بالا با سیستم‌های مختلف
- جامعه کاربری بزرگ و مستندات فراوان
- قدرتمند و انعطاف‌پذیر

## نصب و پیکربندی Bash

### روی لینوکس

اکثر توزیع‌های لینوکس Bash را به صورت پیش‌فرض دارند. برای اطمینان:

```bash
# بررسی نسخه Bash
bash --version
```

### روی macOS

macOS نیز Bash را به صورت پیش‌فرض دارد (هرچند نسخه قدیمی‌تر). برای نسخه جدیدتر:

```bash
# با استفاده از Homebrew
brew install bash
```

### روی ویندوز

روی ویندوز می‌توانید از WSL (Windows Subsystem for Linux) استفاده کنید:

1. WSL را از PowerShell با دسترسی ادمین نصب کنید:
```powershell
wsl --install
```

2. سیستم را ریستارت کنید
3. یک توزیع لینوکس (مثل Ubuntu) را نصب کنید

## ساختار پایه‌ای یک اسکریپت Bash

هر اسکریپت Bash با یک خط خاص به نام shebang شروع می‌شود:

```bash
#!/usr/bin/env bash
```

این خط به سیستم می‌گوید که از چه برنامه‌ای برای اجرای این اسکریپت استفاده کند.

## مثال ۱: اولین اسکریپت Hello World

فایل [examples/01-hello-world.sh](examples/01-hello-world.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# این اولین اسکریپت ماست
# خطوطی که با # شروع می‌شوند کامنت هستند و اجرا نمی‌شوند

echo "Hello, World!"
```

### توضیح خط به خط:

- `#!/usr/bin/env bash` - shebang: مشخص می‌کند که این فایل با Bash اجرا شود
- `# این اولین اسکریپت ماست` - کامنت: توضیح برای انسان، نادیده گرفته می‌شود
- `echo "Hello, World!"` - دستور echo: متن را در خروجی چاپ می‌کند

### اجرای اسکریپت:

```bash
# روش ۱: مستقیم با bash
bash examples/01-hello-world.sh

# روش ۲: با دادن دستور اجرا
chmod +x examples/01-hello-world.sh
./examples/01-hello-world.sh
```

## مثال ۲: اسکریپت با متغیر ساده

فایل [examples/02-simple-variable.sh](examples/02-simple-variable.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# تعریف یک متغیر
NAME="علی"

# استفاده از متغیر با $
echo "سلام، $NAME خوش آمدی!"

# چاپ تاریخ و زمان
echo "امروز: $(date)"
```

### توضیح خط به خط:

- `NAME="علی"` - متغیر NAME را با مقدار "علی" تعریف می‌کند
- `echo "سلام، $NAME خوش آمدی!"` - از متغیر NAME با استفاده از $ استفاده می‌کند
- `$(date)` - دستور date را اجرا کرده و خروجی آن را در متن قرار می‌دهد

## مثال ۳: اسکریپت تعاملی با ورودی کاربر

فایل [examples/03-interactive-input.sh](examples/03-interactive-input.sh) را بررسی کنید:

```bash
#!/usr/bin/env bash

# درخواست نام از کاربر
echo "لطفاً نام خود را وارد کنید:"
read NAME

# درخواست سن از کاربر
echo "لطفاً سن خود را وارد کنید:"
read AGE

# چاپ خروجی شخصی‌سازی شده
echo "سلام $NAME! شما $AGE سال دارید."
```

### توضیح خط به خط:

- `read NAME` - برنامه متوقف می‌شود تا کاربر چیزی تایپ کند، سپس آن را در متغیر NAME ذخیره می‌کند
- `read AGE` - همین کار برای سن انجام می‌دهد
- سپس از متغیرها برای چاپ خروجی استفاده می‌شود

## نکات رایج اشتباهات (Common Pitfalls)

### ۱. فراموش کردن shebang

❌ اشتباه:
```bash
echo "Hello"
```

✅ درست:
```bash
#!/usr/bin/env bash
echo "Hello"
```

### ۲. فاصله در تعریف متغیر

❌ اشتباه:
```bash
NAME = "علی"  # این کار غلط است!
```

✅ درست:
```bash
NAME="علی"  # بدون فاصله
```

### ۳. فراموش کردن $ در استفاده از متغیر

❌ اشتباه:
```bash
NAME="علی"
echo NAME  # چاپ می‌کند: NAME
```

✅ درست:
```bash
NAME="علی"
echo $NAME  # چاپ می‌کند: علی
```

### ۴. استفاده از فونت‌های غیر استاندارد در کد

❌ اشتباه:
```bash
نام="علی"  # ممکن است در برخی سیستم‌ها مشکل ایجاد کند
```

✅ درست:
```bash
NAME="علی"  # از حروف انگلیسی برای نام متغیرها استفاده کنید
```

## بهترین شیوه‌ها (Best Practices)

1. **همیشه shebang را در خط اول قرار دهید**
2. **از کامنت‌های فارسی برای توضیح کد استفاده کنید**
3. **نام متغیرها را با حروف بزرگ انگلیسی بنویسید**
4. **اسکریپت‌ها را قبل از استفاده تست کنید**
5. **از نام‌های معنادار برای متغیرها استفاده کنید**
