# دوره آموزشی جامع Bash Scripting

یک دوره کامل ۲۰ جلسه‌ای برای یادگیری Bash Scripting از سطح مبتدی تا حرفه‌ای

## معرفی دوره

این دوره برای کسانی طراحی شده که می‌خواهند از صفر Bash Scripting را یاد بگیرند و به سطح حرفه‌ای برسند. تمام توضیحات به زبان فارسی است و شامل مثال‌های عملی و تمرین‌های واقعی می‌باشد.

## مخاطب هدف

- مبتدیان مطلق که هیچ تجربه‌ای با Bash ندارند
- توسعه‌دهندگان نرم‌افزار که می‌خواهند کارهای خود را خودکار کنند
- مدیران سیستم (System Administrators)
- هر کسی که با لینوکس/مک کار می‌کند و می‌خواهد بهره‌وری خود را افزایش دهد

## پیش‌نیازها

- سیستم‌عامل لینوکس، macOS، یا WSL (Windows Subsystem for Linux) روی ویندوز
- دسترسی به ترمینال
- هیچ پیش‌زمینه برنامه‌نویسی لازم نیست (هرچند مفید است)

## نحوه اجرای اسکریپت‌ها

برای اجرای اسکریپت‌های این دوره:

```bash
# روش ۱: با استفاده از bash
bash script-name.sh

# روش ۲: با دادن دستور اجرا
chmod +x script-name.sh
./script-name.sh
```
