# تمرین‌های جلسه ۲ — IDE و Emulator

## آسان
1. Android Studio را نصب و SDK را تنظیم کنید.
2. یک Emulator بسازید و `flutter devices` را چک کنید.

## متوسط
3. `flutter create test_app` و `flutter run` را روی emulator اجرا کنید.
4. Hot Reload (r) و Hot Restart (R) را تست کنید — تغییر رنگ AppBar.

## سخت
5. اپ را روی Chrome اجرا کنید (`flutter run -d chrome`).
6. اپ را روی دستگاه واقعی با USB Debugging اجرا کنید.
