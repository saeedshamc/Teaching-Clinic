# تمرین‌های جلسه ۱ — نصب محیط

## آسان
1. `flutter doctor` را اجرا کنید — همهٔ موارد باید ✓ باشند.
2. `dart --version` و `flutter --version` را چک کنید.

## متوسط
3. یک پروژهٔ Dart بسازید: `dart create test_app` و `bin/test_app.dart` را اجرا کنید.
4. در DartPad یک برنامهٔ ساده بنویسید و Run کنید.

## سخت
5. `flutter doctor` را روی هر ۳ OS (Win/Linux/macOS) توضیح دهید.
6. برای خطای Android licenses راه‌حل بنویسید.
