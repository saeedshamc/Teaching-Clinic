# پروژهٔ جلسه ۳ — اولین push به GitHub

## صورت پروژه
یک پروژهٔ Flutter را به GitHub push کنید:
- [ ] `git init` و `.gitignore` مناسب
- [ ] `user.name` و `user.email` تنظیم شده
- [ ] اولین commit با پیام conventional
- [ ] Remote به GitHub متصل (SSH یا HTTPS)
- [ ] `git push -u origin main` موفق
