# تمرین‌های جلسه ۳ — Git و GitHub

## آسان
1. `git config --global user.name` و `user.email` را تنظیم کنید.
2. `.gitignore` مناسب Flutter را در یک پروژه بسازید.

## متوسط
3. یک پروژهٔ Flutter را init کنید، commit کنید و به GitHub push کنید.
4. یک branch بسازید، تغییر دهید، merge کنید.

## سخت
5. SSH key بسازید و به GitHub اضافه کنید — push با SSH.
6. `git rebase` را روی یک branch تمرین کنید.
