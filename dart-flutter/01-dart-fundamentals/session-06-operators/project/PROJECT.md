# پروژهٔ جلسه ۶ — ماشین‌حساب

## صورت پروژه
یک ماشین‌حساب ساده بنویسید:
- دو عدد `a` و `b` (int)
- عملگر `op` (+, -, *, /)
- نتیجه را چاپ کنید
- اگر `b == 0` و op == '/' → 'Cannot divide by zero'

نمونه:
```
a=10, b=3, op=+ → 13
a=10, b=0, op=/ → Cannot divide by zero
```
