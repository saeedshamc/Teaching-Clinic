# پروژهٔ جلسه ۱۰ — دفترچهٔ تلفن

## صورت پروژه
یک دفترچهٔ تلفن ساده بسازید:
- `Map<String, String>` برای name → phone
- `addContact(name, phone)`
- `findContact(name)`
- `listContacts()`
- `main()` که چند مخاطب اضافه و چاپ کند

خروجی نمونه:
```
Contacts:
  Ali: 0912...
  Sara: 0935...
```

## پاسخ
`solution/main.dart`
