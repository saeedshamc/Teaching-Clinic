# تمرین‌های جلسه ۷ — کنترل جریان

## آسان
1. `if/else` بنویسید که عدد را به positive/negative/zero طبقه‌بندی کند.
2. `for` loop برای چاپ ۱ تا ۱۰.

## متوسط
3. `switch` روی `String` با چند case بنویسید.
4. `while` برای شمارش معکوس از ۱۰ تا ۱.

## سخت
5. `for-in` روی `Map` — key و value را چاپ کنید.
6. `break`/`continue` برای پیدا کردن اولین عدد زوج در لیست.
