# تمرین‌های جلسه ۸ — توابع

## آسان
1. تابع `sub(int a, int b)` بنویسید که تفاضل را برگرداند.
2. تابع `isEven(int n)` بنویسید که bool برگرداند.

## متوسط
3. تابع با named parameters برای ساخت `Book(title, author, year)` بنویسید.
4. تابع higher-order بنویسید که یک function را دو بار اجرا کند.

## سخت
5. تابع recursive برای Fibonacci بنویسید.
6. `List<int>` را با `map` و `where` پردازش کنید (پیش‌نمایش collections).
