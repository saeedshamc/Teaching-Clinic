# پروژهٔ جلسه ۸ — سیستم مدیریت وظایف

## صورت پروژه
یک سیستم task manager ساده با توابع بنویسید:
- `addTask(List<String> tasks, String task)`
- `completeTask(List<String> tasks, int index)`
- `listTasks(List<String> tasks)`
- `main()` که چند عملیات را نمایش دهد

خروجی نمونه:
```
Tasks:
  [ ] Buy milk
  [x] Read book
  [ ] Call mom
```

## پاسخ
`solution/main.dart`
