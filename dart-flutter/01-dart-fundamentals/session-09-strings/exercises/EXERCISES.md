# تمرین‌های جلسه ۹ — رشته‌ها

## آسان
1. نام و نام خانوادگی را با interpolation چاپ کنید.
2. `toUpperCase` و `toLowerCase` را تست کنید.

## متوسط
3. یک رشتهٔ CSV را با `split` به لیست تبدیل کنید.
4. `StringBuffer` برای ساختن HTML ساده استفاده کنید.

## سخت
5. یک تابع `reverse(String s)` بنویسید که رشته را برعکس کند.
6. `padLeft`/`padRight` برای فرمت جدول ساده استفاده کنید.
