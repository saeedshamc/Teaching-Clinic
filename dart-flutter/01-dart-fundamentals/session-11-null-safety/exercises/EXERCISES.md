# تمرین‌های جلسه ۱۱ — Null Safety

## آسان
1. `String?` بسازید و با `??` مدیریت کنید.
2. `?.` را برای method call روی nullable تست کنید.

## متوسط
3. `late` را برای فیلدی که دیر initialize می‌شود به‌کار ببرید.
4. `required` named parameter برای constructor بنویسید.

## سخت
5. `!` را در چه مواردی امن است استفاده کنید — توضیح دهید.
6. `??=` را برای caching یک مقدار استفاده کنید.
