# پروژهٔ جلسه ۱۱ — User Profile با Null Safety

## صورت پروژه
کلاس `UserProfile` بسازید:
- `name` (required, non-null)
- `email` (nullable, optional)
- `bio` (nullable, optional)
- `display()` که null-safe چاپ کند

خروجی:
```
Name: Ali, Email: ali@mail.com, Bio: N/A
```
