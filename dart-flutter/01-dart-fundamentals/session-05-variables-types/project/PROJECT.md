# پروژهٔ جلسه ۵ — پروفایل کاربر

## صورت پروژه
یک کلاس `UserProfile` بسازید با فیلدهای:
- `name` (String, required)
- `age` (int, optional با default 0)
- `email` (String?, nullable)
- `isActive` (bool, default true)

متد `display()` که همه را چاپ کند.
نمونهٔ خروجی:
```
Name: Ali, Age: 30, Email: ali@mail.com, Active: true
```
