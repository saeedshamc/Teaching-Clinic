# تمرین‌های جلسه ۵ — متغیرها و انواع

## آسان
1. سه متغیر `var` بسازید: نام، سن، شهر — چاپ کنید.
2. یک `final` و یک `const` تعریف کنید — تفاوت را توضیح دهید.

## متوسط
3. `String?` nullable بسازید و با `??` و `?.` مدیریت کنید.
4. `int.parse` و `num.tryParse` را تست کنید — موفق و ناموفق.

## سخت
5. `late` را برای یک فیلد که دیر initialize می‌شود به‌کار ببرید.
6. یک تابع بنویسید که `num` بگیرد و نوعش را برگرداند (`is int`/`is double`).
