# پروژهٔ جلسه ۱۲ — ماشین‌حساب امن

## صورت پروژه
یک ماشین‌حساب بنویسید که:
- دو عدد و عملگر بگیرد
- `FormatException` برای ورودی نامعتبر
- `DivisionByZeroException` برای تقسیم بر صفر
- `finally` برای چاپ نتیجهٔ نهایی

نمونه:
```
Enter first number: 10
Enter second number: 0
Enter operator: /
Error: Cannot divide by zero
Final result: N/A
```
