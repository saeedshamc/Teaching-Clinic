# تمرین‌های جلسه ۱۲ — Exception ها

## آسان
1. `int.parse('abc')` را در try/catch بگذارید.
2. `10 ~/ 0` را در try/catch بگذارید.

## متوسط
3. `on FormatException` برای specific handling بنویسید.
4. یک custom exception `InvalidInputException` بسازید.

## سخت
5. `finally` برای cleanup (مثلاً بستن فایل) استفاده کنید.
6. nested try/catch برای چند سطح error handling.
