# پروژهٔ جلسه ۱۳ — بازی حدس عدد

## صورت پروژه
یک بازی کنسولی بنویسید:
- عدد تصادفی ۱ تا ۱۰۰ انتخاب می‌شود
- کاربر حدس می‌زند
- برنامه می‌گوید «بیشتر» یا «کمتر»
- تا وقتی درست حدس بزند ادامه می‌دهد
- تعداد تلاش‌ها را چاپ کند

نمونه:
```
Guess a number (1-100): 50
Higher!
Guess: 75
Lower!
...
Correct! You got it in 7 tries.
```
