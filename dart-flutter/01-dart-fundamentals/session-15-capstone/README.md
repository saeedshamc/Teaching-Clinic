## پروژه

**Book Manager** — یک برنامهٔ کنسولی برای مدیریت کتاب:

### قابلیت‌ها
- افزودن کتاب (title, author, year)
- لیست همهٔ کتاب‌ها
- جستجو بر اساس عنوان یا نویسنده
- حذف کتاب
- آمار (تعداد کتاب‌ها، قدیمی‌ترین/جدیدترین)

### داده
از `List<Map<String, dynamic>>` یا ساختار ساده استفاده کنید (کلاس‌ها در فاز ۲ می‌آیند).

### خروجی نمونه
```
=== Book Manager ===
1) Add book
2) List books
3) Search
4) Delete
5) Stats
0) Exit
> 1
Title: Dart in Action
Author: Bob Nystrom
Year: 2019
Book added!
```
