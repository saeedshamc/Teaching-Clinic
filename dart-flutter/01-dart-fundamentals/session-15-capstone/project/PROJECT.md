# پروژهٔ توسعه — Book Manager پیشرفته

نسخهٔ capstone را به این موارد گسترش دهید:

## الزامات
- [ ] ذخیره/بارگذاری در فایل (`books.txt`)
- [ ] مرتب‌سازی بر اساس عنوان/سال/نویسنده
- [ ] خروجی جدول با `StringBuffer` و `padRight`
- [ ] ویرایش کتاب (update title/author/year)
- [ ] فیلتر بر اساس بازهٔ سال
- [ ] خروجی CSV برای import/export

## معیار پذیرش
- داده‌ها بعد از بستن برنامه باقی بمانند
- جستجو و فیلتر سریع باشد
- UI کنسولی تمیز و خوانا باشد

## صورت پروژه
پاسخ در `solution/` — پیاده‌سازی کامل.
