# تمرین‌های جلسه ۴ — اولین برنامه

## آسان
1. `dart create hello` و `dart run` را تست کنید.
2. `main.dart` را طوری تغییر دهید که نام و سن شما را چاپ کند.

## متوسط
3. یک محاسبه بنویسید: مساحت دایره با `pi = 3.14159` و شعاع ۵.
4. چند `print` با String interpolation بنویسید.

## سخت
5. یک تابع `greet(String name)` بنویسید که "Hello, name!" چاپ کند و در main صدا بزنید.
6. خروجی را با `print` چندخطی و emoji زیباتر کنید.
