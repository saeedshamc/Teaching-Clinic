# دوره Django — از صفر تا ساخت پروژه واقعی

دوره‌ای کامل برای یادگیری فریم‌ورک Django با تمرکز بر:

- مفاهیم اصلی: مدل، ویو، قالب، URL، ORM
- پنل ادمین، فرم‌ها، احراز هویت، سشن و میدل‌ور
- Class-Based Views، سیگنال‌ها، تست و بهینه‌سازی
- پروژهٔ نهایی (Capstone) با ساختار واقعی

## ساختار دوره

هر جلسه یک پوشه دارد:

```
session-XX-name/
├── README.md        ← درس + تمرین + جواب تمرین
└── code/            ← کدهای نمونه با کامنت فارسی دقیق
```

## پیش‌نیاز

- Python 3.10+ نصب‌شده
- آشنایی مقدماتی با Python و HTML
- (اختیاری) Virtualenv

## شروع سریع

1. محیط مجازی بسازید: `python -m venv .venv`
2. Django را نصب کنید: `pip install django`
3. پروژه اول را با `django-admin startproject config .` بسازید
4. جلسات را به ترتیب بخوانید و کدهای `code/` را در پروژه خود اجرا کنید

جزئیات بیشتر در [SETUP.md](./SETUP.md) و [SYLLABUS.md](./SYLLABUS.md).
