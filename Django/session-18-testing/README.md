# جلسه ۱۸ — تست در Django

## درس

Django از `unittest` استفاده می‌کند و کلاس `TestCase` دیتابیس تست جداگانه می‌سازد.

### ساختار تست

```python
# library/tests.py یا library/tests/test_models.py
from django.test import TestCase
from .models import Book, Author

class BookModelTest(TestCase):
    def setUp(self):
        # قبل از هر تست اجرا می‌شود — دادهٔ نمونه بسازید
        self.author = Author.objects.create(name="لوییس")
        self.book = Book.objects.create(
            title="جنگو", author=self.author, pages=300
        )

    def test_book_str(self):
        self.assertEqual(str(self.book), "جنگو")

    def test_book_count(self):
        self.assertEqual(Book.objects.count(), 1)

    def test_filter(self):
        self.assertTrue(Book.objects.filter(pages__gt=200).exists())
```

### تست ویو با Client

```python
from django.test import Client
from django.urls import reverse

class BookViewTest(TestCase):
    def setUp(self):
        self.client = Client()
        self.book = Book.objects.create(title="تست", pages=100)

    def test_list_view(self):
        response = self.client.get(reverse("library:book_list"))
        self.assertEqual(response.status_code, 200)
        self.assertContains(response, "تست")   # متن در HTML هست

    def test_detail_view(self):
        url = reverse("library:book_detail", args=[self.book.id])
        response = self.client.get(url)
        self.assertEqual(response.status_code, 200)

        response = self.client.get(reverse("library:book_create"))
```

## تمرین

یک تست بنویسید که اگر کتابی با صفحات منفی ساخته شود ValidationError بدهد.

## جواب تمرین

```python
def test_negative_pages(self):
    with self.assertRaises(ValidationError):
        Book(pages=-5).full_clean()   # full_clean اعتبارسنجی فیلدها را اجرا می‌کند
```

## 📖 شرح فایل `code/tests.py`

**`BookModelTest(TestCase)`** — `setUp` قبل از **هر** تست دادهٔ نمونه می‌سازد (هر تست DB تمیز دارد):
- `test_str_representation` — `__str__` را چک می‌کند.
- `test_default_ordering` — `Meta.ordering` را تأیید می‌کند.
- `test_filter_by_author` — رابطهٔ FK در کوئری.
- `test_price_validation` — `full_clean()` validators را اجرا می‌کند (save() به‌تنهایی صدا نمی‌زند).

**`BookViewTest(TestCase)`** — `setUpTestData` فقط **یک‌بار** برای کل کلاس اجرا می‌شود (سریع‌تر از setUp):
- `self.client` — شبیه‌ساز مرورگر؛ `client.get/post` request واقعی می‌زند.
- `reverse("library:book_list")` — URL را از name می‌سازد (به‌جای هاردکد).
- `assertTemplateUsed` — بررسی می‌کند کدام قالب رندر شده.
- `assertContains(response, "متن")` — متن در HTML هست.
- `force_login(user)` — بدون فرم login واقعی، کاربر را لاگین می‌کند.
