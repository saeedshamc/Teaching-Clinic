# جلسه ۰۹ — معماری پوشه و Custom Hooks (توضیح + الگو)

**مدت:** ۹۰ دقیقه

## پیش‌نیازها
جلسات ۰۱–۰۸.

## اهداف قابل‌اندازه‌گیری
1. یک ساختار پوشه برای اپ کوچک پیشنهاد دهید.
2. custom hook بسازید که منطق state را جدا کند.
3. بگویید این توضیح معماری است و پروژهٔ موجود ریپو را تغییر نمی‌دهیم.

## چرا مهم است؟
بدون قرارداد پوشه، فایل‌ها سریع entropی می‌گیرند. برای اپ کوچک، سادگی بر «enterprise theater» اولویت دارد.

## مفهوم عمیق — الگوی پیشنهادی اپ کوچک
```text
src/
  app/          # یا صفحات اگر router
  components/   # UI قابل‌استفاده مجدد
  hooks/        # useX
  lib/          # توابع خالص، api client
  styles/
```
Feature-first وقتی تیم/دامنه بزرگ شد مفید است؛ برای شروع، لایه‌بندی بالا کافی است.

```jsx
function useToggle(initial = false) {
  const [on, setOn] = useState(initial);
  const toggle = () => setOn((v) => !v);
  return { on, toggle, setOn };
}
```

## اشتباهات رایج
1. کپی ساختار غول برای TODO app.
2. hookهایی که فقط یک useState را بی‌دلیل wrap می‌کنند.
3. قاطی کردن fetch و UI بدون لایهٔ lib.

## مثال
hook `useToggle` را در فایل جدا بگذارید و در دو کامپوننت استفاده کنید.

## تمرین
### آسان
`useLocalStorage(key, initial)` بنویسید.
### چالش
همان hook را با parse JSON و مدیریت خطا کامل کنید.
