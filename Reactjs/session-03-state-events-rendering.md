# جلسه 3: State، Event Handling و Rendering

## اهداف یادگیری
- درک state محلی در کامپوننت‌ها
- مدیریت رویدادها (کلیک، تغییر ورودی، submit)
- رندر شرطی و رندر لیست‌ها
- اصل immutable update

## مفاهیم اصلی
- `useState` و چرخه تغییر state
- Event Object و کنترل فرم
- Conditional Rendering (`&&`, ternary)
- List Rendering و مفهوم `key`

## دمو کدنویسی
- ساخت شمارنده با افزایش/کاهش
- ساخت جستجوی ساده روی لیست محصولات
- نمایش پیام خطا/موفقیت با رندر شرطی

## تمرین کلاسی
1. لیست todo بساز (افزودن/حذف/تغییر وضعیت)
2. بروزرسانی todoها را immutable انجام بده
3. از `id` واقعی به عنوان key استفاده کن

## تمرین خانه
- ماژول `Alerts` بساز (success/error/warning)
- از state برای مدیریت نمایش alertها استفاده کن

## چک‌لیست خروجی جلسه
- [ ] تغییر state را اصولی مدیریت می‌کنی
- [ ] eventها را با هندلرهای تمیز کنترل می‌کنی
- [ ] رندر شرطی و لیستی را صحیح پیاده می‌کنی
