# جلسه ۱۲ — Build، Deploy و تحویل

**مدت:** ۷۵ دقیقه

## پیش‌نیازها
کل مسیر ۰۱–۱۱.

## اهداف قابل‌اندازه‌گیری
1. `npm run build` و پیش‌نمایش `preview` را اجرا کنید.
2. تفاوت env توسعه و تولید را بگویید (`import.meta.env`).
3. گزینه‌های host ایستا (Netlify/Vercel/GitHub Pages) را مفهومی مقایسه کنید.
4. چک‌لیست تحویل آموزشی بسازید — بدون اجبار به تغییر `React-project` موجود ریپو.

## چرا مهم است؟
کد محلی ≠ محصول قابل‌نمایش. Build مشکلات asset و env را زود لو می‌دهد.

## مفهوم عمیق
Vite خروجی را در `dist/` می‌سازد. برای SPA، سرور باید fallback به `index.html` داشته باشد تا refresh روی مسیر عمیق 404 نشود.

متغیرها: فقط پیشوند مجاز (مثل `VITE_`) به کلاینت می‌روند — رمز سرور را در فرانت نگذارید.

## اشتباهات رایج
1. گذاشتن secret در env کلاینت.
2. فراموش rewrite برای router.
3. تست نکردن build قبل از تحویل.

## تمرین نهایی مسیر
یک اپ آموزشی کوچک (جدا) شامل: لیست + فرم + یک route + fetch ساختگی، build موفق، README دو پاراگرافی نحوهٔ اجرا.
