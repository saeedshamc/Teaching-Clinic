# دوره جامع React (از صفر تا پروژه واقعی)

## معرفی دوره

این دوره برای ورود حرفه‌ای به React طراحی شده و شما را از مفاهیم پایه تا ساخت پروژه Production-Ready جلو می‌برد.  
ساختار دوره کاملاً جلسه‌محور است و مشابه دوره JavaScript، برای هر جلسه هدف، محتوای آموزشی، تمرین و خروجی قابل اجرا در نظر گرفته شده است.

**مدت پیشنهادی:** 12 جلسه (هر جلسه 2 ساعت)  
**خروجی نهایی:** یک React Project کامل با احراز هویت، مدیریت state، ارتباط با API، معماری تمیز، تست و آماده‌سازی برای دیپلوی

## React Project نهایی دوره

در پایان دوره، پروژه فعلی `react` از یک نمونه ساده Login به یک پروژه واقعی تبدیل می‌شود:

- **ماژول Auth**: ورود/خروج، محافظت مسیرها، مدیریت session/token
- **ماژول Products**: لیست، جستجو، فیلتر، جزئیات
- **ماژول Dashboard**: نمایش داده‌های کلیدی
- **State Management**: تفکیک state محلی و سراسری
- **API Layer**: سرویس‌بندی و مدیریت خطا
- **Testing**: تست کامپوننت‌های کلیدی
- **Deploy**: آماده‌سازی نسخه نهایی برای استقرار

بعد از پایان این مسیر:
