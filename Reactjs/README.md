# دوره React — Teaching Clinic

مسیر جلسه‌محور فارسی برای یادگیری React مدرن (۱۸+/۱۹) با Vite.

## مخاطب
فرانت‌اندکارانی که JS می‌دانند و می‌خواهند React را اصولی یاد بگیرند.

## پیش‌نیاز ابزار
- Node.js LTS و npm
- مرورگر مدرن
- ویرایشگر با پشتیبانی JSX

## نحوه مطالعه
ترتیب جلسات در [SYLLABUS.md](./SYLLABUS.md). کدها را در پروژهٔ Vite **آموزشی جدا** اجرا کنید.

## مهم دربارهٔ `React-project/`
این پوشه یک اپ ازقبل‌موجود در ریپوست. **مواد این دوره آن را تغییر نمی‌دهند.** برای تمرین، پروژهٔ جدید بسازید یا از snippet داخل README جلسات استفاده کنید.

## نقشه پیشرفت
مبتدی (۱–۴) → کاربردی (۵–۸) → معماری/داده/تست/تحویل (۹–۱۲)

## خروجی
