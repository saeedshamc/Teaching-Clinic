# جلسه 1: شروع حرفه‌ای React

## اهداف یادگیری

- درک اینکه React چه مشکلی را حل می‌کند
- آشنایی با SPA، Virtual DOM و Component-Based Architecture
- راه‌اندازی و اجرای پروژه React
- شناخت ساختار پروژه فعلی و مسیر تبدیل آن به پروژه واقعی

## مفاهیم اصلی

- React چیست و چرا استفاده می‌شود
- تفاوت MPA و SPA
- Virtual DOM و چرخه render/re-render
- ساختار پایه پروژه: `src`, `public`, `components`

## دمو کدنویسی

- اجرای پروژه با `npm install` و `npm start`
- بررسی فایل‌های `src/index.js` و `src/App.js`
- تحلیل مسیرهای فعلی پروژه (Login / Product)

## تمرین کلاسی

1. پروژه را اجرا کن و خروجی فعلی را مشاهده کن
2. ساختار پوشه‌ها را توضیح بده
3. یک کامپوننت ساده Welcome بساز و در `App` نمایش بده

## تمرین خانه

- یک فایل `NOTES.md` بساز و مفاهیم Virtual DOM، Component و SPA را با زبان خودت توضیح بده
- مسیر یادگیری شخصی‌ات در 12 جلسه را بنویس
