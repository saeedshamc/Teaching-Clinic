# جلسه 12: Build، بهینه‌سازی و تحویل پروژه

## اهداف یادگیری
- آماده‌سازی پروژه برای محیط production
- بهینه‌سازی bundle و assetها
- برنامه دیپلوی و تحویل حرفه‌ای
- ساخت چک‌لیست نهایی برای پروژه واقعی

## مفاهیم اصلی
- Build process (`npm run build`)
- Env management (`.env`, متغیرهای محیطی)
- Deployment targets (Vercel, Netlify, VPS)
- Production checklist و monitoring اولیه

## دمو کدنویسی
- ساخت نسخه build و بررسی خروجی
- بررسی خطاهای runtime در production mode
- راه‌اندازی deploy اولیه روی یک سرویس میزبان

## تمرین کلاسی
1. پروژه را build کن و خروجی را تحلیل کن
2. متغیرهای محیطی dev/prod تعریف کن
3. یک release note ساده برای نسخه 1.0 بنویس

## تمرین خانه
- پروژه را روی یک سرویس deploy کن
- لینک نهایی + مستندات استفاده را آماده کن

## چک‌لیست خروجی جلسه
- [ ] پروژه قابل build و deploy است
- [ ] محیط dev/prod از هم تفکیک شده
- [ ] مستندات تحویل پروژه آماده است

## خروجی نهایی دوره (Capstone)

دانشجو باید یک نسخه کامل از React Project ارائه دهد که حداقل شامل این ویژگی‌ها باشد:

- احراز هویت کاربر و مسیر محافظت‌شده
- لیست محصولات با جستجو/فیلتر
- مدیریت state ساختارمند
- اتصال به API با مدیریت خطا
- حداقل 10 تست کاربردی
- استقرار روی محیط آنلاین

اگر این موارد کامل باشند، دانشجو برای ورود به پروژه واقعی تیمی آماده است.
