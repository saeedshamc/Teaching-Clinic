# راهنمای دقیق رودمپ React (جلسه‌به‌جلسه)

این فایل نسخه دقیق و اجرایی رودمپ است:  
در هر جلسه می‌گوید **چه کاری انجام می‌دهی، چه دستوراتی می‌زنی، چه کتابخانه‌ای اضافه می‌شود، چرا اضافه می‌شود، و خروجی عملی چیست**.

---

## جلسه 1 - شروع حرفه‌ای React

### کارهایی که انجام می‌دهی
- نصب پیش‌نیازها (Node.js, npm)
- ساخت اولین پروژه React
- اجرای پروژه و شناخت ساختار فایل‌ها
- ساخت اولین کامپوننت‌ها

### دستورات کلیدی
- `npx create-react-app session-01-project`
- `cd session-01-project`
- `npm start`

### کتابخانه‌ها و نقششان
- `react`: ساخت UI به شکل کامپوننتی
- `react-dom`: اتصال React به مرورگر (DOM)
- `react-scripts`: اجرای dev server، build، test

### خروجی جلسه
- پروژه اجرا می‌شود
- دانشجو ساختار `src` و `public` را می‌فهمد
- دو کامپوننت ساده می‌سازد

---

## جلسه 2 - JSX، Components و Props

### کارهایی که انجام می‌دهی
- نوشتن JSX استاندارد
- شکستن UI به کامپوننت‌های مستقل
- ارسال داده از والد به فرزند با props

### دستورات کلیدی
- دستور جدید CLI نیاز نیست (فقط `npm start`)

### کتابخانه‌ها و نقششان
- فقط React (ابزار اضافی لازم نیست)

### خروجی جلسه
- UI ماژولار می‌شود
- دانشجو می‌فهمد data flow در React یک‌طرفه است

---

## جلسه 3 - State، Events و Rendering

### کارهایی که انجام می‌دهی
- مدیریت state محلی با `useState`
- ساخت event handler برای فرم و دکمه
- رندر شرطی و لیست

### دستورات کلیدی
- `npm start`

### کتابخانه‌ها و نقششان
- React Hooks (`useState`) برای مدیریت وضعیت

### خروجی جلسه
- کامپوننت تعاملی (مثل Todo یا جستجو) ساخته می‌شود

---

## جلسه 4 - Hooks پایه و Fetch

### کارهایی که انجام می‌دهی
- دریافت داده با `useEffect`
- مدیریت loading/error/success
- cleanup برای جلوگیری از رفتار ناخواسته

### دستورات کلیدی
- `npm start`

### کتابخانه‌ها و نقششان
- فعلاً بدون کتابخانه جدید (Fetch داخلی مرورگر)

### خروجی جلسه
- اتصال پروژه به API یا فایل JSON

---

## جلسه 5 - فرم و اعتبارسنجی

### کارهایی که انجام می‌دهی
- ساخت فرم Controlled
- اعتبارسنجی فیلدها
- مدیریت پیام خطا و UX فرم

### دستورات کلیدی
- `npm start`

### کتابخانه‌ها (اختیاری)
- `react-hook-form` یا `yup` (اگر خواستی فرم حرفه‌ای‌تر شود)
- اگر استفاده شد: `npm install react-hook-form yup`

### خروجی جلسه
- فرم Login/Register استاندارد و قابل استفاده

---

## جلسه 6 - Routing

### کارهایی که انجام می‌دهی
- ساخت چند صفحه
- تعریف مسیرهای عمومی و محافظت‌شده
- مدیریت 404

### دستورات کلیدی
- `npm install react-router-dom`
- `npm start`

### کتابخانه‌ها و نقششان
- `react-router-dom`: مسیر‌یابی در SPA بدون refresh

### خروجی جلسه
- پروژه مسیرهای واقعی و قابل توسعه دارد

---

### دستورات کلیدی

### کتابخانه‌ها (اختیاری)

### خروجی جلسه

- استخراج منطق مشترک به custom hooks

### دستورات کلیدی

### خروجی جلسه

## جلسه 10 - API Layer و امنیت پایه

### کارهایی که انجام می‌دهی

- مدیریت خطاهای API
- مدیریت auth token و logout flow

### دستورات کلیدی
- اگر axios لازم شد: `npm install axios`

### کتابخانه‌ها

### خروجی جلسه
- ارتباط API تمیز، امن‌تر و قابل تست

## الگوی ثابت برای تمام جلسات

در هر جلسه این ترتیب را حفظ کن:

1. **هدف جلسه** (چرا این جلسه مهم است)
2. **مفهوم** (به زبان ساده)
3. **کد واقعی** (مرحله‌ای و کوتاه)
4. **تمرین فوری** (همان کلاس)
5. **تمرین خانه**
6. **چک‌لیست خروجی**

این الگو باعث می‌شود دانشجو فقط «حفظ» نکند، بلکه بداند «دقیقاً چه کاری باید انجام دهد».
