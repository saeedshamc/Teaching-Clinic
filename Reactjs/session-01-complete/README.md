# جلسه 01 کامل - شروع React از صفر

این پوشه یک بسته آموزشی کامل برای **جلسه اول React** است و کاملاً مستقل از پروژه‌های دیگر نگهداری می‌شود.

## محتوای این جلسه

1. `01-teaching-script.md`  
   متن تدریس مدرس (چی بگی، به چه ترتیب بگی)

2. `02-live-coding-steps.md`  
   سناریوی لایوکدنویسی مرحله‌به‌مرحله

3. `03-exercises.md`  
   تمرین کلاسی + تمرین خانه + پاسخ پیشنهادی

4. `04-commands-libraries-deep-dive.md`  
   توضیح عمیق دستورات، کتابخانه‌ها و کاربرد واقعی هر بخش

5. `project/`  
   مینی‌پروژه جلسه اول با کد کامل و کامنت آموزشی

## هدف جلسه

- دانشجو بداند React چرا ساخته شده
- بتواند پروژه React را از صفر اجرا کند
- ساختار پایه پروژه را درک کند
- اولین کامپوننت‌های ساده را بسازد و اجرا بگیرد

## خروجی قابل قبول جلسه

- اجرای موفق پروژه با `npm start`
- درک فایل‌های `index.js` و `App.js`
- ساخت حداقل دو کامپوننت ساده
