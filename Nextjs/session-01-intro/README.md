# جلسه ۰۱: Next.js چیست و چه فرقی با CRA/Vite دارد (۷۵ دقیقه)

**نسخه هدف:** Next.js 15 · App Router

## پیش‌نیاز
آشنایی با React (کامپوننت، props، state) — ترجیحاً دورهٔ `Reactjs/`.

## اهداف یادگیری
1. نقش Next به‌عنوان فریم‌ورک React با سرور، routing و tooling یکپارچه را بگویید.
2. تفاوت Vite SPA خالص با Next (SSR/RSC، فایل‌روتر، API routes) را توضیح دهید.
3. بگویید App Router چیست و چرا محور این دوره است.

## چرا مهم است
انتخاب اشتباه «فقط Vite» یا «فقط Next» هزینهٔ معماری دارد. باید بدانید چه قابلیتی می‌خرید.

## مفهوم اصلی
- **Vite + React:** کلاینت‌محور؛ برای SPA عالی.
- **Next.js:** همان React + مسیریابی فایل‌محور + کامپوننت سرور + بهینه‌سازی تصویر/فونت + الگوی deploy مشخص.
- **CRA:** قدیمی‌تر؛ مسیر جدید آموزشی معمولاً Vite یا Next است.

## اشتباهات رایج
1. فکر کردن که Next فقط «React با فولدر pages» است.
2. اجبار Next برای لندینگ کاملاً ایستا بدون نیاز.
3. قاطی کردن مفاهیم Pages Router و App Router.

## مثال
جدول تصمیم: اگر SEO سروری، auth لبه‌ای، و API هم‌ریپو می‌خواهید → Next؛ اگر داشبورد کاملاً کلاینتی جدا از BFF → گاهی Vite کافی است.

## نسخهٔ بهتر
نیاز را بنویسید؛ بعد ابزار را انتخاب کنید — نه برعکس.

## تمرین
### آسان
سه قابلیت Next که در Vite خام باید خودتان بسازید فهرست کنید.
### چالش
برای یک فروشگاه کوچک و یک پنل داخلی، انتخاب ابزار را توجیه کنید.

## راهنمای چالش
فروشگاه: SEO + SSR/RSC مفید؛ پنل داخلی پشت login: Vite یا Next هر دو ممکن — ترجیح تیم و hosting.

## خودآزمایی

- [ ] انتخاب ابزار را نیازمحور می‌کنم
