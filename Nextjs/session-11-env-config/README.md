# جلسه ۱۱: env و تنظیمات (۶۰ دقیقه)

## پیش‌نیاز
جلسه ۰۲

## اهداف یادگیری
1. تفاوت `NEXT_PUBLIC_` و متغیرهای فقط سرور را بگویید.
2. فایل‌های `.env.local` را برای لوکال استفاده کنید.
3. secret را commit نکنید.

## چرا مهم است
لو رفتن کلید API از باندل کلاینت حادثهٔ رایج است.

## مفهوم اصلی
- بدون پیشوند: فقط سرور/Route Handler/Server Component
- `NEXT_PUBLIC_*`: به کلاینت می‌رود — فقط دادهٔ غیرحساس

## اشتباهات رایج
1. گذاشتن کلید خصوصی در NEXT_PUBLIC.
2. commit کردن `.env.local`.
3. فراموش restart بعد از تغییر env.

## تمرین
### آسان
یک `NEXT_PUBLIC_APP_NAME` بخوانید.
### چالش
کلید فرضی سرور را فقط در route handler چاپ مفهومی کنید (نه در client).

## خودآزمایی
- [ ] NEXT_PUBLIC را می‌فهمم
- [ ] secret در گیت نیست
- [ ] restart بلدم
- [ ] env تولید جدا است
- [ ] نام‌گذاری واضح می‌گذارم

## جمع‌بندی + پل
تنظیمات امن‌تر. جلسهٔ بعد auth مفهومی.
