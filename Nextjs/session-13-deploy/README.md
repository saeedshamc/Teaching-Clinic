# جلسه ۱۳: Deploy مفهومی — Vercel و جایگزین‌ها (۷۵ دقیقه)

## پیش‌نیاز
جلسات ۰۲ و ۱۱

## اهداف یادگیری
1. مسیر deploy روی Vercel را مفهومی شرح دهید.
2. جایگزین‌ها (Node سرور، Docker، host استاتیک محدود) را بشناسید.
3. تفاوت preview و production را بگویید.

## چرا مهم است
Next به Vercel نزدیک است ولی زندانی آن نیست؛ باید محدودیت‌های خروجی (standalone) را بدانید.

## مفهوم اصلی
- Vercel: git connect → preview per PR → env در داشبورد
- Self-host: `output: 'standalone'` در config و اجرای Node
- محدودیت: بعضی فیچرهای لبه وابسته به پلتفرم‌اند

## اشتباهات رایج
1. فراموش env در محیط تولید.
2. فرض اینکه همه hostها ISR یکسان دارند.
3. تست نکردن `next build` قبل از deploy.

## تمرین
### آسان
`npm run build` محلی؛ خطاها را یادداشت کنید.
### چالش
چک‌لیست ۵ آیتمی قبل از انتشار بنویسید.
