# دوره Next.js (App Router) — Teaching Clinic

**نسخه هدف:** Next.js 15 · React 19 · **App Router** محور اصلی است.

## مخاطب
کسانی که React را در حد دورهٔ `Reactjs/` می‌دانند و می‌خواهند اپ production-readyتر با سرور و routing فایل‌محور بسازند.

## پیش‌نیاز ابزار
- Node.js LTS
- npm یا pnpm
- حساب اختیاری Vercel برای بخش deploy مفهومی

جزئیات: [SETUP.md](./SETUP.md) · فهرست جلسات: [SYLLABUS.md](./SYLLABUS.md)

## نحوه مطالعه
1. جلسات را به‌ترتیب بخوانید.
2. پروژه را با `create-next-app` **روی ماشین خودتان** بسازید — این ریپو اپ غول داخل Nextjs/ نمی‌سازد.
3. snippetهای هر جلسه را در همان پروژهٔ آموزشی کپی کنید.

## نقشه پیشرفت
آشنایی و اسکلت (۱–۴) → Server/Client و داده (۵–۸) → قابلیت‌های واقعی (۹–۱۳) → تمرین‌های متصل و مسیر پایانی (۱۴–۱۶)

## خروجی
توانایی توضیح و پیاده‌سازی App Router، Server/Client Components، Route Handlers، Metadata، و ذهنیت deploy.
