# جلسه ۱۶: مسیر پایانی — لندینگ + فهرست + API (۱۲۰ دقیقه)

## پیش‌نیاز
همهٔ جلسات قبل

## اهداف یادگیری
یک مسیر چندبخشی آموزشی روی ماشین خودتان تحویل دهید که App Router، Server/Client، metadata، و route handler را نشان دهد.

## چرا مهم است
معیار «دوره تمام شده» خروجی قابل‌نمایش است نه فقط خواندن.

## مفهوم اصلی — بخش‌ها
1. لندینگ `/` با layout مشترک و فونت
2. فهرست `/items` از دادهٔ سرور
3. جزئیات `/items/[id]` + not-found
4. `GET /api/items` برای JSON
5. یک فرم کلاینت کوچک (علاقه/خبرنامه ساختگی) بدون بک‌اند واقعی الزامی
6. `next build` بدون خطا

## اشتباهات رایج
1. ساختن مونورپو غول داخل Teaching-Clinic/Nextjs
2. رد شدن از build
3. auth کامل اجباری — لازم نیست؛ مفهوم کافی است
