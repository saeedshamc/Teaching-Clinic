# جلسه ۰۲: ایجاد پروژه آموزشی با create-next-app (۶۰ دقیقه)

## پیش‌نیاز
جلسه ۰۱ · Node LTS

## اهداف یادگیری
1. پروژه را با `create-next-app` بسازید.
2. اسکریپت‌های `dev`/`build`/`start` را اجرا کنید.
3. نقش پوشه‌های `app/` و `src/` را بشناسید.

## چرا مهم است
بدون اسکلت استاندارد، مثال‌های بعدی جابه‌جا می‌شوند.

## مفهوم اصلی
```bash
npx create-next-app@latest clinic-next --typescript --eslint --app --src-dir
cd clinic-next && npm run dev
```
App Router یعنی مسیرها زیر `app/` تعریف می‌شوند نه `pages/` (مگر مهاجرت).

## اشتباهات رایج
1. انتخاب Pages Router وقتی دوره App است.
2. اجرا از پوشهٔ غلط.
3. قاطی کردن پورت 3000 اشغال‌شده.

## مثال
فایل `src/app/page.tsx` را باز کنید و یکHeading فارسی اضافه کنید؛ hot reload را ببینید.

## نسخهٔ بهتر
TypeScript را از روز اول روشن بگذارید.

## تمرین
### آسان
عنوان تب را در metadata پایه تغییر دهید (جلسه ۸ عمیق‌تر می‌شود).
### چالش
یک کامپوننت `Hello` در `src/components` بسازید و در page استفاده کنید.
