# جلسه ۱۶: مسیر پایانی — استک آموزشی (۱۲۰ دقیقه)

**محیط فرض:** Docker Desktop / Engine · [SETUP.md](../SETUP.md)

## پیش‌نیازها
جلسات ۰۱–۱۵.

## اهداف قابل‌اندازه‌گیری
1. یک استک Compose با حداقل دو سرویس + volume بالا بیاورید
2. از میزبان صفحه و API را چک کنید
3. لاگ و health/وضعیت را بررسی و سپس clean down کنید
4. چک‌لیست نهایی دوره را کامل کنید

## چرا مهم است؟
جمع‌بندی عملی: build، شبکهٔ نام‌محور، داده، دیباگ، پاک‌سازی ایمن.

## مفهوم عمیق
استک capstone:
- `api` — Node کوچک با شمارنده در فایل روی volume
- `web` — nginx با پروکسی به api
- volume نام‌دار برای ماندگاری شمارنده بین restartها (بدون `down -v`)

آمادگی ذهنی بعد از این دوره: استقرار روی سرور/CI — **بدون Kubernetes در این پوشه**.

## اشتباه‌های رایج
1. تمام کردن بدون `compose down`.
2. `down -v` و تعجب از صفر شدن شمارنده.
3. دست زدن به اپ‌های Clinic به‌جای این examples.

## مثال گام‌به‌گام
```powershell
powershell -File Docker/session-16-capstone/examples/01-capstone.ps1
```

## الگوی بهتر
قبل از ارائه: `ps` سبز، یک درخواست موفق، لاگ بدون خطا، down تمیز.

## تمرین‌ها
### آسان
چک‌لیست [`01-capstone-checklist.md`](./examples/01-capstone-checklist.md) را تیک بزنید.
### چالشی
یک سرویس سوم (مثلاً `worker` که فقط sleep و log می‌کند) اضافه کنید.

## راهنمای حل
اسکریپت build/up، دو بار hit به API برای دیدن شمارنده، down بدون `-v`.

## خودآزمایی
1. نقش volume در capstone؟
2. چرا نام سرویس `api`؟
3. چه چیزهایی خارج از این دوره ماند؟
4. قانون دست‌نزدن؟
5. دستور پاک‌سازی امن جلسه؟

## جمع‌بندی و پل
دورهٔ Docker تمام. ادامهٔ ذهنی: CI ساخت image، رجیستری، اورکستراسیون — جدا پلن می‌شوند.
