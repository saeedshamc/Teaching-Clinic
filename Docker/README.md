# دوره Docker — Teaching Clinic

مسیر جلسه‌محور فارسی برای یادگیری Docker کاربردی، از نصب تا Compose چندسرویسی.

## مخاطب
کسانی که ترمینال بلدانند و می‌خواهند اپ را reproducible در کانتینر اجرا کنند.

## پیش‌نیاز ابزار
[SETUP.md](./SETUP.md)

فهرست جلسات: [SYLLABUS.md](./SYLLABUS.md)

## قانون دست‌نزدن
تمرین فقط روی مثال‌های داخل `Docker/`. **اپ‌های واقعی Teaching Clinic را آزمایشگاه نکنید.**

مطالعهٔ مکمل (دست نخورده): [Bash/session-24-docker-basics](../Bash/session-24-docker-basics/) · گردش‌کار گیت: [Git/](../Git/)

## نحوه مطالعه
1. جلسات را به‌ترتیب بخوانید.
2. اسکریپت‌ها / `docker build` / `docker compose` را اجرا کنید.
3. تمرین آسان را حتماً؛ چالش را جدی بگیرید.
