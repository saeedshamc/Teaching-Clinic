# جلسه ۱۵: گردش کار Teaching Clinic (۹۰ دقیقه)

**محیط فرض:** Docker + Git پایه · [SETUP.md](../SETUP.md) · دوره [`Git/`](../../Git/)

## پیش‌نیازها
جلسات ۱۱–۱۴؛ آشنایی سبک با Git.

## اهداف قابل‌اندازه‌گیری
1. برای imageهای آموزشی پیشوند `clinic-` و شماره جلسه بگذارید
2. بگویید چرا تمرین Docker را روی اپ‌های واقعی Clinic اجرا نمی‌کنیم
3. پیوند ذهنی با Bash CI و Git را بدون نوشتن GitHub Actions توضیح دهید
4. قبل از commit دوره، فقط فایل‌های `Docker/` را stage کنید

## چرا مهم است؟
Docker قدرتمند است؛ بدون قرارداد نام و مرز، ماشین و ریپو شلوغ/خطرناک می‌شود.

## مفهوم عمیق
قرارداد این دوره:
- تگ: `clinic-sNN:...`
- مثال‌ها فقط زیر `Docker/session-.../examples/`
- اپ‌های `React-project` / Next / غیره دست‌نخورده
- پیام کامیت: `Docker: session-NN — ...`

پل به [`Bash/session-24-docker-basics`](../../Bash/session-24-docker-basics/): مکمل Bash است، جایگزین این دوره نیست.

## اشتباه‌های رایج
1. build کردن Dockerfile اپ production Clinic برای «تست سریع».
2. تگ `latest` روی ده‌ها آزمایش بدون نام.
3. `prune -a --volumes` بعد از یک تمرین شکست‌خورده.
