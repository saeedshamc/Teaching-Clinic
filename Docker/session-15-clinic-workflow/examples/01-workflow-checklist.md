# چک‌لیست گردش کار Docker در Teaching Clinic

1. [ ] Docker Desktop / daemon روشن است (`docker info`).
2. [ ] داخل پوشهٔ `Docker/session-NN-.../examples` کار می‌کنم، نه ریشهٔ اپ‌های Clinic.
3. [ ] تگ image با پیشوند `clinic-sNN` است.
4. [ ] secret واقعی در Dockerfile/`ENV` نیست.
5. [ ] بعد از تمرین: `docker compose down` (و در صورت نیاز بدون `-v` مگر عمدی).
6. [ ] برای کامیت دوره فقط `Docker/` را stage می‌کنم.
7. [ ] پیام: `Docker: session-NN — ...`
8. [ ] `Co-authored-by: Cursor` در پیام نباشد.
9. [ ] ارجاع اختیاری مطالعه: `Bash/session-24-docker-basics` و دورهٔ `Git/`.
