# دوره کامل اسکریپت‌نویسی ویندوز - Batch و PowerShell (هرکدام ۵۰ جلسه)

این مخزن شامل دو مسیر کاملا مستقل و موازی است:

- [`Batch/`](Batch/README.md) — ۵۰ جلسه آموزش Batch، از صفر تا پروژه نهایی
- [`PowerShell/`](PowerShell/README.md) — ۵۰ جلسه آموزش PowerShell، از صفر تا پروژه نهایی

## ساختار هر جلسه

```
session-NN-slug/
├── README.md              توضیح جلسه + لینک به مثال و تمرین
├── examples/
│   └── example1.bat|ps1   کد کامل و قابل‌اجرا با توضیح کنار هر بخش
└── exercises/
    ├── question.md        سوال تمرین این جلسه
    └── answer.bat|ps1      پاسخ پیشنهادی (یکی از راه‌حل‌های ممکن)
```

## نحوه استفاده پیشنهادی

1. وارد پوشه‌ی `session-NN-.../` شوید و `README.md` را بخوانید.
2. فایل `examples/exampleN` را باز کنید و اجرا کنید (Batch: دابل‌کلیک؛ PowerShell: با `-ExecutionPolicy Bypass -File`).
3. سوال `exercises/question.md` را بخوانید و خودتان حل کنید.
4. فقط بعد از تلاش خودتان، `exercises/answerN` را برای مقایسه باز کنید.

## نکته درباره پاسخ‌های تمرین

پاسخ‌ها یکی از راه‌حل‌های ممکن هستند، نه تنها راه‌حل درست. در برنامه‌نویسی معمولا
چند روش مختلف برای رسیدن به یک نتیجه وجود دارد؛ اگر پاسخ شما با پاسخ ارائه‌شده
فرق دارد ولی خروجی درستی می‌دهد، کاملا قابل قبول است.
