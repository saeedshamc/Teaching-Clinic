# جلسه ۲۰: تمرین‌های جمع‌بندی و مسیر پایانی (۱۲۰ دقیقه)

**محیط فرض:** Go 1.22+

## پیش‌نیاز
- جلسات ۰۱ تا ۱۹

## اهداف یادگیری
پس از این جلسه می‌توانید:
1. چند مفهوم را در یک تمرین ترکیب کنید (HTTP + json + error + test)
2. با checklist خودآزمایی دوره شکاف‌ها را پیدا کنید
3. یک مسیر مطالعهٔ مرور برای هفتهٔ بعد طراحی کنید

## چرا این مطلب مهم است
یادگیری جلسه‌ای بدون ترکیب، شکننده است. این جلسه عمداً یکپارچه‌سازی می‌کند — بدون ساخت محصول غول.

## مفهوم اصلی
تمرین نهایی آموزشی: سرویس `Counter` با:
- `POST /inc` افزایش
- `GET /value` خواندن
- خطا برای متد غلط
- حداقل یک تست table-driven برای منطق خالص (نه الزاماً HTTP)

منطق شمارنده را از HTTP جدا کنید تا تست آسان شود.

## اشتباهات رایج
1. **گذاشتن همه چیز در handler بدون تابع خالص**
2. **ننوشتن تست برای منطق**
3. **فراموش mutex اگر بعداً همزمان شد**

## مثال آموزشی قدم‌به‌قدم
اسکلت منطق در `examples/counter.go` و تست در `examples/counter_test.go`:

```bash
cd session-20-capstone/examples
go test .
go run .   # اگر main کوچک برای دمو دارید
```

## نسخهٔ بهتر / الگوی درست
اول تست منطق سبز؛ بعد HTTP نازک روی آن.

## تمرین عملی

### آسان
متد `Dec` که زیر صفر نرود اضافه کنید و تست کنید.

### چالش
یک `Handler` HTTP برای `/value` و `/inc` روی همان Store بسازید (می‌توانید از جلسه ۱۷ الگو بگیرید) و دستی با curl چک کنید.

## راهنمای راه‌حل (چالش)
Store را به handler بدهید؛ متدها را جدا کنید؛ برای race در آینده mutex بگذارید.
