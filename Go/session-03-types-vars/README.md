# جلسه ۰۳: انواع پایه، متغیر، ثابت و تبدیل نوع (۹۰ دقیقه)

**محیط فرض:** Go 1.22+

## پیش‌نیاز
- جلسات ۰۱ و ۰۲

## اهداف یادگیری
پس از این جلسه می‌توانید:
1. انواع پایه (`int`, `float64`, `bool`, `string`, `byte`, `rune`) را درست انتخاب کنید
2. با `var`، `:=` و `const` متغیر/ثابت تعریف کنید
3. تبدیل نوع (**type conversion**) صریح انجام دهید و خطر برش عدد را بشناسید
4. مقدار صفر (**zero value**) هر نوع را پیش‌بینی کنید

## چرا این مطلب مهم است
Go نوع‌ایستا و بدون تبدیل ضمنی خطرناک بین عددهاست. تازه‌کارها یا از JavaScript عادت به coercion دارند یا از C عادت به فرض اندازهٔ `int` — هر دو در باگ‌های مرزی دیده می‌شوند.

## مفهوم اصلی

### اعلان‌ها
```go
var n int          // zero value = 0
x := 42            // short declaration داخل تابع
const Pi = 3.14159 // ثابت؛ نوع می‌تواند بدون نوع صریح باشد (untyped const)
```

### Zero value
اگر مقدار ندهید: عدد `0`، `bool` برابر `false`، `string` برابر `""`، اشاره‌گر `nil`.

### تبدیل نوع
```go
var i int = 65
f := float64(i)
s := string(rune(i)) // "A" — تبدیل int مستقیم به string در Go مدرن برای عدد کدپوینت نیست؛ از rune/strconv استفاده کنید
```
برای عدد به رشته در کار واقعی: بستهٔ `strconv` (جلسات استاندارد لایبرری).

## اشتباهات رایج
1. **انتظار تبدیل ضمنی `int` به `float64`** — باید `float64(x)` بنویسید.
2. **استفاده از `string(65)` به‌عنوان `"65"`** — در Go این تبدیل به rune/کد یونیکد است نه رقم اعشاری؛ برای رقم از `strconv.Itoa` استفاده کنید.
3. **فرض اینکه `int` همیشه 64 بیتی است** — اندازه به معماری وابسته است؛ برای قرارداد ثابت از `int32`/`int64` استفاده کنید.

## مثال آموزشی قدم‌به‌قدم

```bash
cd session-03-types-vars/examples
go run .
```

```go
package main

import "fmt"

func main() {
	var ready bool
	count := 3
	const Title = "clinic"
	price := float64(count) * 1.5
	fmt.Println(Title, ready, count, price)
}
```

## نسخهٔ بهتر / الگوی درست
نوع را در API عمومی صریح کنید (`int64` برای شناسه، `float64` برای محاسبهٔ علمی با آگاهی از خطا). از `:=` داخل توابع برای خوانایی استفاده کنید؛ در سطح پکیج معمولاً `var`/`const`.

## تمرین عملی

### آسان
سه متغیر دما به‌صورت `float64` بسازید و میانگین را چاپ کنید.

### چالش
تابعی بنویسید که `int` بگیرد و رشتهٔ قابل‌خواندن مثل `"n=12"` برگرداند بدون `fmt` (راهنمایی: فعلاً با الحاق و محدودیت، یا از `strconv` اگر بلدید؛ در غیر این صورت با `fmt.Sprintf` مجاز است و در خودآزمایی تفاوت را بنویسید).

## راهنمای راه‌حل (چالش)
اگر هنوز `strconv` نخوانده‌اید، `fmt.Sprintf("n=%d", n)` قابل قبول است؛ هدف تمرین کنترل نوع ورودی است. نسخهٔ سخت‌تر بعداً با `strconv.Itoa`.

## خودآزمایی
- [ ] zero value برای `string` و `bool` را بلدم
- [ ] می‌دانم `:=` فقط داخل تابع است
- [ ] تبدیل `int` → `float64` را بلدم
- [ ] اشتباه `string(عدد)` به‌جای رقم را می‌شناسم
- [ ] تفاوت `int` و `int64` را می‌گویم
- [ ] untyped const را در حد مفهوم می‌فهمم
