# دوره Go — Teaching Clinic

مسیر خودکفای یادگیری Go به فارسی، از صفر تا سطح قابل‌اتکا برای نوشتن CLI و HTTP API آموزشی.

## مخاطب
- برنامه‌نویسانی که زبان دیگری می‌دانند و می‌خواهند Go را اصولی یاد بگیرند
- مبتدیان جدی که حاضرند با خط فرمان و تست کار کنند

## پیش‌نیاز ابزار
| ابزار | نسخه |
|--------|------|
| Go | **1.22+** (توصیه: آخرین پایدار) |
| ویرایشگر | VS Code + افزونه Go، یا GoLand |
| Git | برای کلون ریپو |

جزئیات نصب: [SETUP.md](./SETUP.md)

## نحوه مطالعه
1. جلسات را به‌ترتیب بخوانید؛ از روی عنوان رد نشوید.
2. هر `examples/` را با `go run .` یا `go test .` اجرا کنید.
3. تمرین آسان را حتماً؛ چالش را جدی بگیرید.
4. خودآزمایی را صادقانه بزنید — اگر ضعیف بودید همان جلسه را مرور کنید.

## نقشه پیشرفت
- **مبتدی (۰۱–۰۷):** محیط، سینتکس، داده، struct
- **متوسط (۰۸–۱۳):** interface، error، generic، concurrency، context، test
- **کاربردی (۱۴–۲۰):** stdlib، HTTP، API، layout، tooling، capstone

## خروجی نهایی دوره
- ذهنتان با idiomatic Go هم‌راستا است (خطا، interface کوچک، تست)
- می‌توانید یک API حافظه‌ای کوچک و تست‌پذیر بنویسید
- ساختار `cmd`/`internal` و ابزارهای `gofmt`/`vet` را می‌شناسید
