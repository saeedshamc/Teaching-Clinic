# جلسه ۱۵: json، time و strconv (۱۲۰ دقیقه)

**محیط فرض:** Go 1.22+

## پیش‌نیاز
- جلسات ۰۱ تا ۱۴

## اهداف یادگیری
پس از این جلسه می‌توانید:
1. با `encoding/json` ساختار را Marshal/Unmarshal کنید
2. تگ‌های `json:"name"` را درست بگذارید
3. با `time.Now`، `Format` و `Parse` کار کنید
4. تبدیل رشته↔عدد را با `strconv` بدون غافلگیری انجام دهید

## چرا این مطلب مهم است
APIهای HTTP تقریباً همیشه JSON و زمان و پارامتر رشته‌ای دارند. اشتباه در timezone یا parse عدد، باگ تولید می‌سازد.

## مفهوم اصلی

```go
type User struct {
	Name string `json:"name"`
	Age  int    `json:"age"`
}
b, _ := json.Marshal(User{Name: "Sara", Age: 20})
```

زمان: برای ذخیره و تبادل، ترجیح `time.RFC3339`. برای UI محلی، در لبهٔ نمایش تبدیل کنید.

`strconv.Atoi` / `Itoa` / `ParseInt` با پایه و بیت‌سایز مشخص.

## اشتباهات رایج
1. **نادیده گرفتن خطای Unmarshal** و کار با struct صفر
2. **Format سفارشی اشتباه** — لی‌آوت مرجع Go زمان `Mon Jan 2 15:04:05 MST 2006` است
3. **ParseInt بدون چک error** روی ورودی کاربر

## مثال آموزشی قدم‌به‌قدم

```bash
cd session-15-json-time-strconv/examples
go run .
```

## نسخهٔ بهتر / الگوی درست
فیلدهای اختیاری را با pointer یا `omitempty` طراحی کنید؛ زمان را در UTC نگه دارید مگر دلیل قوی داشته باشید.

## تمرین عملی

### آسان
struct محصول را به JSON چاپ کنید.

### چالش
رشتهٔ `"2024-01-02T15:04:05Z"` را Parse کنید و فقط تاریخ را با `Format("2006-01-02")` چاپ کنید.

## راهنمای راه‌حل (چالش)
`time.Parse(time.RFC3339, s)` سپس `t.Format("2006-01-02")`.
