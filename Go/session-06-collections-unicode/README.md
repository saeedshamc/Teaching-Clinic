# جلسه ۰۶: آرایه، slice، map و رشته/rune (۱۲۰ دقیقه)

**محیط فرض:** Go 1.22+

## پیش‌نیاز
- جلسات ۰۱ تا ۰۵

## اهداف یادگیری
پس از این جلسه می‌توانید:
1. تفاوت **array** (طول ثابت) و **slice** (دینامیک روی آرایهٔ زیرین) را توضیح دهید
2. با `append`، `len`/`cap` و برش `s[i:j]` کار کنید
3. `map` بسازید، بخوانید و با `, ok` وجود کلید را چک کنید
4. تفاوت `byte` و **rune** در پیمایش رشتهٔ UTF-8 را بدانید

## چرا این مطلب مهم است
بیشتر داده‌های واقعی در Go با slice و map جابه‌جا می‌شوند. اشتباه در اشتراک آرایهٔ زیرین یا پیمایش با ایندکس بایتی روی فارسی، باگ‌های کلاسیک می‌سازد.

## مفهوم اصلی

### slice
```go
s := []int{1, 2, 3}
s = append(s, 4)
part := s[1:3] // view؛ تغییر ممکن است آرایهٔ مشترک را عوض کند
```

### map
```go
ages := map[string]int{"Ali": 20}
v, ok := ages["Sara"] // ok == false اگر نباشد
```

### رشته و rune
`string` دنبالهٔ بایت UTF-8 است. `for i, r := range s` روی **rune** (کدپوینت) می‌گردد؛ `for i := 0; i < len(s); i++` روی بایت.

## اشتباهات رایج
1. **تغییر slice حاصل از برش و انتظار دست‌نخوردن اصل** — ممکن است آرایه مشترک باشد.
2. **خواندن map بدون `, ok`** — صفر نوع را با «نبود کلید» اشتباه می‌گیرید.
3. **شمارش طول حروف فارسی با `len(s)`** — تعداد بایت است نه نویسه؛ از `utf8.RuneCountInString` یا range استفاده کنید.

## مثال آموزشی قدم‌به‌قدم

```bash
cd session-06-collections-unicode/examples
go run .
```

```go
package main

import "fmt"

func main() {
	nums := []int{10, 20}
	nums = append(nums, 30)
	m := map[string]int{"a": 1}
	if _, ok := m["b"]; !ok {
		m["b"] = 2
	}
	s := "سلام"
	for _, r := range s {
		fmt.Printf("%c ", r)
	}
	fmt.Println(nums, m)
}
```

## نسخهٔ بهتر / الگوی درست
قبل از mutate کردن برش، اگر مالکیت لازم است `append([]T(nil), s...)` یا `slices.Clone` (Go 1.21+) بگیرید. برای map همیشه الگوی `, ok` را پیش‌فرض بدانید.

## تمرین عملی

### آسان
slice از نام‌ها بسازید، یکی append کنید، و همه را چاپ کنید.

### چالش
تابعی بنویسید که رشته بگیرد و تعداد runeها را بدون import اضافه (فقط با `range`) برگرداند؛ با یک رشتهٔ فارسی تست کنید و با `len` مقایسه کنید.

## راهنمای راه‌حل (چالش)
```go
func RuneLen(s string) int {
	n := 0
	for range s { n++ }
	return n
}
```
برای `"سلام"` مقدار rune از `len` بایت کمتر/متفاوت است.
