# جلسه ۰۴: کنترل جریان — if، for و switch (۹۰ دقیقه)

**محیط فرض:** Go 1.22+

## پیش‌نیاز
- جلسات ۰۱ تا ۰۳

## اهداف یادگیری
پس از این جلسه می‌توانید:
1. `if` با اعلان کوتاه (`if err := ...; err != nil`) بنویسید
2. تنها حلقهٔ Go یعنی `for` را در سه شکل رایج به‌کار ببرید
3. `switch` بدون fallthrough پیش‌فرض را درست استفاده کنید
4. `break` / `continue` و برچسب ساده را در حد نیاز به کار ببرید

## چرا این مطلب مهم است
Go عمداً `while` جدا ندارد و `switch` رفتار C را تکرار نمی‌کند. اگر با عادت زبان دیگر بیایید، یا حلقهٔ بی‌نهایت اشتباه می‌نویسید یا از `break`های غیرضروری پر می‌کنید.

## مفهوم اصلی

### if با scope کوتاه
```go
if n := len(items); n == 0 {
    return
}
// n اینجا بیرون دیده نمی‌شود
```

### for — سه چهره
```go
for i := 0; i < 3; i++ { }   // کلاسیک
for i < 3 { i++ }            // شبیه while
for { break }                // بی‌نهایت با خروج صریح
for idx, v := range items { _ = idx; _ = v }
```

### switch
هر `case` به‌صورت پیش‌فرض break دارد (برخلاف C). برای ادامه به case بعدی باید `fallthrough` صریح بنویسید — معمولاً لازم نیست.

## اشتباهات رایج
1. **نوشتن `while`** — در Go وجود ندارد؛ از `for شرط` استفاده کنید.
2. **فرض fallthrough خودکار در switch** — نمی‌شود؛ هر case تمام می‌شود.
3. **نادیده گرفتن متغیر حلقه در `range` روی slice** — گاهی فقط مقدار لازم است: `for _, v := range items`.

## مثال آموزشی قدم‌به‌قدم

```bash
cd session-04-control-flow/examples
go run .
```

```go
package main

import "fmt"

func Grade(score int) string {
	switch {
	case score >= 90:
		return "A"
	case score >= 70:
		return "B"
	default:
		return "C"
	}
}

func main() {
	sum := 0
	for i := 1; i <= 5; i++ {
		sum += i
	}
	fmt.Println(sum, Grade(85))
}
```

## نسخهٔ بهتر / الگوی درست
شاخه‌های خطا را زود برگردانید (`early return`) تا تو در توی `else` کم شود. برای بازه‌های نمره از `switch` بدون عبارت (tagless) استفاده کنید.

## تمرین عملی

### آسان
اعداد ۱ تا ۲۰ را چاپ کنید؛ مضرب ۳ را با `continue` رد کنید.

### چالش
تابعی بنویسید که برش (`[]int`) بگیرد و اولین عدد منفی را برگرداند؛ اگر نبود `-1` و یک `bool` دوم برای «پیدا شد».

## راهنمای راه‌حل (چالش)
با `for _, v := range nums` پیمایش کنید؛ اگر `v < 0` همان لحظه `return v, true`. بعد از حلقه `return -1, false`.
