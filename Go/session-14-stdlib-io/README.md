# جلسه ۱۴: استاندارد لایبرری — fmt، os، io، bufio (۱۲۰ دقیقه)

**محیط فرض:** Go 1.22+

## پیش‌نیاز
- جلسات ۰۱ تا ۱۳

## اهداف یادگیری
پس از این جلسه می‌توانید:
1. با `fmt` چاپ و `Sprintf` قالب‌بندی کنید
2. با `os.ReadFile` / `os.WriteFile` و `os.Open` کار کنید
3. مفهوم `io.Reader` / `io.Writer` را توضیح دهید
4. با `bufio.Scanner` خط‌به‌خط بخوانید

## چرا این مطلب مهم است
تقریباً هر CLI و سرویس با فایل و استریم سروکار دارد. درک Reader/Writer شما را از قفل شدن به یک API خاص آزاد می‌کند.

## مفهوم اصلی
`io.Reader` فقط `Read([]byte) (int, error)` دارد. خیلی از توابع استاندارد (`json.NewDecoder`, `http.Response.Body`) Reader می‌گیرند — همین ترکیب‌پذیری قدرت Go است.

`bufio` روی Reader بافر می‌گذارد تا خواندن خط‌به‌خط ارزان‌تر شود.

## اشتباهات رایج
1. **نادیده گرفتن خطای `WriteFile`/`Close`**
2. **خواندن کل فایل بزرگ با ReadFile بدون نیاز** — حافظه
3. **فراموش بررسی `scanner.Err()` بعد از حلقه**

## مثال آموزشی قدم‌به‌قدم

```bash
cd session-14-stdlib-io/examples
go run .
```

برنامه یک فایل موقت می‌نویسد، خط‌به‌خط می‌خواند، پاک می‌کند.

## نسخهٔ بهتر / الگوی درست
برای فایل متنی کوچک آموزشی `os.ReadFile` OK است؛ برای استریم بزرگ `bufio` + پردازش تدریجی.

## تمرین عملی

### آسان
متنی را با `os.WriteFile` بنویسید و با `ReadFile` بخوانید و چاپ کنید.

### چالش
با `bufio.Scanner` تعداد خطوط غیرخالی یک فایل را بشمارید.

## راهنمای راه‌حل (چالش)
بعد از `Scan` اگر `strings.TrimSpace(scanner.Text()) != ""` شمارنده++؛ در پایان `scanner.Err()`.
