# جلسه ۱۰ — انیمیشن‌ها، افکت‌ها و صف انیمیشن

## ۱. چرا افکت‌ها مهم‌اند؟

افکت‌ها به کاربر حس روان‌تر و حرفه‌ای‌تر می‌دهند. jQuery افکت‌های آماده‌ای دارد که با چند خط کد قابل استفاده‌اند.

## ۲. افکت‌های پایه

```javascript
$('#box').fadeIn(400);
$('#box').fadeOut(400);
$('#box').slideUp(300);
$('#box').slideDown(300);
$('#box').toggle(300);
```

این متدها برای نمایش/مخفی‌کردن سریع و ساده مناسب‌اند.

## ۳. انیمیشن سفارشی با `animate()`

```javascript
$('#box').animate({
  width: '200px',
  opacity: 0.5,
  marginLeft: '30px'
}, 800);
```

`animate()` به شما اجازه می‌دهد استایل‌های عددی را به‌صورت تدریجی تغییر دهید.

## ۴. Queue و ترتیب اجرای انیمیشن

jQuery برای هر المان، یک queue از انیمیشن دارد. اگر چند انیمیشن پشت‌سرهم اجرا شوند، به‌صورت ترتیبی انجام می‌شوند.

```javascript
$('#box')
  .fadeOut(300)
  .delay(200)
  .fadeIn(300);
```

### متدهای مهم

- `delay()` → توقف موقت در صف انیمیشن
- `stop()` → توقف انیمیشن فعلی
- `finish()` → پایان دادن به همه‌ی انیمیشن‌های صف

## ۵. تله‌های رایج

1. استفاده از `hide()` و `show()` بدون زمان، که انیمیشن ندارد.
2. فراموش کردن `stop()` در رویدادهای تکراری.
3. تلاش برای انیمه‌سازی استایل‌های غیرعددی (مثل `display` یا `background-color` با `animate()` بدون تبدیل مناسب).

## ۶. تمرین‌های پیشنهادی

1. یک پنل را با `slideToggle()` باز/بسته کنید.
2. با `animate()` یک دکمه را به سمت راست حرکت دهید.
3. با `stop()` از اجرای تکراری جلوگیری کنید.

## ۷. جمع‌بندی

انیمیشن‌ها در jQuery فقط برای زیبایی نیستند؛ آن‌ها به کاربر کمک می‌کنند جریان عملیات را بهتر درک کند.
