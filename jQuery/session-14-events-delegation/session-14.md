# جلسه ۱۴ — رویدادها، delegation و مدیریت رویدادهای پویا

## ۱. رویدادها در jQuery

jQuery رویدادها را با `on()` مدیریت می‌کند. این روش نسبت به `click()` و `bind()` مدرن‌تر و انعطاف‌پذیرتر است.

```javascript
$('#btn').on('click', function () {
  console.log('کلیک شد');
});
```

## ۲. Event Delegation

وقتی عناصر بعداً به DOM اضافه می‌شوند، باید رویداد را به والد اصلی وصل کنیم.

```javascript
$('#list').on('click', '.item', function () {
  $(this).addClass('selected');
});
```

این روش برای لیست‌های پویا بسیار مهم است.

## ۳. رویدادهای مفید دیگر

- `hover`
- `keyup`
- `change`
- `submit`
- `focus` / `blur`

## ۴. تمرین‌های پیشنهادی

1. یک لیست پویا بسازید که با کلیک روی دکمه، آیتم جدید اضافه شود.
2. روی آیتم‌های اضافه‌شده نیز رویداد کلیک کار کند.
3. با `change` روی select، متن صفحه را تغییر دهید.

## ۵. جمع‌بندی

delegation به شما کمک می‌کند کدهای پویا و قابل‌نگهداری بنویسید.
