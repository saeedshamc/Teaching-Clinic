# جلسه ۹ — پیمایش DOM پیشرفته و ساخت/حذف المان‌ها

## ۱. چرا پیمایش DOM مهم است؟

تا اینجا با انتخاب المان‌ها شروع کرده‌ایم. اما در پروژه‌های واقعی، معمولاً باید بعد از پیدا کردن یک المان، به عناصر مرتبط آن دسترسی داشته باشیم: پدر، فرزند، برادر، نزدیک‌ترین عنصر مادر، یا عنصر بعد/قبل از یک آیتم.

jQuery این کار را با متدهای پیمایش DOM بسیار ساده می‌کند.

## ۲. متدهای اصلی پیمایش

### ۲.۱ parent / parents / children / find

```javascript
$('#card').parent();      // پدر مستقیم
$('#card').parents();     // همه والدین
$('#list').children();    // همه فرزندان مستقیم
$('#list').find('.item'); // جستجو در همه فرزندان
```

- `.parent()` فقط یک سطح بالا می‌رود.
- `.parents()` تا بالاترین سطح ممکن می‌رود.
- `.children()` فقط فرزندان مستقیم را برمی‌گرداند.
- `.find()` در همه‌ی زیرمجموعه‌ها جستجو می‌کند.

### ۲.۲ siblings / next / prev / closest

```javascript
$('#active').siblings();  // همه برادرها
$('#active').next();      // برادر بعدی
$('#active').prev();      // برادر قبلی
$('#active').closest('.box'); // نزدیک‌ترین والد سازگار
```

`.closest()` یکی از پرکاربردترین متدهاست، چون به‌ویژه در رویداد delegation بسیار مفید است.

## ۳. ساخت و درج المان‌ها

### ۳.۱ append / prepend / after / before

```javascript
$('#list').append('<li>آیتم جدید</li>');
$('#list').prepend('<li>آیتم اول</li>');
$('#item-2').after('<li>بعد از آیتم ۲</li>');
$('#item-2').before('<li>قبل از آیتم ۲</li>');
```

- `append` در انتها اضافه می‌کند.
- `prepend` در ابتدا اضافه می‌کند.
- `after` و `before` قبل و بعد از یک المان مشخص قرار می‌دهند.

### ۳.۲ ساختن المان با `$()`

```javascript
var $li = $('<li></li>').text('آیتم ساخته‌شده');
$('#list').append($li);
```

این روش بهتر است چون از ساخت رشته‌ی HTML مستقیم جلوگیری می‌کند و خوانایی بالاتر دارد.

## ۴. حذف و پاک‌کردن المان‌ها

```javascript
$('#item-2').remove();   // حذف کامل
$('#list').empty();      // پاک کردن محتوا
$('#item-2').detach();   // حذف ولی نگه‌داشتن برای استفاده بعدی
```

- `remove()` المان و همه‌ی داده‌های آن را از DOM حذف می‌کند.
- `empty()` فقط محتویات داخل المان را پاک می‌کند.
- `detach()` برای جابه‌جایی‌های مکرر بهتر است.

## ۵. تفاوت مهم: `html()` و `append()`

```javascript
$('#list').html('<li>فقط یکبار</li>');
$('#list').append('<li>افزودن</li>');
```

`html()` کل محتوا را جایگزین می‌کند، اما `append()` فقط چیزی جدید می‌افزاید.

## ۶. تله‌های رایج

1. استفاده از `children()` به‌جای `find()` زمانی که نیاز به عمق بیشتر دارید.
2. فراموش کردن اینکه `append()` و `prepend()` چندین بار، DOM را بازنویسی نمی‌کنند؛ بلکه به‌صورت پیوسته اضافه می‌کنند.
3. استفاده از `html()` برای افزودن چند آیتم در حلقه، که باعث کاهش کارایی می‌شود.
4. حذف المان و تلاش برای دسترسی دوباره به آن بدون ذخیره‌ی مرجع.

## ۷. تمرین‌های پیشنهادی

1. یک دکمه بسازید که با کلیک، یک آیتم جدید به لیست اضافه کند.
2. روی هر آیتم، دکمه‌ی حذف بسازید و با event delegation آن را حذف کنید.
3. با `closest()` رنگ والد یک آیتم انتخاب‌شده را تغییر دهید.
4. یک دکمه برای «جابه‌جایی آیتم به ابتدای لیست» اضافه کنید.

## ۸. جمع‌بندی

در این جلسه شما با توانایی‌های پایه‌ی پیمایش DOM آشنا شدید: از انتخاب عناصر مرتبط تا ساخت و حذف المان‌ها. این مهارت، پایه‌ی بسیاری از پروژه‌های jQuery و حتی فریم‌ورک‌های مدرن است.
