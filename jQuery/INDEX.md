## 🎯 محتویات کل دوره

### بلاک ۱: مبانی jQuery (جلسات ۱-۴)
#### جلسه ۱: شروع کار و سلکتورها
- علامت `$` و معادل آن
- انواع سلکتورها (CSS و jQuery اختصاصی)
- متدهای `.text()`, `.html()`, `.val()`, `.attr()`, `.prop()`
- تفاوت `attr` و `prop`
- Method Chaining و کش سلکتورها

#### جلسه ۲: رویدادها و انیمیشن
- مدیریت رویداد: `on()`, `off()`, `one()`
- Event Delegation
- افکت‌های آماده: `fadeIn`, `slideToggle`
- `animate()` سفارشی
- صف انیمیشن (Queue)

#### جلسه ۳: DOM و Ajax
- پیمایش: `parent()`, `find()`, `siblings()`
- ساخت و درج المان
- `$.ajax()` و Promise
- مدیریت خطا

#### جلسه ۴: پلاگین و معماری
- ساخت پلاگین `$.fn.plugin`
- Namespacing
- Module Pattern

### بلاک ۲: مباحث پیشرفته (جلسات ۵-۸)
#### جلسه ۵: Deferred و Binding
- `$.Deferred()` و `resolve()`
- `$.proxy()` و `bind()`
- `offset()` و `position()`
- رویدادهای scroll

#### جلسه ۶: UI Components
- ساخت Tabs
- Modal و Dialog
- Tooltip و Dropdown
- Drag & Drop

#### جلسه ۷: فرم و API
- اعتبارسنجی فرم
- آپلود فایل
- کار با API واقعی
- CORS

#### جلسه ۸: معماری و پروژه
- Module Pattern
- Event Bus Pattern
- Loose Coupling
- پروژه: داشبورد گالری

### بلاک ۳: مهارت‌های تخصصی (جلسات ۹-۲۰)
#### جلسه ۹: DOM Traversal پیشرفته
- `closest()` برای نزدیک‌ترین والد
- `detach()` و `remove()`
- ساخت المان

#### جلسه ۱۰: انیمیشن و Queue
- افکت‌های متقدم
- صف انیمیشن
- `delay()`, `stop()`, `finish()`

#### جلسه ۱۱: Ajax پیشرفته
- `$.get()`, `$.post()`
- Promise: `done()`, `fail()`, `always()`
- مدیریت خطا

#### جلسه ۱۲: فرم و اعتبارسنجی
- `submit` رویداد
- `keyup` برای validation زنده
- نمایش پیام خطا

#### جلسه ۱۳: localStorage
- `setItem()`, `getItem()`
- ذخیره و بازیابی
- مثال: یادداشت‌برداری

#### جلسه ۱۴: Event Delegation
- رویدادهای پویا
- Delegation pattern
- لیست‌های پویا

#### جلسه ۱۵: پلاگین‌نویسی
- پارامترهای پلاگین
- `return this` برای Chaining
- مثال: پلاگین سفارشی

#### جلسه ۱۶: متدهای کمکی
- `$.each()` و `$.map()`
- `$.grep()` برای فیلتر
- `$.extend()` برای ادغام

#### جلسه ۱۷: بهینه‌سازی عملکرد
- Selector Caching
- Event Delegation بجای رویداد جداگانه
- `detach()` برای تغییرات مکرر

#### جلسه ۱۸: دیباگ و تست
- `console.log()` و `console.table()`
- DevTools
- `debugger;`

#### جلسه ۱۹: ساختار پروژه
- سازمان‌دهی فایل‌ها
- Module Pattern
- Namespacing

#### جلسه ۲۰: پروژه نهایی
- Todo List کامل
- ترکیب تمام مهارت‌ها
- localStorage + Event
