# جلسه ۱۸ — تست و دیباگ‌کردن کد jQuery

## ۱. چرا دیباگ مهم است؟

در هر پروژه‌ای، خطاهای ساده‌ای وجود دارد که فقط با ابزارهای درست قابل تشخیص‌اند. مرورگر و Console ابزار اصلی شما هستند.

## ۲. استفاده از `console.log` و `console.table`

```javascript
console.log($('#box'));
console.table([{ name: 'علی' }, { name: 'سارا' }]);
```

## ۳. بررسی خطاها در DevTools

- Console را باز کنید.
- Network را بررسی کنید.
- Elements را ببینید که DOM درست ساخته شده یا نه.

## ۴. نکات مهم

- اگر selector چیزی پیدا نکرد، وجود `$(document).ready` را بررسی کنید.
- اگر رویداد کار نمی‌کند، احتمالاً delegation اشتباه است.
- اگر Ajax جواب نمی‌دهد، CORS و URL را بررسی کنید.

## ۵. تمرین‌های پیشنهادی

1. یک خطای intentional بسازید و آن را با console بررسی کنید.
2. با `debugger;` اجرای کد را متوقف کنید.
3. در Console، مقدار یک سلکتور را مشاهده کنید.

## ۶. جمع‌بندی

دیباگ‌کردن مهارتی است که هر توسعه‌دهنده‌ای باید یاد بگیرد؛ jQuery هم از این قاعده مستثنی نیست.
