# دوره آموزش jQuery — از صفر تا پیشرفته (۴ جلسه)

این دوره در ۴ جلسه طراحی شده. هر جلسه شامل دو بخش است:

1. پوشه `code/` → یک فایل `index.html` قابل اجرا که همه‌ی نمونه‌کدهای همان جلسه را به‌صورت زنده و تعاملی نشان می‌دهد (فقط کافیست فایل را در مرورگر باز کنید، نیازی به نصب چیزی نیست چون jQuery از CDN لود می‌شود).
2. فایل `session-0X.md` → توضیح کامل، خط‌به‌خط و مفهومی همان جلسه، شامل نکات پیشرفته، تله‌های رایج (Gotchas)، و تمرین‌های پیشنهادی.

## نقشه راه دوره

| جلسه | عنوان | موضوعات کلیدی |
|---|---|---|
| ۱ | شروع کار و سلکتورها (Selectors) و مانیپولیشن پایه DOM | نصب/CDN، `$(document).ready`، انواع سلکتور (CSS، فیلترها، ویژه jQuery)، متدهای پایه خواندن/نوشتن (`text`, `html`, `val`, `attr`, `css`, `addClass`...)، Method Chaining، `each` |
| ۲ | رویدادها (Events) و انیمیشن/افکت‌ها | مدل رویداد jQuery، `on`/`off`/`one`، Event Delegation، شیء Event، افکت‌های آماده (`fadeIn`, `slideToggle`...)، `animate` سفارشی، صف انیمیشن (fx queue)، `.stop()`/`.finish()` |
| ۳ | پیمایش DOM پیشرفته و Ajax | Traversing (`parent`, `find`, `siblings`, `closest`...)، ساخت/درج/حذف المان‌ها، `$.ajax` / `$.get` / `$.post`، Promise و Deferred، `$.when`، مدیریت خطا، سریالایز فرم |
| ۴ | مباحث پیشرفته: پلاگین‌نویسی، عملکرد، معماری و پروژه نهایی | ساخت پلاگین jQuery (الگوی رسمی + namespacing)، `$.fn.extend` و `$.extend`، رویدادهای سفارشی، بهینه‌سازی عملکرد (caching سلکتور، delegation، detach)، jQuery در دنیای مدرن (مقایسه با Vanilla JS و فریم‌ورک‌ها)، یک پروژه کوچک جمع‌بندی (To-Do List با Ajax شبیه‌سازی‌شده) |

## پیشنهاد نحوه مطالعه

- ابتدا فایل `.md` هر جلسه را بخوانید تا مفاهیم را عمیق درک کنید.
- سپس فایل `code/index.html` را در مرورگر باز کنید و هم‌زمان با خواندن توضیحات، کد را در Console و DevTools بررسی و دستکاری کنید.
- در انتهای هر فایل md، بخش «تمرین‌های پیشنهادی» و «تله‌های رایج» را جدی بگیرید — بیشترین یادگیری از آنجا اتفاق می‌افتد.
