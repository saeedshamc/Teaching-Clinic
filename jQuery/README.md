# دوره آموزش jQuery — از صفر تا پیشرفته (۲۰ جلسه)

این دوره در ۲۰ جلسه طراحی شده و هر جلسه شامل دو بخش است:

1. پوشه `code/` → یک فایل `index.html` قابل اجرا که نمونه‌های همان جلسه را به‌صورت زنده و تعاملی نشان می‌دهد. فقط کافیست فایل را در مرورگر باز کنید؛ نیازی به نصب چیزی نیست چون jQuery از CDN لود می‌شود.
2. فایل `session-0X.md` → توضیح کامل، خط‌به‌خط و مفهومی همان جلسه، شامل نکات پیشرفته، تله‌های رایج و تمرین‌های پیشنهادی.

## نقشه راه دوره

| جلسه | عنوان | موضوعات کلیدی |
|---|---|---|
| ۱ | شروع کار و سلکتورها | نصب/CDN، `$(document).ready`، سلکتورها، `.text()`/`.html()`/`.val()`/`.attr()`/`.prop()` |
| ۲ | رویدادها و افکت‌ها | `on`/`off`/`one`، Event Delegation، `fadeIn`/`slideToggle`/`animate` |
| ۳ | DOM/Ajax پایه | `$.ajax`، `$.get`/`$.post`، Promise، مدیریت خطا |
| ۴ | پلاگین و معماری ساده | پلاگین‌نویسی، Namespacing، Module Pattern |
| ۵ | Deferred و `this` binding | `$.Deferred()`، `$.proxy()`، `bind`/`call`/`apply` |
| ۶ | کامپوننت‌های UI از صفر | Tabs، Modal، Tooltip، Dropdown |
| ۷ | فرم‌های پیشرفته و API | اعتبارسنجی فرم، FormData، API واقعی |
| ۸ | معماری و پروژه نهایی | Event Bus، Module Pattern، پروژه گالری |
| ۹ | پیمایش DOM پیشرفته | `parent`/`children`/`find`/`siblings`/`closest` |
| ۱۰ | انیمیشن و صف انیمیشن | `animate()`، Queue، `delay()`، `stop()` |
| ۱۱ | Ajax و کار با API | `$.ajax`، Promise، CORS |
| ۱۲ | فرم و اعتبارسنجی | `submit`، `keyup`، نمایش خطا |
| ۱۳ | localStorage | ذخیره و بازیابی داده در مرورگر |
| ۱۴ | رویدادهای پویا | Delegation، رویدادهای فرم و UI |
| ۱۵ | پلاگین‌نویسی | ساخت پلاگین‌های ساده و قابل استفاده |
| ۱۶ | متدهای کمکی jQuery | `$.each`، `$.map`، `$.grep`، `$.extend` |
| ۱۷ | بهینه‌سازی عملکرد | cache selector، detach، بهبود کارایی |
| ۱۸ | دیباگ و تست | `console`، `debugger`، DevTools |
| ۱۹ | ساختار پروژه | سازمان‌دهی فایل‌ها و کدها |
| ۲۰ | پروژه نهایی | Todo List با jQuery و localStorage |

## پیشنهاد نحوه مطالعه

- ابتدا فایل `.md` هر جلسه را بخوانید تا مفاهیم را عمیق درک کنید.
- سپس فایل `code/index.html` همان جلسه را در مرورگر باز کنید و هم‌زمان با خواندن توضیحات، کد را در Console و DevTools بررسی و دستکاری کنید.
- در انتهای هر فایل md، بخش «تمرین‌های پیشنهادی» و «تله‌های رایج» را جدی بگیرید.
