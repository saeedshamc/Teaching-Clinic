# جلسه ۱۲ — فرم‌ها، اعتبارسنجی و مدیریت ورودی کاربر

## ۱. چرا فرم‌ها مهم‌اند؟

بسیاری از پروژه‌ها در فرم‌ها خلاصه می‌شوند. jQuery کمک می‌کند فرم‌ها را سریع‌تر، قابل‌پیش‌بینی‌تر و حرفه‌ای‌تر کنیم.

## ۲. خواندن مقادیر فرم

```javascript
var name = $('#name').val();
var isChecked = $('#agree').prop('checked');
```

## ۳. رویدادهای فرم

```javascript
$('#form').on('submit', function (e) {
  e.preventDefault();
});
```

## ۴. اعتبارسنجی ساده

```javascript
if (!$('#name').val()) {
  alert('نام را وارد کنید');
}
```

## ۵. نمایش خطا به کاربر

```javascript
$('#error').text('فیلد اجباری است').show();
```

## ۶. تمرین‌های پیشنهادی

1. فرم ثبت‌نام با فیلدهای نام، ایمیل و رمز عبور بسازید.
2. هنگام ارسال فرم، اگر فیلد خالی بود، خطا نمایش دهید.
3. با `keyup` وضعیت ورودی را به‌صورت زنده بررسی کنید.

## ۷. جمع‌بندی

فرم‌ها بخشی حیاتی از هر وب‌اپلیکیشن هستند. کنترل درست ورودی‌ها، تجربه کاربری را بسیار بهتر می‌کند.
