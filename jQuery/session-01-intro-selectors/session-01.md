# جلسه ۱ — شروع کار با jQuery، سلکتورها و مانیپولیشن پایه DOM

## ۱. jQuery چیست و چرا هنوز مهم است؟

jQuery یک کتابخانه جاوااسکریپت است که در سال ۲۰۰۶ منتشر شد و هدفش ساده‌کردن سه چیز بود:

- کار با DOM (انتخاب و تغییر المان‌ها)
- مدیریت رویدادها (Event Handling)
- درخواست‌های Ajax
- انیمیشن‌ها و افکت‌ها

با اینکه امروز فریم‌ورک‌هایی مثل React و Vue محبوب‌ترند، jQuery هنوز در میلیون‌ها سایت (به‌خصوص WordPress، پروژه‌های legacy و سیستم‌های سازمانی) استفاده می‌شود. یادگیری آن به شما کمک می‌کند:

- کدهای قدیمی را بخوانید و نگهداری کنید
- منطق DOM را عمیق‌تر درک کنید (حتی اگر بعداً React یاد بگیرید)
- سریع پروتوتایپ بسازید بدون build tool

## ۲. راه‌اندازی

سه روش رایج:

```html
<!-- روش ۱: از CDN (پیشنهادی برای یادگیری) -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<!-- روش ۲: دانلود و لینک محلی -->
<script src="js/jquery-3.7.1.min.js"></script>

<!-- روش ۳: نصب با npm در پروژه‌های build-tool-دار -->
<!-- npm install jquery -->
```

نکته مهم: تگ `<script>` باید **قبل از** کدی که از `$` استفاده می‌کند لود شود، یا کد شما باید داخل `$(document).ready` باشد (در ادامه توضیح می‌دهیم).

## ۳. علامت `$` چیست؟

`$` فقط یک اسم مستعار (Alias) برای شیء `jQuery` است:

```javascript
$ === jQuery // true (در حالت عادی)
```

اگر کتابخانه دیگری هم از `$` استفاده کند (مثل Prototype.js) می‌توانید با `jQuery.noConflict()` تداخل را حل کنید و به‌جای `$` از `jQuery` استفاده کنید.

## ۴. اجرای کد بعد از آماده‌شدن DOM

مشکل کلاسیک: اگر اسکریپت شما قبل از رندر کامل صفحه اجرا شود، ممکن است المانی که دنبالش هستید هنوز در DOM نباشد. راه‌حل:

```javascript
$(document).ready(function () {
  // کد شما اینجا امن است
});

// معادل کوتاه‌تر و رایج‌تر:
$(function () {
  // همان کار بالا
});
```

تفاوت با `window.onload`: `ready` به‌محض ساخته‌شدن ساختار DOM اجرا می‌شود (نیازی به لود کامل عکس‌ها و فایل‌ها نیست)، در حالی که `onload` صبر می‌کند همه چیز (عکس، فونت، ...) کامل بارگذاری شود. بنابراین `ready` معمولاً سریع‌تر و مناسب‌تر است.

## ۵. شیء jQuery چیست؟

هر بار که `$(...)` را صدا می‌زنید، یک **شیء jQuery** (شبه‌آرایه) برمی‌گردد که می‌تواند صفر، یک یا چند المان DOM را در خود نگه دارد.

```javascript
var $btn = $('#myBtn');
console.log($btn.length); // تعداد المان‌های پیدا شده
console.log($btn[0]);     // دسترسی به المان خام DOM (نه jQuery)
```

**قرارداد نام‌گذاری**: معمولاً متغیرهایی که شیء jQuery در خود دارند را با `$` شروع می‌کنیم (`$btn`, `$list`) تا از متغیرهای DOM خام (`btn`) متمایز شوند. این فقط یک قرارداد است، نه قانون زبان.

## ۶. سلکتورها (Selectors) — قلب jQuery

### ۶.۱ سلکتورهای پایه CSS

jQuery از همان syntax سلکتورهای CSS پشتیبانی می‌کند:

```javascript
$('div')            // همه div ها
$('.classname')      // بر اساس کلاس
$('#idname')          // بر اساس id
$('div.card')          // div هایی که کلاس card دارند
$('ul > li')             // فرزند مستقیم
$('div, p')                // چند سلکتور با هم
$('input[type="text"]')     // بر اساس attribute
$('a[href^="https"]')        // href که با https شروع می‌شود
$('a[href$=".pdf"]')          // href که با .pdf تمام می‌شود
$('a[href*="google"]')         // href که شامل google است
```

### ۶.۲ سلکتورهای اختصاصی jQuery (فراتر از CSS استاندارد)

```javascript
$('li:first')          // اولین li
$('li:last')             // آخرین li
$('li:eq(2)')              // li با index دقیق ۲ (شروع از صفر)
$('li:gt(2)')                // li هایی که index شان بزرگتر از ۲ است
$('li:lt(2)')                 // کوچکتر از ۲
$('li:even')                   // اندیس‌های زوج
$('li:odd')                      // اندیس‌های فرد
$(':input')                        // همه input, textarea, select, button
$(':checkbox:checked')               // چک‌باکس‌های تیک‌خورده
$(':visible')                          // فقط المان‌های قابل‌مشاهده
$(':hidden')                             // فقط المان‌های مخفی
$('p:contains("متن")')                     // پاراگرافی که شامل این متن است
$('div:empty')                               // div بدون محتوا/فرزند
```

⚠️ **نکته عملکردی مهم**: سلکتورهای اختصاصی jQuery (مثل `:eq`, `:contains`) توسط موتور CSS مرورگر پشتیبانی نمی‌شوند و jQuery خودش باید آن‌ها را با جاوااسکریپت پردازش کند (کندتر از `querySelectorAll`). برای پروژه‌های حساس به سرعت، ترجیحاً از سلکتورهای استاندارد CSS + متدهای فیلتر (`.eq()`, `.filter()`) استفاده کنید:

```javascript
$('li').eq(2)          // معادل سریع‌تر برای li:eq(2)
```

### ۶.۳ کش‌کردن سلکتورها (Selector Caching)

هر بار `$('.item')` صدا زده شود، jQuery دوباره کل DOM را جستجو می‌کند. اگر قرار است چندبار از یک سلکتور استفاده کنید، آن را در متغیر ذخیره کنید:

```javascript
// ❌ بد — سه بار جستجوی DOM
$('.box').css('color', 'red');
$('.box').fadeIn();
$('.box').addClass('active');

// ✅ خوب — یک بار جستجو، سه بار استفاده
var $box = $('.box');
$box.css('color', 'red');
$box.fadeIn();
$box.addClass('active');

// ✅ بهتر — Method Chaining (بخش بعدی)
$('.box').css('color', 'red').fadeIn().addClass('active');
```

## ۷. Method Chaining (زنجیره‌کردن متدها)

اکثر متدهای jQuery که برای «نوشتن/تغییر» استفاده می‌شوند (setter) خودِ شیء jQuery را برمی‌گردانند، پس می‌توان آن‌ها را زنجیره کرد:

```javascript
$('#box')
  .addClass('highlight')
  .css('color', 'blue')
  .slideDown(300)
  .delay(1000)
  .slideUp(300);
```

نکته: متدهایی که برای «خواندن» مقدار استفاده می‌شوند (getter) مثل `.text()` بدون آرگومان، یک مقدار برمی‌گردانند نه شیء jQuery — پس زنجیره در آن نقطه قطع می‌شود.

## ۸. متدهای پایه خواندن و نوشتن محتوا

| متد | کاربرد |
|---|---|
| `.text()` | خواندن/نوشتن متن خام (بدون تگ HTML) |
| `.html()` | خواندن/نوشتن محتوای HTML |
| `.val()` | خواندن/نوشتن مقدار فیلدهای فرم (input, select, textarea) |
| `.attr(name)` / `.attr(name, value)` | خواندن/نوشتن یک attribute دلخواه (مثل src, href, data-*) |
| `.removeAttr(name)` | حذف یک attribute |
| `.prop(name)` / `.prop(name, value)` | خواندن/نوشتن property (مثل checked, disabled) |
| `.css(prop)` / `.css(prop, value)` | خواندن/نوشتن استایل |
| `.addClass()` / `.removeClass()` / `.toggleClass()` | مدیریت کلاس CSS |
| `.hasClass()` | بررسی وجود کلاس |

```javascript
$('#title').text('عنوان جدید');
$('#title').html('<b>عنوان پررنگ</b>');
$('#name-input').val('علی');
$('img').attr('src', 'new.jpg');
$('#chk').prop('checked', true);
$('div').css('background-color', '#333');
$('div').css({ color: 'white', padding: '10px' }); // چند استایل با هم با آبجکت
```

### ⚠️ تفاوت مهم `.attr()` و `.prop()`

این یکی از رایج‌ترین اشتباهات مبتدیان است:

- `attr` مقدار **اولیه/نوشته‌شده در HTML** را می‌خواند و روی خودِ attribute در markup کار می‌کند.
- `prop` مقدار **فعلی/زنده در DOM** (به‌روزشده توسط کاربر یا جاوااسکریپت) را می‌خواند.

مثال کلاسیک با چک‌باکس:

```javascript
// وقتی کاربر چک‌باکس را با ماوس تیک می‌زند:
$('#chk').attr('checked'); // ممکن است همچنان مقدار اولیه HTML را نشان دهد یا undefined باشد
$('#chk').prop('checked'); // همیشه true/false واقعی و به‌روز را برمی‌گرداند
```

**قاعده کلی**: برای خصوصیات boolean مثل `checked`, `disabled`, `selected` همیشه از `.prop()` استفاده کنید. برای attributeهای معمولی HTML مثل `href`, `src`, `data-*`, `title` از `.attr()` استفاده کنید.

## ۹. متد `.each()` — پیمایش روی مجموعه المان‌ها

```javascript
$('li').each(function (index, element) {
  // این‌جا:
  // - `this` برابر است با المان خام DOM
  // - `element` هم همان `this` است (پارامتر دوم)
  // - برای تبدیل به شیء jQuery باید $(this) بنویسیم
  console.log(index, $(this).text());
});
```

نکته: `each` روی خودِ شیء jQuery صدا زده می‌شود و با هر متد قابل ترکیب (chain) است، برخلاف `$.each()` (با نقطه بعد از `$`) که یک تابع سراسری‌تر برای پیمایش روی هر نوع آرایه/آبجکت جاوااسکریپتی است (نه فقط المان‌های jQuery):

```javascript
$.each([10, 20, 30], function (i, val) {
  console.log(i, val);
});

$.each({a: 1, b: 2}, function (key, val) {
  console.log(key, val);
});
```

## ۱۰. تفاوت‌های مهم با جاوااسکریپت خالص (Vanilla JS)

| کار | جاوااسکریپت خالص | jQuery |
|---|---|---|
| انتخاب یک المان | `document.querySelector('.x')` | `$('.x')` |
| انتخاب چند المان | `document.querySelectorAll('.x')` (NodeList) | `$('.x')` (شیء jQuery، شبیه آرایه) |
| تغییر متن | `el.textContent = 'x'` | `$(el).text('x')` |
| افزودن کلاس | `el.classList.add('x')` | `$(el).addClass('x')` |
| رویداد | `el.addEventListener('click', fn)` | `$(el).on('click', fn)` |

نکته مفهومی مهم: نتیجه `$(selector)` همیشه یک شیء jQuery است که می‌تواند صفر یا چند المان داشته باشد؛ متدهای jQuery معمولاً به‌صورت خودکار روی **همه** المان‌های داخل آن اجرا می‌شوند (نیازی به حلقه دستی نیست، برخلاف `querySelectorAll` که باید خودتان روی آن حلقه بزنید).

## ۱۱. تله‌های رایج (Common Gotchas)

1. **فراموش‌کردن `$(document).ready`**: باعث می‌شود کد قبل از ساخته‌شدن DOM اجرا شود و سلکتورها چیزی پیدا نکنند.
2. **قاطی‌کردن `attr` و `prop`** برای خصوصیات boolean.
3. **فراخوانی مکرر یک سلکتور** به‌جای کش‌کردن آن در متغیر.
4. **اشتباه‌گرفتن `.html()` با `.text()`**: اگر محتوای کاربر (User Input) را با `.html()` درون صفحه بگذارید، در معرض حمله XSS قرار می‌گیرید. برای نمایش متن خام کاربر همیشه از `.text()` استفاده کنید.
5. **تصور اینکه `$('.x')` فقط یک المان برمی‌گرداند**: همیشه یک مجموعه است، حتی اگر یک عضو داشته باشد.

## ۱۲. تمرین‌های پیشنهادی

1. یک لیست `<ul>` با ۵ آیتم بسازید و با `each` شماره هر آیتم را جلوی متنش اضافه کنید.
2. یک چک‌باکس بسازید و با کلیک روی یک دکمه، وضعیت `checked` آن را با `prop` بخوانید و در یک `<p>` نمایش دهید.
3. یک ورودی متنی بسازید که با تایپ‌کردن در آن (فعلاً بدون event — فقط با یک دکمه) مقدار `val()` آن در کنسول چاپ شود.
4. با سلکتور `:odd` و `:even` رنگ ردیف‌های زوج و فرد یک جدول را متفاوت کنید (Zebra Table).

فایل `code/index.html` این جلسه، نمونه زنده همه این مفاهیم را دارد — آن را باز کنید، Console مرورگر را باز نگه دارید و با مقادیر بازی کنید.
