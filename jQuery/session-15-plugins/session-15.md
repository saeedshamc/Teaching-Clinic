# جلسه ۱۵ — پلاگین‌نویسی در jQuery

## ۱. چرا پلاگین؟

وقتی چندبار یک رفتار تکرارشونده دارید، بهتر است آن را به یک پلاگین تبدیل کنید.

## ۲. ساخت پلاگین ساده

```javascript
$.fn.highlight = function (color) {
  this.css('background-color', color);
  return this;
};

$('#box').highlight('yellow');
```

## ۳. نکات مهم

- پلاگین باید روی `$.fn` نوشته شود.
- در پایان `return this;` بدهید تا chaining کار کند.
- از Namespacing استفاده کنید تا با پلاگین‌های دیگر تداخل نداشته باشید.

## ۴. تمرین‌های پیشنهادی

1. یک پلاگین `fadeTitle` بسازید.
2. یک پلاگین `tooltip` ساده برای عناصر ایجاد کنید.
3. پلاگین را روی چند عنصر مختلف اعمال کنید.

## ۵. جمع‌بندی

پلاگین‌نویسی باعث می‌شود کد شما قابل‌استفاده، قابل‌تکرار و حرفه‌ای‌تر شود.
