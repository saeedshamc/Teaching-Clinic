# جلسه ۱۷ — بهینه‌سازی عملکرد در jQuery

## ۱. چرا عملکرد مهم است؟

در صفحه‌های بزرگ، هر عمل DOM گران است. اگر کدهای jQuery به‌درستی نوشته نشوند، تجربه کاربری ضعیف می‌شود.

## ۲. نکات مهم برای بهینه‌سازی

- از selector caching استفاده کنید.
- از `on()` با delegation استفاده کنید.
- از `detach()` برای تغییرات مکرر استفاده کنید.
- از DOM insertion یک‌جا استفاده کنید اگر حجم داده زیاد است.

## ۳. مثال

```javascript
var $items = $('#list .item');
$items.addClass('active');
```

## ۴. تمرین‌های پیشنهادی

1. یک لیست ۱۰۰۰تایی بسازید و عملکرد آن را با و بدون cache مقایسه کنید.
2. از `detach()` برای جابجایی چندین آیتم استفاده کنید.

## ۵. جمع‌بندی

بهینه‌سازی، بخش جدایی‌ناپذیر پروژه‌های حرفه‌ای است.
