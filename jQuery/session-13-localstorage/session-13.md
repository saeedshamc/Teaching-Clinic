# جلسه ۱۳ — ذخیره داده با localStorage و تعامل با مرورگر

## ۱. localStorage چیست؟

`localStorage` یک فضای ذخیره‌سازی در مرورگر است که داده‌ها را حتی بعد از بستن صفحه نگه می‌دارد.

## ۲. ذخیره و خواندن داده

```javascript
localStorage.setItem('name', 'علی');
var name = localStorage.getItem('name');
```

## ۳. حذف داده

```javascript
localStorage.removeItem('name');
localStorage.clear();
```

## ۴. کاربرد در jQuery

می‌توانیم داده‌های فرم یا وضعیت UI را در `localStorage` ذخیره کنیم تا بعد از رفرش صفحه دوباره بازیابی شوند.

## ۵. تمرین‌های پیشنهادی

1. متن یک textarea را در localStorage ذخیره کنید.
2. هنگام بارگذاری صفحه، متن ذخیره‌شده را دوباره نمایش دهید.
3. یک دکمه برای پاک‌کردن داده‌ها اضافه کنید.

## ۶. جمع‌بندی

localStorage ساده و پرکاربرد است؛ برای ذخیره‌ی حالت‌های سبک و کاربرمحور، انتخاب خیلی خوبی است.
