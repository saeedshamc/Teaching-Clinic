# جلسه ۱۹ — ساختار پروژه و سازمان‌دهی کد در jQuery

## ۱. چرا ساختار پروژه مهم است؟

هرچه پروژه بزرگ‌تر شود، کدهای پراکنده و بدون ساختار، نگهداری را سخت می‌کنند.

## ۲. ساختار پیشنهادی

```text
css/
js/
index.html
```

- فایل HTML برای ساختار صفحه
- فایل JS برای منطق برنامه
- فایل CSS برای استایل‌ها

## ۳. مثال ساده

```javascript
var App = {
  init: function () {
    console.log('اپ شروع شد');
  }
};

$(function () {
  App.init();
});
```

## ۴. تمرین‌های پیشنهادی

1. یک پروژه ساده با سه فایل HTML/CSS/JS بسازید.
2. کدهای مربوط به فرم و لیست را جدا کنید.
3. از یک Object برای سازمان‌دهی منطق استفاده کنید.

## ۵. جمع‌بندی

ساختار خوب، تفاوت بین کدهای آزمایشی و کدهای قابل‌نگهداری است.
