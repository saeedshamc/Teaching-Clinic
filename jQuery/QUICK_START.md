## 🎯 شروع سریع

### مسیر یادگیری توصیه‌شده:

#### **مبانی (الزامی)** ⭐
```
session-01 → session-02 → session-03 → session-04
```
**زمان:** ۴ روز (هر روز یک جلسه)  
**نتیجه:** کار کامل با DOM، رویداد، Ajax و پلاگین

---

#### **تعمیق** (اختیاری اما مفید)
```
session-05 → session-06 → session-07 → session-08
```
**زمان:** ۴ روز  
**نتیجه:** معماری قابل‌نگهداری و کامپوننت‌های پیشرفته

---

#### **تخصصی** (براساس نیاز)
```
session-09 تا session-20
```
**نکته:** هر کدام مستقل است، می‌توانید انتخابی یادگیری کنید
