# دوره آموزش jQuery — بخش دوم: مباحث پیشرفته (جلسات ۵ تا ۸)

این پوشه، ادامه مستقیم دوره ۴ جلسه‌ای قبلی است (جلسات ۱ تا ۴: مقدمات، رویدادها/افکت‌ها، DOM/Ajax، پلاگین‌نویسی). فرض بر این است که آن ۴ جلسه را گذرانده‌اید.

ساختار هر جلسه دقیقاً مثل قبل است:

1. پوشه `code/` → یک `index.html` قابل‌اجرا با نمونه‌های زنده (فقط با مرورگر باز کنید).
2. فایل `session-0X.md` → توضیح کامل، مفهومی و پیشرفته همان جلسه، همراه با تله‌های رایج و تمرین.

## نقشه راه بخش دوم

| جلسه | عنوان | موضوعات کلیدی |
|---|---|---|
| ۵ | Deferred/Promise پیشرفته، `$.data()`، `this` binding و موقعیت‌یابی | `$.Deferred()` سفارشی، Chaining با `.then()`، تفاوت با Promise استاندارد، `$.data()` در برابر `data-*`، `$.proxy()` و `bind`/`call`/`apply`، `offset()` در برابر `position()`، مدیریت رویداد scroll |
| ۶ | ساخت کامپوننت‌های UI از صفر (بدون jQuery UI) | Tabs، Modal/Dialog، Tooltip سفارشی، Dropdown با بستن با کلیک بیرون، Drag & Drop ساده با HTML5 Drag Events + jQuery |
| ۷ | فرم‌های پیشرفته، آپلود فایل و کار با API واقعی | اعتبارسنجی سفارشی فرم، نمایش خطا به کاربر، آپلود فایل با `FormData` و `$.ajax`، کار با یک API واقعی (JSONPlaceholder)، مفهوم CORS، ترکیب jQuery با `localStorage` |
| ۸ | معماری، الگوهای طراحی و پروژه نهایی (Capstone) | الگوی Module Pattern برای سازمان‌دهی کد، الگوی Event Bus (پیام‌رسانی بین ماژول‌ها بدون وابستگی مستقیم)، Namespacing، جمع‌بندی مهاجرت به Vanilla JS/فریم‌ورک‌های مدرن، پروژه نهایی: یک داشبورد گالری تصاویر با جستجو، فیلتر، Drag-to-reorder و ذخیره در localStorage |

## پیشنهاد مطالعه

مثل بخش اول: اول md را بخوانید، بعد فایل `code/index.html` را باز کنید و هم‌زمان با DevTools باز، مقادیر و رفتار را دستکاری کنید. جلسه ۸ یک پروژه ترکیبی کامل است — بهتر است آخر از همه سراغش بروید.
