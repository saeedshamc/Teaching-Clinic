# سناریوی لایو کدنویسی جلسه اول

## گام 1: ساخت پروژه

```bash
npx create-react-app session-01-project
cd session-01-project
npm start
```

انتظار: صفحه پیش‌فرض React در مرورگر باز شود.

---

## گام 2: پاکسازی اولیه فایل App

- فایل `src/App.js` را باز کن.
- محتوای پیش‌فرض را با نسخه ساده‌شده جایگزین کن.
- فعلاً فقط ساختار حداقلی نگه دار.

---

## گام 3: پوشه components

- داخل `src/` یک پوشه `components` بساز.
- داخلش دو فایل جدید بساز:
  - `Header.js`
  - `IntroCard.js`

---

## گام 4: ساخت Header

- یک کامپوننت بساز که عنوان دوره را نمایش دهد.
- با کامنت توضیح بده props چیست (فعلاً از title ثابت هم می‌شود استفاده کرد).

---

## گام 5: ساخت IntroCard

- یک کارت ساده بساز که توضیح کوتاه جلسه را نشان دهد.
- خروجی شامل عنوان، توضیح، و یک لیست 3 موردی از هدف‌های جلسه باشد.

---

## گام 6: اتصال کامپوننت‌ها در App.js

- `Header` و `IntroCard` را import کن.
- در `App` پشت سر هم render کن.

---

## گام 7: استایل پایه

- در `src/index.css` یک استایل ساده برای:
  - `body`
  - `.container`
  - `.header`
  - `.card`
  بنویس تا UI خوانا شود.

---

## گام 8: تست نهایی

- مرورگر را بررسی کن:
  - آیا عنوان دیده می‌شود؟
  - آیا کارت جلسه دیده می‌شود؟
  - آیا UI به‌هم‌ریخته نیست؟

---

## خروجی این سناریو

- یک React app ساده ولی استاندارد
- کامپوننت‌بندی درست
- درک اولیه از مسیر کار در جلسات بعدی
