# پروژه جلسه اول React

این پروژه فقط برای آموزش جلسه اول ساخته شده است.

## اجرا

```bash
npm install
npm start
```

## ساختار

- `public/index.html`: ریشه HTML
- `src/index.js`: نقطه ورود React
- `src/App.js`: کامپوننت اصلی
- `src/components/Header.js`: هدر جلسه
- `src/components/IntroCard.js`: معرفی هدف‌های جلسه
- `src/index.css`: استایل پایه

## نکته آموزشی

این پروژه عمداً ساده نگه داشته شده تا دانشجو در جلسه اول فقط روی پایه‌ها تمرکز کند.
