# جلسه 1 - تمرکز عمیق روی دستورات، کتابخانه‌ها و عملکردشان

این فایل مخصوص تدریس دقیق جلسه اول است تا دانشجو فقط کپی نکند و **فهم عملی** بگیرد.

---

## 1) دستور ساخت پروژه: `npx create-react-app session-01-project`

### این دستور دقیقاً چه می‌کند؟
- یک پروژه React کامل با تنظیمات اولیه می‌سازد.
- ساختار پوشه‌ها را می‌سازد (`public`, `src`, ...)
- وابستگی‌های لازم را نصب می‌کند.
- اسکریپت‌های آماده `start`, `build`, `test` را در `package.json` می‌گذارد.

### چرا از `npx` استفاده می‌کنیم؟
- لازم نیست ابزار را globally نصب کنی.
- آخرین نسخه ابزار را موقت اجرا می‌کند.

---

## 2) دستور ورود به پوشه پروژه: `cd session-01-project`

### چرا مهم است؟
- تمام دستورات بعدی (`npm start`, `npm install`) باید داخل پوشه همان پروژه اجرا شوند.

---

## 3) دستور اجرای پروژه: `npm start`

### این دستور دقیقاً چه می‌کند؟
- dev server را بالا می‌آورد.
- پروژه را در حالت توسعه compile می‌کند.
- با هر تغییر، به‌صورت خودکار مرورگر را refresh یا hot-reload می‌کند.

### دانشجو باید چه خروجی‌ای ببیند؟
- برنامه روی آدرس `http://localhost:3000` باز شود.
- اگر خطا وجود داشته باشد، در ترمینال یا مرورگر نمایش داده شود.

---

## 4) کتابخانه‌های اصلی جلسه اول

## `react`
- قلب اصلی برنامه UI
- با کامپوننت‌ها کار می‌کند
- state و lifecycle را مدیریت می‌کند

## `react-dom`
- React را به DOM واقعی مرورگر وصل می‌کند
- `createRoot(...).render(...)` از همینجا می‌آید

## `react-scripts`
- پشت‌صحنه build, dev server, test را مدیریت می‌کند
- باعث می‌شود بدون درگیری با webpack/babel شروع کنی

---

## 5) فایل‌های کلیدی جلسه اول

## `public/index.html`
- اسکلت HTML
- فقط یک `div#root` دارد
- React داخل `root` mount می‌شود

## `src/index.js`
- نقطه ورود React
- `App` را import و render می‌کند

## `src/App.js`
- کامپوننت اصلی پروژه
- بقیه کامپوننت‌ها را کنار هم می‌چیند

## `src/components/*`
- قطعه‌های قابل استفاده مجدد UI

---

## 6) متن پیشنهادی برای توضیح به دانشجو (کوتاه و آموزشی)

- «بچه‌ها `index.html` فقط ظرف برنامه است. مغز برنامه داخل `src` است.»
- «`index.js` مثل کلید استارت ماشین است؛ برنامه را روشن می‌کند.»
- «`App.js` صفحه اصلی ماست که بقیه قطعات را داخلش می‌گذاریم.»
- «هر قطعه UI را جدا می‌کنیم تا کد قابل نگهداری شود.»

---

## 7) اشتباهات رایج جلسه اول

- دستورها را بیرون پوشه پروژه اجرا کردن
- فراموش کردن `export default` برای کامپوننت
- اشتباه نوشتن مسیر import
- قاطی کردن `class` با `className` در JSX
