# متن تدریس جلسه اول React (اسکریپت مدرس)

## بخش 1 - شروع کلاس (10 دقیقه)

### چیزی که مدرس می‌گوید

- امروز از صفر React را شروع می‌کنیم.
- هدف امروز: پروژه را اجرا کنیم، ساختار را بفهمیم، و اولین کامپوننت‌ها را بنویسیم.
- فعلاً وارد مباحث سنگین نمی‌شویم؛ فقط پایه را محکم می‌کنیم.

### نکته مهم مدرس

- به دانشجو بگو: اگر جلسه اول را خوب بفهمی، ادامه مسیر راحت می‌شود.

---

## بخش 2 - React چیست و چرا؟ (15 دقیقه)

### چیزی که مدرس می‌گوید

- React یک کتابخانه برای ساخت رابط کاربری است.
- ایده اصلی React: UI را به قطعات کوچک به اسم Component تقسیم می‌کنیم.
- وقتی داده تغییر می‌کند، UI به شکل بهینه به‌روزرسانی می‌شود.
- React برای SPA خیلی مناسب است.

### مثال ساده کلامی

- صفحه را مثل لگو ببین: Header، Sidebar، ProductCard، Footer.
- هر قطعه یک Component مستقل است.

---

## بخش 3 - پیش‌نیازها و ساخت پروژه (20 دقیقه)

### چیزی که مدرس می‌گوید

- برای کار با React نیاز داریم:
  - Node.js نسخه LTS
  - npm
  - VS Code
- ساخت پروژه:

```bash
npx create-react-app session-01-project
cd session-01-project
npm start
```

- وقتی اجرا شد، یعنی محیط توسعه آماده است.

### تاکید مدرس

- امروز هیچ عجله‌ای برای حفظ کردن نیست؛ فقط درک ساختار مهم است.

---

## بخش 4 - معرفی ساختار پروژه (20 دقیقه)

### چیزی که مدرس می‌گوید

- `public/index.html` قالب اصلی صفحه است.
- `src/index.js` نقطه شروع برنامه React است.
- `src/App.js` کامپوننت اصلی برنامه است.
- `src/components/` محل کامپوننت‌های قابل استفاده مجدد.

### پرسش از دانشجو

- اگر بخوای یک کارت محصول بسازی، کجا می‌نویسی؟  
  پاسخ درست: داخل `src/components/`.

---

## بخش 5 - لایو کدنویسی (30 دقیقه)

### چیزی که مدرس می‌گوید

- الان با هم یک صفحه ساده آموزشی می‌سازیم.
- دو کامپوننت می‌سازیم: `Header` و `IntroCard`.
- از `App.js` آن‌ها را render می‌کنیم.

### حین کدنویسی تاکید کن

- اسم فایل/کامپوننت‌ها واضح باشد
- هر کامپوننت یک مسئولیت داشته باشد
- کد را تمیز و قابل خواندن بنویس

---

## بخش 6 - جمع‌بندی و تکلیف (10 دقیقه)

### چیزی که مدرس می‌گوید

- امروز یاد گرفتیم React یعنی کامپوننت‌محور فکر کردن.
- پروژه را از صفر ساختیم و ساختارش را فهمیدیم.
- تکلیف: یک کامپوننت جدید به نام `CourseInfo` بسازید و به `App` اضافه کنید.

### جمله پایانی مدرس

- جلسه بعد می‌رویم سراغ JSX، Props و مدیریت بهتر ساختار UI.
