# جلسه 9: معماری پروژه و Custom Hooks

## اهداف یادگیری
- ساختاردهی پروژه برای تیم و مقیاس
- استخراج منطق مشترک با Custom Hooks
- مرزبندی لایه UI، logic و data access
- بهبود maintainability

## مفاهیم اصلی
- Feature-based Folder Structure
- Separation of Concerns
- Custom Hook Design Rules
- Naming conventions و کدنویسی تیمی

## دمو کدنویسی
- ساخت `useAuth`, `useProducts`, `useDebounce`
- انتقال logic تکراری از کامپوننت‌ها به hookها
- طراحی پوشه‌های `features`, `shared`, `services`

## تمرین کلاسی
1. یک منطق تکراری را شناسایی کن
2. آن را به custom hook تبدیل کن
3. در حداقل 2 کامپوننت reuse کن

## تمرین خانه
- پوشه‌بندی کل پروژه را بازطراحی کن
- یک README فنی کوچک برای معماری جدید بنویس
