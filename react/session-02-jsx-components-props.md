# جلسه 2: JSX، کامپوننت و Props

## اهداف یادگیری
- تسلط بر JSX syntax
- ساخت کامپوننت‌های تابعی قابل استفاده مجدد
- ارسال داده بین کامپوننت‌ها با Props
- تفکیک UI به اجزای کوچک

## مفاهیم اصلی
- قوانین JSX (یک root، `className`، expressionها)
- Functional Component و الگوی تفکیک UI
- Props و Data Flow یک‌طرفه
- Prop Drilling (مقدمه)

## دمو کدنویسی
- ساخت کامپوننت `Header`, `Card`, `Button`
- پاس دادن عنوان، متن و event handler با props
- ساخت لیست ساده کارت‌ها با `map`

## تمرین کلاسی
1. UI صفحه محصولات را به حداقل 3 کامپوننت جدا تقسیم کن
2. داده کارت‌ها را از والد ارسال کن
3. یک prop اختیاری با مقدار پیش‌فرض تعریف کن

## تمرین خانه
- یک `ProfileCard` قابل استفاده مجدد بساز که با props کامل شخصی‌سازی شود
- برای هر prop، نوع داده مورد انتظار را مستند کن

## چک‌لیست خروجی جلسه
- [ ] JSX را بدون خطای ساختاری می‌نویسی
- [ ] UI را به کامپوننت‌های کوچک شکسته‌ای
- [ ] ارسال داده با props را کامل انجام می‌دهی
