# جلسه 11: تست‌نویسی React (Unit + Integration)

## اهداف یادگیری
- نوشتن تست برای کامپوننت‌ها و منطق
- تست سناریوهای UI واقعی
- افزایش اطمینان در refactor
- شناخت استراتژی تست کاربردی

## مفاهیم اصلی
- Testing Pyramid در Frontend
- Unit Test برای توابع و hookها
- Integration Test برای flowهای کاربری
- Mock کردن API و سناریوهای خطا

## دمو کدنویسی
- تست Login flow (موفق/ناموفق)
- تست نمایش لیست محصولات
- تست loading و error state

## تمرین کلاسی
1. برای یک کامپوننت کلیدی 3 تست بنویس
2. یک تست برای مسیر محافظت‌شده اضافه کن
3. سناریوی API error را mock و تست کن

## تمرین خانه
- برای custom hookهای اصلی تست واحد بنویس
- حداقل پوشش تست 60٪ برای بخش‌های حیاتی هدف‌گذاری کن

## چک‌لیست خروجی جلسه
- [ ] تست‌ها رفتار واقعی UI را بررسی می‌کنند
- [ ] سناریوهای خطا پوشش داده شده‌اند
- [ ] پروژه برای توسعه امن‌تر آماده است
