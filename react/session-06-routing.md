# جلسه 6: مسیر‌یابی حرفه‌ای با React Router

## اهداف یادگیری
- تسلط بر Route، Nested Route و Layout
- ساخت مسیرهای عمومی و محافظت‌شده
- کار با پارامتر مسیر و query string
- مدیریت 404 و ناوبری برنامه

## مفاهیم اصلی
- Router architecture در React
- `Route`, `Routes`, `Navigate`, `Outlet`
- Protected Route Pattern
- Dynamic Route (`/products/:id`)

## دمو کدنویسی
- تبدیل مسیرهای فعلی پروژه به ساختار استاندارد
- ساخت Layout مشترک (Header/Sidebar/Footer)
- افزودن صفحه NotFound

## تمرین کلاسی
1. مسیر `/dashboard` را فقط برای کاربر لاگین‌شده باز کن
2. صفحه جزئیات محصول با `id` بساز
3. ریدایرکت پس از لاگین موفق پیاده کن

## تمرین خانه
- breadcrumb ساده برای صفحات اصلی پیاده‌سازی کن
- مسیرهای پروژه را در یک فایل config متمرکز کن

- [ ] مسیرها ساختارمند و قابل نگهداری شده‌اند
- [ ] مسیر محافظت‌شده درست کار می‌کند
