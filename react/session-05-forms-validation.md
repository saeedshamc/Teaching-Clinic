# جلسه 5: فرم‌ها و اعتبارسنجی

## اهداف یادگیری
- ساخت فرم‌های Controlled
- اعتبارسنجی ورودی‌ها
- مدیریت خطاهای فرم
- بهبود تجربه کاربری فرم

## مفاهیم اصلی
- Controlled vs Uncontrolled
- مدیریت state فرم و touched fields
- validation sync و async
- الگوی reusable validation helpers

## دمو کدنویسی
- بهبود فرم لاگین فعلی پروژه
- اعتبارسنجی ایمیل و رمز عبور
- نمایش خطای فیلد به‌صورت inline

## تمرین کلاسی
1. فرم ثبت‌نام با 4 فیلد بساز
2. اعتبارسنجی حداقل طول و فرمت ایمیل را پیاده کن
3. دکمه submit را در حالت invalid غیرفعال کن

## تمرین خانه
- فرم پروفایل با امکان ویرایش اطلاعات بساز
- الگوی validation را ماژولار و قابل استفاده مجدد کن

## چک‌لیست خروجی جلسه
- [ ] فرم Controlled را کامل پیاده می‌کنی
- [ ] خطاهای validation را تمیز نمایش می‌دهی
- [ ] UX فرم (disable/loading/message) را رعایت می‌کنی
