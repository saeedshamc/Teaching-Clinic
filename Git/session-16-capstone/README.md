# جلسه ۱۶: مسیر پایانی (۱۲۰ دقیقه)

**محیط فرض:** Git · sandbox کامل

## پیش‌نیازها
جلسات ۰۷–۱۲ و ۱۵.

## اهداف قابل‌اندازه‌گیری
1. sandbox با bare + دو شاخه + merge + push بسازید
2. چک‌لیست ۱۶ جلسه را صادقانه بزنید
3. بگویید قدم بعدی پیشنهادی Docker است (خارج از این دوره)
4. تأیید کنید هیچ دستور خطرناک روی Clinic اجرا نکرده‌اید

## چرا مهم است؟
جمع‌بندی عملی از init تا remote.

## مفهوم عمیق
اسکریپت capstone این مسیر را یکجا می‌رود:
init → feature → merge → bare push → clone تأیید

## اشتباه‌های رایج
1. اجرای capstone روی ریشهٔ Clinic.
2. رد شدن از `status` نهایی.
3. force push «برای تمیزکاری».

## مثال گام‌به‌گام
```powershell
powershell -File Git/session-16-capstone/examples/01-capstone.ps1
```

## الگوی بهتر
همین جریان را فردا روی پروژهٔ شخصی کوچک تکرار کنید.

## تمرین‌ها
### آسان
اسکریپت را اجرا و graph نهایی را بخوانید.
### چالشی
یک tag `v0.1.0` بعد از merge روی main بگذارید و push tag به bare (اختیاری: `git push origin v0.1.0`).

## راهنمای حل
`git tag v0.1.0` روی main؛ `git push origin v0.1.0`.

## خودآزمایی
1. ترتیب capstone چیست؟
2. چرا bare؟
3. force به main؟
4. گردش Clinic را بلدید؟
5. Docker کجای صف است؟

## جمع‌بندی و پل
Git پایه تمام شد. برای کانتینر و استقرار مفهومی بعداً دورهٔ Docker جدا پلن می‌شود.
