# دوره Git — Teaching Clinic

مسیر جلسه‌محور فارسی برای یادگیری Git کاربردی، از صفر تا همکاری پایه با remote.

## مخاطب
کسانی که ترمینال بلدانند و می‌خواهند قبل از کار تیمی/CI، Git را اصولی یاد بگیرند.

## پیش‌نیاز ابزار
[SETUP.md](./SETUP.md)

فهرست جلسات: [SYLLABUS.md](./SYLLABUS.md)

## قانون sandbox
همهٔ تمرین‌های مخرب‌نما فقط در پوشهٔ موقت اجرا می‌شوند. **ریپوی Teaching Clinic را آزمایشگاه نکنید.**

## نحوه مطالعه
1. جلسات را به‌ترتیب بخوانید.
2. اسکریپت‌های `examples/*.ps1` را اجرا کنید.
3. تمرین آسان را حتماً؛ چالش را جدی بگیرید.

## نقشه پیشرفت
- **۰۱–۰۶** هستهٔ محلی
- **۰۷–۱۰** شاخه، merge، rebase، stash/tag
- **۱۱–۱۴** remote، همکاری، GitHub مفهومی، ایمنی
- **۱۵–۱۶** گردش کار Clinic و مسیر پایانی

## خروجی
توانایی init تا branch/merge/push به remote محلی و ذهنیت «بدون force روی main اشتراکی».

بعداً: Docker (جدا پلن می‌شود).
